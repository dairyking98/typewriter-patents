# A timeline of important features

This page follows, era by era from 1829 to 1950, the inventions that shaped the index typewriter: how the character was chosen, held in place, shifted between cases, printed, inked and spaced, and how the type element itself was made. Each entry gives the patent, what it did and what came after it, and a table at the end sums up when each feature first appears in this library and when it was most common.

*A note on "first".* The dates below are the oldest patent **in this library** that shows a feature, not necessarily the true first invention, so read every "earliest example" as "the earliest example here". Card counts and peak decades come from [Mechanisms](../views/mechanisms.md) and count only the patents that have been read. The summaries were made by machine from OCR scans and can be wrong in detail. Dates of older German patents are sometimes estimated from the patent number.

An *index typewriter* is one where you pick a character by moving a pointer, dial, stylus or lever over a chart, then make a single print stroke. Most of its basic parts were in place before keyboard typewriters were common. Index machines then borrowed ribbons, escapements and shift mechanisms from the keyboard machines, which in their turn used index ideas such as type wheels, type cylinders and rubber type.

## Early experiments, 1829 to 1870

Before 1870 there was no typewriter industry, only individual inventors trying to replace the pen. Almost every one of them built what we would now call an index machine, because a single moving type carrier set by hand was far simpler than a keyboard. Between them they found most of the basic answers.

**1829: pointer over a chart, separate print lever, print-and-space.** William A. Burt's "Typographer", [USX5581](../patents/USX5581.md), is the earliest example here of [SEL:pointer-chart](../features/sel-pointer-chart.md). A type segment on a swinging lever is moved over an index until the chosen type is at the printing point. Then a separate impression lever ([IMP:print-lever](../features/imp-print-lever.md)) prints it, and the same stroke moves the paper on one letter space ([ESC:print-and-space](../features/esc-print-and-space.md)). According to the reading, ink pads on each side ink the types not in use ([INK:pad](../features/ink-pad.md)). The patent text is only partly legible, so treat the details with care. The machine is [Burt](../machines/burt.md). Pointer-over-chart selection grew into one of the defining index layouts (114 cards, peaking in the 1890s), and print-and-space became the standard way to space an index machine (300 cards).

**1843: the type wheel and proportional spacing.** Charles Thurber's [US3228](../patents/US3228.md) puts one spring-returned key per character on a horizontal wheel, which the operator turns until the wanted key is over a hole and then presses through onto the paper. It is the earliest example here of [ELEM:wheel-rim](../features/elem-wheel-rim.md), which later became the most common index element (242 cards, 43 of them index-type). It also has an ink roller ([INK:roller](../features/ink-roller.md)), a pawl-and-rack carriage drive ([ESC:pawl-rack](../features/esc-pawl-rack.md)) and [ESC:variable-spacing](../features/esc-variable-spacing.md): a pin on each key sets how far the carriage moves, so narrow letters take less room.

**1850: a two-way grid of type.** Oliver T. Eddy's [US7771](../patents/US7771.md) moves a grid of 78 type bars in six rows sideways and back and forth until the wanted type is over a hole in an inking plate, then presses it through. This is the earliest example here of a flat type plate ([ELEM:plate-flat](../features/elem-plate-flat.md)) set in two directions. Choosing a type by two motions, one for the row and one for the column, came back with the type cylinders of the 1880s and the Mignon.

**1852 and 1856: dropping into a notch to hold the letter.** John M. Jones's [US8980](../patents/US8980.md) turns a type wheel with a lever until an index drops into the notch beside the wanted letter on a fixed rack. Pressing the same lever prints, which is the earliest example here of [SEL:pointer-hole](../features/sel-pointer-hole.md) and of [SEL:pointer-press-prints](../features/sel-pointer-press-prints.md) (select and print in one motion). In 1854 Robert S. Thomas's four-sided type bar, [US10995](../patents/US10995.md), is pinned in place by a guide pin before printing. That is the earliest example here of [SEL:selector-locking](../features/sel-selector-locking.md), later one of the most widely used index features (333 cards). The bar can also be taken out and replaced ([ELEM:interchangeable](../features/elem-interchangeable.md)).

Jones's second patent, [US14919](../patents/US14919.md) (1856), is the more important step. Pressing the lever drives an arm into the tooth above the chosen type, which aligns the wheel exactly as it prints. It is the earliest example here of [ELEM:alignment-lock](../features/elem-alignment-lock.md): instead of trusting the operator's aim, the print stroke itself forces the type into register. That idea runs through the rest of this page (182 cards, peaking in the 1890s).

**1856: the dial, and moving the paper to the type.** John H. Cooper's [US14907](../patents/US14907.md) (machine: [Cooper](../machines/cooper.md)) has a pointer that is pressed into a conical countersink beside each character on a fixed disc ([SEL:dial](../features/sel-dial.md)). The type wheel below stays put, and a presser bar carries the paper against it. This is the earliest example here of [IMP:platen-to-element](../features/imp-platen-to-element.md), the alternative to swinging the element down to the paper ([IMP:element-to-platen](../features/imp-element-to-platen.md)).

**1868: keys that only set the element, and a spring hammer.** John Pratt's [US81000](../patents/US81000.md) moves a single flat type plate in two directions by key-set amounts until the chosen character is under a hammer. The hammer is cocked by a spring and released ([IMP:spring-energy](../features/imp-spring-energy.md)) and strikes from behind the paper ([IMP:hammer-behind](../features/imp-hammer-behind.md)), with an escape-wheel carriage ([ESC:escape-wheel](../features/esc-escape-wheel.md)). It is an early bridge between index and keyboard machines: the keys do no printing, they only set the carrier ([SEL:dummy-keyboard](../features/sel-dummy-keyboard.md)).

## The 1870s: cheap machines and the ribbon

Once keyboard typewriters reached the market in the 1870s, the index machine took the other path: cheap, small and simple. Several features that the 1880s would rely on appear in this decade.

**1876: the detent wheel and the arc arm.** Edward A. Calahan's toy, [US175661](../patents/US175661.md), turns a type wheel and a notched "rag wheel" together to a letter shown on a dial. A spring with a double-inclined end drops into the notches, so each letter is placed accurately and held while printing. This spring detent became the usual simple form of selector locking. In the same year Benjamin Arnold's [US175584](../patents/US175584.md) swings a lever over a notched arc, the earliest example here of [SEL:arc-arm](../features/sel-arc-arm.md) (50 cards, peaking in the 1890s, used later on the [American Index](../machines/american-index.md) and [Gerda 2](../machines/gerda-2.md)). The depth of each notch also sets how far that letter spaces.

**1878 to 1879: ribbon, ribbon feed and axial shift.** Homer and Frank Anderson's [US210739](../patents/US210739.md) (1878) prints through a ribbon and is the earliest example here of [INK:ribbon](../features/ink-ribbon.md). Henry M. Ward's [US218148](../patents/US218148.md) (1879) moves the ribbon on to a fresh section each line ([INK:ribbon-feed](../features/ink-ribbon-feed.md)). The ribbon peaked on keyboard machines in the 1900s (526 cards) and reached index machines later; the Mignon changed from an ink roller to a ribbon with [Mignon 2](../machines/mignon-2.md) (1904). William A. Slocum's [US215251](../patents/US215251.md) (1879) raises the type wheel along its shaft to bring capitals into use, the earliest example here of [SHIFT:axial](../features/shift-axial.md) (209 cards). The [Brady-Warner](../machines/brady-warner.md) index machine (1878, [US202143](../patents/US202143.md)) adds a carriage pulled by a mainspring ([ESC:spring-drum](../features/esc-spring-drum.md)).

## The American index boom, 1880 to 1900

Most index-type features peak in the 1880s and 1890s. Dozens of cheap American machines came to market, including the [Columbia Index 1](../machines/columbia-index-1.md), [World 1](../machines/world-1.md), [Morris](../machines/morris.md), [Herrington](../machines/herrington.md), [Crown Index 1](../machines/crown-index-1.md), [Dollar Typewriter](../machines/dollar-typewriter.md) and [American Index](../machines/american-index.md). Their patents work on three problems over and over: more characters from one element, exact register without slowing the operator, and cheap type.

**1880: swappable chart and element, multi-row wheel.** Carl McKinley's [US232741](../patents/US232741.md) swings one lever over a notched sector to turn a multi-row type wheel, and a slide shifts the wheel along its shaft to change row. The wheel can be swapped quickly for another type style, and the index chart is changed with it: the earliest example here of [SEL:chart-interchangeable](../features/sel-chart-interchangeable.md). Its use for non-Latin alphabets is also the earliest example here of [USE:special-script](../features/use-special-script.md).

**1881: rotary shift and the multi-row type cylinder.** Lucien S. Crandall's [US251338](../patents/US251338.md) carries 81 types on an interchangeable sleeve with nine rows of nine. Keys slide it and twist it so that any type reaches one printing point. It is the earliest example here of [ELEM:cylinder-multirow](../features/elem-cylinder-multirow.md) and of [SHIFT:rotary](../features/shift-rotary.md) (turning the element by a fixed angle to change case). Crandall's machine had a keyboard, but the type cylinder became the element of the best-known index machines, from Thomas Hall's single-pointer cylinder machine ([US453593](../patents/US453593.md), 1891) to the [Mignon 1](../machines/mignon-1.md).

**1881 to 1882: rubber type.** George H. Herrington's [US247058](../patents/US247058.md) (1881) is a dial-and-pointer type wheel set by one knob, pushed in to print and pulled out to space. Its types are lifted back by an elastic ring, and it is the earliest example here of [ELEM:rubber-type](../features/elem-rubber-type.md). John S. Martin's [US264091](../patents/US264091.md) (1882) goes further: all the characters are **cast in relief on one elastic disc**. It is the earliest example here of [ELEM:element-construction](../features/elem-element-construction.md). Rubber type was cheap, quiet and printed through a pad or roller without damage, and it peaked sharply in the 1890s (87 cards, 23 index-type). Its weakness, soft and short-lived type, was still being worked on in the 1920s.

**1880 to 1883: Hammond's segment and stop.** James B. Hammond's [US224183](../patents/US224183.md) (1880) turns a type segment by cams on the key levers. Pins raised by the keys catch a stop arm, so the segment is held exactly in place while a hammer strikes the paper against it from behind. [US290419](../patents/US290419.md) (1883) is a complete machine with a hard-rubber, three-row segment and two shift keys. The [Hammond 1](../machines/hammond-1.md) is a keyboard machine, but its curved segment ([ELEM:sector-segment](../features/elem-sector-segment.md)) and its stop-then-strike sequence are the same problem an index machine faces. The same patent is the earliest example here of automatic ribbon reversing ([INK:ribbon-reverse](../features/ink-ribbon-reverse.md)).

**1884: the V-notch.** In George H. Herrington and David G. Millison's children's machine [US299785](../patents/US299785.md), pressing the rubber-faced wheel down brings a V-notch on its flange onto a fixed knife, which centres the letter as it prints. This simple V-notch, in which the print stroke snaps the element into register, recurs through the next decades. Nathan Grier Moore's [US358469](../patents/US358469.md) (1887) seats a V-tipped pin in a serrated crown. Franz X. Wagner's [US364556](../patents/US364556.md) (1887) drops a tooth into a downward-tapering notch, and Louis T. Weiss's [US438665](../patents/US438665.md) (1890) uses a toothed register wheel.

**1885: one finger selects, locks, prints and spaces.** Andrew P. Hansen's [US327946](../patents/US327946.md) (machine: [Hammonia (Hansen patent)](../machines/hammonia-hansen-patent.md)) slides a type rack under a finger key. Pressing the key drops its indicator into a notch to lock the rack, and pressing further prints through a ribbon and steps the frame one tooth. This combined stroke was the goal of most later index patents.

**1886 to 1888: paper to type, and two cases on one disc.** Charles Spiro's [US352160](../patents/US352160.md) (1886, linked to the [Columbia Index 1](../machines/columbia-index-1.md)) keeps two stacked type wheels still and tilts the paper carriage against them. A shift key lowers the capital wheel into place, and stops of different depth on the wheel give proportional spacing. Juan De la Cruz Escobar's [US382146](../patents/US382146.md) (1888) gives rotary shift to a pointer-and-arc machine: a finger plate turns a disc that carries two sets of rubber type part of a revolution, so one index and one centring arc serve both cases. Adolphe Prosper Eggis's [US380792](../patents/US380792.md) (1888, [Velograph 2](../machines/velograph-2.md)) uses a disc with capitals on one half and small letters on the other. The pointer drops into a marked hole to locate the disc, and the same press prints and feeds.

**1890: the moulded hard-rubber wheel.** George C. Blickensderfer's [US432296](../patents/US432296.md) moulds a whole type wheel, hub, rim and webs, as one hollow piece of hard rubber, pressed into intaglio dies by heat and steam. It was written for his keyboard machines (the [Blickensderfer 2](../machines/blickensderfer-2.md) and later models), but it shows the type element becoming a single cheap moulded part. In the same year Robert H. Ingersoll's [US429195](../patents/US429195.md) (linked to the [Dollar Typewriter](../machines/dollar-typewriter.md)) turns a rubber-type wheel from a slide running along a spirally grooved rod, a very cheap way to link pointer and wheel.

**1891: the V-notch wheel that forgives the operator.** Byron A. Brooks's [US463723](../patents/US463723.md) (linked to the [Crown Index 1](../machines/crown-index-1.md) and [Crown Index 2](../machines/crown-index-2.md)) turns a multi-row wheel by rack and pinion from a pointer on a letter plate. A knob slides the wheel to choose the row, and pressing the pointer swings the whole frame down to print. Just before impact, a notched wheel on the shaft drops onto a V-shaped anvil so the type lands squarely, *so the operator need not set the pointer exactly*. Weiss's cord coupling of 1890 ([US438665](../patents/US438665.md)) had addressed the same strain from the other side, letting the pointer give way when the register wheel corrects the type wheel. The same year also brought Thomas Hall's cylinder ([US453593](../patents/US453593.md)), in which one pointer handle both slides and rotates a thin-shell type cylinder and then drops a conical point into a perforated plate to lock it. George Becker's [US455299](../patents/US455299.md) has a two-row type plate locked by a chisel-pointed print lever, and Enrique Jovar Blacio's [US465589](../patents/US465589.md) makes the index lever itself print and space.

**1893: the American Index.** Louis P. Valiquet's [US510214](../patents/US510214.md), the patent of the [American Index](../machines/american-index.md), brings these elements together in a small, low-priced machine. A finger pointer swings a rubber type segment over a fixed index, and a separate print lever presses the type through a shield, its nose entering the notch under that type to lock the segment. On release a spring pawl spaces the carriage. It combines arc-arm selection, a separate print lever, alignment by the print stroke, rubber type and print-and-space.

**1895: wide targets.** Albert B. Dick's [US533530](../patents/US533530.md) lays out capitals, small letters and figures on the type wheel in the same order, with one index section for each group. Each space on the character board is shared by the groups and so can be wider, which makes registration looser and operation faster. This idea of several characters per chart field returned in Germany in the 1920s.

## The turn of the century and the Mignon, 1900 to 1918

After 1900 the American index boom faded, as cheap keyboard machines took the market and index patents became fewer. The main development moved to Germany, where AEG built the most successful index machine of all.

**1901: index machines for special jobs.** Blickensderfer's [US666176](../patents/US666176.md) is a cipher machine: a dial sets the type wheel, a detent locks dial and wheel together for the print, and after each impression an escapement turns the wheel against the dial so the cipher keeps changing. Newman R. Marshman's [US672680](../patents/US672680.md) prints pictures from an elastic band on a type wheel set by a pointer over a notched alphabet plate, struck by a hammer inside the rim.

**1903: the Mignon.** [DE149308](../patents/DE149308.md), dated 1903 in this library, is the patent behind the [Mignon 1](../machines/mignon-1.md) (1902) and the [Hefner-Alteneck Tasterapparat](../machines/hefner-alteneck-tasterapparat.md), designed by Friedrich von Hefner-Alteneck for AEG. One handle moves a swinging frame and a rack, which both turns and slides an 84-character type cylinder, while a pointer moves over a checkerboard index plate. A magnifying linkage makes the pointer's travel larger than the cylinder's, so the chart is large enough to read. Pressing down prints, and a knife in a comb plus a knife in a star wheel give the exact setting as the frame descends, one knife for each axis. A felt roller inks the type. The American version, [US914272](../patents/US914272.md) (1909), describes the pantograph-like linkage in more detail. The Mignon went through [Mignon 2](../machines/mignon-2.md) (1904, now with a ribbon), [Mignon 3](../machines/mignon-3.md) (1913) and [Mignon 4](../machines/mignon-4.md) (1924), and many later German cylinder patents describe their problem as one found "in Mignon-type pointer machines".

**1905 to 1915: one-handed and cheap variants.** John T. Porter's [US866514](../patents/US866514.md) (1907) is a keyboardless 81-character cylinder machine, twisted and slid by a hand grip so one hand can type while the other follows notes. Alois van Loy's [US1079812](../patents/US1079812.md) (1913) hangs a spherical segment type carrier from a long print lever, so a light press prints and the wrist does not tire. Halbert Edwin Payne's [US1121284](../patents/US1121284.md) (1914) moves a flexible two-row type band behind an index laid out like a standard keyboard. Index machines of this period include the [Simplex Little Giant](../machines/simplex-little-giant.md), [Picht Index](../machines/picht-index.md), [Aktiv](../machines/aktiv.md) and [Virotyp (B)](../machines/virotyp-b.md).

## German and European small machines, 1919 to 1950

After the First World War almost all patents in this library are German. Index machines became small home, pocket and travel typewriters, among them [Gerda 2](../machines/gerda-2.md), [Gundka 3](../machines/gundka-3.md), [Karli 1 Einreihig](../machines/karli-1-einreihig.md), [Olympia Plurotyp](../machines/olympia-plurotyp.md) and [Tip-Tip](../machines/tip-tip.md). The patents mostly refine three things: smaller charts with more characters per field, keeping the type exactly in register during a stroke made by a swinging lever, and better type than soft rubber.

**1921: several fonts on one cylinder.** Heinrich Vester's [DE332718](../patents/DE332718.md) carries several fonts as spring-loaded type pistons in radial bores of a cylinder. A hammer-tipped key strikes from above, and cutting edges drop into a gear rim and a groove ring for fine alignment. The aim was to change fonts without changing parts, and to print on thick objects such as bound books and boxes.

**1923 to 1924: fewer fields, more characters.** [DE377030](../patents/DE377030.md) (1923, inventor unknown) gives each letter field two or more print keys. The extra keys also turn or slide the type cylinder by a fixed step, so the key you strike chooses the case. Robert Langguth's [DE393930](../patents/DE393930.md) (1924) has each of 24 chart fields serve four types on a 96-type cylinder: a finger button on the pointer adds a fixed rotation, a lever adds a fixed axial withdrawal, or both. These are later versions of Dick's 1895 idea, built on the Mignon's two-axis cylinder. Paul Muchajer's [DE386555](../patents/DE386555.md) (1923, linked to [Gundka 3](../machines/gundka-3.md) and [Gundka 5](../machines/gundka-5.md)) instead raises a type wheel to the second or third row by a wedge as the stylus moves inward over a three-ring plate. Selection, row change and printing are all done with one stylus.

**1924: the pointer over the wheel.** Georg Emig's [DE393929](../patents/DE393929.md), the patent of [Gerda 2](../machines/gerda-2.md), says that pointers linked to a distant type wheel set it imprecisely and bend on impact. It moves the pointer and character plate directly above the wheel's axis, drives the wheel by a toothed segment, and swings the wheel frame to change row. A notched spring pawl holds the row while the frame is down.

**1927: metal type in a pocket machine.** Karl Dietrich's [DE440774](../patents/DE440774.md) (the [Karli 1 Einreihig](../machines/karli-1-einreihig.md) and [Karli 2 Zweireihig](../machines/karli-2-zweireihig.md)) replaces rubber bands, which "print unsharply and break", with spring-loaded metal types in a sliding double rail. The print button drives the type through a ribbon, and a pin on the button drops into a slot to centre the type.

**1935 to 1937: locking before the blow.** Several patents of the 1930s deal with one weakness of a swinging print lever: the setting gear can roll slightly on its rack during the stroke. Edgar Hoffmann's [DE609811](../patents/DE609811.md) (1935) slides the wheel straight to the platen, and a pin on the setting rack enters a fixed comb before the type hits. [DE651112](../patents/DE651112.md) (1937, inventor unknown) pulls the alignment knife fully into its comb notch first and only then releases a pre-tensioned impression spring. This is the spring-energy hammer of Pratt's 1868 patent, used to make every impression even.

**1938: interchangeable drums for music.** [DE657555](../patents/DE657555.md), from the Heady company (see [Heady](../machines/heady.md)), is a stylus-and-board type drum machine that takes either a letter drum or a music drum. A centring device sets the height of each note on or between staff lines, which shows how far interchangeable elements had come since McKinley's 1880 swappable wheel and chart.

**1949: moulded wheels on a metal core.** The library's index story ends with the type element. [DE850530](../patents/DE850530.md) and [DE866858](../patents/DE866858.md) (both 1949, inventor not recorded) mould the type in plastic or rubber, such as polyamide or cellulose acetate butyrate, around a stamped steel disc whose bent teeth back each character. The second uses a split, springy engraved steel die that opens to release the undercut characters. They combine Martin's cast elastic disc of 1882 and Blickensderfer's moulded wheel of 1890 with a rigid metal core, so the type is soft enough to mould and the wheel is still rigid enough to stay in register.
