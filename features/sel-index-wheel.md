# Hand-turned type wheel

*Selection feature · code `SEL:index-wheel`*

Hand wheel carrying the characters turned directly (the element is the index)

**87 patents**, 1843–1949. Often together with:

- **Selection:** [Selection locked for printing](../features/sel-selector-locking.md) (36)
- **Type element:** [Type wheel (types on the rim)](../features/elem-wheel-rim.md) (35)
- **Impression:** [Element struck to the platen](../features/imp-element-to-platen.md) (42), [Separate print key or lever](../features/imp-print-lever.md) (38), [Hand presses the type through](../features/imp-press-through.md) (37)
- **Inking:** [Ink roller](../features/ink-roller.md) (32)
- **Spacing and escapement:** [Prints and spaces in one stroke](../features/esc-print-and-space.md) (44), [Pawl-and-rack escapement](../features/esc-pawl-rack.md) (37)

**Machines:** [Dollar Typewriter](../machines/dollar-typewriter.md) (1)
