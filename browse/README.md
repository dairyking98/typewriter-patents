# Browse

Every page in the library, by kind. Each list is one long page you can search with the browser (Ctrl+F); the search box at the top searches page titles across the whole site.

| Section | What is in it |
|---|---|
| [Machines](../machines/README.md) | 1,045 machines, oldest first: year, maker, country, kind, price, patents, notes, links to collectors' pages |
| [Patents](../patents/README.md) | 10,201 patents, oldest first: summary, drawings, original document |
| [Mechanism features](../features/README.md) | every mechanism feature, with the patents that show it |
| [People](../people/README.md) | inventors and designers, with their patents and machines |
| [Companies](../companies/README.md) | makers and patent assignees |
| [Patent families](../families/README.md) | patents grouped by Google Patents' similar-document links |
| [Tags](../tags.md) | patents by mechanism tag (selection/pointer-chart, spacing/backspace, …) |
