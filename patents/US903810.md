## Reading (opening only, OCR fair)

**Problem:** A visible front-strike action pulls on type bars torsionally and gives uneven key tension.

**Solution:** Each type bar has individually removable connections giving a direct pull through quick leverage.

**How it works:** A type carriage frame has an open type basket of a semicircular series of type bars, open at the top, front and rear for visibility. Each set of bar connections is individually removable and gives a direct pull without twist and a uniform tension.

**Features:**

- **Type element:** [Typebars](../features/elem-typebar.md)
- **Frame and body:** [Visible writing](../features/frm-writing-visible.md), [Cleaning access](../features/frm-cleaning-access.md)

**Parts:** type carriage frame; type basket; type bar; hanger
