## Summary

**Category:** related office machine, not a typewriter (matrix-making justification attachment) · **Subject (patent classes):** Auxiliary feed or adjustment devices for justifying

**How it works (reading):** An indicator attached to an ordinary typewriter advances a counter by the matrix width unit of each character, so the operator sees how many units remain in the line.

## Reading (short summary from the opening, OCR fair)

**Problem:** Copy for matrix machines must justify, but ordinary typewriters give no indication of the matrix width units used up per line.

**Solution:** An indicator attached to an ordinary typewriter advances a counter by the matrix width unit of each character, so the operator sees how many units remain in the line.
