## Reading (full text, OCR good)

**Problem:** Existing cipher typewriters have a fixed relation between selector and type, so the frequency of repeated letters in the output gives the key away; a machine is wanted whose relation changes irregularly and that also decodes.

**Solution:** A hand-turned character dial positions a type wheel on one shaft, and after each impression a spring-driven pin-disk escapement automatically rotates the wheel relative to the dial by an amount set by adjustable pins, producing a cipher that can be reversed with the same settings.

**How it works:** The type wheel, a dial with a knob and a pin-disk escapement all sit on one shaft carried in a vertically sliding plate in a pillar. The operator turns the knob to bring a message letter under a detent, then presses a hand lever that lowers the plate; the detent drops into the dial notch to lock dial and wheel together, the type wheel prints with an ink roll, and a bell-crank pulls the feed plate so the carriage spaces on the return. On the return stroke a spring dog turns a ratchet which rocks an escapement shaft; this releases one pin of a spring-driven pin-disk so it advances to the next pin, turning the type wheel by the pin spacing. Pins can be pushed to either face of the disk, so the sender and receiver agree on a code by pin layout and starting letter. A pawl wound by the plate's descent charges the mainspring (with a slip lever to prevent overwinding). A second row of type on the wheel is reached by pushing the shaft rearward, held by a lock lip, and the repeat feature disables the ratchet dog. The ink-roll frame swings aside to remove the wheel.
