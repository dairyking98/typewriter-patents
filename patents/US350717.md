## Reading (full text, OCR good)

**Problem:** Inventor wants a simple, efficient index typewriter; earlier index machines put a shadow-casting lever over the index chart and needed bearing surfaces next to rubber type that wore it.

**Solution:** A sliding index plate carries a pivoted rubber type segment moved by a lever whose pin points at the matching letter on the chart, and a separate printing lever presses the type to the paper and advances the plate one ratchet tooth.

**How it works:** The index plate slides on a toothed feed-bar parallel to a rubber paper-feed roll. The type segment, with rubber type molded in reverse order of the chart letters, pivots at the plate centre; the operator swings its lever until the pin registers with the desired letter on the chart. A countersunk-hole centering segment on the type segment is then caught by a pin on the printing lever to correct small misplacement. Depressing a bail-shaped rocking lever pushes the printing lever down; flat springs touch the type to ink pads and a lug presses it to the paper, while a gravity feed-dog on the printing lever steps the whole plate forward one tooth and is at rest during the impression. A spring plate on the printing lever lets it descend only far enough to feed without printing, giving a word space. The feed-dog is lifted out and used as a handle to return the plate to the left margin.

**Parts:** index plate; feed-bar; type-carrying segment; rubber type segment; operating lever; pointer pin; printing lever; rocking bail lever; feed-dog; ink pad; centering segment; spring plate; feed roll; bed plate; guard

**Numbers:** 4-arm thumb-piece for line spacing

**Improves on:**

- earlier index machines with chart under the operating lever: operating lever passes beneath the index chart so it casts no shadow
- rubber type segments with adjacent bearing surfaces: deep grooves between types let each type be pushed through independently
