## Reading (opening only, OCR fair)

**Problem:** One ribbon guide must serve two colours, stencil mode, and accent dead keys.

**Solution:** One driving member lifts the ribbon guide from the universal bar for normal keys or via a transmission from dead keys for accents.

**How it works:** Type lever cams push a universal bar, which through a guide lever, link and three-armed lever lifts a vibrator and ribbon guide. Adjustable stops set black or red zone height. For stencils, a rotary disc disables the lift. Accent keys carry spring shoes pushing a rod that acts on the same lever, giving the right colour zone.

**Features:**

**Parts:** key lever; type lever; universal bar; three-armed lever; lifting bar; ribbon guide lever; stop; spring; rotary disc; accent key
