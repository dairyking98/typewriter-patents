## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried on sliding bars or rods

**In Google’s translation of the patent’s own words:** The invention relates to a type bar typewriter in which each with a plurality of type groups provided type bar with one of the number of types a plurality of key levers corresponding to each group is in communication and in which the type bars are slidably mounted on a carrier that is connected by connections with one part the button lever can be swung out to another To bring the type into the printing position.

**How it works (reading):** Each sliding type bar is mounted in its own carrier, pivotable as a whole, so every carrier can be made and adjusted separately.

## Reading (opening only, OCR fair)

**Problem:** With type bars sharing one carrier, the carriers cannot be adjusted individually, so manufacturing inaccuracies cannot be compensated for.

**Solution:** Each sliding type bar is mounted in its own carrier, pivotable as a whole, so every carrier can be made and adjusted separately.

**How it works:** Each type bar has four types and slides in a guide frame part that forms one arm of an angle lever pivoted on a support member. A toggle link pair moves the bar toward the platen. Two key levers per bar act on a common arm through angle levers with bent tabs: one key gives the longitudinal stroke only (printing one type), while the other also pivots the bar's carrier (printing another type). The platen is shifted to a second position to use the other pair of types. A support member is adjusted by a screw, and springs return everything to rest.

**Parts:** type bar; carrier; angle lever; toggle link; key lever; support member; adjusting screw; return spring; platen

**Numbers:** four types per bar

**Improves on:**

- typebar machines with a common carrier for all bars: one adjustable carrier per type bar
