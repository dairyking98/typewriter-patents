## Reading (short summary from the opening, OCR fair)

**Problem:** When a machine changes between ribbons, the operator can print partly in one ink colour and partly in another because the join between ribbons reaches the print point unnoticed.

**Solution:** A bar and arms on the ribbon spool lock the key and type actuating mechanism at a set point in the ribbon travel, warning the operator before the join reaches the print point.

**Features:** [Ink ribbon](../features/ink-ribbon.md), [Ribbon feed](../features/ink-ribbon-feed.md)
