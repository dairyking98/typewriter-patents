## Summary

**Category:** related office machine, not a typewriter (electrically operated duplicate typewriting) · **Subject (patent classes):** Apparatus or circuits at the receiving end using mechanical translation and type-bar printing

**In the patent’s own words:** This invention relates to certain improvements in electrical distributing systems and refers more particularly.

**How it works (reading):** Electrically operated selectors send keyboard actions over a minimum number of line wires so a remote machine repeats the typing.

## Reading (short summary from the opening, OCR fair)

**Problem:** Duplicate typing needs a distant machine to reproduce keystrokes over few wires.

**Solution:** Electrically operated selectors send keyboard actions over a minimum number of line wires so a remote machine repeats the typing.

**How it works:** Sending keyboard closes circuits; relays at the receiving machine drive corresponding keys.

**Features:**

- **Impression:** [Electric drive](../features/imp-electric.md)
- **Uses:** [Printing telegraph](../features/use-telegraph-printer.md)
