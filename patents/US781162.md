## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** A key-action lets the typebar return to normal position right after its printing stroke, independent of the key, so the next key can be struck while the first is still down.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typebar cannot return until the key has returned, so a second key cannot be struck until the first is released.

**Solution:** A key-action lets the typebar return to normal position right after its printing stroke, independent of the key, so the next key can be struck while the first is still down.

**Features:** [Typebars](../features/elem-typebar.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md)
