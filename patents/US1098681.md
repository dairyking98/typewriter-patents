## Reading (short summary from the opening, OCR poor)

**Problem:** Linotype matrix escapement releases more than one matrix per key depression.

**Solution:** An escapement bar with lugs engages one matrix per stroke; an eccentric and trigger lock the parts until the next key depression.

**How it works:** Eccentric cam and trigger return the escapement bar so only one matrix is released per key depression.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Type element:** [Separate type slugs or plungers](../features/elem-individual-slugs.md)
