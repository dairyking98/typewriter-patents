## Reading (full text, OCR good)

**Problem:** In type-wheel and segment machines the momentum of the wheel has been an obstacle to rapid printing, and if the rotating and tilting bails are timed only by the shape of the key lever, the first bail can run away from the second so the wrong letter prints and the wheel trembles when it locks.

**Solution:** Trip levers carried on the rotating bail are interposed between the key lever and the tilting bail, so the wheel is first rotated by a geared segment to the character set by an adjustable screw, and only then the trip lever meets the tilting bail and the locked wheel is carried to the platen using the momentum already built up.

**How it works:** A type-wheel with three rows of characters is mounted on a spindle in a carrier fixed to a rock shaft, and a ten-tooth gear on the wheel meshes with two five-tooth segments that swing loose on the shaft, one turning it half a turn each way. Each segment is hung on a bail that carries one spring-held trip lever for each key lever. Pressing a key lever moves the bail and segment, rotating the wheel, until the trip lever's long arm hits the adjusting screw set for that character in a second bail rigidly fixed to the rock shaft. From that moment the segments and carrier move together, tilting the wheel to the platen, while a locking wheel with slots meets a fixed locking blade so the wheel is held rigid before the impression. Adjusting the screw's height changes how far the wheel is turned before tilting, and thereby which type comes to the print point. Return springs bring the bails back and a lug on each segment meets a single-tooth normalising wheel to stop the wheel exactly at rest; a key lever pushing a pin on the spindle lifts the wheel to bring another row to print.
