## Reading (opening only, OCR fair)

**Problem:** Plastic cladding frames are only decorative, while a strong metal base frame carries the bearings; a plastic base frame would need to be much larger.

**Solution:** Mould the cladding frame and base frame together, with all bearings and guides, as one synthetic resin moulding where each stiffens the other.

**How it works:** Cladding frame and base frame partly merge into one pressed resin body. Key lever bearings, idle lever axle bearings, edge release guide, ribbon zone lever slot, switching lever bearing, carriage guide support surfaces, intermediate lever bearing seats and screw faces for rubber feet are all moulded in without reworking. Hexagonal recesses hold nuts so no thread need be cut. The unit gives low weight and sound absorption without added damping.

**Features:** [FRM:frame-construction](../features/frm-frame-construction.md), [FRM:few-parts](../features/frm-few-parts.md), [FRM:cover-enclosure](../features/frm-cover-enclosure.md)

**Parts:** cladding frame; base frame; bearing; guide; carriage guide surface; hexagonal nut recess; rubber foot

**Improves on:**

- metal base frame with plastic cladding: plastic frame itself carries bearings, using cladding as reinforcement

> Description Translated from German The invention relates to an office machine body, in particular a Typewriter frame with a base frame bearing the bearings, guides or the like, which is covered on all sides by a cladding frame. In the known typewriters, the carrier of all parts is one stable metal base frame, which is often surrounded by a cladding frame. Office machine cladding frame, which only serve to give the machine a pleasing appearance are already made of plastic. The particular advantages are in the weight reduction, in the rustproof, unpainted surface and in the possibility of any desired Achieve shaping. The molding material is economical for mass production an increase in production with a reduced wage share and savings in work steps. If you want the many advantages of plastic for the base frame too using the machine, there are considerable difficulties: Since the base frame accommodates a large number of moving parts, it is exposed to significant stresses. One would have to enlarge its dimensions many times over, because the plastic does not have the same strength as the metals previously used.
