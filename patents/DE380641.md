## Description (Google Patents OCR, opening)

> Description Translated from German Auxiliary keyboard for typewriters, calculators and. The like. The invention relates to a further embodiment of the auxiliary keyboard according to patent 377919 and consists in that in a housing which is located above the keys of the machine by electric, spring, motor or Foot drive and the like, rotated shafts are mounted parallel to the rows of keys, on which, by lightly pressing the auxiliary keys with a finger, connectable lifting thumbs sit, which cause the main keys to stop or set the type lever in motion. For each key, a sleeve is firmly seated on the shaft Thumbwheel, when a driver tooth is pressed down, the otherwise -by spring force held out of engagement with the thumbwheel, a keystroke lever with the Drive shaft couples so that the main button is struck. Each auxiliary key carries a preferably semicircular guide rail below, which by their exactly coordinated length the duration of the coupling to be achieved between the sleeve and Thumb wheel regulates.
