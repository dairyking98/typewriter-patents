## Reading (full text, OCR fair)

**Problem:** Printing several thousand Japanese characters normally needs hundreds of keys or irregular shift keys.

**Solution:** A 48-key chequerboard keyboard where each key face carries 48 index characters laid out like the keys: a first 'provisional' key press stops a spinning case on the stick holding the character, then the key bearing the character prints it by row and column bars that turn and extend a type lever.

**How it works:** A tilted cylindrical case holds 48 hexagonal type-sticks, each with eight rows of characters on each of six sides. The operator presses the key matching the character's position among the index characters on its key, which stops the power-driven case via a selector wheel with graded projections and stops, selecting that stick. A power wheel's inertia then slides forward, releasing the stick from the case's holding gears and letting a spring gripper on the type lever catch it. Pressing the character's own key sets a row bar and column bar and lifts the type lever by a printing bar. The type lever's gear runs up a step-track with tipping pieces that block it after the right number of teeth, turning the stick to the right face, while a folding link extended by the column bar pushes the stick out to the right row. The stick prints on the paper cylinder, then returns to the case and a feeler operates the rack letter-spacing bar.

## Description (English translation of the Japanese text, opening)

> Specification. Japanese-language typewriter. Nature and object of the invention. This invention relates to a Japanese typewriter in which the action of the "shift key" of the office European-language typewriter is performed between the keys themselves. It has a keyboard of several tens of keys arranged in a chequerboard grid; on each key face are written as many index characters as there are keys, arranged in the same way as the keys. The character to be printed is found on the keyboard; the key whose place in the keyboard corresponds to the place of that character among the other index characters on its key is pressed; this stops the "case", turned by the power wheel, and selects the type-stick (群型, "group type") to which the character belongs. Next, the key on which the character was found is pressed. According to that key's row and column on the keyboard, its key lever presses down the row bar, column bar, printing bar and other bars belonging to it, swings the type lever, and gives it the rotation and extension that set the specified row and column, so that the wanted character is printed on the paper cylinder.
