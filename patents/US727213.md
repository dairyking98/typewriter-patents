## Reading (opening only, OCR fair)

**Problem:** Messages need enciphering without separate code books.

**Solution:** Cipher type-wheel whose characters are shifted relative to the keys at set intervals, so key and printed letter differ and a like machine decodes.

**How it works:** A spring-driven gear train turns a vertical shaft, whose gear drives a pinion on a hub and shifts the type-wheel relative to the keys. A type-wheel with arbitrarily arranged characters rotates on a sleeve on a stud. A stop mechanism returns the wheel to an initial position; the shift reverses direction and can be automatic. A second type-wheel allows translating.

**Features:** [ELEM:wheel-rim](../features/elem-wheel-rim.md), [ELEM:interchangeable](../features/elem-interchangeable.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [USE:telegraph-printer](../features/use-telegraph-printer.md)

**Parts:** type-wheel; vertical shaft; gear train; coiled spring; pinion; hub; stud; sleeve; stop mechanism
