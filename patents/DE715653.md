## Summary

**Category:** related office machine, not a typewriter (zero pressure device, cash registers) · **Subject (patent classes):** Devices for printing the point

**How it works (reading):** Each amount switching element returns to rest at the start of its setting movement and triggers the zero-print control, so the type wheels are set during the setting movement and printing can start earlier.

## Reading (short summary from the opening, OCR fair)

**Problem:** Zero-suppression printing in cash registers waited for the amount setting to finish, delaying the print.

**Solution:** Each amount switching element returns to rest at the start of its setting movement and triggers the zero-print control, so the type wheels are set during the setting movement and printing can start earlier.
