## Reading (full text, OCR good)

**Problem:** Printing machines with a type magazine need small, light, efficient type pieces, and a single-faced piece wastes half its area.

**Solution:** Flat type pieces carry a character on both faces, and a latch chooses whether the gripper stays parallel or half-turns during the swing, so either face prints.

**How it works:** Pressing the push-button lifts the chosen flat type from the magazine to a gripper, through two ink rollers that ink its face, while a cam loads a leaf spring on the printing bars. The gripper is held by crossed struts linked to two sets of parallel printing bars via a shaft frame. A pawl then releases the shaft frame and the spring swings the bars hard toward the platen. If the latch locks the central shaft to the shaft frame the gripper stays parallel and the front character prints; if the latch locks it to a bar, the shaft turns with the bar and the crossed struts flip the gripper by a half turn, printing the back character.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. A printing machine of the kind in which pressing a push-button makes the wanted type piece in the magazine be gripped by the printing bars, which then swing to press it on the paper on the platen. It uses flat type pieces with a character formed on both faces. The type gripper that holds and carries them is linked, through a link mechanism, to a pair of printing bars, each a set of two parallel bars; by changing how the link mechanism is coupled to the bars, the gripper can be turned over during the bars' swing so that the character on the back is printed. The object: a small, light-working, efficient printing machine that uses light type pieces, small flat plates with characters on both faces, and can print either face at will.
