## Summary

**Category:** related office machine, not a typewriter (typewriter with column counters)

**How it works (reading):** A single common, adjustable intermediate link between all number key levers and the arithmetic units transmits the keyed values to the counters, and the same link sets the invoice type, with the counter drive engaging as the carriage moves from column to column.

## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriters with column counters attached are complex, and the counter dials can roll over unsafely.

**Solution:** A single common, adjustable intermediate link between all number key levers and the arithmetic units transmits the keyed values to the counters, and the same link sets the invoice type, with the counter drive engaging as the carriage moves from column to column.

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
