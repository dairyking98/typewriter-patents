## Reading (opening only, OCR fair)

**Problem:** Type-wheel writers need a compact, portable machine with durable yet elastic type and simple spacing.

**Solution:** A combined type-and-key disk of radial spring fingers carrying a rubber web with type faces and knobs, turned by an index disk on a hinged carriage and pressed down to print.

**How it works:** The printing wheel has a concave index disk fitted over a type disk whose radial spring fingers each carry a rubber type face and a knob that serves as the key. The wheel is mounted on a hinged carriage plate held up by a spring; the operator turns the index disk to the chosen character and depresses the wheel so the finger bends the type to the paper. The carriage runs along a track on a hinged frame with a presser bar for the paper, and inking devices and spacing devices operate with the stroke. The base is the cover of a box that holds the machine.
