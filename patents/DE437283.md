## Summary

**Category:** related office machine, not a typewriter (calculating attachment for typewriters)

**In Google’s translation of the patent’s own words:** The invention relates to one for use for every typewriter of the standard system suitable calculating machine for execution of steep additions or subtractions of any number of columns in any one divisible steep addition counter and simultaneous, but freely adjustable Line cross addition or subtraction in a fixed cross counter.

**How it works (reading):** A long row of counting disks slides sideways by hand independently of the carriage; it is set by the tabulator keys to match column spacing, advances column to column by finger pressure, and can be disconnected so the typewriter runs without adding.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adding and subtracting columns on a typewriter needs a separate calculator that cannot easily follow the column spacing.

**Solution:** A long row of counting disks slides sideways by hand independently of the carriage; it is set by the tabulator keys to match column spacing, advances column to column by finger pressure, and can be disconnected so the typewriter runs without adding.
