## Summary

**Kind:** typebar machine · **Subject (patent classes):** Bearings or hangers for type levers

**How it works (reading):** A type bar rest with a cross section that stops rebound supports the heads of the type bars, and each key lever tension is adjustable independently.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type bar segment support and key lever tension need better adjustment and quieter rest.

**Solution:** A type bar rest with a cross section that stops rebound supports the heads of the type bars, and each key lever tension is adjustable independently.
