## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** The present invention relates to type mechanism for type-writing machines, and more particularly to type mechanism for visiblewriting machines, so-called.

**How it works (reading):** Each type action is made complete so it can be assembled in the machine and removed as a unit, and the type carriers shift vertically to bring a second set of characters into printing position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Visible-writing typewriters need many parts, and each type action cannot easily be removed or replaced as one unit for repair.

**Solution:** Each type action is made complete so it can be assembled in the machine and removed as a unit, and the type carriers shift vertically to bring a second set of characters into printing position.

**Features:**

- **Typebars:** [Typebars](../features/elem-typebar.md), [Typebar action](../features/bar-type-action.md)
- **Frame and body:** [Visible writing](../features/frm-writing-visible.md), [Few parts, low cost](../features/frm-few-parts.md)
