## Reading (opening only, OCR fair)

**Problem:** Shifting between lower and upper case normally requires moving the platen or the whole type-bar basket.

**Solution:** Give each key lever two connections, to a lower-case and an upper-case type bar, and let the shift key make only one connection active.

**How it works:** Each key lever carries a pair of opposed wings, one linked through a bell crank to the lower-case type bar and one to the upper-case bar. A shift key rocks a shaft and a universal shift bar that moves stirrups, so only one wing engages the key lever. The unused connection stays idle, so neither platen nor basket moves. The two type bars of a pair are pivoted at different distances from the segment so their types rest one behind the other.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** key lever; wing; stirrup; bell crank; connecting rod; shift lever; universal shift bar; type bar; segment

**Improves on:**

- conventional shift (platen or basket moves): shift selects which of two type bars a key drives, nothing large moves
