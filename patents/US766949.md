## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Pawl-and-ratchet mechanisms moving a paper or like carriage in the form of a roller rotated for line spacing

**In the patent’s own words:** My invention relates more particularly to the line-spacing mechanism of type-writing machines;

**How it works (reading):** The carriage's return lever enters an adjustable U-shaped guide on a segment, so the platen rotates by an amount set by the guide angle.

## Reading (short summary from the opening, OCR fair)

**Problem:** Platen spacing on return of the carriage must be set by hand.

**Solution:** The carriage's return lever enters an adjustable U-shaped guide on a segment, so the platen rotates by an amount set by the guide angle.
