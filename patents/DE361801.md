**How it works (reading):** Adjustable pressure stamps, mounted across the type wheels, are pressed against separate ink rollers (for example red and blue), so the colour marking is applied independently of the type wheels, which are inked separately.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing with several colours in cash registers usually needs ribbons, and the author wants a simple printing device without ribbons.

**Solution:** Adjustable pressure stamps, mounted across the type wheels, are pressed against separate ink rollers (for example red and blue), so the colour marking is applied independently of the type wheels, which are inked separately.
