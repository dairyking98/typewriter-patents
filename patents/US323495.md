## Reading (full text, OCR good)

**Problem:** A typebar machine needs evenly balanced key resistance, more characters from one key without extra keys, ribbon or pad inking that keeps writing visible, and letter spacing proportional to letter width.

**Solution:** A typebar keyboard with adjustable-fulcrum key levers, a laterally shifting key frame so each key works one of two bell-crank type-levers, an inking pad swung down by the space key, and a variable escapement that spaces the platen carriage according to the key struck.

**How it works:** Key levers rest in grooves of a fulcrum slab so their leverage can be set to equalise key resistance; each bell-crank lever carries one type and the thin levers strike a common point on the platen. A shifting key frame above the levers moves sideways on a shift key so each key presses one of two levers, giving two characters per key. An arc-shaped inking pad swings down onto all the type faces whenever the space key (or a separate inker key) is pressed; alternatively a ribbon on two reels, one with ratchet and pawl and a spring return reel, is held above the paper and advances per impression. The platen carriage rides on bars and is moved by a rack and a revolving screw turned by a spring-driven escapement wheel, whose stop is a pawl and prong between pins, with set screws for each key lever adjusting the stroke of the spacing bar and so the space for broad or narrow letters; a rack and pinions return the carriage.
