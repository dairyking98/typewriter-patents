## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Intermediate levers are movably mounted between the key linkage and the type-lever linkage, their lower ends joined by a rod to downward levers, so a key stroke can be transferred to the type lever independently of the carriage movement and the type lever can be released before it reaches the platen.

## Reading (short summary from the opening, OCR fair)

**Problem:** Key-lever release devices that let type levers return on their own exist only for invisible-writing machines, because the type levers strike the platen from below; front-striking visible-writing machines have no such release, and the keyboard is wider than the type lever arc.

**Solution:** Intermediate levers are movably mounted between the key linkage and the type-lever linkage, their lower ends joined by a rod to downward levers, so a key stroke can be transferred to the type lever independently of the carriage movement and the type lever can be released before it reaches the platen.
