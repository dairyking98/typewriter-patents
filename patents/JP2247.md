**How it works (reading):** A knob-turned type plate with spring-returned types round its edge and a pointer over a fixed character dial; a guide tongue drops into a guide hole to locate the type, a press stem drives it out, and the same stroke ratchets a paper-gripping roller so the machine walks along the paper.

## Reading (full text, OCR good)

**Problem:** Writing kana and other text by brush is slow; the inventor wants a small hand printing machine that prints quickly, surely and clearly in type.

**Solution:** A knob-turned type plate with spring-returned types round its edge and a pointer over a fixed character dial; a guide tongue drops into a guide hole to locate the type, a press stem drives it out, and the same stroke ratchets a paper-gripping roller so the machine walks along the paper.

**How it works:** Turning a knob drives a bevel gear and a gear train that rotates the type plate under the dial and a pointer over the dial together. When the pointer shows the wanted character, its guide tongue drops into a guide hole, which locates the matching type exactly under the press stem at the type guide path. Pressing the stem pushes a pressing piece against the type, which passes down through the guide path and prints on the paper, then springs back. The type plate turns against an inking roller fed from an ink tube, so each type is inked as it passes. The same stem stroke moves a feed finger that turns a ratchet wheel and a rubber-skinned roller touching the paper, so friction carries the whole machine one step along the paper; skins of different size set the character spacing. At line end the machine is lifted and moved by hand.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. This invention concerns a printing machine in which a rotating type-carrying plate, a pointer, a fixed character dial, a press stem that is pushed down, and a rotating plate (roller) that moves the machine along work together, so that by quick and simple actions sounds (kana) and other texts are printed quickly, surely and clearly in type, replacing the labour of writing by brush. It has three objects: first, to mount a type plate that turns inside the case, and by the pointer to show on the dial exactly which type is at the guide path; second, to drive that type accurately out through the type guide path and print it; third, to move the machine along after each impression.
