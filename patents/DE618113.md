## Reading (short summary from the opening, OCR fair)

**Problem:** Type wheels carrying two identical type sets at diametrically opposite points cannot be engraved by existing twin-stylus machines, because the workpiece rotates.

**Solution:** An engraving machine drives two gravers at opposite points in opposite tangential and radial directions from one template, while the workpiece only moves axially, so both type sets are cut together.

> Description Translated from German Engraving machine, in particular for the production of type wheels For registration cash registers and booking machines, type wheels are often required which are assigned to two different printing points at the same time. Such type wheels are provided with two type sets, the same type being arranged in each case at two diametrically opposite points of the type wheels. The invention relates to an engraving machine for producing such type wheels. Engraving machines are already known for the simultaneous engraving of the same pattern at two opposite points on a workpiece by means of styluses that are moved as a function of a single template. These known machines are JE not suitable for the manufacture of wheels of the type mentioned type, because the workpiece is rotating. The production of type wheels is only made possible with such machines that, according to the invention, the .the opposite points of the workpiece machining graver depending on the template are moved in opposite directions in both tangential and radial direction, while the ZVerkstück only a lateral axial movement executes.
