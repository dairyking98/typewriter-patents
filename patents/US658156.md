## Reading (short summary from the opening, OCR fair)

**Problem:** The paper must be squared on the platen and set to the printing point while the platen is in working position; setting it in the non-working position is troublesome and operators forget steps.

**Solution:** A platen scale placed as close as possible to the printing point squares the paper, and the platen can be released from line spacing to turn either way for a set distance.
