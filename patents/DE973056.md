## Reading (short summary from the opening, OCR fair)

**Problem:** Punched-card statistical machines must run every card through the same path, but earlier designs split the card path behind the scanner.

**Solution:** A card machine prints a note punched on one card onto an unperforated data card, with all cards on one common path past a scanner that controls the printing device.
