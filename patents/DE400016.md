## Summary

**Category:** related office machine, not a typewriter (cash register multiple adders)

**In Google’s translation of the patent’s own words:** The invention relates to a cash register with several adding units, in which the ad- through laterally displaceable input control organs optionally with a common Printing unit brought in connection can be.

**How it works (reading):** Adding units stay fixed; a sum key moves pairs of bent feeler arms so that the selected adder's setting is coupled to the common printing unit, and a separate tape prints only the grand totals.

## Reading (short summary from the opening, OCR good)

**Problem:** A cash register's several adding units must each print through one shared printing mechanism, which needs a simpler linkage.

**Solution:** Adding units stay fixed; a sum key moves pairs of bent feeler arms so that the selected adder's setting is coupled to the common printing unit, and a separate tape prints only the grand totals.
