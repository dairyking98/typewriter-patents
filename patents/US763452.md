## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** The object is toprovide a type-writing machine of comparatively simple construction so arranged'that the type-carrying bars and operating-levers may be moved to printing operation by a very little pressure and upon release bequickly returned to their normal position.

**How it works (reading):** Link each typebar through an angle lever and H-blank links to its finger lever, with comb-guided low-friction pivots and a screw-adjustable return spring.

## Reading (full text, OCR fair)

**Problem:** Typebars and key levers should move to print with very little pressure and return quickly, in a simple machine.

**Solution:** Link each typebar through an angle lever and H-blank links to its finger lever, with comb-guided low-friction pivots and a screw-adjustable return spring.

**How it works:** Typebars swing on a rod in kerfs in a curved arc plate, so each is thrown to the centre for printing. A rearward projection on each bar is linked to the vertical arm of an angle lever pivoted on a wire in a comb bar; its horizontal arm is linked to a finger lever pivoted on a wire in a comb plate. Links are stamped as H-shaped blanks and folded so the sides present flat bearing surfaces, resisting twisting. A spring on each finger lever runs to a threaded sleeve moved by an adjusting screw, which sets the key tension. The text is cut off before the adjustment is fully described.
