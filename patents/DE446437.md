## Summary

**Category:** related office machine, not a typewriter (key lever register check)

**In Google’s translation of the patent’s own words:** The invention relates to a key lever cash register with check dispensing, at which during the making of the check strip imprint, the key lever is locked in the depressed position and the checkout mechanism released when setting the amount on Closing the checkout is stopped again by a locking device, whereupon the key levers that have been locked up to that point return to their rest position.

**How it works (reading):** A switching device linked to the locking device makes the checkout gear run twice per checkout so that one of every two checks is printed again as a double.

## Reading (short summary from the opening, OCR fair)

**Problem:** A cash register must issue a double check, meaning two identical checks printed in one checkout, which the usual machine does not do.

**Solution:** A switching device linked to the locking device makes the checkout gear run twice per checkout so that one of every two checks is printed again as a double.
