**How it works (reading):** Two rows of amount type wheels, each split into groups, are set from one rack set; only the printing hammers facing the active groups are released to strike.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cash register printing into several columns should strike only the printing hammers that face the active type wheel groups.

**Solution:** Two rows of amount type wheels, each split into groups, are set from one rack set; only the printing hammers facing the active groups are released to strike.
