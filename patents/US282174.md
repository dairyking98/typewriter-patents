## Reading (opening only, OCR fair)

**Problem:** Spacing each letter by its width and combining several type styles in a power-driven machine.

**Solution:** A rotating cylinder of sliding rods presses a paper strip onto a rotating type ring; rod width fixes how far the strip is pulled, and a pedal shifts the type ring axially to another row.

**How it works:** A revolving cylinder with longitudinal grooves holds sliding rods that protrude over a type ring with types set radially, which turns at the same rate through gearing. A key for each rod throws it up against a cam so that it presses the paper strip against the type, and the strip is dragged along while held. Rods are made wider for wide letters so they pass the cam apex longer and pull the paper farther. With several type rows each rod has several widths and the cam slides in a groove to meet the right one. A grooved ring on the shaft with a yoke, shifting bar and pedal moves the type ring to change row; Roman and Italic fonts of equal width can share one set of rods. A forked spring throws the paper off the type.
