## Summary

**Category:** related office machine, not a typewriter (card punching machine with typewriter keyboard) · **Subject (patent classes):** Apparatus specially adapted for preparation of record carriers for controlling composing machines

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter keyboard Card punching machine, whose columns are arranged in a row along a card column The number of punch selectors corresponds to the number keys and is set from the keys be to select the punch, which then simultaneously in a single punching process through the previously automatically supplied and then automatically withdrawn card are driven.

**How it works (reading):** Letter keys are divided into two groups, each driving one or two punch selectors, with some letters using combination holes.

## Reading (short summary from the opening, OCR fair)

**Problem:** Card punching with a typewriter keyboard needs too many connections to express letters as well as numbers.

**Solution:** Letter keys are divided into two groups, each driving one or two punch selectors, with some letters using combination holes.

**How it works:** Keys set the punch selectors through electromagnets; the second group drives two selectors through a shared common connection.
