## Reading (opening only, OCR good)

**Problem:** The usual shift key is awkward, needing a different finger from the one that is already working.

**Solution:** Shift key extended across the full keyboard width in front of the space bar so the thumb can work shift and space, while a finger hits any key.

**How it works:** On a Remington style machine with type blocks carrying several types, the platen is carried on a carriage and supported by arms from the frame. The shift key is lengthened across the whole width of the keyboard near the space bar, letting the same thumb press space then shift for a capital, and making one-handed operation possible. It can be added to existing machines.

**Features:** [SHIFT:platen](../features/shift-platen.md), [ESC:space-key](../features/esc-space-key.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** shift key; space bar; key lever; platen; carriage

**Improves on:**

- usual shift key: extended across the keyboard width beside the space bar
