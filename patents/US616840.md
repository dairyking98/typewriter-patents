## Reading (opening only, OCR fair)

**Problem:** Typists must use the space bar twice after a period or word end; this wastes strokes.

**Solution:** Provide duplicate keys for terminal characters that print and also give double or multiple spacing via separate spacing frames that engage the spacing rocker.

**How it works:** Some characters, mostly terminal ones, get a second key. Each key independently operates the type and a spacing frame. Single-spacing keys share one spacing frame and multiple-spacing keys another. The spacing rocker is not fixed to the frames but is engaged and moved by whichever frame operates, and at least one frame positions a stop to set the spacing amount. Only a small number of added keys is needed.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Spacing and escapement:** [Space key or bar](../features/esc-space-key.md), [Proportional spacing](../features/esc-variable-spacing.md)

**Parts:** key; spacing frame; spacing rocker; stop; spacing bar

**Improves on:**

- spacing-bar after word end: spacing is done by the character key itself
