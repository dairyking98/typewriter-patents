## Reading (short summary from the opening, OCR poor)

**Problem:** In known sprocket-wheel counters the printing type segment is a separate part linked by a pinion, which makes the device bulky, costly and sensitive.

**Solution:** Printing types are carried on the same sliding rungs that set the counter, and a slotted guard lets only the type of the effective rung reach the print point.
