## Reading (full text, OCR good)

**Problem:** In a typewriter where a type rod carrying a type is pushed down a type tube, the printing force varies with the operator's push, so the impression is uneven.

**Solution:** Spring-loaded cams project into the type tube so the descending type rod must push past a constant resistance, evening out the impression.

**How it works:** A type tube on an arm slides along two guide rods on the frame. Two off-centre-weighted cams on pivots face each other inside the tube and project slightly into the rod's path. The tweezer-shaped, normally open type rod is gripped onto the type by pressing a push knob that drives a clamp ring down its sloped sides. When the rod is pushed down it must force past the cams, whose resistance is constant, so the final blow is nearly uniform whatever the push. On the way up the cams swing aside freely and fall back by their off-centre weight.

## Description (English translation of the Japanese text, opening)

> Specification. Printing device for a typewriter. Nature and object of the invention. This invention relates to a typewriter printing device in which a type rod holding a type goes down by pushing past cams that project into the path of the type tube, and so prints. Its object is to make the typewriter's printing even by using the resistance of the cams. Brief description of the drawings. The drawings show the construction of the invention. Fig. 1 is a perspective of a typewriter fitted with this device; Fig. 2 a perspective of the type rod; Fig. 3 a front view of the type rod and the type tube, the latter shown in section. The same signs in the drawings show the same or equivalent parts. Detailed description. In this invention, guide rods are provided on a suitable frame, and a type tube is provided on an arm that can slide along the guide rods. Cams are provided facing each other on the inside of the type tube, projecting into the path of the type rod that holds the type. The type rod is made like tweezers and always springs open; when its push knob is pressed down it easily grips the type.
