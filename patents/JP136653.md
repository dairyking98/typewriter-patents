## Reading (full text, OCR good)

**Problem:** A Japanese typewriter with a very large character set needs fast, continuous printing without moving the type store for every character.

**Solution:** A hand-turned compound magazine of many type discs on one shaft presents one row of loose types at a time under a fan of key-driven type bars, each of which picks up and prints its own type.

**How it works:** Many flat discs on one straight shaft hold loose types face outward in compartments, aimed differently on each disc to point at its type tube. A handle turns the magazine to a row; type-stop rods through all discs hold the types with stops, and discs at the frame ends bump each rod once so the row facing the tubes is released. Pressing a key first lifts a push-up lever that raises the type into its type tube on a type bar, then through links swings the bar through 180 degrees so the type strikes the platen's print point. Releasing the key reverses everything, and every type in that row can be printed in turn without moving the magazine. Bars are pivoted on an arc support centred on the print point.

## Description (English translation of the Japanese text, opening)

> Specification. European-style Japanese-language typewriter. Nature and object of the invention. The type magazine consists of many flat discs fixed on one straight shaft; round the edge of each disc types are inserted face outward, in type holes whose direction differs from disc to disc. There is a type-stop rod common to all the discs, and type bars, as many as there are discs, arranged in a fan above the magazine and pivoted on an arc-shaped support. Each type bar is worked by its own key. When the magazine is turned and stopped in a set position, the type of each disc comes directly under its corresponding type tube, so that every type in that row can be printed one after another, at will, simply by pressing keys. The object: by this combination of mechanisms, to create a continuous printing device that is precise and sure, moves smoothly and is easy to work. Brief description of the drawings.
