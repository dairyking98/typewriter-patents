## Description (Google Patents OCR, opening)

> Description Translated from German Note typewriter The invention relates to a note typewriter for writing notes on paper without staves. The known typewriters of this type compared to the invention is that on each individual type carrier except the note type also the five-line system is appropriate, so that by writing side by side the note types create the staves by themselves. The advancement of the paper carrier does not happen as with the known ones Typewriters when you hit the character keys, but exclusively through Hit the space bar, but not just like on ordinary typewriters moves the car, but also prints five staves. The character keys are therefore in the music typewriter according to the Invention designed as so-called dead buttons. This is required to save to be able to produce polyphonic notation more unanimously.
