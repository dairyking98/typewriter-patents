## Summary

**Category:** related office machine, not a typewriter (10-key keyboard for calculating machines) · **Subject (patent classes):** Keyboards with one set of keys for all denominations, e.g. ten-key board

**How it works (reading):** Each key button sits on a support arm and can be adjusted horizontally, along the fingers and across, by gripping screws in slots.

## Reading (short summary from the opening, OCR good)

**Problem:** On ten-key adding keyboards, one hand size does not fit all, which makes blind keying uncertain.

**Solution:** Each key button sits on a support arm and can be adjusted horizontally, along the fingers and across, by gripping screws in slots.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
- **Uses:** [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** ten key buttons; support arms; slotted backdrop; gripping screws
