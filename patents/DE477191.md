## Summary

**Category:** related office machine, not a typewriter (cash register rotating type head) · **Subject (patent classes):** Computing machines characterised by the structural interrelation of their functional units, e.g. invoicing machines

**How it works (reading):** A dial-set type disk carries inner and outer type rings; a finger on the disk turns a lever that lifts a locking hook, so the drawer opens only after the seller has removed the receipt.

## Reading (short summary from the opening, OCR fair)

**Problem:** The cash register's receipt carrier must shift sideways with each printed character, and the drawer must be locked until the seller finishes.

**Solution:** A dial-set type disk carries inner and outer type rings; a finger on the disk turns a lever that lifts a locking hook, so the drawer opens only after the seller has removed the receipt.
