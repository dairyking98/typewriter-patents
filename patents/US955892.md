## Reading (opening only, OCR fair)

**Problem:** Closely packed typebars in the basket can interfere or clash when adjacent bars are operated at about the same time.

**Solution:** Each typebar is driven by a pivoted driver plate and guided at its front end by a radial guide link working in a slot, so the bars stay separated.

**How it works:** A key lever pulls a link that turns a bell crank; its rear arm pulls a rod linked to a driver pivoted on a segmental hanger. The driver is pivoted to the typebar proper, whose forward end is pivoted to a radially arranged guide link running in a radial slot of a segment, so the bar swings to the platen along a guided path. A coiled spring restores each driver. The carriage and escapement are of any usual construction.

**Features:** [Typebars](../features/elem-typebar.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Element struck to the platen](../features/imp-element-to-platen.md)

**Parts:** key lever; bell crank; pull link; driver; typebar; guide link; segment; restoring spring; auxiliary frame

**Improves on:**

- Smith application Serial 260,441 (1904): improves the type action with guide links for close, non-clashing bar spacing
