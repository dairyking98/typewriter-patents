## Reading (short summary from the opening, OCR fair)

**Problem:** The element must be readjusted longitudinally after each character, so the operator can only form one character per spacing movement.

**Solution:** Mechanism that forms several characters in a row before the element is repositioned, and lets the operator set the character-producing elements ahead of their operation.

**Features:** [ELEM:element-construction](../features/elem-element-construction.md), [PAP:platen-roller](../features/pap-platen-roller.md)
