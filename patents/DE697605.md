## Summary

**Category:** related office machine, not a typewriter (accounting machine paper carriage) · **Subject (patent classes):** Line-spacing devices

**In Google’s translation of the patent’s own words:** The invention relates to the device for moving of the paper cart of an accounting machine.

**How it works (reading):** The carriage return device is set in motion again by a control that comes into effect when the disabling device has stopped the carriage in an intermediate position, so the carriage can return and tabulate correctly for a new line.

## Reading (short summary from the opening, OCR fair)

**Problem:** When the carriage is stopped partway by the fast return, the next line of entries cannot be started, because the carriage does not return to the start while the carriage moves column by column.

**Solution:** The carriage return device is set in motion again by a control that comes into effect when the disabling device has stopped the carriage in an intermediate position, so the carriage can return and tabulate correctly for a new line.
