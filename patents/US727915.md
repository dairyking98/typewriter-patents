## Summary

**Category:** related office machine, not a typewriter (cipher-writing machine) · **Subject (patent classes):** Cryptography or similar special procedures in a franking system; Typewriters for ciphering or deciphering cryptographic text wherein the operative connections between the keys and the type-bars are automatically and continuously permuted, during operation, by a coding or key member the connections being mechanical

**How it works (reading):** A machine that carries out a variable-substitution cipher method: a set of alphabets with letters arranged alike, and a fixed cipher key that chooses which alphabet encodes each group of letters. The mechanism is not described in the first 3000 chars.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cipher writing with a fixed substitution is easy to break, so the letter a should be represented by different letters at different points, following a predetermined rule.

**Solution:** A machine that carries out a variable-substitution cipher method: a set of alphabets with letters arranged alike, and a fixed cipher key that chooses which alphabet encodes each group of letters. The mechanism is not described in the first 3000 chars.
