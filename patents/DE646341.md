## Reading (opening only, OCR poor)

**Problem:** A small, simple but strong typebar machine small enough for travel was wanted.

**Solution:** Key levers are pivoted on a circular arc concentric with the intermediate levers' bearing arc, with a cranked pull on the intermediate lever, so the machine is compact.

**How it works:** Pressing a key lowers the key lever, which through a link rocks the intermediate lever. A guide rivet on the intermediate lever slides in a slot of the type carrier, driving the typebar in a straight line against the platen. A spring returns the intermediate lever. The type carrier is guided by combs and a bracket above.
