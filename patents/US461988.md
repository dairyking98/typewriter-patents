## Reading (opening only, OCR fair)

**Problem:** Typebar machines needed fewer keys and levers.

**Solution:** A shiftable pawl ring lets one key lever operate any of several type bars.

**How it works:** Pawls are small rods guided in a ring and connected by rods to the type levers. Each key lever acts on a pawl; shifting levers move the ring so a different pawl lines up with the key. The ring rides in grooved brackets. The frame is a metal box with the keyboard in front and a roller platen on the carriage.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Typebars:** [Typebars](../features/elem-typebar.md)
- **Shift and cases:** [Three or more cases](../features/shift-triple.md)

**Parts:** frame; pawl ring; pawl; connecting rod; key lever; shifting lever; bracket; spring
