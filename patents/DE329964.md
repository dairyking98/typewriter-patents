## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Writing or like instruments in holders or guides

**In Google’s translation of the patent’s own words:** The subject of the present invention is a ruling device, in which the special type set for writing a string of characters when opening always occupies the same position on the ribbon and the paper roller, regardless of which one Font comes to the stop.

**How it works (reading):** A single special underline type sits on the type cylinder, which moves axially and rotates so it always takes the same ribbon and paper position for any character.

## Reading (short summary from the opening, OCR fair)

**Problem:** Underlining with a bracket-held special type changed the stroke positions per character and jammed the type window.

**Solution:** A single special underline type sits on the type cylinder, which moves axially and rotates so it always takes the same ribbon and paper position for any character.
