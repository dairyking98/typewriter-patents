## Reading (opening only, OCR fair)

**Problem:** Machines with several type groups for different alphabets change group by moving the type carrier, which is cumbersome and upsets alignment.

**Solution:** Move the platen, not the type carrier, between type groups, using a changeover frame in which the platen frame is locked at positions by spring hooks.

**How it works:** The platen frame slides in a changeover frame and is held by spring hooks in holes at two positions. That frame sits in a further frame that gives the usual case shift by roller and lever and the letter-space movement. Racks and gears keep the platen frame parallel and unjammed. Pressing a handle swings the hooks out so the platen is pushed down until the hooks snap into the second holes, bringing a second group on the type carrier (e.g. Russian beside German) to the print point. Case shift within each group works as usual.
