## Summary

**Category:** related office machine, not a typewriter (printing unit for calculating machines) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing having type hammers

**In Google’s translation of the patent’s own words:** The invention relates to a printing unit especially for calculating machines where type rails are used to place on a to write paper held against a cylindrical platen.

**How it works (reading):** Two-part type rails whose types are interleaved (the second rail passes through the first) so that more types fit on one rail without increasing the adjustment travel; each rail is set by its own drive segment and stop.

## Reading (short summary from the opening, OCR fair)

**Problem:** Types on a type rail sit close together, so adjustment is limited; more types per rail are needed for currencies with bases above ten, but widening the adjustment range would make inked types contaminate the paper.

**Solution:** Two-part type rails whose types are interleaved (the second rail passes through the first) so that more types fit on one rail without increasing the adjustment travel; each rail is set by its own drive segment and stop.

**How it works:** Stop rails are positioned by amount keys and drive segments; the two interleaved type rails are set differently, and hammers throw the set rail against the platen.
