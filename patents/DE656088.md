> Description Translated from German The present invention relates to type printing telegraph apparatus such as those in particular are used in stock exchange operations, in which the imprint takes place in two different rows, so that the letters in one row and the numbers in the row below. In the case of such apparatuses one initially worked with the five-letter alphabet, i. H. it five individual types were used for transmission for the lower and the upper type group Drawing elements used, so that when printing each symbol it was necessary to just like in the normal telegraph operation, to send a shift character as soon as should be passed from one type group to the other. This shift character However, it has a very disadvantageous effect, especially when it comes to stock exchange operations, as there is a frequent change between the individual type groups is required. In order to shorten the time required for the transmission of the shift character, apparatuses have been built in which the character code, which normally consists of five character elements, is appended with an additional character element which effects the selection between letters and numbers.
