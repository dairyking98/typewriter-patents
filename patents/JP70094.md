## Reading (full text, OCR good)

**Problem:** Earlier machines using a rotary-cylinder type magazine took much floor area or needed types of special shape.

**Solution:** A cylindrical type magazine sits just under the paper cylinder (gap less than one type length); a lever locks the magazine and uncovers one type box, and the print key drives a lifter and striker that knock the plain type up against the paper cylinder, which turns a quarter turn for the blow.

**How it works:** The magazine of boxed types is turned by hand (small gear on internal teeth) to bring a box under the paper cylinder. Pressing a knob lever locks the magazine by a projection entering internal teeth and shifts a cover plate off that box. Pressing the print key swings a striker lever; a type lifter head first enters a hole in the box and raises the type a little while an ink roller is pushed across it. The striker end then hits a type-rising piece inside the lifter, which shoots up and drives the type onto the paper cylinder. The same key stroke turns the paper cylinder a quarter turn via levers and a sector disc, and on release a pawl advances the cylinder gear one tooth for letter spacing.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention relates to a printing machine in which the gap between the paper cylinder and a cylindrical type magazine is kept smaller than the length of a type. Working a lever pivoted on the magazine support fixes the magazine in any position and, at the same time, shifts a cover plate so that the type to be printed is free to rise. Pressing the print key then gives the paper cylinder a set amount of rotation and, at the same time, pushes the head of the type lifter into the type box, and the tip of the striker lever strikes the type-rising piece in the type lifter, so that the type is printed on the paper cylinder. Its object is a printing machine that takes up little floor area and needs no type of special shape. Brief description of the drawings.
