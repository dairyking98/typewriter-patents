## Reading (opening only, OCR fair)

**Problem:** Earlier electromagnetic type-stop devices needed extensive, costly changes when fitted to existing typewriters.

**Solution:** Use the machine's existing universal (stop) rail, carried along mechanically by the keys, as the contact breaker that closes the electromagnet circuit, so the magnet completes the type stroke after a light key tap.

**How it works:** Each key lever turns a driver on its type lever; a hook on the driver takes the common universal rail with it. A slight rotation moves the rail enough to close a breaker contact on the escapement shaft, energising an electromagnet whose core is hinged to the rail. The magnet then moves the rail further, which through the driver tip throws the type lever against the platen and triggers the escapement. The contact opens again at the end of rail travel. A removable common stop limits key travel so the typist taps lightly, or can be removed for normal writing.
