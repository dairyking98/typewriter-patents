## Reading (opening only, OCR fair)

**Problem:** Line spacing, carriage return and underscoring need separate hand actions on a Blickensderfer-type machine.

**Solution:** A pawl carrier on the platen shaft is cammed by the carriage return so the paper line-spaces itself, plus a ruling device for underscoring.

**How it works:** A pawl pivoted on a plate concentric with the platen ratchet carries an anti-friction roller. As the carriage returns, the roller runs up an inclined cam on the frame and the pawl turns the ratchet to feed one line. Limit faces on the plate and a limiting screw set how far it moves. On the next printing stroke to the left the pawl leaves the cam and a spring returns it. Lifting the pawl arm by hand gives double spacing. Ruling devices and a feed cam draw lines on the paper.

**Features:** [ESC:carriage-return](../features/esc-carriage-return.md), [PAP:line-space](../features/pap-line-space.md), [PAP:platen-roller](../features/pap-platen-roller.md), [ESC:pawl-rack](../features/esc-pawl-rack.md)

**Parts:** pawl; pawl carrier plate; platen ratchet; cam plate; limiting screw; return spring; hand wheel; ruling device; feed cam

**Improves on:**

- US459093 Blickensderfer: adds automatic line feed on carriage return and ruling
