## Reading (opening only, OCR fair)

**Problem:** Electromagnet-driven typewriters were too slow and unreliable compared with motor-driven ones because the armature return takes time.

**Solution:** One shared electromagnet drives all type levers; each type lever has a rigid segment extension acting as the armature, so only a light mass moves.

**How it works:** Pressing a key lever lifts the type lever slightly via a push pawl so its segment extension enters the field of the pole piece of an already excited magnet, which pulls it in and accelerates the type lever. At the end of the stroke a nose on the type lever knocks a bracket on a leaf spring and opens the coil contact, so the lever can fly on to the platen unhindered. The vibrating contact arm lags in phase so the segment passes the pole piece freely on return. The lever returns by its own weight, rebound and a spring, with no return spring.
