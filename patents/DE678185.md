> Description Translated from German Typewriter, type printer or the like with electric drive all Type carrier by a single electromagnet The invention relates to a typewriter, a type printer or the like, in which a single electromagnet for all type carriers together form the drive. Electric drives for typewriters and the like are known. So far, only the motor-driven arrangements have been able to prevail despite their complicated structure, since they work relatively quickly and reliably compared to the types with magnetic drive. The simple electromagnet requires a certain time between two successive current surges during which its armature returns to the rest position under the influence of a restoring force. As a result of the relatively large masses to be moved, the reset time is not short enough. The aim of the invention is to achieve a solution — the object of using electromagnets to create a drive that works quickly enough and reliably.
