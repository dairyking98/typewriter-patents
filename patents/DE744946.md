**In Google’s translation of the patent’s own words:** The invention relates to a through Business machine controlled by counting cards with a noting printing mechanism and intended to contribute Use of type carriers with types lying one behind the other in a row, the are assigned to several different groups which enforce one another, d.

**How it works (reading):** Each card hole couples the type carrier to the drive and selects the type group in two stages, using overhole zones to print several type groups in one line.

## Reading (short summary from the opening, OCR poor)

**Problem:** Card-controlled printing needs type groups that can be selected without a long sensing motion.

**Solution:** Each card hole couples the type carrier to the drive and selects the type group in two stages, using overhole zones to print several type groups in one line.
