## Reading (opening only, OCR fair)

**Problem:** Operators slap the carriage back hard, damaging it, and return speed varies.

**Solution:** Carriage is tensioned by a spring via a bell crank and moves forward under escapement control; a key flips the spring tension to return it at constant speed.

**How it works:** The carriage rack drives a gear train to an arc rack on a bell crank lever. A spring pulls a rolling frame/pin on the lever, tending to drive the carriage forward under the escapement. Pressing a key moves the rolling frame to the lever's other end, reversing the tension so the carriage returns freely under spring force. On key release a return spring restores forward tension.

**Features:** [ESC:spring-drum](../features/esc-spring-drum.md), [ESC:carriage-return](../features/esc-carriage-return.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** carriage; rack; gear; arc rack; bell crank lever; spring; rolling frame; key

**Improves on:**
