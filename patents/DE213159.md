## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Key levers slotted on a rod push the type levers to the paper roller, and the type-lever frame is removable so frames for other languages can be exchanged.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type-lever machines tie the paper carriage switching to the type levers, so the type frame cannot be removed simply.

**Solution:** Key levers slotted on a rod push the type levers to the paper roller, and the type-lever frame is removable so frames for other languages can be exchanged.
