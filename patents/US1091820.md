## Reading (short summary from the opening, OCR poor)

**Problem:** The register wheels turn before the number is checked, and the operator cannot inspect the typed number before adding.

**Solution:** An arrangement that delays register turning until a number is set, so the operator can check the written number before it is added.

**How it works:** Register drive is held until a number is set and checked, then the addition is made.

**Features:** [USE:calculating](../features/use-calculating.md), [FRM:writing-visible](../features/frm-writing-visible.md)
