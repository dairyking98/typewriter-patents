## Reading (full text, OCR good)

**Problem:** Japanese typewriters with type cases need separate print levers for spare types and a separate space bar, making them complex and heavy.

**Solution:** Pivot a main and an auxiliary printing lever side by side so the main lifts the type case and the auxiliary prints, feeds, and handles spare types alone.

**How it works:** A cylindrical magazine of type cases is turned or slid by a handle until the wanted character is at an indicator rod. Pressing the main-lever handle drags the auxiliary lever down too; the main lever lifts the case through a cam lever and rod so its row of types protrudes. The auxiliary lever swings a piece for the first stage of sideways platen feed and, through bent levers and a cord, turns an arm whose striker hits the rear of the protruding type. Releasing lets a spring return everything and complete the feed. For a spare type held in a socket on the printing piece, pressing only the auxiliary handle prints and feeds without lifting a case.

## Description (English translation of the Japanese text, opening)

> Japanese-script typewriter. Nature and object of the invention. The invention relates to a Japanese-script typewriter in which a main and an auxiliary printing lever are set side by side and pivoted on one side of the frame; the rear end of the auxiliary lever engages so as to hold the lower side of the main lever; a spring fitted to the auxiliary lever keeps both levers suspended; the main lever is linked to the mechanism that pushes up a type case, and the auxiliary lever to the sideways-feed mechanism and to the printing mechanism for both the types in the cases and spare types. The object is a Japanese-script typewriter that prints both the types in the cases and spare types easily, with a simple, light mechanism, and is easy to work. Brief description of the drawings.
