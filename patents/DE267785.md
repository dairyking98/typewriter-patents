## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary type mechanisms for printing distinguishing marks, e.g. for accenting, using dead or half-dead key arrangements, for printing marks in telegraph printers to indicate that machine is receiving

**In Google’s translation of the patent’s own words:** The invention relates to a device for writing accents and changing the type lever for typewriters in which the type lever has a universal rail with a move the switch frame, the switch lock and the ribbon fork, and at which the type levers mounted in a common segment are slit and from the universal rail against unintentional ίο- lifting off the common bearing rod be kept secure.

**How it works (reading):** The switch frame is mounted adjustably on a rocker so that when an accent key is pressed its stop evades the switch-lock stop; the type levers are slit so the universal rail is kept from lifting off the bearing rod.

## Reading (short summary from the opening, OCR fair)

**Problem:** Accent writing and removing type levers each need extra intermediate links or releases.

**Solution:** The switch frame is mounted adjustably on a rocker so that when an accent key is pressed its stop evades the switch-lock stop; the type levers are slit so the universal rail is kept from lifting off the bearing rod.
