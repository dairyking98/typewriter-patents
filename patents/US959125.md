## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Bearings with rolling contact, for exclusively rotary movement with bearing balls essentially of the same size in one or more circular rows for both radial and axial load with a single row of balls with angular contact

**In the patent’s own words:** This invention relates to type bar bearings of writing machines;

**How it works (reading):** A ball bearing joint at the bearing end of each type bar, carried in a narrow hanger secured to the segment, allows many bars to be spaced closely.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type bar pivots need a narrow, dust-proof bearing so many bars fit in a small space on the segment.

**Solution:** A ball bearing joint at the bearing end of each type bar, carried in a narrow hanger secured to the segment, allows many bars to be spaced closely.

**Parts:** type bar; type block; hanger; supporting segment; set screw; returning spring; ball bearing
