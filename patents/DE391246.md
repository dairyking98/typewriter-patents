## Summary

**Category:** related office machine, not a typewriter (calculating and typewriter compound machine)

**In Google’s translation of the patent’s own words:** The invention relates to a computer and a typewriter compound machine, in which the calculating machine after putting on the typewriter on the former can be operated by the latter.

**How it works (reading):** The typewriter is combined with a multiplication machine so that its tab keys set the decimal places and number keys, letting the typewriter multiply with no added connection and then type on normally.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adding a typewriter to a calculating machine for multiplication needed special attachments and adjustments on both machines before use.

**Solution:** The typewriter is combined with a multiplication machine so that its tab keys set the decimal places and number keys, letting the typewriter multiply with no added connection and then type on normally.
