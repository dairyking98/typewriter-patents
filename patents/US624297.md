## Reading (opening only, OCR poor)

**Problem:** The carriage escapement should feed on the key return stroke and the carriage should return automatically near the line end.

**Solution:** Key-driven pawl and spring feed with a stop pawl, plus a sliding plate and hook that release the pawls near the line end so the carriage-return spring acts.

**How it works:** A key lever depression tensions a spring and moves a pawl past a ratchet wheel; the spring then drives the pawl upward on key release to feed the carriage one tooth. A stop pawl linked to the keys releases a stop wheel briefly to prevent overtravel. A pin on the carriage moves a plate with a hook so, two letters before the end, the next key stroke engages a shaft arm that lifts both pawls, freeing the return spring.
