## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** The invention relates to improvements in the type bar action and the parts immediately connected therewith.

**How it works (reading):** Type bars pivot on a single curved rod in a segmental type basket and strike a common printing point; each type bar heel carries a variable gear meshing with a rock lever, pivoted on a common rod, so the bar moves in a controlled way.
