## Description (Google Patents OCR, opening)

> Description Translated from German Jumper arrangement for typewriters. Subject of the invention is a jumper arrangement for typewriters and the like Way, an oscillating shaft mounted on a fixed part of the machine is provided, to which the actual switching bridge can be adjusted in a vertical direction. The purpose of the invention is to provide a jumper arrangement to design this type so that the production is significantly simplified and in particular the entire switching bridge arrangement before being introduced into the machine can be set correctly. These advantages are achieved according to the invention in the new switching bridge arrangement primarily achieved by the fact that in the same the oscillating shaft, even perpendicular unadjustable to its axial direction, in longitudinally adjustable bearing mandrels known per se is mounted between approaches of the type lever support web, and the facilities for setting the switching ring in the latter parts connecting with the shaft are arranged.
