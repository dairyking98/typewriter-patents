## Reading (opening only, OCR fair)

**Problem:** Automatic punched-tape typewriters set and print one character at a time, which is slow.

**Solution:** Six-row punched tape gives binary values (1,2,4,8,16,32); each type carrier is coupled to a common mover for partial movements adding to its position, and the whole line is set and printed at once.

**How it works:** Each hole pattern sums to a value up to 63. Type carriers (type wheels or bars) take part, by coupling, in the partial movements of sizes 32, 16, 8, 4, 2, 1 executed in order by a common organ, so each ends at its own position. Pneumatic control mechanism is mentioned. The full line is then printed together.

**Features:** [ELEM:interchangeable](../features/elem-interchangeable.md), [USE:telegraph-printer](../features/use-telegraph-printer.md), [SEL:differential-drive](../features/sel-differential-drive.md)

**Parts:** punched tape; type wheel; type bar; common drive organ; coupling; pneumatic control

**Numbers:** 6 hole rows; 63 combinations; values 1,2,4,8,16,32
