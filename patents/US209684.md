## Reading (full text, OCR good)

**Problem:** A simple, compact typewriter small enough for the pocket, easily used with little practice, in place of the expensive complicated machines of the time.

**Solution:** A hand-turned cylindrical table holding one spring-returned plunger type per letter in a circle is rotated until the letter is under a single press pin, which pushes the type down onto the paper; the whole frame is then racked forward one space.

**How it works:** A cylindrical table with a ring of vertical holes carries one sliding type plunger per letter (and figures 1-9 if wanted), each held up by a spiral spring. The table turns on a centre standard through an outer cog wheel and bevel pinion with an end button; letters on the cog wheel top are marked radially to the holes, so the wanted letter is set under a fixed vertical pin with a button. Pressing the button pushes that plunger down so its lower end prints on paper lying on a stationary block. Tapered ink rollers on the centre standard ink the type faces below the table, and pressing down the standard lowers them clear so the table can spin without taking ink; they are charged from a distributing table. Four corner-post pinions on racks of the base frame move the whole apparatus one letter space after each print, and the paper is moved sideways by hand between lines.
