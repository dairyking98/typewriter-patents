> Description Translated from German Type lever drive for typewriters is the subject of the invention a type lever drive for typewriters, in which in a known manner on a Fixed axis, pin or the like. Mounted type lever by one and the same drive is guided swinging and pushing against the platen. In the previously known type lever drives, in which the on one stationary axis mounted type lever swinging and pushing against the platen was carried out, several levers were arranged on the type lever that form the type lever set in the swinging and pushing motion. This created a lot of space needed and the masses to be moved were relatively large, the stop of the The machine was therefore a heavy one and the machine did not run smoothly. The main part of the type lever drives of the type mentioned above was but that the thrusting movement was not a decidedly straight one, because that Type lever was guided by pivoting about an axis against the platen; the result was a blurring of the writing.
