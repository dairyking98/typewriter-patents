**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**How it works (reading):** A barrier segment, moved into the path of the type bars by a link from the tabulator stop, blocks any type bar whose key is struck.

## Reading (short summary from the opening, OCR fair)

**Problem:** When a carriage is jumped to a new column, type bars must not reach the printing point until the carriage is arrested.

**Solution:** A barrier segment, moved into the path of the type bars by a link from the tabulator stop, blocks any type bar whose key is struck.
