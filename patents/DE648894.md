## Summary

**Category:** related office machine, not a typewriter (touch board for die setting machines) · **Subject (patent classes):** Keyboards

**In Google’s translation of the patent’s own words:** The invention relates to the touchpad of dies of die setting and line casting machines;

**How it works (reading):** Keys that trigger partial matrices also carry the full character, with the part that triggers the matrix marked, often by colour, so the operator can see which part each key contributes.

## Reading (short summary from the opening, OCR good)

**Problem:** Matrix keyboards with too few keys for Hebrew and similar scripts force the operator to join partial character keys in memory, which is slow and error-prone.

**Solution:** Keys that trigger partial matrices also carry the full character, with the part that triggers the matrix marked, often by colour, so the operator can see which part each key contributes.
