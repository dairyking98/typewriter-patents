## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Regulating touch, key dip or stroke, or the like

**In Google’s translation of the patent’s own words:** The invention relates to a device for changing tension the return springs on typewriters, especially power-driven typewriters or similar machines in which the tension exerted by the return springs must be overcome by the finger pressure to be carried out by the writer.

**How it works (reading):** Return springs attach at anchor points in groups, with one adjustable point per group, so spring tension can be set to the key pressure wanted.

## Reading (short summary from the opening, OCR fair)

**Problem:** On powered typewriters the key touch feels too light for an operator used to hand machines.

**Solution:** Return springs attach at anchor points in groups, with one adjustable point per group, so spring tension can be set to the key pressure wanted.
