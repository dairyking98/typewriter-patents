## Summary

**Category:** related office machine, not a typewriter (simultaneous printing of several type wheels) · **Subject (patent classes):** Arrangements thereof of more than one hammer, e.g. one for each character position

**How it works (reading):** A thin hard sheet steel layer, about 0.05 mm, is placed under the common rigid hammer so it conforms to each type, and it keeps the types from sinking into the rubber. Steel plates vulcanized to rubber are an alternative.

## Reading (short summary from the opening, OCR good)

**Problem:** A rigid print hammer over several type wheels hits only the highest type because of tolerances, while a soft rubber hammer digs into the type, wears fast and wastes travel.

**Solution:** A thin hard sheet steel layer, about 0.05 mm, is placed under the common rigid hammer so it conforms to each type, and it keeps the types from sinking into the rubber. Steel plates vulcanized to rubber are an alternative.
