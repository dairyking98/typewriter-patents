## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Side-stop mechanisms

**How it works (reading):** Each margin block carries an extra spring button that engages the rack, so the teeth seat in a tooth gap at the end of each adjustment and the block locks in place.

## Reading (short summary from the opening, OCR fair)

**Problem:** Margin-setting blocks on the typewriter can end up with their teeth misaligned with the rack, so they do not lock and get damaged.

**Solution:** Each margin block carries an extra spring button that engages the rack, so the teeth seat in a tooth gap at the end of each adjustment and the block locks in place.
