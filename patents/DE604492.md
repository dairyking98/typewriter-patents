## Reading (opening only, OCR fair)

**Problem:** In power typewriters with calculators, a separate drive for the number types could print amounts that were never properly entered in the counter.

**Solution:** One drive part moves out to set the counter and back to drive the number type, so printing can only follow counter setting.

**How it works:** A continuously running motor turns cams that single-turn clutches couple on key press. A spring-loaded drive lever first moves out of rest, setting the counter. A clutch engages only during the lever's return movement to rest, which drives the number type lever for a strong impression. The cam is held against the reaction of the spring pawls by an inclined surface on the cam attachment, avoiding rattle and wear.
