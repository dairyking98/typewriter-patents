> Description Translated from German There are writing calculating machines known in which the printing of the types takes place in that a platen, over which a strip of paper runs, beats on fixed types. The platen must naturally after each print can be switched on by one line width. This is done by means of a ratchet, which is mounted eccentrically to the pivot axis in known designs, an arrangement; which takes up too much space for the available space. To avoid this disadvantage, it is known, the pivot axis of the platen within the eccentric mounting of the pawl and thereby pawl and toothing keep in constant touch with the platen. Such an arrangement now has the serious disadvantage that the constant engagement of the pawl and return wheel does not allow the latter to be rotated backwards in the event of a correction is possible because it is prevented by the pawl. This disadvantage is like that serious that the construction afflicted with it no entry into practice has found.
