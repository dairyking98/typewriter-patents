## Reading (short summary from the opening, OCR fair)

**Problem:** A cash register cannot issue several checks of which some need different lengths or marks, since the check transport runs the same way every time.

**Solution:** The check transport path is split into several sections, each tied to a plunger movement, which can be switched on or off per operation so checks of different lengths and marks are issued.
