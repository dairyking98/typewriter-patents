## Reading (opening only, OCR fair)

**Problem:** Pawl and ratchet line spacing allows only fixed intervals, so ruled sheets need hand spacing by eye.

**Solution:** Add an auxiliary clutch-wheel line-space with an adjustable dog throw, selected by a shiftable tooth on the single line-space lever.

**How it works:** The usual ratchet wheel on the platen axle is driven by a pawl on a slide pushed by the line-space lever. A switch shifts the tooth so it instead operates a supplementary clutch wheel through a dog and transmission lever. The throw of the dog is set by an adjustable stop, giving any interval between lines. The same switch withdraws the spring detent from the ratchet. Shown on an Underwood front-strike machine.

**Features:** [PAP:line-space](../features/pap-line-space.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** platen axle; ratchet wheel; detent; slide; line-space lever; pawl; clutch wheel; dog; transmission lever; switch; adjustment stop

**Numbers:** 3 sheets of drawings

**Improves on:**

- pawl and ratchet line spacing: adds continuously variable line spacing
