## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection; Cylindrical Japanese-language typewriter

**In the English translation of the patent’s own words:** The first object is a device in which any type on a row of type wheels, mounted to turn on one shaft, can be brought to a fixed printing point by working a key, each wheel acting on its own, so that one or several wheels can be used in turn or at once.

**How it works (reading):** A row of independently turnable type wheels on one shaft, each turned by a toothed-rim key disc set eccentric to it, with a spring-driven paper table that runs to the turned wheel and stays there after printing, spacing by a row of spacer pieces.

## Reading (full text, OCR good)

**Problem:** To hold many types in small space and print one or several at once for any script, with light operation, the paper carrier moving as seldom and quietly as possible, and quiet printing.

**Solution:** A row of independently turnable type wheels on one shaft, each turned by a toothed-rim key disc set eccentric to it, with a spring-driven paper table that runs to the turned wheel and stays there after printing, spacing by a row of spacer pieces.

**How it works:** Each type wheel turns on an eccentric hub; a keyboard disc with tooth-shaped keys is eccentric to it and drives it by a pin in a radial slot. The operator pushes a key along a quadrant character table until its slope meets the table end, which brings the wanted type to the print point. Turning a wheel lifts a lever that sets a clutch, pushing the spring-driven sliding table to the wheel left or right, where combs and a brake wheel stop it. The print lever swings the paper roller with a printing plate onto the type, pushing it first sharply and then quietly through an arc slot, while an aligning plate enters valleys between types and the ribbon is lifted to the wheel face. The print lever also pushes a spacer forward for each character printed, returns the turned wheels by a toothed bar, winds the table-driving spiral spring, and advances the ribbon. Separate keys give line space with spacer reset and independent spacing.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention concerns a printing machine that holds a comparatively large number of types in a small space and can print one or several types at the same time; that can be used for most of the characters and signs of any language, whether phonetic or ideographic; and that is built so that every part can be worked lightly by simple means. The first object is a device in which any type on a row of type wheels, mounted to turn on one shaft, can be brought to a fixed printing point by working a key, each wheel acting on its own, so that one or several wheels can be used in turn or at once. The second object is a device in which the paper carrier, which slides parallel to the axis of the type wheels, moves by itself to the place of a wheel as soon as that wheel is turned; and in which, after the print lever has been worked and the character printed, the carrier does not go straight back to its starting point but stays in front of that wheel, and when another wheel is turned moves from there to the place of that second wheel and prints.
