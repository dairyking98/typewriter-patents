## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters for ciphering or deciphering cryptographic text wherein the operative connections between the keys and the type-bars are automatically and continuously permuted, during operation, by a coding or key member the connections being mechanical

**How it works (reading):** Two type cylinders set by one pointer over two letter tables, one fixed and one an endless band indexed after each stroke, so each plain letter prints with a changing cipher letter beside it.

## Reading (opening only, OCR good)

**Problem:** Earlier cipher typewriters with two type cylinders on one axle had a cumbersome set-up needing a switching device adjusted each time.

**Solution:** Two type cylinders set by one pointer over two letter tables, one fixed and one an endless band indexed after each stroke, so each plain letter prints with a changing cipher letter beside it.

**How it works:** A pointer over the fixed table (and the movable band table beneath it) positions two type cylinders on a hollow shaft via a rack and gear. The key lever prints both cylinders at once, plain text and cipher. The cipher cylinder and band are turned by a pawl and a notched disc whose cuts have different depths, so each stroke advances them by a varying amount.
