## Reading (opening only, OCR fair)

**Problem:** Stenography normally needs special signs requiring initiation to write and read.

**Solution:** A chord keyboard strikes several keys at once, each group on its own printing point, to print whole syllables phonetically in ordinary letters.

**How it works:** A complete keyboard with two to four type-carrying hammers, each group having its own printing point, hits a ribbon with an inking device. Levers connect keys to the hammers, so striking several keys together prints all the phonetic elements of a syllable on one line. Keyboard layouts for two hands and for one hand are shown, tied to the language used. Opening only.

**Features:** [USE:stenotype](../features/use-stenotype.md), [IMP:hammer-behind](../features/imp-hammer-behind.md), [INK:ribbon](../features/ink-ribbon.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** keyboard; type hammer; key lever; printing ribbon; inking device

**Numbers:** 2 to 4 hammers

**Improves on:**

- signed shorthand: prints phonetic syllables in plain letters
