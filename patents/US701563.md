## Reading (opening only, OCR good)

**Problem:** A keyboard has one alphabet per key; changing character sets requires changing keys.

**Solution:** Each key is a body with several faces on pivots, turned to expose another character and held by a leaf spring.

**How it works:** A multi-faced key body has pintles in a bracket fixed on a post that clamps to the key lever. A thin leaf spring loop bears on the concave underside of the key body and locks it in each position; turning the key presses the spring down until the corner passes, then the spring completes the turn and locks it. Keys can be struck slightly off-centre, rocking against the spring. Turning every key changes the alphabet on the keyboard.
