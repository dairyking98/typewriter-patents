## Reading (short summary from the opening, OCR fair)

**Problem:** Known carriage-retraction devices using a key, spring capsule and cord pulley are complicated.

**Solution:** An angle-shaped key lever acts directly on the spring capsule, releasing it on descent, so a cord disc couples to the capsule on return and retracts the carriage.

**Features:** [Carriage return](../features/esc-carriage-return.md), [Mainspring-drawn carriage](../features/esc-spring-drum.md)

**Parts:** spring capsule; cord pulley; angle key lever; pawls; shaft
