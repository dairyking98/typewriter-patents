## Description (Google Patents OCR, opening)

> Description Translated from German Type body for typewriters with recessed diagonally at the ends End faces and gauge for aligning such type bodies To type bodies for typewriters when soldering to align with the type levers or rods that hold them, reference marks are used, which are exactly the same in every set of type bodies Be spaced from the baseline. Such alignment marks exist in known type bodies from recesses or from wedge-shaped or conical projections. Recessed guidelines are inferior to the raised directing marks because their production in the Embossing die requires sharp-edged protrusions that wear easily. Raised alignment marks on the type bodies must be removed after soldering. -The The invention relates to a type body with a Richtmal which does not suffer from these deficiencies. This is achieved by dividing the straightening mark into two straightening surfaces, so to speak that are located at both ends of the type body. Accordingly, the type body contains at the ends inclined faces, which together with in the plane of the type body or form the guiding mark parallel to this straightening surface.
