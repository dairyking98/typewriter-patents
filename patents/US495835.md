## Reading (short summary from the opening, OCR fair)

**Problem:** Matrix forming needs independent type dies and correct spacing, which the older machines do not give.

**Solution:** A matrix-making machine in which a lever carries type dies that are impressed one at a time, with space-throwing keys and electric contacts that set the spacing between impressions.

**Features:** [Separate type slugs or plungers](../features/elem-individual-slugs.md), [Space key or bar](../features/esc-space-key.md)
