> Description Translated from German Adjustment device for the return spring of the universal rail from Typewriters The invention relates to an adjustment device for the return spring the universal rail of typewriters guided by handlebars, by means of which the Tension of the spring and thus the resistance to finger pressure when it hits of the keys adjustable according to the wishes of the typewriter operator is. There are typewriters known in which the return spring with a End on the universal rail and the other end on a fixed machine frame arranged member acts, which is set by means of a tool in its position can be. In contrast, the invention relates to such typewriters, in which the return spring acts with one end each on a link and at Pivoting the universal rail is tensioned. This arrangement of the return spring has the particular advantage that the moving parts are always in the correct position Position to each other and thus secured against loosening and rattling are.
