## Reading (short summary from the opening, OCR fair)

**Problem:** The return spring tension of the universal rail cannot be changed without moving the handlebars too.

**Solution:** The return spring attaches to an intermediate member on the link and is set by an adjusting shaft with a pinion from the outside, so spring tension changes without moving the bar.

There are typewriters known in which the return spring with a End on the universal rail and the other end on a fixed machine frame arranged member acts, which is set by means of a tool in its position can be. In contrast, the invention relates to such typewriters, in which the return spring acts with one end each on a link and at Pivoting the universal rail is tensioned. This arrangement of the return spring has the particular advantage that the moving parts are always in the correct position Position to each other and thus secured against loosening and rattling are.
