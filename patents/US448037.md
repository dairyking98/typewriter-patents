## Reading (opening only, OCR fair)

**Problem:** Typewriters should be simpler, and each letter should get space proportional to its width (i narrower than n, n narrower than m).

**Solution:** A typebar machine with shifting case in which key levers act through intermediate levers, giving proportional letter spacing.

**How it works:** Stamped sheet-metal key levers each have two platforms, one for a lower-case and one for an upper-case character, and act on intermediate levers that drive the type levers, which pivot on rails. A case-changing key selects which font the key levers act on. The spacing step is varied per character according to the width of the type.

**Features:** [Typebars](../features/elem-typebar.md), [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md), [Shift by moving the platen](../features/shift-platen.md), [Proportional spacing](../features/esc-variable-spacing.md), [How the element is made](../features/elem-element-construction.md)

**Parts:** key lever; intermediate lever; type lever; rail; case-changing key; stationary frame; platform; guide wing
