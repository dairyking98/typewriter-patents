**How it works (reading):** Angle levers in each key row sit on a common straight axis and tie rods attach directly to the type levers, with all articulation points in one straight line so every key gets the same power transmission.

## Reading (short summary from the opening, OCR fair)

**Problem:** Key-to-typebar linkage uses angle levers of differing arm lengths and tie rods at varying inclinations, costly to make and hard to build.

**Solution:** Angle levers in each key row sit on a common straight axis and tie rods attach directly to the type levers, with all articulation points in one straight line so every key gets the same power transmission.
