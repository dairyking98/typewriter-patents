## Summary

**Category:** related office machine, not a typewriter (note sensor for cash registers)

**How it works (reading):** Switching off the receipt printer in idle state withdraws the protruding note sensors from the document guide and holds them ineffective.

## Reading (short summary from the opening, OCR fair)

**Problem:** A cash register's note sensor moves through the document guide on each release, and switching it off needs an extra stop.

**Solution:** Switching off the receipt printer in idle state withdraws the protruding note sensors from the document guide and holds them ineffective.

To switch off the note sensor, a stop must be brought into the effective position that only allows a partial movement of the note sensor. This facility is Inexpedient for the reason that there is always a movement of the note feeler takes place. This disadvantage is avoided by the invention. It consists in that by switching off the receipt printer in the idle state of the machine in Note sensors protruding into the document guide are removed from the document guide and inserted into the ineffective position is held.
