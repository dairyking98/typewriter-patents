## Summary

**Kind:** a part or mechanism (any kind of machine)

**How it works (reading):** Coupling is timed while the camshaft peripheral speed turns from perpendicular to parallel to the pull direction, so the pull element is accelerated gradually.

## Reading (short summary from the opening, OCR fair)

**Problem:** On power-drive machines the pull element coupled at peak shaft speed, causing sudden impact.

**Solution:** Coupling is timed while the camshaft peripheral speed turns from perpendicular to parallel to the pull direction, so the pull element is accelerated gradually.
