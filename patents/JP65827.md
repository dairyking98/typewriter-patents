## Reading (full text, OCR good)

**Problem:** On existing Japanese typewriters the operator must slide the paper cylinder to the next line and turn it back to the start position by hand after each line.

**Solution:** A spring urges the cylinder frame to slide sideways, a stop disc holds it, and at the end of a line the stop is released so the frame moves one line space while gearing also turns the cylinder back to the start of the next line.

**How it works:** The cylinder frame slides on rails, and a rack on the base turns a spring case through a gear as it moves, winding a spring when the cylinder is drawn left. Bevel gears pass the spring case motion through a pawl and ratchet to the cylinder so rightward travel turns it but pulling left does not. A notched stop disc on a cross shaft holds the frame against the spring; each print key stroke advances the shaft one tooth with a feed pawl until the notch reaches the rack and the frame is released. A worm and gear on the cross shaft set the free travel, which equals the line spacing, and a screw adjusts it. A lever lifts the rack out of mesh to return the cylinder by hand.

## Description (English translation of the Japanese text, opening)

> Specification. Continuous printing device for a Japanese-text typewriter. Nature and object of the invention. This invention relates to a continuous printing device for a Japanese-text typewriter of the kind that prints one character at a time in succession in the direction in which the paper cylinder turns, constructed so that every time a line has been printed the cylinder is sent automatically to the position for the first character of the next line. Its object is to do away with the troublesome work, seen in existing Japanese typewriters, of moving the cylinder to the next line when a line has been printed and at the same time turning the cylinder back to the starting position; when the last character of a line has been printed, the first printing point of the next line is brought into position automatically, so as to increase the printing speed.
