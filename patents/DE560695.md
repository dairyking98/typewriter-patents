## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter with type levers in a segment are mounted to oscillate and when a key lever is depressed, an oscillating movement run in a substantially horizontal position in front of the roller, whereupon they are common to all type levers, in the center of the type lever segment arranged and brought into effect when the button lever is further depressed pressed against the platen.

**How it works (reading):** Each type lever swings to a horizontal position in front of the platen and carries a sliding type block, which a common pressure member in the segment centre then pushes straight against the platen.

## Reading (opening only, OCR fair)

**Problem:** Getting a sharp impression normally requires the type to travel in a straight line to the platen, which makes type drive and pressure linkages complicated.

**Solution:** Each type lever swings to a horizontal position in front of the platen and carries a sliding type block, which a common pressure member in the segment centre then pushes straight against the platen.

**How it works:** Key levers pull rods, with an adjustable buffer spring, that swing weighted type carriers from the segment up to a horizontal position in front of the roller, extending a knee joint with a cushioned stop. Further key travel brings a common pressure device into play, which pushes the sliding type block on the stationary carrier head against the platen. The writing remains visible.
