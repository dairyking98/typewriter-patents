## Summary

**Category:** related office machine, not a typewriter (line setting device for registers and booking machines) · **Subject (patent classes):** Output mechanisms with visual indication, e.g. counter drum

**How it works (reading):** A control pawl is kept in engagement with the rack while the machine cycles, driven by a control disc on a shaft set by the keyboard, so the table does not advance during those strokes.

## Reading (short summary from the opening, OCR fair)

**Problem:** The automatic line advance of a cash register printing table cannot be stopped during a series of machine strokes that print on the same line, so repeated entries land on the next line.

**Solution:** A control pawl is kept in engagement with the rack while the machine cycles, driven by a control disc on a shaft set by the keyboard, so the table does not advance during those strokes.
