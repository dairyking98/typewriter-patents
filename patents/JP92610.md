**In the English translation of the patent’s own words:** The object is a handy type-setting stamp machine that transfers the types for printing an amount or number of the required number of digits automatically into a stamp holder, and after use takes the types apart again automatically.

## Reading (full text, OCR good)

**Problem:** Setting the types for an amount or number into a hand stamp is slow when done type by type; a machine should set any amount or serial number in the stamp automatically and take the types apart again afterwards.

**Solution:** A row of identical arc-shaped type frames, one per digit position, each turned by a space-advancing sliding piece driven from control levers so the chosen type comes to the top, then all pushed together into a stamp holder.

**How it works:** Fourteen identical arc frames (1) turn loosely side by side on a horizontal shaft (3), each carrying radial type cups with types face down. Tipping a character's control lever swings elbow plates and elbow arms (6)(7) through a set angle; a sliding piece (9) on a guide bar (8) pushes the hook (4-3) of one frame's elbow and turns that frame so the wanted type is at the top, where a pawl (10) on its ratchet teeth holds it. On return the sliding piece creeps forward and a guide piece (11) makes it advance exactly one frame space, so the next lever press sets the next digit. When the row is set, pressing a rack bar (38) lifts a beam of push rods (34) that push the types up through the cups into clips (40) of a stamp holder (43) above. After use a push-down plate returns the types; pushing a vertical rod (23) releases all pawls and lays down the guide pieces so springs return the frames, and a pull rod (31) draws the sliding piece back to the start.

## Description (English translation of the Japanese text, opening)

> Specification. Automatic type-setting stamp machine. Nature and object of the invention. In this invention, identical arc-shaped type-carrier frames, as many as there are characters in the largest amount of money or number of the required number of digits, are pivoted side by side horizontally. In type cups set radially round the rim of each frame the required types are seated face down, so that they can come out. On a horizontal guide bar that moves about the axis of the frames, one sliding piece is mounted so that it can slide; with it, the tip of a bent elbow projecting below the axis from the lower part of a frame is pushed, turning the frame. When the type lying at the corresponding angle has been carried up to the topmost position, one of a row of stop pawls holds the frame there. As the sliding piece returns to its starting position and leaves the tip of the bent elbow, it creeps forward a little along the horizontal guide bar, and just before it is back it touches one of a row of guide pieces, spaced like the arc frames, and so moves fully forward by one space.
