## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Locking devices applied to printing mechanisms and automatically actuated by completion of a page or predetermined number of lines or exhaustion of paper to lock the keyboard

**How it works (reading):** An attachment added to an existing machine warns the operator as the page bottom nears the printing point, and then locks parts of the machine when it reaches a set position relative to the printing centre.

## Reading (short summary from the opening, OCR fair)

**Problem:** Operators write too far down the page, and the platen is damaged when the paper edge passes the printing point.

**Solution:** An attachment added to an existing machine warns the operator as the page bottom nears the printing point, and then locks parts of the machine when it reaches a set position relative to the printing centre.

**Features:**

- **Spacing and escapement:** [Margin stops](../features/esc-margin-stop.md)
- **Paper and carriage:** [Roller platen](../features/pap-platen-roller.md)
