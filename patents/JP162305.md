## Reading (full text, OCR good)

**Problem:** On a Japanese typewriter, European letters held in the type magazine have different widths but the platen feed is the same, so letter gaps vary.

**Solution:** A limiter of different height beside each type cell stops a riser at a height set by the picked type's width, which sets how many teeth the platen feed works.

**How it works:** Pressing the printing key lifts the type-lifting rod and picks a type from its cell in the magazine. The same key movement releases a stop plate so spring-loaded movable frames rise until the riser beside the lifting rod meets the underside of the limiter fixed beside that cell. The height reached pushes up a rack bar, which turns a gear that decides the platen feed for that character. After printing, a spring-driven cam on a cam shaft, released by an anchor, turns once and returns the frames and rack bar. A change-over shaft disengages the system for Japanese text, and special types cast with the letter left-aligned in the matrix are used.
