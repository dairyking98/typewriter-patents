## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Type

**In the patent’s own words:** The object of this invention is to provide means whereby type-writing machines can be used to produce type-writing in what is known as the Arabic alphabet, which includes the characters usually employed in Hindustani, Persian, and other oriental and African languages, and also to facilitate printing in such languages by the printing-press.

**How it works (reading):** Arabic alphabet with all types of equal base width, joined on one common horizontal line, with initial and medial forms merged.

## Reading (opening only, OCR good)

**Problem:** Arabic letters vary in base width and join on differing lines, which blocks typewriting.

**Solution:** Arabic alphabet with all types of equal base width, joined on one common horizontal line, with initial and medial forms merged.

**How it works:** All type are struck from equal blocks, final letters on a shifted key. The machine's motion is reversed, as Arabic goes right to left, so lateral movement is equal for all characters. There are 32 keys in four rows for Arabic, 4 more for Persian, 8 more for Hindustani.

**Features:**

- **Type element:** [Metal type](../features/elem-metal-type.md)
- **Uses:** [Special scripts and characters](../features/use-special-script.md)

**Parts:** type; key; shift key

**Numbers:** 32 keys in 4 rows; +4 for Persian; +8 for Hindustani
