## Reading (short summary from the opening, OCR fair)

**Problem:** A machine must be changed in several places to write a right-to-left language such as Arabic instead of English.

**Solution:** Carriage feeding and return mechanism, with line spacing driven from the carriage-return mechanism on the main frame, that can be geared for either writing direction with minimal change.

**Features:**

- **Spacing and escapement:** [Carriage return](../features/esc-carriage-return.md)
- **Uses:** [Special scripts and characters](../features/use-special-script.md)
