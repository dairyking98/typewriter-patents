## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to typewriters "of the kind in which the Type lever carrier is removable and this includes the type lever, button lever and the associated mechanism, so that then another type lever carrier for a other font or language can be used.

**How it works (reading):** A removable type lever carrier with coupling and a spacer that lets one swing arm pair be locked to the frame so the other pair moves to free the carrier for exchange.

## Reading (short summary from the opening, OCR poor)

**Problem:** A type lever carrier can only be removed from the machine after the swing arm pairs are coupled and moved, which makes changing fonts or languages awkward.

**Solution:** A removable type lever carrier with coupling and a spacer that lets one swing arm pair be locked to the frame so the other pair moves to free the carrier for exchange.
