## Summary

**Category:** related office machine, not a typewriter (setting device for tabulating machine type carriers) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers

**How it works (reading):** The tooth sector gets a fixed stop and a movable stop, released by the punch-card controlled release members, so the separate stop sector is removed and the characters can sit closer together.

## Reading (short summary from the opening, OCR fair)

**Problem:** Selecting many characters on a tabulator needs separate stop sectors for each value point, which takes up too much space beside the type sectors.

**Solution:** The tooth sector gets a fixed stop and a movable stop, released by the punch-card controlled release members, so the separate stop sector is removed and the characters can sit closer together.
