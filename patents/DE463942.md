## Summary

**Category:** related office machine, not a typewriter (receipt typewriter and calculator)

**How it works (reading):** A cheap adding machine that also prints totals and sales receipts: sprocket wheels set digits, gears carry the motion to toothed-rack type rods that print, and the type bars return to zero after each print.

## Reading (short summary from the opening, OCR fair)

**Problem:** Calculating machines with sprocket-wheel setting are too complicated and expensive for small firms.

**Solution:** A cheap adding machine that also prints totals and sales receipts: sprocket wheels set digits, gears carry the motion to toothed-rack type rods that print, and the type bars return to zero after each print.
