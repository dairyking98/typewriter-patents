## Reading (short summary from the opening, OCR fair)

**Problem:** Several line parts advance to different end positions, so they cannot always return to a common start position by separate drives.

**Solution:** All parts are coupled to one common drive shaft through claw or friction couplings, with a nested shaft and sleeve whose wedge surfaces disengage the coupling, so one drive resets every part to the same start position.

**How it works:** A spring or weight return moves the coupled parts back, and the wedge surfaces release the coupling at the end of the return.
