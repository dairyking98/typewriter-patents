## Summary

**Category:** related office machine, not a typewriter (adding machine with special print characters) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**How it works (reading):** A two-colour ribbon has a second colour strip that the machine crank moves into print position, so special marks print in a different colour from normal results.

## Reading (short summary from the opening, OCR fair)

**Problem:** Special machine operation marks print in the same colour as the results, so they are hard to tell apart at a glance.

**Solution:** A two-colour ribbon has a second colour strip that the machine crank moves into print position, so special marks print in a different colour from normal results.
