## Reading (opening only, OCR fair)

**Problem:** Typewriters need many keys or several shift keys, and shift keys invite wrong impressions; type groups on a lever are limited to two or three.

**Solution:** Types are grouped on oscillating frames, each with its own key, and the whole frame set is slid along the machine by a handle that points at the chosen type on an index plate, so no shift keys are needed.

**How it works:** Groups of types sit on oscillatory frames hung in a common carriage that moves lengthwise. A handle moves this type carriage and indicates on an index plate which type of each group is set to print. Each key lever acts through an axle running along the carriage's travel, so the connecting rod can slide along the axle at rest and the carriage move freely. A crooked part in an axle can leave a frame unmoved, giving a space with no impression. Key depression also advances the paper slide by an average letter width, so no space key is needed.

**Features:**

- **Selection:** [Slider along a straight index](../features/sel-linear-slider.md), [Pointer over a chart](../features/sel-pointer-chart.md), [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
- **Type element:** [Straight type bar or rule](../features/elem-linear-bar.md)
- **Impression:** [Separate print key or lever](../features/imp-print-lever.md), [Element struck to the platen](../features/imp-element-to-platen.md)
- **Spacing and escapement:** [Prints and spaces in one stroke](../features/esc-print-and-space.md)
- **Frame and body:** [Few parts, low cost](../features/frm-few-parts.md)

**Parts:** oscillatory type frame; type carriage; handle; index plate; key lever; axle; connecting rod; paper slide

**Improves on:**
