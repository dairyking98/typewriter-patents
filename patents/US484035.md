## Reading (full text, OCR good)

**Problem:** The earlier ribbonless Maskelyne machine (US457903) used a complicated link system to move type from an ink pad to the paper, with a heavier key action.

**Solution:** A simpler two-lever linkage from each key lifts the type rod off its ink pad, advances it to the platen and returns it, with a V-piece and notch to lock the rod at impression.

**How it works:** Pressing a key draws a link rod that turns a hook-shaped lever on a fixed bracket; its projection depresses the tail of a second lever pivoted to the type rod and the bracket. That second lever first lifts the rod off the ink pad (the guide piece is pivoted to allow this), then pushes it forward through guides until a recess in the rod drops into a fixed V-shaped piece, locking it in both directions as the type prints on the roller. On release a spring coiled on the bracket returns the first lever, which engages projections on the second lever to retract the rod to the ink pad. Rods are set radially in a segment so every type hits the same point.
