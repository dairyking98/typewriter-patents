## Summary

**Category:** related office machine, not a typewriter (column punching of payment cards) · **Subject (patent classes):** Mechanisms producing characters by printing and also producing a record by other means, e.g. printer combined with RFID writer

**How it works (reading):** A replaceable control card lets memory values be punched to a set column count, and can stop automatic duplication of group marks under master-card control.

## Reading (short summary from the opening, OCR fair)

**Problem:** Punch-card machines fill memory and need control cards that the card trolley and fields follow, with fixed field and group marks duplicated by hand.

**Solution:** A replaceable control card lets memory values be punched to a set column count, and can stop automatic duplication of group marks under master-card control.
