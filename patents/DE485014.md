## Summary

**Category:** related office machine, not a typewriter (tabulating machine printing unit with type bars) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried on sliding bars or rods on side surfaces thereof, e.g. fixed thereto the types or dies being movable relative to the bars or rods; Arrangements for fixing to a bracelet

**How it works (reading):** Printing units whose type carriers each carry several types in a short row on one side, so many types can sit on one type bar, with type groups selectable by the bar's setting and only one type of a carrier printed at a time.

## Reading (short summary from the opening, OCR fair)

**Problem:** Long reciprocating type bars with many types on one pole must travel far, which slows the machine; types on different sides of a square bar proved unusable.

**Solution:** Printing units whose type carriers each carry several types in a short row on one side, so many types can sit on one type bar, with type groups selectable by the bar's setting and only one type of a carrier printed at a time.

**How it works:** Each type carrier is moved individually against the ribbon or platen; the carrier's setting picks a type within its short row, so the bar's travel stays short.
