## Reading (opening only, OCR good)

**Problem:** On an ordinary typewriter letters of different widths cannot be set with letterpress-like proportional spacing, so narrow letters get wide gaps.

**Solution:** Typebars of equal width strike a ribbon over an elastic band that is advanced by the width of the widest type and pulled back by the difference for narrower letters, then the line is transferred to paper.

**How it works:** Type images sit on equal-width typebar heads, offset so narrow letters sit at the start of their space. The ribbon and a rubber band behind it are indexed like a carriage by the widest type width each stroke. Two side-movable rollers return the band by the difference between the widest and the struck letter, set by hammers on the key levers in five width groups (1, 1.5, 2, 2.5, 3 units). At line end the band is stretched to a mark and passed with a transfer paper roller that receives the printed line.
