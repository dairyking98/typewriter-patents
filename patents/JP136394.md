## Reading (full text, OCR good)

**Problem:** Typewriters for very many kinds of characters become large and awkward to operate.

**Solution:** Select a character with two telephone dials, one sliding a multi-ring type cylinder along its axis to the right ring and the other turning it to the right type, with the print released by spring when the second dial finishes its turn.

**How it works:** A fixed index disc shows character groups in columns along radii, with order numbers beside them. Dial one, marked with group abbreviations, drives a gear train and rack that slides the type cylinder axially against a spring until the wanted ring lies in the hammer's swing plane. Dial two, marked with numbers, drives a bevel gear train that rotates the cylinder to bring the wanted type to the print position. Turning each dial to its end pushes a catch and bar that rotate a cam in two stages; the first stage cocks a bell crank against a strong spring, and the second frees it so the spring jerks a piano wire that fires the (known) printing hammer. Releasing the dials returns everything, and a cam over-centre spring resets for the next stroke.

## Description (English translation of the Japanese text, opening)

> Typewriter. Nature and object of the invention. The invention relates to a typewriter characterised as follows. On the shaft of a fixed index disc, on which groups of letters (figures) [brackets in the original] sorted as convenient are set out in columns along many radii, are fitted two dials made like the dial of an automatic telephone. A type cylinder is provided that carries the type groups of each class side by side as separate rings. As one dial is turned according to the column index of a type group, the type cylinder moves along its axis so that the line of the wanted group is brought into the plane in which the printing hammer swings. As the other dial is turned according to the order index of the wanted type in that group, the type cylinder turns through a suitable angle and brings the wanted type to the printing position; at the same time the printing mechanism is released from the catch that holds it against its spring, and prints by the spring's force. When both dials return, the whole mechanism returns to its original, inactive position.
