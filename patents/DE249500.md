## Reading (opening only, OCR fair)

**Problem:** Writing a syllable at once by pressing several keys needs the keys pressed or released at exactly the same moment on earlier machines.

**Solution:** Keys only set character-wheel sectors; a separate movement mechanism carries the set types to the print point only once all keys are released, so keys can be pressed and released one by one.

**How it works:** Keys in rows each belong to one oscillating plate; pressing a key frees a spring-driven locking rod which slides back until a ratchet tooth meets the key stem, setting the position of that row's character wheel sector. The sectors, hinged to horizontally slidable wedge-shaped rods, carry the types on their outer surface. When all keys are up, the movement mechanism drives the rods rearward and a cross rail guides the sectors to the platen, wedge faces shifting neighbours sideways so the selected types print side by side in one line. A space key is also on the keyboard.
