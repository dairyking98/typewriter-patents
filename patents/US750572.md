## Reading (opening only, OCR good)

**Problem:** Full keyboards (one key per character) have too many keys and cause errors and fatigue, while single-keyboard shift machines put dissimilar characters on one key and cause mistakes.

**Solution:** Split the keyboard into a fixed section for single-form characters and a sideways-shiftable section whose keys each carry capital and small forms.

**How it works:** A fixed section carries keys for numerals, punctuation and other single-form characters, each working one key lever. A second section, guided in transverse ways on the base frame, carries keys such as A/a, each working one lever when in normal position and a different lever when shifted. A shift key at the left end slides along an inclined lug on the section and moves it sideways against stops, with helical springs returning it. The key levers lie in the base beneath the key stems.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Shift and cases:** [Shift by moving the platen](../features/shift-platen.md)
- **Frame and body:** [Few parts, low cost](../features/frm-few-parts.md)

**Parts:** fixed keyboard section; shiftable keyboard section; shift key; key lever; return spring; transverse guide

**Improves on:**

- Yost full keyboard: fewer keys
- Hammond keyboard: avoids combined letter/figure keys
