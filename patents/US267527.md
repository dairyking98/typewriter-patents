## Reading (full text, OCR good)

**Problem:** Keyboard machines need a key for every character; the inventor wants one simple lever to both select the type and print it.

**Solution:** A hand lever turns a turn-table of spring-retracted vertical type plungers to the character shown by a pointer on a graduated scale, and pressing the same lever pushes that type up against the paper roller.

**How it works:** A box frame has a circular opening whose edge is graduated with the characters. A V-grooved turn-table rides on rollers and carries type plungers in tubular guides near its rim, each pulled down by a coiled spring. A hand lever pivoted to the table swings it round, and a pointer on the lever handle shows on the scale which type is over a second pivoted lever. Pressing the handle down drives a sleeve on a stud that pushes the second lever up, lifting that one type through the table against the paper roller above; a spring raises the levers again. The paper roller sits in a bow yoke with a rack and pinion that shifts it sideways, and a ratchet and pawl from either lever could space it automatically. Felt-covered inking tubes touch the type faces as the table turns.
