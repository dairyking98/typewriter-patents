## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Detecting means for copy material, e.g. for detecting or sensing presence of copy material or its leading or trailing end

**In the patent’s own words:** My invention relates to a type-writing machine wherein two types may be operated at the same time, so that two letters may be printed at the same time, thus increasing the speed of the machine, which is the principal object of my invention.

**How it works (reading):** Two semicircles of type-carrying levers with double the keys so that two types, one from each semicircle, print at the same time.

## Reading (opening only, OCR fair)

**Problem:** Typewriter speed is limited by printing one letter at a time.

**Solution:** Two semicircles of type-carrying levers with double the keys so that two types, one from each semicircle, print at the same time.

**How it works:** Typebars on a Remington-style machine are mounted on two semicircular bars set apart so levers from each can rise to the same print point without hitting. One set carries upper and lower case letters and the other two lower-case letters, so a capital can print together with a small letter. Transverse bars connected to the typebars by wires and to the keys by rods can be pulled down at either end. The number of letter keys is doubled, one set joined to each semicircle. A carriage dog is arranged to space for the double printing.
