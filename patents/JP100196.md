## Reading (full text, OCR good)

**Problem:** Typewriters that grip loose types are complicated and break down; the type set should be easy to change and printing light, smooth and accurate.

**Solution:** Each row of types is a belt or chain on sprockets in a swinging frame; turning one common shaft runs all belts to choose the character along the column, a sliding carriage handle picks the frame, and pressing the handle swings only that frame to print.

**How it works:** A type belt (metal, rubber, leather or chain) runs between two sprockets on a thin frame; many such units sit side by side on a common shaft, the frames free to turn on it while the sprockets are keyed to it. Turning the shaft by a knob runs every belt, and a film-like character roller driven by a gear shows the lengthwise position. The operator slides the carriage frame, carrying the paper cylinder, ink roller, print key and character pointer, under the wanted unit, then presses the handle so the key tips that unit's frame against the cylinder. An ink roller linked to the handle inks the type as it descends, and a spring returns the frame; cylinder feed is automatic on the return with adjustable ratio levers.

## Description (English translation of the Japanese text, opening)

> Specification. Rotary typewriter. Nature and object of the invention. This invention relates to a printing machine characterised as follows: types are set in a single row along a belt of sheet metal, rubber or leather, or a chain; this belt is stretched between two or more sprockets mounted on a thin-plate frame, making one unit; several or several tens of these units are threaded on one common shaft; turning the common shaft, or a separate common gear, selects the type in the lengthwise (column) direction; the crosswise selection is made by bringing a carriage handle, which slides left and right and carries the paper cylinder and the print key on one frame, under the wanted unit; and to print, after selecting as above, the handle is pressed down so that it strikes the frame of the unit that has the wanted type and swings that frame, with its type belt, about the common shaft, printing on the paper cylinder.
