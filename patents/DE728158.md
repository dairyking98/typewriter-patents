## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Mechanisms for setting or restoring tabulation stops; Side-stop mechanisms

**In Google’s translation of the patent’s own words:** The object of the invention is for this purpose flocking a simple device that can be operated from within the keypad, which is particularly advantageous for small typewriters, as little as possible To take up space in the touch area.

**How it works (reading):** Stops are set through the key top itself, which is rotatably mounted on the key lever, so one key press sets the stop before the type key is depressed.

## Reading (short summary from the opening, OCR fair)

**Problem:** Margin and tabulator stop setting needs separate keys or levers that take up keyboard space.

**Solution:** Stops are set through the key top itself, which is rotatably mounted on the key lever, so one key press sets the stop before the type key is depressed.
