## Description (Google Patents OCR, opening)

> Description Translated from German Typewriter. The invention relates to improvement and further training of the typewriter, which is protected by the main patent 35796o and in particular consists in making the machine suitable for lines to write the same width, as is customary in letterpress printing. The invention is aimed in particular at a further training: the embodiment of the Main patent and achieves the writing of lines of equal length in particular by that the width of the type bars corresponds to the shape of the letters of different widths and the type bars in the writing position are movable in such a way that between the individual Words spaces can be inserted. To make the machine easier to handle according to the invention, the j e all types of a type set having Bars divided into individual type bars expediently of the same width, which more or less have letters of the same width. These type sticks are placed in magazines, which first bring the type sticks up or the position in which the Writing should take place, whereupon the type dusts brought out of the magazines are such that the characters to be used to write the line are in a Line lie.
