## Reading (short summary from the opening, OCR fair)

**Problem:** Friction feed segments on a labelling type drum sit lower than the types, so the strip feeds unevenly.

**Solution:** The friction feed segments are made the same height as the types and inserted into the type drum like ordinary types, in lengths of one line spacing, so the strip advances by a precise amount.

## Description (Google Patents OCR, opening)

> Description Translated from German Labeling machine working with a rotating type drum for Printing and stamping of labels or the like. Marking machines are already there with rotating type drum for printing and stamping labels or the like in continuous Known strips in which the advancement of the strip intermittently with the help of Friction segments takes place. In these machines, the friction segments are fixed to the printing cylinder connected and lower in height than the types. According to the invention, the friction segments have the same height as the types to be inserted in the type drum and are light in the drum itself interchangeable or changeable or arranged in an understandable manner. Through this arrangement an extremely simple machine is created. The friction segments can according to the invention from individual transport types of the length of a line spacing exist, so they are inserted into the type drum just like ordinary types and in this way cause a simple and precisely determinable length and reliable feeding of the paper tape to be printed.
