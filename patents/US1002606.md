## Reading (short summary from the opening, OCR fair)

**Problem:** A book-type typewriter needs the keyboard and type basket to move relative to the platen for letter and line spacing on a bound book.

**Solution:** The keyboard frame rides on tracks on the flat platen and is driven along rack teeth by pinions, with the type basket shiftable between supports, so letter and line spacing come from relative movement.

**How it works:** Pinions on the keyboard frame run on rack teeth in the tracks, moving the keyboard and type basket along the flat platen over the book.

**Features:** [USE:book-typewriter](../features/use-book-typewriter.md), [ESC:moving-print-head](../features/esc-moving-print-head.md), [PAP:flat-bed](../features/pap-flat-bed.md)

**Parts:** flat platen; tracks with rack teeth; keyboard frame; pinions; type basket
