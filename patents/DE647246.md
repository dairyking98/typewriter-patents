## Summary

**Category:** related office machine, not a typewriter (print hammer for cash registers)

**How it works (reading):** The setting lever is held locked in its set position from the start of machine operation until after the first imprint, driven from a disk and pawl linkage on the machine cycle.

## Reading (short summary from the opening, OCR fair)

**Problem:** After the first print stroke, the setting lever on a cash register printing unit can be moved and so allow a second unwanted stroke; the setting also changes during machine operation.

**Solution:** The setting lever is held locked in its set position from the start of machine operation until after the first imprint, driven from a disk and pawl linkage on the machine cycle.

**Features:** [Check writer](../features/use-check-writer.md), [Separate print key or lever](../features/imp-print-lever.md)
