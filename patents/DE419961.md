## Reading (opening only, OCR fair)

**Problem:** Writing syllable by syllable on a typewriter saves time over single letters.

**Solution:** Four coaxial type wheels (prefix, consonant, vowel, ending) are each set by key-driven stepped drives so one key press prints a whole syllable.

**How it works:** Four type wheels sit side by side on one axis in a housing that slides sideways on ball-guided rods. Key rows set each wheel: keys move toothed-segment levers that engage stepped drives (decreasing in diameter) through bevel gears to turn the wheel to the chosen type. Only part of the key stroke sets the wheel; the rest swings the paper roller to the wheels and trips the gap-switching device. Extra key rows couple a consonant with one of five vowels at once. An inked roller replaces the ribbon.
