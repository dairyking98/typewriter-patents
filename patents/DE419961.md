The well-known Devices of this type compared to the invention is that several rows of auxiliary keys are provided, each of which with intermediate links in such a way several type carriers is connected that when an auxiliary key is pressed several Type carrier at the same time in the pressure position corresponding to the pressed auxiliary key to be brought.
