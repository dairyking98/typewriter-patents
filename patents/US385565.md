## Reading (opening only, OCR fair)

**Problem:** McLaughlin's electric typewriter must record locally by one key action and transmit an impulse to a remote receiver, with replaceable type and keys.

**Solution:** Circular ring of electromagnets with elbow frames pulls angular armatures that move type levers, with interchangeable key tops and removable type letters.

**How it works:** A conducting ring on the base has binding posts opposite a circular series of electromagnets, one per key, whose lower poles are bent up parallel to the helix so both poles attract an angular armature. A slotted non-conducting ring above holds the armatures. A key press mechanically strikes the local type-lever and sends an impulse to the distant end, where the electromagnet moves a similar lever. Finger-keys and letter types are removable so alphabets can be changed.
