**In the English translation of the patent’s own words:** This invention relates to a Japanese-script printing machine in which the handle used to steer a type magazine, movable relative to a fixed character chart, engages a clutch between a main shaft linked to an electric motor and a second shaft connected to the printing mechanism, and an arm on the second shaft strikes the starting part of the printing mechanism so that printing is done.

## Reading (full text, OCR good)

**Problem:** On a one-hand Japanese-script machine the hand that steers the type magazine is already loaded, and should not also have to supply the printing force.

**Solution:** Use the same handle that steers the movable type magazine over the fixed character chart to engage a clutch between a constantly running motor shaft and a second shaft whose arm strikes the printing mechanism's starting parts.

**How it works:** A frame slides lengthwise on the body and carries a type magazine sliding sideways; the handle steers it over a fixed character chart. Pressing the handle turns a shaft whose arm, through a wing plate, hook, crank frame and bell crank, pushes the motor-driven main shaft against a cone friction clutch (normally held apart by a spring) and starts the second shaft. A striker on that shaft hits the tails of the type push-up lever and the printing lever, which take the type from the magazine, fit and hold it, and print on the paper cylinder. Releasing the handle disengages the clutch and everything returns. The speed of engagement varies the blow so characters of different stroke counts print evenly.

## Description (English translation of the Japanese text, opening)
