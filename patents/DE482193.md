**In Google’s translation of the patent’s own words:** The invention relates to typewriters with an inclined type lever segment, where each key lever by two! Handlebar guided almost parallel to itself the bottom of which is the key movement with an upward arm transfers to the type lever by pull rods, the position of which is that of the type lever approximates.

**How it works (reading):** Both handlebar axles are made straight and parallel, so all keys give the same angular path; the upright arms are lengthened or bent to compensate, and a universal rail driven by the same arms actuates carriage control and ribbon functions equally.

## Reading (short summary from the opening, OCR fair)

**Problem:** Inclined type lever segments have key linkage with two pivot axes, one straight and one curved, giving imprecise lever guidance and unequal angular deflection for each key.

**Solution:** Both handlebar axles are made straight and parallel, so all keys give the same angular path; the upright arms are lengthened or bent to compensate, and a universal rail driven by the same arms actuates carriage control and ribbon functions equally.
