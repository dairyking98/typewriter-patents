## Reading (opening only, OCR fair)

**Problem:** Tabulating needs several operations to select a column and a denomination position.

**Solution:** Keys set a single denomination stop member to cooperate with any chosen column stop in one operation.

**How it works:** On a No. 6 Remington typebar machine adjustable column stops sit on the carriage. A single denomination stop member is moved by several keys to a position where it meets a chosen column stop, bringing the chosen denomination place to the printing point on release of the carriage.

**Features:**

- **Type element:** [Typebars](../features/elem-typebar.md)
- **Spacing and escapement:** [Tabulator](../features/esc-tabulator.md), [Carriage release](../features/esc-carriage-release.md)

**Parts:** column stop; denomination stop member; denomination key; carriage release bar; type bar; platen carrier
