## Summary

**Category:** related office machine, not a typewriter (loose sheet writing pad for accounts)

**In Google’s translation of the patent’s own words:** The invention relates to to an accounting system, in which at the same time the basic booking sheet (journal) and the required account sheets are described.

**How it works (reading):** A writing pad holds the loose booking sheets with carbon interleaving so the individual account sheets can be set exactly against the continuously written base sheet.

## Reading (short summary from the opening, OCR fair)

**Problem:** Entries on a base journal and on exchangeable account sheets at once do not line up, because the sheets shift relative to each other.

**Solution:** A writing pad holds the loose booking sheets with carbon interleaving so the individual account sheets can be set exactly against the continuously written base sheet.
