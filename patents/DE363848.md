> Description Translated from German Line switching device on calculating machines. The present invention relates to a line index device in which line index gears of different types Pitch should be exchanged for one another with ease. The already known line switch devices that allow such a replacement have however, the disadvantage that it is only possible with difficulty and loss of time, To attach line indexing wheels with a different tooth pitch. The ones belonging to the carriage return In these older devices, parts must either be trimmed (bent), if the design allows, made to fit the various ratchet gears or specially made parts must be made for each ratchet division be used. The invention avoids these inconveniences in that the line connection belonging, unchangeable parts are adjustable, so that in particular the movement of the pawl rotating the line index wheel corresponds to the various Tooth pitches of the respective line index gears used can be adapted.
