## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing musical scores

**How it works (reading):** The paper carriage moves at a constant rate and carries along helper types; releasing the key stops them, so the note value matches the length of the key hold.

## Reading (short summary from the opening, OCR fair)

**Problem:** Note values are set by holding the key with knee levers and toggle levers, which takes the hands away from playing.

**Solution:** The paper carriage moves at a constant rate and carries along helper types; releasing the key stops them, so the note value matches the length of the key hold.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
