## Summary

**Category:** related office machine, not a typewriter (calculating machine two-part platen) · **Subject (patent classes):** Detents, brakes, or couplings for feed rollers or platens

**How it works (reading):** Each platen part gets its own line-switching device, normally blocked; control members on the moving carriage release the return device at chosen column positions, so each part can be switched on its own.

## Reading (short summary from the opening, OCR fair)

**Problem:** A two-part platen with forms on each part wastes paper, and the two roller parts cannot be line-switched independently because indexing is manual.

**Solution:** Each platen part gets its own line-switching device, normally blocked; control members on the moving carriage release the return device at chosen column positions, so each part can be switched on its own.

**How it works:** The carriage carries control members that act at set column positions to release line switching for one part, driven from the main shaft.

**Features:**

**Parts:** two-part platen; line switching device; carriage control members; return device; main drive shaft; shift finger
