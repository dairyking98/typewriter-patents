## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Erasing or correcting tables

**In the patent’s own words:** The object of my invention is to provide a device of the above character of simple and inexpensive construction.

**How it works (reading):** An erasing head on an arm pivoted at the outer end of a typebar is driven by the key-lever and bell-crank so that it strikes the same print point as the normal type, using the erasing action without extra labour.

## Reading (short summary from the opening, OCR good)

**Problem:** Typing errors need erasing, and a separate erasing tool is inconvenient, so the inventor wants erasures made in the same way characters are printed.

**Solution:** An erasing head on an arm pivoted at the outer end of a typebar is driven by the key-lever and bell-crank so that it strikes the same print point as the normal type, using the erasing action without extra labour.
