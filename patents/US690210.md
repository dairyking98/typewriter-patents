## Reading (short summary from the opening, OCR fair)

**Problem:** Type-bars and type blocks do not line up, so the type must be adjusted for alignment at the print point.

**Solution:** Each type-bar has a slotted doubled end, and a conoidal stem on the type block sits in its opening, so squeezing or expanding the slot moves the type nearer or farther from the bar pivot.

**How it works:** Lateral compression of the doubled portion pushes the type farther from the pivot; expansion brings it nearer, aligning each type on its block.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ELEM:alignment-lock](../features/elem-alignment-lock.md)

**Parts:** type-bar; slotted doubled portion; conoidal stem; type block; segmental plate
