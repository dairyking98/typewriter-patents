## Reading (full text, OCR good)

**Problem:** Key-operated type wheel machines need a separate stop rod for every key; the inventor wants a simple, cheap machine that still allows two-handed writing.

**Solution:** Use one rotary stop arm that swings against a pen (stylus) inserted into a hole in a depressible letter board, so the pen position stops the type wheel and the same press prints.

**How it works:** A letter board with one hole per character pivots on an axis; a lever on the same axis is joined to it by a spring. Two pointed pens with stop collars are inserted by the hands into the chosen letter holes, and pressing the board down pulls the lever, which slides a rack along an inclined notch. The rack turns a gear on the type wheel axis, and a rod fixed to that axis swings over the board until it touches the inserted pen, which stops the type wheel on the right character. Further downward pressure stretches the spring (the lever can no longer follow) and a print hammer strikes the wheel and the paper roller is advanced. Lifting the pen lets springs return the board, lever and rack.
