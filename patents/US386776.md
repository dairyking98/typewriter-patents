## Reading (opening only, OCR fair)

**Problem:** Operate many typewriter levers with fewer keys.

**Solution:** Each of six keys tilts a tumbler-support; notched tumblers drop onto the supports only when a key combination aligns them, selecting one lever.

**How it works:** Six operating levers (keys) are restored by springs. Each key tilts its own transverse tumbler-support through an inclined arm. A set of tumblers, one per lever to be operated, rests on the supports, and each tumbler has a distinct pattern of notches on its bearing edge. A tumbler falls and moves its lever only when a particular combination of keys tilts the supports to the right spacing under its notches. It replaces the notched slides and smooth tumbler-rods of an earlier Ganse application.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md), [Keys drive the element by racks or gears](../features/sel-differential-drive.md)

**Parts:** operating lever; key; tumbler; tumbler-support; spring; notch; inclined arm

**Numbers:** 6 keys

**Improves on:**

- Ganse earlier application with notched slides and tumbler-rods: notches are now on the tumblers and the supports tilt
- [US382298](../patents/US382298.md): different mechanism for the same few-keys-many-levers aim
