## Summary

**Category:** related office machine, not a typewriter (clear checking device for cross counter)

**In Google’s translation of the patent’s own words:** The invention relates to typewriters with a cross counter in which a The digits written one after the other in a horizontal line are offset.

**How it works (reading):** Carriage movement activates and releases a lock so digits cannot be written in a computing column unless the cross counter has been cleared first.

## Reading (short summary from the opening, OCR fair)

**Problem:** The lock on numeric keys in a typewriter with cross counter depended only on carriage stepping, so digits could be written into a column before the cross counter was cleared.

**Solution:** Carriage movement activates and releases a lock so digits cannot be written in a computing column unless the cross counter has been cleared first.
