## Reading (short summary from the opening, OCR fair)

**Problem:** Register strips for photoelectrically controlled typesetting are too wide, and their symbols need cumbersome step-by-step advance with the space keys.

**Solution:** Typewriter-like types each print a symbol whose width matches the carriage slide shift, so symbols touch in the line; the types also print the legible character beside the symbol, and control symbols are typed like characters.

**How it works:** Each type carries a symbol and a rectangular glyph in dense two-row arrangement, so the strip is narrower and the line advances without extra spacing keys.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [USE:special-script](../features/use-special-script.md)

**Parts:** typewriter-like type; symbol; control symbols
