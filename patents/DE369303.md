## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The subject of the invention is illustrated by the drawing, in fig.

**How it works (reading):** A single bearing bracket has two offset rows of radial incisions, one row holding the key levers and the other the type levers, with a pin on each key lever engaging the type lever; the bracket is made by moulding so no machining is needed.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type lever linkages need a large type-lever deflection for a small key movement, but intermediate levers add cost, friction and space; radial-slot carriers are also costly to make.

**Solution:** A single bearing bracket has two offset rows of radial incisions, one row holding the key levers and the other the type levers, with a pin on each key lever engaging the type lever; the bracket is made by moulding so no machining is needed.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** bearing bracket with two rows of radial incisions; key levers with pin; type levers; bearing wire
