## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In Google’s translation of the patent’s own words:** The invention relates to a table writing device of the aforementioned Design, which is set up so that the column stops easily taken out of the rod carrying them, exchanged for one another or after Changed at will and still using the device by simple Depressing the keys can easily be both depressed and pushed up can.

**How it works (reading):** Each tab has a tail piece in a cavity of a carriage rod and a spring snapping into grooves, so tabs can be pulled out, exchanged per form, and still be set and pushed by keys.

## Reading (short summary from the opening, OCR fair)

**Problem:** Column stops on a table writer that are pivoted cannot be removed easily, and sliding ones cannot be pushed up with a button.

**Solution:** Each tab has a tail piece in a cavity of a carriage rod and a spring snapping into grooves, so tabs can be pulled out, exchanged per form, and still be set and pushed by keys.
