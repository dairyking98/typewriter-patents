## Reading (full text, OCR fair)

**Problem:** Type-wheel and type-sector machines vibrate and flex when the carrier stops at the printing point, and need a simple, cheap, rigid construction.

**Solution:** Swing an arc-shaped, two-row type sector in a slotted guide and stop it with key-selected stop bars placed right beside the type, with an independent fixed anvil behind the type.

**How it works:** The type carrier is a sector-shaped piece on an arm pivoted at the centre of an arc-shaped guide slot, carrying two rows of types (lower and upper font). A flier arm, which pins into the carrier arm, is thrown left or right by two operating levers worked by cross bars lying over the key levers. Each key lever also raises its own flat stop bar, mounted in slots in an arc just below the carrier guide; the flier arm hits the raised stop, so the selected type sits at the printing point with the stop very close to the type, limiting vibration. Pressing a shift key raises the guide and carrier on pins so the second row aligns with the printing point, and a spring returns it. A fixed anvil sits between the guide and the type carrier, behind the types, in the plane of the type hammer.

**Parts:** type carrier sector; carrier arm; arc-shaped guide; guide slot; flier arm; operating lever; rock shaft; cross bar; key lever; fulcrum bar; stop bar; shift key; shift rod; anvil; type hammer; supporting frame

**Numbers:** two rows of types

**Improves on:**

- type carriers with the stop on the opposite side of the carrier axis: stops near the type reduce vibration and allow a longer carrier with more types per row
- carrier guide serving as the anvil: separate fixed anvil independent of the guide
