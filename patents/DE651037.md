## Summary

**Kind:** a part or mechanism (any kind of machine)

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter, in which a calculation mode switching gear and a font switching device can be controlled by a common key.

**How it works (reading):** One common key drives a pin and slot connection that reverses both the calculation gear and the font switching device.

## Reading (short summary from the opening, OCR fair)

**Problem:** On a combined calculating typewriter, reversing calculation mode and font needs separate settings, causing mistakes.

**Solution:** One common key drives a pin and slot connection that reverses both the calculation gear and the font switching device.

**How it works:** A common key moves both reversing members through a pin and slot, so one key changes the calculating mode and the font.
