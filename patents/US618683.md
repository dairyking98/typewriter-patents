## Reading (opening only, OCR fair)

**Problem:** Direct-blow typing offers no chance to correct, is noisy, needs precise fitting, and needs an impression for every letter.

**Solution:** A magazine of disks, one per letter space in a line, each carrying a full alphabet, set up by a piano-style keyboard and then printed as a whole line by steady pressure.

**How it works:** A 27-key piano-type keyboard has two shift keys (capitals, figures) and a pawl key. Pressing a finger-key releases a type disk on a spindle to move itself, and the same key movement limits how far the disk turns, so no accurate key fit is needed. A disk is used for each letter or space in the line, so the whole line is set up visibly and can be corrected. Then one steady impression prints the line, and the paper only advances from line to line. A composing sector and telescoping rack position the disks.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md), [Selection locked for printing](../features/sel-selector-locking.md)
- **Type element:** [Type disc (types on the face)](../features/elem-disc-face.md), [Interchangeable element](../features/elem-interchangeable.md)
- **Shift and cases:** [Three or more cases](../features/shift-triple.md)
- **Impression:** [Separate print key or lever](../features/imp-print-lever.md)
- **Frame and body:** [Visible writing](../features/frm-writing-visible.md)

**Parts:** type disk; disk spindle; composing sector; telescoping rack; finger-key; pawl key; shift key; keyboard; bed-board; printing lever

**Numbers:** 27 keys; 14 white keys; 13 black keys; 2 shift keys

**Improves on:**

- direct-blow typewriters: sets the line first, silent keys, no need for accurate key fit
