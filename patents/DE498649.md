> Description Translated from German Printing mechanism for cash registers with control strip printing and optional Issuing a double check The invention relates to printing units for cash registers with control strip printing and optional issue of a double check, for which the drive of the conveyor for the check and the printing stamp through each other rigidly connected reversible lifting means takes place. In printing units of this type, it is known to use the lifting means set from the Position for control strip printing to position for control strip printing and Check issuance for several consecutive machine aisles by means of a hand knob and to switch for individual special machine aisles using special keys. According to the invention the known reversing device is significantly simplified in that the changeover of the lifting equipment set during machine operation after presetting one with the Lifting means sets directly cooperating control member takes place through Spring action is held in the position in which no check is issued, while it is moved against the spring action by two different adjusting means can be used when a check is to be issued.
