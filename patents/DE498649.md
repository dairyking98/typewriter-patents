## Summary

**Category:** related office machine, not a typewriter (cash register printing unit with double check)

**In Google’s translation of the patent’s own words:** The invention relates to printing units for cash registers with control strip printing and optional issue of a double check, for which the drive of the conveyor for the check and the printing stamp through each other rigidly connected reversible lifting means takes place.

**How it works (reading):** A spring-held control member, moved against the spring by two adjusting means, switches the lifting means set during machine operation; the check is issued only when it is moved.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cash register printing unit needs a simpler way to switch the lifting-means set between control-strip printing and double-check issue.

**Solution:** A spring-held control member, moved against the spring by two adjusting means, switches the lifting means set during machine operation; the check is issued only when it is moved.

In printing units of this type, it is known to use the lifting means set from the Position for control strip printing to position for control strip printing and Check issuance for several consecutive machine aisles by means of a hand knob and to switch for individual special machine aisles using special keys.
