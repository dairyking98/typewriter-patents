## Reading (short summary from the opening, OCR fair)

**Problem:** Ribbon re-inking was awkward, so office staff needed a convenient way to prepare fresh typewriter ribbons.

**Solution:** A table-top machine impregnates a ribbon web with ink from a container that is housed inside the machine.

**How it works:** Ink is fed into a ribbon web inside a closed housing; the web is run through the machine to take up ink.
