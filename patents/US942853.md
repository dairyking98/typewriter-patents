## Reading (opening only, OCR fair)

**Problem:** Keys returning against the keyboard plate make a thumping noise.

**Solution:** Felt strips in sheet-metal casings, one per key row, arrest the key-stem collars below the keyboard plate.

**How it works:** Each key stem carries a collar below the keyboard plate. A felt strip, held in a folded metal casing with ears, lies under each transverse row; the collars strike the felt on the return stroke instead of the plate. The strip is perforated for the stems, and the casing ends are screwed to the frame on the keyboard incline.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Typebars:** [Typebars](../features/elem-typebar.md)
- **Frame and body:** [Frame construction](../features/frm-frame-construction.md)

**Parts:** key stem; collar; felt strip; metal casing; keyboard plate; type bar; sub-lever

**Improves on:**

- felt washer on key stem striking keyboard plate: the stop is moved below to a felt strip, quieter
