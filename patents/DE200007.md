## Reading (opening only, OCR fair)

**Problem:** Syllable typewriters with a type shuttle need a separate switch to set each type series, and the hammer must cope with printing one, two or three letters at once.

**Solution:** Each key sets the shuttle's type row itself by raising the shuttle frame against a per-row stop, while a hammer with selectable stop noses of different widths prints single letters or syllables.

**How it works:** A type shuttle with eight type series around its circumference sits in a vertically adjustable frame beneath an anvil. Pressing a key moves a bell crank and pull rod that rock a lever raising the frame until a stop pin on one of eight slides, chosen by that key, blocks it, so the key picks the series. The shuttle is turned until a pin limits its rotation. The hammer carries a rotatable body with three noses of different widths, lifted by pins from a cam-and-gear shaft started by syllable keys, so the pawl releases after the right number of spaces. After the key is released the shuttle drops below the print point so writing is visible. Interchangeable type bars on a roller are an alternative.
