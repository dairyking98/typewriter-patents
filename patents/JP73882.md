## Reading (full text, OCR good)

**Problem:** Typewriter print with every letter the same width looks poor, since real printing types differ in width; the inventor wants even gaps between letters of varying width on a Japanese-script typewriter.

**Solution:** Sort European letters of one point size into a few width classes (1:2:3), set the feed-gear pitch to the narrowest width, and advance the gear by as many teeth as the letter's width ratio, using types whose letter is flush to one side.

**How it works:** All letters of a point size are designed in a few widths in ratio 1, 2 and 3. The character-feed gear that moves the paper cylinder has a pitch equal to the narrowest letter. Each type carries its letter set against one edge (e.g. left) so the left margin is the same on every type, the width growing to the right. Before printing a wider letter the gear is first advanced extra teeth so the cylinder has moved the right number of teeth; after printing, the gear is advanced one tooth automatically. Types of equal width are kept together in the character plate.
