## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Means for centralising short lines

**In Google’s translation of the patent’s own words:** The invention relates to a Tabulation and border limiting device, in which one for each carriage step Rider adjustable from a central position into two different end positions is provided is that in one effective position as a tabulator and in the other effective position as a margin stop serves.

**How it works (reading):** One common actuator returns each step rider from a central position into two end positions, one for tab and one for margin stop, driven by two set and delete buttons; stroke limiting members give each rider a dual function for individual deletion.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tab and margin stops set by hand on each carriage step were easy to set wrongly, and other tab setting methods were not reliable in the intermediate positions.

**Solution:** One common actuator returns each step rider from a central position into two end positions, one for tab and one for margin stop, driven by two set and delete buttons; stroke limiting members give each rider a dual function for individual deletion.
