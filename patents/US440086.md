## Reading (opening only, OCR fair)

**Problem:** A typewriter that also makes type matrices; the keys must arrange a line of type to be set before printing.

**Solution:** Each key pushes a pin through a perforated plate to slide a full-alphabet type bar to the required symbol, setting the whole line before it is printed by a traveller.

**How it works:** Hexagonal keys on key bars lift stickers that turn a rocking bar, which fires a spring-loaded shooting bolt against a headed pin in a perforated plate. The pin pushes a vertical type bar, forked and sliding on a plate, so that the symbol row on its face is positioned at the printing level. Every bar carries the same complete set of symbols, and the number of bars equals the number of symbols in a line. After each key the traveller escapes to the next bar, until the whole line is set. A printing apparatus then prints or makes the matrix.

**Features:** [Straight type bar or rule](../features/elem-linear-bar.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Separate type slugs or plungers](../features/elem-individual-slugs.md), [Escape-wheel escapement](../features/esc-escape-wheel.md)

**Parts:** hexagonal key; key bar; sticker; rocking bar; shooting bolt; headed pin; perforated plate; type bar; traveller; segment wheel; ratchet gear
