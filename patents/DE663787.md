> Description Translated from German Frame for office machines The invention relates to a frame for office machines, on which the machine is in the position of use and in a swiveled position Position is adjustable, and the aim is a good and safe installation of such Machines to enable. In order to mount a typewriter so that it can be swiveled into different positions during manufacture, it has been proposed to mount the machine on a special support frame by means of screws and to mount this support frame in vertical supports so that it can be swiveled about an axis passing through the center of gravity . A spring or a sliding weight was provided to hold the support frame in the various positions. A safe installation of the machine in the position of use is neither intended nor achieved with this proposal. It has also been proposed for repairing and demonstrate writing and similar machines to store adjustable "on a table one serving for setting up the machine frame by means of flexible supports.
