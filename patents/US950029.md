## Reading (opening only, OCR good)

**Problem:** Key and typebar return depends on a weak spring acting near the pivot, so strong springs make the touch hard.

**Solution:** An added recovery spring on the key lever that speeds rebound without raising touch force.

**How it works:** A key lever fulcrumed near its rear end actuates the typebar by articulated bell cranks and a wire. The normal return spring acts close to the pivot. A further recovery spring below the forward end of the key lever helps the return, giving a light touch and quick rebound without a stronger return spring.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** key lever; return spring; recovery spring; bell crank; connecting wire; type bar
