## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing musical scores

**How it works (reading):** Each piano-style key links to a notehead type that is set at the pitch position on the paper roll, so several keys pressed together print chords in one stroke; auxiliary types add stems, flags and bars.

## Reading (short summary from the opening, OCR fair)

**Problem:** Note typewriters need two keystrokes per note and cannot print chords, and the sheet must be shifted for each pitch.

**Solution:** Each piano-style key links to a notehead type that is set at the pitch position on the paper roll, so several keys pressed together print chords in one stroke; auxiliary types add stems, flags and bars.

**Features:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Separate type slugs or plungers](../features/elem-individual-slugs.md)
