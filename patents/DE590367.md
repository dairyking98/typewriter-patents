## Summary

**Category:** related office machine, not a typewriter (shorthand and plain text writing machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for stenographic writing

**In Google’s translation of the patent’s own words:** The invention relates to a machine for writing shorthand and plain text for all languages with several.

**How it works (reading):** Each key carries the usual plain letter plus a shorthand character, with a switch selecting the second character and fine vertical adjustment of paper roller and type carrier so characters print above and below the baseline.

## Reading (short summary from the opening, OCR fair)

**Problem:** Existing shorthand typewriters use an unknown stenographic system and a hard-to-read type face, so ordinary typists cannot use them.

**Solution:** Each key carries the usual plain letter plus a shorthand character, with a switch selecting the second character and fine vertical adjustment of paper roller and type carrier so characters print above and below the baseline.
