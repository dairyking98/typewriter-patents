## Reading (short summary from the opening, OCR fair)

**Problem:** Matrix punches and their key connections are the subject; the stated problem is not clear in the first 3000 characters.

**Solution:** A matrix-making machine in which each key transmits motion through sheaves and connections to a type-carrying arm that drives its punch, with the matrix table moved and supported beneath.

**How it works:** Keys link through sheaves and plates to individual type-carrying arms, which are spaced by plates; the matrix table moves on its own mechanism.
