## Description (Google Patents OCR, opening)

> Description Translated from German Device for the implementation of braille-like holes or key movements corresponding to these perforations in typescript. Devices for alphabetical order punched cards are known. The production of a catalog or a list according to the alphabetically ordered cards would have to be in the way so far be made that in turn each individual card from the ordered pile taken and copied on the typewriter and then back on the pile was inserted. Aside from the laboriousness of this work, it was destructive order the sorted cards by this picking up and reinsertion very easily possible, so that in the end both the catalog and the order of the deck of cards was faulty. The new machine avoids all of this, as well as being done during of the organizing itself carries out its work and when the sorting is finished also that of the Order has finished writing the corresponding catalog. The machine is designed so that it is not perforated with the help of Cards and movable styli is controlled, but with the help of hand too operating keys, it can be used as a typewriter, especially as a result of the possibility with six keys to write sixty-three letters or groups of letter…
