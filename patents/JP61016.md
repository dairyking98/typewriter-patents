## Reading (full text, OCR good)

**Problem:** Typewriter frames are one piece, so a different type face, language or carriage width needs a whole new machine, and cleaning and repair are awkward.

**Solution:** Split a visible-writing typebar typewriter into a front frame (keys, type levers, ribbon gear) and a rear frame (carriage, escapement, platen frame) joined by four screws, so either half can be exchanged.

**How it works:** The front frame holds an arc plate carrying the type levers on an upper arc and intermediate levers on a lower concentric arc, each driven by a key through a pull rod. A cross shaft at the back carries the space lever, reverse lever and line-change lever and a rocking release bridge; a type lever pushes the bridge back, which through a feed rod advances the carriage escapement one character and lifts the ribbon fork via a bell crank. Shifting the bell crank sideways selects ribbon lift, stencil (no lift) or other colour. The rear frame holds the carriage slide, rack drive and a freely liftable platen frame that can be raised for erasing and removed alone, with line-end bell and a line lock that is overridden by a button. Only the first 40,000 of 78,000 characters of the input were available; the platen coupling details are not covered.

## Description (English translation of the Japanese text, opening)

> Reference numerals follow the printed text, including the numerals marked doubtful in the transcription; where the transcription gives a corrected reading, the translation uses it. Specification. Visible-writing typewriter. Nature and object of the invention. This invention is an improvement of the visible-writing typewriter. The machine frame is divided into a front and a rear part. The front part holds the type keys, the members for reversing the platen, the ribbon controls, the spool and the release bridge. The rear part holds the carriage, its bed, its feed and drive mechanism, the platen reversing and line-change gear and the line-length (margin) limiting gear. The two parts are joined by screws. The object is to make the two parts detachable, so that a needed part can easily be exchanged (for example a different type face, or a different carriage or platen) and one machine can be used in several ways; and at the same time to make the frame easy to clean.
