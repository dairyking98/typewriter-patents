## Summary

**Category:** related office machine, not a typewriter (calculating machine printing transfer) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing; Actuating devices therefor

**How it works (reading):** A set value is moved by a toothed slide into the arithmetic unit and printing unit together, with the result kept in the result counter so the next calculation can continue.

## Reading (short summary from the opening, OCR fair)

**Problem:** Earlier calculators printed a value or total but lost the result, so later calculations could not continue from it.

**Solution:** A set value is moved by a toothed slide into the arithmetic unit and printing unit together, with the result kept in the result counter so the next calculation can continue.
