## Description (Google Patents OCR, opening)

> Description Translated from German Typewriter keyboard The invention relates to a further embodiment of the typewriter keyboard according to patent 470 8 0 3. According to the main patent, typewriter keys are divided into five Rows of the same height. Arranged in such a way that only eight main character keys in each row lie. For the seldom occurring characters is next to the top two rows of keys each one arranged a key. The purpose of this arrangement was to allow each of the eight to write used fingers to clearly assign a vertical row of keys. This should the security of blind typing can be increased. In practical application it has been shown that in -dem expected Measures an increase in writing security was achieved. - However, it was disturbing that the hands are always very close to each other, and much closer to one another than in the so-called normal position with the usual keyboard, so that easily the Thumbs of both hands could collide. According to the present invention, this drawback is eliminated and at the same time the typing speed is increased by the auxiliary character keys for less common characters as a ninth vertical row with preferably a different one Key shape…
