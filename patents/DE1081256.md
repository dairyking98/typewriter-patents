## Summary

**Category:** related office machine, not a typewriter (print hammer drive for calculating machines) · **Subject (patent classes):** Arrangements thereof of single hammers, e.g. travelling along printing line of stationary hammers, e.g. engaging a single type-carrier engaging more than one type-carrier; Springs

**In Google’s translation of the patent’s own words:** The invention relates to such printing units for calculating machines in which a single spring-force-driven Print hammer acts simultaneously on a number of adjustable type bars, the one to be printed The number of type bars changes with the number of digits of the respective amount.

**How it works (reading):** The hammer spring preload, or additional springs, is varied automatically by a feeler lever on the adjustment rails, passed through an intermediate lever, so the force matches the number of type bars printed.

## Reading (short summary from the opening, OCR fair)

**Problem:** A single spring-driven print hammer strikes a varying number of type bars, so impression strength is uneven and the printed line looks poor.

**Solution:** The hammer spring preload, or additional springs, is varied automatically by a feeler lever on the adjustment rails, passed through an intermediate lever, so the force matches the number of type bars printed.
