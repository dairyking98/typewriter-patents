## Reading (full text, OCR good)

**Problem:** In a Japanese-script typewriter the platen must stop and move sideways accurately by a set character spacing, and the spacing should be adjustable.

**Solution:** A spring-pulled slider carries a feed pawl that alternates with a locking pawl on the platen rack, and an adjustable rod limits the slider's travel to set the spacing.

**How it works:** The platen is always pulled one way by a spring. A feed pawl, spring-loaded on a slider, normally engages the platen rack. Pressing the handle rocks a lever and shaft so the locking pawl enters the rack and holds the platen while the feed pawl lifts out. A spring then pulls the slider forward until it meets the tip of the adjusting rod, which carries the feed pawl ahead by the set distance. On release, the feed pawl drops into the rack at the new position, the locking pawl leaves, and the platen is free to advance until the feed pawl stops it. The rod is set by squeezing a grip to lift an engaging piece out of a row of teeth, then sliding the rod to a scale mark. For the return the feed pawl tips down so the platen can move freely to the right.

## Description (English translation of the Japanese text, opening)

> Sideways feed device in a Japanese-script typewriter. Nature and object of the invention. This invention relates to a sideways feed device in a Japanese-script typewriter, made of the combination of two parts. The first is an engaging device with the rack: the platen feed pawl, pressed by a spring so that it can bend and straighten, is mounted on a slider; the slider is always pulled by a spring so as to move one way; the feed pawl so made is mounted, together with a locking pawl, so that both can tip forward and back, so that the two pawls engage and leave the platen's rack in turn; and the moment the feed pawl leaves the rack it moves and comes to engage the next set tooth. The second is a device for changing the range of travel of the feed pawl: an adjusting rod is mounted so that it can move, and by setting the root of an engaging piece, one end of which engages the adjusting rod, in any one of a row of engaging teeth, the gap between the adjusting rod and the slider is set as wished, which decides the character spacing.
