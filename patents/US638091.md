## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing mechanisms having dual functions or combined with, or coupled to, apparatus performing other functions

**In the patent’s own words:** Object of the invention is to place the type at the ends of-small levers, which rise to make the impression on the paper, and to mount these letters on a wheel or disk, so that this machine is intermediate in construction and operation between the machines with key-levers only and those with key-disks only and has all the'advantages of both systems, with the inconvenience of neither.

**How it works (reading):** A five-key machine where keys pressed alone or together give 31 characters, with two auxiliary lever keys tripling the set to 91 characters, one hand only.

## Reading (opening only, OCR fair)

**Problem:** Full keyboards need many keys and two hands.

**Solution:** A five-key machine where keys pressed alone or together give 31 characters, with two auxiliary lever keys tripling the set to 91 characters, one hand only.

**How it works:** Five main keys act on a key-operated cylinder and levers that select the type; two auxiliary lever keys, moved by tilting a finger, extend the set. The space is measured automatically per letter so type form and size can vary. Details of the cylinder and type carrier are not in the excerpt.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md), [Keys that only set the element](../features/sel-dummy-keyboard.md)
- **Spacing and escapement:** [Proportional spacing](../features/esc-variable-spacing.md)

**Parts:** main key; auxiliary lever key; key-operated cylinder; type carrier; casing

**Numbers:** 5 keys; 31 combinations; 91 characters
