## Reading (opening only, OCR fair)

**Problem:** A single carriage serving two sets of typebars cannot use types of different widths because the letter-space is fixed.

**Solution:** Give the carriage a separate feed rack for each type set, each meshing with its own escapement pinion, so letter spacing matches the type size of the set in use.

**How it works:** Two Underwood front-strike machines are fixed side by side on a common base with long front and rear rails. One carriage runs across both and cooperates with either set of typebars, each with its own keyboard. The carriage carries a rack for each set, joined in a swinging frame operated by a key that lifts the racks to release them from their pinions. Each rack meshes with the pinion and escapement wheel of its own machine, proportioned to the type width; larger types or other languages can be used on one side.
