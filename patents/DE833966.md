## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Applications of scales or indicators

**In Google’s translation of the patent’s own words:** The object of the invention is a straightening rod for the typewriter, with the help of which you can immediately use fonts and columns of numbers in the case of larger line spacings can write exactly one below the other.

**How it works (reading):** A transparent alignment rod fixed above the type guide on the line-height indicator is parallel to the sheet edges, so the new line is held against it to align below the previous text.

## Reading (short summary from the opening, OCR fair)

**Problem:** Column alignment on a typewriter needs turning the roller back and forth between lines.

**Solution:** A transparent alignment rod fixed above the type guide on the line-height indicator is parallel to the sheet edges, so the new line is held against it to align below the previous text.
