**How it works (reading):** Calculating type carriers are moved by linkage rods driven by a cam, so they rest below the print line and print at the same point as the typewriter type bars on the platen.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adding machine type bars are driven from below by pinions, which is costly and bulky, and their rest position cannot be kept below the print line when a writing unit shares the same print point.

**Solution:** Calculating type carriers are moved by linkage rods driven by a cam, so they rest below the print line and print at the same point as the typewriter type bars on the platen.
