## Reading (full text, OCR good)

**Problem:** In an all-electromagnetic printing machine the many keyboard switches spark when the hand leaves the key, wearing them out and making the machine costly.

**Solution:** An automatic cut-out, tripped by the hammer stroke and then by key release, switches the main current off and the return magnet on so keyboard switches open with no current flowing.

**How it works:** A key press closes a travel-stop switch and a rotation-stop switch via crossed wires; relays then energise the main electromagnet. Its travel core slides the cylindrical type wheel along its axis to a catch set by a travel-stop magnet, and its turning core drives a helix tube and planet gear train that turns the wheel left or right until a locking lever hits a stop pin. The core's spare stroke drives a rack that cocks and releases a spring hammer, which strikes from behind the paper through the ribbon. As the rack descends, a snap-acting contact breaks the main circuit and closes the return magnet; releasing the key trips a second switch that restores the contact. A reversing device with an over-centre spring keeps the turning direction between successive characters.

## Description (English translation of the Japanese text, opening)

> Specification. Electromagnetic printing machine. Nature and object of the invention. This invention relates to an electromagnetic printing machine in which all the movements needed for printing are made electromagnetically. When one key is pressed, the machine prints any chosen type completely, and at the same moment an automatic cut-out breaks all the circuits, so that no spark can form when the switches open, even when the hand is taken off the key that was pressed; the switches are protected in this way. Its object is to lengthen the life of the many switches in the keyboard, to simplify the construction and so to make the machine cheaper. Brief description of the drawings.
