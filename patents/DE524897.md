**How it works (reading):** The pawl carrier return spring is hooked between the top of the pawl carrier and the switch bracket, so it is not tensioned while the type keys are pressed and the stroke is lighter.

## Reading (short summary from the opening, OCR fair)

**Problem:** A return spring tensioned between the pawl carrier and the fixed frame stiffens every keystroke, giving a hard key action.

**Solution:** The pawl carrier return spring is hooked between the top of the pawl carrier and the switch bracket, so it is not tensioned while the type keys are pressed and the stroke is lighter.

## Description (Google Patents OCR, opening)

> Description Translated from German Paper carriage switching device for typewriters The invention relates to a paper carriage switching device for typewriters in which at Stop of the type keys of the pawl carrier by a horizontally guided, from The switch bracket, which is moved by the type levers and is under the action of a spring, is will. The pawl carrier is in these known devices by a short Compression spring or moved back by a tension spring. These well-known springs are on the one hand on the pawl carrier and on the other hand attached to the fixed machine frame and are therefore influenced with every movement of the pawl carrier. Because when you press one Type key this spring must be tightened the more, the further the pawl carrier fades out, the result is a hard keystroke. According to the invention is the return spring on the one hand at the upper end of the pawl carrier and on the other hand on the switch bracket attached. This spring provides an elastic connection between the switch bracket and Pawl carrier and is not tensioned while the type buttons are pressed down, which results in a much lighter keystroke.
