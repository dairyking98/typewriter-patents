## Summary

**Category:** related office machine, not a typewriter (calculating machine printing device) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing having type hammers

**In Google’s translation of the patent’s own words:** The invention relates to a calculating machine with a printing device.

**How it works (reading):** Each numerical order's printing unit is controlled by its own control element, which is set so that the unit prints only when the next lower digit is moved into printing position, so the special character appears only once.

## Reading (short summary from the opening, OCR fair)

**Problem:** Protective printing of a special character immediately left of an amount on a calculating machine is not reliably possible across several numerical orders.

**Solution:** Each numerical order's printing unit is controlled by its own control element, which is set so that the unit prints only when the next lower digit is moved into printing position, so the special character appears only once.
