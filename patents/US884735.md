## Reading (opening only, OCR fair)

**Problem:** Typebar key strokes feel sharp and uneven at the start and end, and key dip differs across the keyboard of a Sun front-strike machine.

**Solution:** Use a looped, zigzag-crimped link between key and typebar that yields slightly at start and end of stroke, and set the link angles and lever heights so key dip is uniform.

**How it works:** Four banks of keys sit on bell-cranks pivoted on four stacked cross rods, with upstanding arms inclined rearward. Links run back from these arms to the typebars at obtuse angles, forming a partly open toggle, so key resistance is greatest at the start of the stroke and falls, speeding the typebar into a powerful blow. A loop in each link permits slight lengthening at the start and end of the stroke, with stops limiting the yielding, and zigzag crimps let the workman lengthen or shorten the link to adjust. Link attachment heights increase toward the sides of the set to keep key dip uniform.
