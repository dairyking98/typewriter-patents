## Reading (short summary from the opening, OCR poor)

**Problem:** Moving a paper carriage from an advanced column back to a preceding column requires returning it to the right limit and reversing, which is slow for tabulated listings.

**Solution:** Tabulating mechanism for an adding machine that moves the carriage directly from an advanced columnar position to a preceding one in one movement, without the return to the right-hand limit.

**How it works:** The carriage is shifted by continuous action from any column to any other. The present mechanism lets the carriage move in one direction directly to an earlier column position, avoiding the reversal the prior design required. The full mechanism is in the 31,000-character text, of which only the start was read; the OCR is too damaged to trace the parts.

**Features:** [ESC:tabulator](../features/esc-tabulator.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** paper carriage; column stops; tabulating mechanism

**Improves on:**

- carriage return to right limit before moving back to earlier column: direct one-direction movement to a preceding column
