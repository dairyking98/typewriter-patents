## Reading (full text, OCR good)

**Problem:** Ordinary typewriter keyboards make the hands roam over many keys, wasting time and effort and making them hard for beginners.

**Solution:** Two identical 36-sign button groups, one per hand, with each character selected by pressing the matching row button on one and column button on the other, closing a circuit to an electromagnet that pulls the typebar's key lever.

**How it works:** Both hands rest at fixed positions; each finger covers a set of signs (thumb two). Pressing one button in the left group and one in the right group completes a circuit through a wiring matrix to exactly one of 36 electromagnets. The magnet plunger pulls a chain and hook lever attached to the ordinary typewriter's key lever, as if struck by hand. A spring or counterweight returns the lever when the current stops. The magnets, battery and wiring sit in a box under the typewriter, with magnets at staggered heights. Feet work the spacer and capitals.

## Description (English translation of the Japanese text, opening)

> Nature and object of the invention. This invention concerns a European-script printing machine characterised by two groups of push buttons, each group containing the same number of the same characters arranged suitably, placed for the left and the right hand respectively; pressing at the same time the button of each group whose row contains the same character closes the exciting circuit of an electromagnet that works a type lever, and the character is printed by that lever. Its object is a European-script printing machine that does away entirely with the waste of time and effort, and the difficulty for beginners, caused by moving the fingers of both hands over the keyboard, so that even the unskilled can print quickly, easily and without error.
