## Reading (opening only, OCR fair)

**Problem:** On visible typebar writers the accent type must print without the carriage feeding, so the accent and the letter register on one spot.

**Solution:** An accent (blank) key vibrates the ribbon but a lock set by that key stops the universal bar and carriage from feeding, until the next ordinary key releases the lock.

**How it works:** A typebar carrying the accent mark is struck first. The accent key sets a normally idle lock or detent that holds back the universal bar's return and the carriage feed. The next ordinary type key prints its letter over the accent and releases the lock so spacing resumes. Shown on an Underwood visible writer.

**Improves on:**

- Underwood visible writer: accent can be struck without advancing the carriage
