## Description (Google Patents OCR, opening)

> Description Translated from German Device for temporarily deactivating the clear character printing device on typewriters and the like The present invention relates to an apparatus for temporarily deactivating the plain character printing device on typewriters and the like There are devices of this type are already known in which the clear character printing device with the deactivation of the carriage step lock Pressing a tab key or the carriage release key simultaneously and automatically is rendered ineffective. However, these devices had the disadvantage that when not in use the counters controlled by the clear character printing device, e.g. B. the cross counters., an imprint of the clear sign was possible when the cross counters were at zero, which is particularly unpleasant in the case of automatic clear character printing devices was felt. This disadvantage is eliminated according to the invention in that with the deactivation of the cross counter or the driver linkage for the same at the same time and the clear character printing device is automatically made ineffective.
