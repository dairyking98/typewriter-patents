## Summary

**Category:** related office machine, not a typewriter (printing device for tabulating machines) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers

**In Google’s translation of the patent’s own words:** The present invention relates to a printing device having a number of Adjacent, up and down type carriers and with the different Type sets individually assigned, spring-loaded pressure hammers for the Types that are preferably used for machines controlled by counting cards (tabulating machines) is determined.

**How it works (reading):** All type carriers move continuously and the hammers are triggered for the types selected by card-hole sensing, so the selected type is hit against the paper while a mechanical power drive moves the hammers.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing from individually moved type carriers under spring-loaded hammers needs strong control forces and makes the print hammers hard to trigger from a card hole, and the types must not strike each other.

**Solution:** All type carriers move continuously and the hammers are triggered for the types selected by card-hole sensing, so the selected type is hit against the paper while a mechanical power drive moves the hammers.
