## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary feed or adjustment devices for justifying

**In Google’s translation of the patent’s own words:** The invention relates to a device for effecting line balancing.

**How it works (reading):** A one-armed lever sets the carriage advance per space, with its pivot set by hand on a graduated scale so the total spare width is divided across the inter-word gaps, widening or narrowing each gap.

## Reading (short summary from the opening, OCR fair)

**Problem:** Existing line-locking uses the type itself, auxiliary space keys, or doubled spaces, and spaces can be widened but never narrowed.

**Solution:** A one-armed lever sets the carriage advance per space, with its pivot set by hand on a graduated scale so the total spare width is divided across the inter-word gaps, widening or narrowing each gap.

**Features:**

- **Spacing and escapement:** [Proportional spacing](../features/esc-variable-spacing.md), [Space key or bar](../features/esc-space-key.md)

**Parts:** one-armed lever; adjustable pivot bearing; graduated scale with holes; locking pin

**Numbers:** scale gap 3.2 mm = 4 x 0.8 mm; spaces counted per line
