## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In Google’s translation of the patent’s own words:** The invention relates to a tabulator for typewriters, calculating machines or the like with stops that are moved into the path of the paper carriage when the key is pressed.

**How it works (reading):** A motor-driven cam is common to all tab stops, and pressing a tab key engages only the selected stop so the motor brings it into positive connection.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulator stops must be set by hand against the carriage, and the tab action has no power assist.

**Solution:** A motor-driven cam is common to all tab stops, and pressing a tab key engages only the selected stop so the motor brings it into positive connection.
