## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Carriage return or release devices therefor with special means to maintain character-spacing or back- spacing elements in engagement during case-shift or like movement

**In Google’s translation of the patent’s own words:** The invention relates to typewriters in which, the paper trolley bed for the purpose of easy interchangeability of the paper trolley in two vertical socket pin of the machine frame is detachably attached, and concerns a device that makes it easier to align the paper roller with the type stop, in order to achieve a consistently identical type imprint for the entire length of the roller.

**How it works (reading):** Each socket pin is adjusted separately through slotted bushings, so the carriage bed can be set parallel to the type point.

## Reading (short summary from the opening, OCR fair)

**Problem:** Paper carriage can only be shifted parallel, not tilted to line up with the type point.

**Solution:** Each socket pin is adjusted separately through slotted bushings, so the carriage bed can be set parallel to the type point.
