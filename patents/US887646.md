## Reading (short summary from the opening, OCR fair)

**Problem:** Operator must use hands to shift and return the carriage at each line end, and carriage return must be easy and stop at a set point.

**Solution:** An attachment with a pedal to shift the keys and a motor-driven shaft that returns the carriage to an adjustable position after a chosen key.
