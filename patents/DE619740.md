## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The subject of the invention is a type lever drive for writing, writing arithmetic and similar machines in which the movement of all on a common axis of rotation mounted button lever on the type lever or intermediate lever with the mediation of Rocker arms and tie rods is transmitted.

**How it works (reading):** The rocker-arm attack points for each row sit at distances matched to key-lever length, so all type-lever drives share the same amplitude, acceleration and force through tie rods.

## Reading (short summary from the opening, OCR fair)

**Problem:** Keys in different rows have different lever lengths, so they differ in depth and force needed to strike the type levers.

**Solution:** The rocker-arm attack points for each row sit at distances matched to key-lever length, so all type-lever drives share the same amplitude, acceleration and force through tie rods.

With the previously known machines of this kind, only provision was made that the type lever an increasing Got acceleration. In the case of the invention, not only are the type levers increasing with Speed driven but special emphasis is placed on that all keys, regardless of which row they are in, have the same depth and can be struck with the same force. To achieve this benefit, the key levers are driven Rocker arm for the whole machine designed so that despite different Key lever lengths are the rear ends of the rocker arm of all type lever drives have the same oscillation amplitude, the same acceleration and the same oscillation force.
