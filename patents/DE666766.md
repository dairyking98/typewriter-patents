## Reading (short summary from the opening, OCR fair)

**Problem:** Types are hard to hold and press onto the type support when soldering them to the type lever.

**Solution:** Type outer sides are angled so clamp jaws can press it toward the base at any clamp direction.

> Description Translated from German Type for type levers The invention relates to a type for type lever. When placing types on type levers, the type is placed on a type support that is shaped to match the platen. After the alignment, the type lever is inserted into the slot of the type and soldered into it. Holding the type on the type pad was difficult, however, because pressing the type from above prevented the soldering process. For this reason, attempts have been made to hold the usual types firmly on the type support devices by means of holding jaws engaging them laterally. However, this did not succeed, or only inadequately, because the lower edges of the types had surfaces that ran parallel or almost parallel to one another and the force of the holding jaws acted almost perpendicular to these surfaces, so that these devices, even when exerting considerable pressure, were unable to express the type between did not allow the holding jaws in the direction of the type edition.
