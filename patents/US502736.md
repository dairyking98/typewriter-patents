## Reading (opening only, OCR fair)

**Problem:** Typebar type with the character centred over the shank prints out of line when all bars pivot at the same distance from the printing point, forcing costly individually adjustable hangers.

**Solution:** Make each type so the shank centre bears the same relation to a common centre line of the whole alphabet, rather than to the character's own centre.

**How it works:** A common centre line is drawn midway between the top of tall letters and the bottom of descending letters. Each type shank is placed with its centre at that fixed relation to this line, so a descender letter's body sits higher on the shank than a capital's. All typebars can then pivot on one common ring at equal distance from the printing point and still print in alignment. A modified font and sockets on a typering are also shown; the figures compare a word printed with the new and the old type.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ELEM:alignment-lock](../features/elem-alignment-lock.md), [ELEM:element-construction](../features/elem-element-construction.md), [ELEM:metal-type](../features/elem-metal-type.md)

**Parts:** type shank; printing character; type carrier; fulcrum ring; common centre line; typering socket

**Improves on:**

- type with character centred on shank, individually adjustable hangers: alignment is built into the type shape so no adjustment is needed
