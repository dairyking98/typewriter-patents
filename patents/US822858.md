## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** A front-stroke typebar machine in which each typebar's heel is attached to a flexing connection anchored at an adjustable, detachable fixed point, with the platen shifted for upper and lower case.
