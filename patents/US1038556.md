## Reading (opening only, OCR fair)

**Problem:** Cipher messages should be impossible to read without the key, and the key should be changeable, even mid-message.

**Solution:** A key-driven enciphering machine coupled to a standard typewriter that transposes each character through geared segmental racks set by a key dial.

**How it works:** Each character key lever has a gear wheel and a driven segmental rack normally out of mesh; pressing a key throws the rack into mesh and turns the gear partly. A selecting mechanism and a transposing mechanism combine this with a dial setting so any letter can map to a different letter each time. Power or hand drive is possible. A handwheel alters the key during a message. Deciphering is done by setting the dial and striking keys of a duplicate machine.

**Features:** [SEL:differential-drive](../features/sel-differential-drive.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [USE:accessory](../features/use-accessory.md), [USE:special-script](../features/use-special-script.md)

**Parts:** key lever; gear wheel; segmental rack; dial; handwheel; main driving shaft; clutch; pawl; ratchet
