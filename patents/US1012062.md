## Reading (opening only, OCR fair)

**Problem:** Front-strike typebar actions need an easy start and accelerating typebar, with uniform leverage, touch and key dip across all keys.

**Solution:** Each typebar is pulled by a link from a nearly upright sub-lever, with sub-lever fulcrums arranged in a curve at increasing heights so touch and dip are uniform.

**How it works:** Segmental upward-and-rearward typebars strike the front of the platen and rest on a type rest. Each is connected by a forward pull link to a sub-lever fulcrumed on a curved pivot wire in front of the typebar pivots, at gradually higher elevations towards the sides. The sub-lever's lower arm connects by a rearward link toward the key lever, giving accelerating typebar motion. Several modifications are shown.

**Features:** [Typebars](../features/elem-typebar.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Element struck to the platen](../features/imp-element-to-platen.md)

**Parts:** typebar; pull link; sub-lever; curved pivot wire; type rest; key lever; platen

**Improves on:**

- Daugherty application Serial No. 283,758: simpler front-strike action with uniform leverage
