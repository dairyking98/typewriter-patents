> Description Translated from German Method and device for attaching type bodies with only a fastening tab on bumpers for typewriters The invention relates to a method for fastening type bodies with only one fastening tab (type tail) on the bumpers for typewriters. It has already been proposed that the type body of bumper typewriters to be soldered to the bumpers. For this purpose, the type body was made just like with lever type typewriters provided with two fastening tabs, between which the bumpers were inserted. This training of the type body has however Practically not proven for bumper typewriters. Their manufacture noted namely too expensive here because the fastening tabs on bumper typewriters for each type body at a different angle to the printing surface, type body pointed lies, so that the formation of two fastening tabs made great difficulties. For this reason, the type bodies for bumper typewriters have hitherto been used only provided with a fastening tab and by means of this fastening tab riveted to the bumpers.
