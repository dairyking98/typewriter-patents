## Reading (full text, OCR good)

**Problem:** When a character is misprinted or skipped by an empty stroke in a sideways-feed Japanese-script typewriter, the platen has to be returned by exactly the spacing it just moved so the character can be reprinted in the same place.

**Solution:** A return pawl on a sliding holder engages the platen rack and pushes it back, while a transmission lever freezes the feed pawl and a limiter on the spacing adjusting rod stops the return at the right distance.

**How it works:** Normal feeding uses a spring-pulled slider with a feed pawl and a locking pawl alternating on the platen rack, with the step set by an adjusting rod. To back-space, a handle tips a rocking lever that slides the return pawl holder over a guide roller, lifting the L-shaped return pawl into the rack and moving the rack and platen back. As the holder moves, a roller on the pawl pivot rides a cam and presses a transmission lever, whose end drops onto the feed slider and stops it. The return ends when the pawl's back meets a limiter on the adjusting rod, so the return distance always equals the set character spacing. With zero feed the limiter and rod are fully in and no return occurs.

## Description (English translation of the Japanese text, opening)

> Return device in a Japanese-script typewriter. Nature and object of the invention. This invention relates to a return device in a Japanese-script typewriter characterised by the combination of: a platen return device in which a return pawl, pressed by a spring piece, is hinged so that it can rise and fall at one end of a pawl holder, and the pawl holder is mounted so that it can slide on a roller fixed in the machine frame; a device that, at the start and at the end of the travel of the return pawl and pawl holder, raises or lowers them so that they engage or leave the rack; a device that, as the return pawl rises or falls, works a transmission lever that stops the feed pawl and its slider from moving; and a device, moving in and out with the adjusting rod (printed 調製杆, read 調整杆), that limits the travel of the return pawl. The object is that, when printing with the sideways feed, if a character has been misprinted or left out, the platen can be returned by the spacing it has just moved, so that the character can be printed again neatly in the same line.
