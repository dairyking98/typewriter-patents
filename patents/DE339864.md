## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary devices therefor

**How it works (reading):** A plate fixed to the type basket (or to a removable segment) carries stops spaced at the character pitch and a magnet holds the types against the stops, so each type is located by the stops and then soldered in place.

## Reading (short summary from the opening, OCR fair)

**Problem:** Positioning and soldering type characters onto type levers one by one is slow, and it is hard to get each type at the correct spacing.

**Solution:** A plate fixed to the type basket (or to a removable segment) carries stops spaced at the character pitch and a magnet holds the types against the stops, so each type is located by the stops and then soldered in place.
