## Summary

**Kind:** typebar machine · **Subject (patent classes):** Bearings or hangers for type levers

**In Google’s translation of the patent’s own words:** The invention relates to on type lever bearings for typewriters with a hose-like body as Resting camp.

**How it works (reading):** A hose body of braided rubber thread with knitted fabric or web is elastic transversely so only a few threads take each hit, and the threads spring back without disturbing neighbours.

## Reading (short summary from the opening, OCR fair)

**Problem:** A pure rubber rest hose transmits impact to neighbouring levers, and a textile hose does not spring back.

**Solution:** A hose body of braided rubber thread with knitted fabric or web is elastic transversely so only a few threads take each hit, and the threads spring back without disturbing neighbours.
