## Description (Google Patents OCR, opening)

> Description Translated from German Printing unit for calculating machines The invention relates to a printing unit for calculating machines, in which in a known manner the type bars by the The machine's digit-adjusting device is raised to the appropriate height and are then thrown against the platen by the type hammers, and the aim is to design such a printing unit so that by a particularly limited Impact path for the type hammers an extraordinarily favorable impact effect the type bars carrying the types is achieved. According to the invention, this technical advance is achieved by that the type rods in the rest position apply resiliently to the type hammers and to achieve a favorable stroke path when cranking forward through the return bar the type hammers are pivoted into a preparatory position in which this Bracket serves as a stop for the type hammers. The drawing shows an embodiment of the printing unit according to FIG Invention shown in three different positions.
