## Reading (short summary from the opening, OCR fair)

**Problem:** Type-bar hammers need a short, favourable impact stroke to strike the type bars against the platen.

**Solution:** Type rods rest resiliently on the type hammers in rest position, and a return bracket swung out during cranking pivots the hammers into a preparatory position where the bracket is the stop, shortening the hammer stroke before release.

**How it works:** The digit arch raises each type rod onto its hammer; when the return bracket is swung out the hammer is released and snaps to the stop, hurling the type bar against the platen, and a spring returns the rod.
