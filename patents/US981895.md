## Reading (opening only, OCR fair)

**Problem:** Radial horizontal typebar machines have small characters and cannot exceed about 90 characters; Slavonic scripts need more and larger ones, but moving the type set outward makes the machine huge.

**Solution:** Each typebar is guided on a radially slotted plate only for the last half of its stroke, with a short tail and guide block through the slot, so the type arc can be larger without a longer machine.

**How it works:** Key depression turns a key lever and an intermediate fork lever that throws the typebar, carrying a type block, horizontally against the platen; a spring returns it. A guide plate is slotted radially for part of its length. The front comb of the slot guides sideways with the typebar's guide block passing down through the slot, and the unslotted rear part guides horizontally. The bar's tail end carries an eye wider than the slot so it rides on the plate and cannot drop through. The eyes also engage a locking comb when a whole type set is exchanged.
