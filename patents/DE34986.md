## Reading (full text, OCR fair)

**Problem:** Key typewriters need one key per character, which is complex.

**Solution:** Two separate key groups set a type roller's axial position (row) and rotation (character), so the number of characters is roughly the product of the key counts.

**How it works:** A spring-loaded upper box on a sideways-moving support holds a shaft carrying a type roller with seven rows of ten characters (69 total). Keys 1-6 lock the roller's forward travel at a chosen row; keys i1-i9 stop the shaft's spring-driven rotation by hitting wings on the shaft. Pressing the box down releases pins so springs pull the roller forward while rotating it until the two pressed keys stop it, and it prints. On release, levers and a toothed segment return the roller and shaft, and the support steps sideways for spacing. With no row key the seventh row prints, with no character key the shaft turns a full revolution to the tenth character.
