## Reading (full text, OCR good)

**Problem:** Japanese typewriters need very many types and made the user pick inverted types; a short key stroke leaves too little gap between roller and type faces to arrange thousands of types.

**Solution:** Telescoping stroke multipliers (nested sliding bars joined by chains, each doubling the travel of the previous) are arranged radially so that type boxes at their tips form a spherical type block, one key per type.

**How it works:** A stepped keyboard (50 steps of 50 keys, 2,500 keys) has each key stem connected through two cranks and a link to the first bar (E) of a multiplier inside a square hollow outer tube (M). Bar E's end presses on a chain (L) fixed to bar F and anchored to the tube, so F moves twice as far as E; each later bar (G, H, I) again doubles, so five bars give 16 times the key stroke. The last bar carries a type box (V) with the type (K), which is shot out to the roller (R) at the centre of the sphere formed by the tube ends and prints lightly on the paper. Bars are I-section and fit closely to keep alignment. On release the weight of the bars or a spring returns the type. The roller advances a short distance each stroke and an ink ribbon passes before the strike point.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention relates to a printing machine characterised by stroke multipliers, each built from any number of guide bars arranged one after another lengthwise inside a hollow outer tube. Each bar is joined at one end by a chain to a point on the inner wall of the tube, and its other end overlaps the chain of the next bar, so that it slides in and out in contact with that chain. Many of these multipliers are arranged radially, and their outer ends, which hold the type boxes, are gathered together so that the type faces form a spherical surface. The object is to increase the key stroke passed through the transmission to the multiplier, and so leave a large enough gap between the roller and the type faces for a great many types to be arranged.
