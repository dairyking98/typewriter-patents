## Summary

**Category:** related office machine, not a typewriter (teletyper transmitting signals while printing) · **Subject (patent classes):** Digital/analogue conversion; Apparatus or local circuits for transmitting or receiving codes wherein each character is represented by the same number of equal-length code elements, e.g. Baudot code

**In the patent’s own words:** This invention relates to teletypers, by which term I designate type-writing machines which are provided with electro mechanical devices for transmitting electrical signals, whereby during the printing of a message on a type-writer said message is electrically transmitted to a distant station and received there in the form ofthe well-known Morse or equivalent code-signals.

**How it works (reading):** An attachment to a typewriter with electromechanical devices that send Morse-type signals for each key as it prints, with key lockout until the signal is sent.
