## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies

**How it works (reading):** The type pieces are attached in a jig: the carrier frame is clamped adjustably on the machine frame, and each stop is set against a fixed reference mark visible in a window so all stops reach one defined position before soldering.

## Reading (short summary from the opening, OCR poor)

**Problem:** Type pieces on the type levers are hard to set so that every stop lands at exactly the same position, and the stop blocks cannot be machined precisely enough to repeat it by socket fitting alone.

**Solution:** The type pieces are attached in a jig: the carrier frame is clamped adjustably on the machine frame, and each stop is set against a fixed reference mark visible in a window so all stops reach one defined position before soldering.
