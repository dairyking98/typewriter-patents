## Summary

**Category:** related office machine, not a typewriter (accounting machine with several type printers)

**How it works (reading):** Each print point's type set is made distinct (different letters or marks) so every imprint shows which point made it.

## Reading (short summary from the opening, OCR fair)

**Problem:** Identical imprints from several print points on an accounting machine allow forged receipts to go unnoticed.

**Solution:** Each print point's type set is made distinct (different letters or marks) so every imprint shows which point made it.

**Features:** [USE:calculating](../features/use-calculating.md), [ELEM:element-construction](../features/elem-element-construction.md)

**Parts:** print point; type set; distinguishing mark
