## Reading (opening only, OCR good)

**Problem:** Converging forearms and a cramped, view-blocking keyboard make typing tiring.

**Solution:** Split the keyboard into two key groups with a central gap so the forearms lie parallel, with key levers angled to converge on the print point.

**How it works:** Keys sit in two groups separated by a gap sized to the operator's parallel forearms. Parallel key levers in each group are angled to the key rows so they converge toward the printing point. Shift and space keys sit in the central gap for the thumbs. Variants angle the groups or curve the key rows to the fingers' lengths.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** key; key lever; shift key; spacing key
