## Summary

**Category:** related office machine, not a typewriter (line selection for cash registers)

**How it works (reading):** The pressed line-selection keys are latched by a locking plate and released at the end of each machine cycle, optionally cancelled, so the printing table can return and be reset to the same line without re-pressing.

## Reading (short summary from the opening, OCR fair)

**Problem:** When several machine aisles print on the same line, the operator must press the line-selection key again each time to return the printing table to its position.

**Solution:** The pressed line-selection keys are latched by a locking plate and released at the end of each machine cycle, optionally cancelled, so the printing table can return and be reset to the same line without re-pressing.
