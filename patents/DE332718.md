## Reading (full text, OCR fair)

**Problem:** Pointer typewriters needed part changes to switch fonts and could not write on thick, rigid objects such as bound books, cardboard boxes or wood with durable ink.

**Solution:** A pointer-driven type cylinder carries several fonts as spring-loaded type pistons, positioned by rotation and axial slide, struck from above by a hammer-tipped key and inked by a self-inking roller, so it can write on any thick object.

**How it works:** The type cylinder has radial bores, each with a type piston carrying one type and a return spring, and a conical recess on its end. Its axle slides inside a hollow cylinder on a carriage. Moving the setting pointer over a plate of character designations drives a gear that rotates the hollow cylinder, while sideways pointer motion slides the carriage, so the chosen type comes under the print hammer. Pressing a key lowers a guide piece and a hammer with a rubber cone into the type's conical recess, and cutting edges drop into a gear rim and a groove ring for fine alignment and locking. The same key motion swings a fork carrying an ink roller (with wick and ink container) onto the chosen type and then pulls it away so the type can descend. An adjustable abutment with rubber rollers supports books or cardboard being written on.
