## Description (Google Patents OCR, opening)

> Description Translated from German Device for total printing on writing adding machines. The invention relates to a writing adding machine of the type in which, when a key is depressed, a locking device releases the path of a pull rod connected to the drive toothed sector, which finds a stop on the depressed key, while the toothed sector, following the action of a spring, extends the key setting accordingly follows. In these machines, after you have set a number of a series of numbers to be added on the keyboard, this number is printed on the control strip when you move the hand lever, while the number rolls of the machine are incremented so that they show the respective sum of the numbers already added . If you want to print the final sum on the control strip after the addition of the numbers, a special switch must be made using a special key and the hand lever must be moved, when it is returned to the starting position, the number rollers snap back into the zero position, so that the machine is ready for a new one Addition is ready. Often, e.g. B. when going from one book page to the other, but it is necessary to draw a partial total, i. H. to add up the numbers on just one page…
