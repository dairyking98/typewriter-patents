## Reading (full text, OCR good)

**Problem:** A kanji machine must fit a great many characters into a small volume, with easy changing of type frames and easy finding of characters.

**Solution:** A holding frame moved under a character index plate by a handle and pointer prints from a type frame, with upper and lower storage frames for the common and rare type frames that can be swapped into the holding frame by a button.

**How it works:** A rail frame slides forward-back and a holding frame slides left-right on it beneath a fixed index plate, with a T-arm carrying a handle and pointer out over the plate. The holding frame has two rooms, each taking an upper (common) or lower (rare) type frame; spring pawls on sliding rods hold the frames. At a set position the pawls withdraw, and pressing a button lifts the lower frame on raising pawls so it replaces the upper one, which rises into storage and is caught by pawls. Pressing the print button pulls a lifting lever, pushes a rod up and drives the pointed type from its tube past the ink roller onto the paper cylinder. The same button turns a rocking lever whose pawl turns a saw-tooth wheel one tooth, spacing vertical lines, or, with the cylinder frame lever held by a stop, a feed pawl moves a rack so the cylinder slides sideways for horizontal lines. A spacing button repeats the feed without printing, and a mirror rod lets the printed line be checked.
