## Summary

**Category:** related office machine, not a typewriter (printing device, booking machines)

**In Google’s translation of the patent’s own words:** The invention relates to a printing device for booking and similar machines for column-wise printing of supporting documents.

**How it works (reading):** Type sets for each column are staggered and arranged so they can be moved together from a single point, so no frames are needed per column.

## Reading (short summary from the opening, OCR fair)

**Problem:** Column printing devices need a separate frame per column, and the type sets are costly to arrange.

**Solution:** Type sets for each column are staggered and arranged so they can be moved together from a single point, so no frames are needed per column.
