## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Each type bar carries four types and is guided by two links, each pivoted by one of two keys from a four-row keyboard, so it reaches the print point by one of two paths.

## Reading (opening only, OCR fair)

**Problem:** Quiet typewriters using a toggle action were hard to build with a crowded bank of push rods acting at one print point.

**Solution:** Each type bar carries four types and is guided by two links, each pivoted by one of two keys from a four-row keyboard, so it reaches the print point by one of two paths.

**How it works:** Keys act on lever linkages whose toggle extension throws the type bar to the print point and withdraws it again at impact for silent printing. Each bar has four types (two lower case, two upper). Which of its two keys is struck sets which link pivot moves and so which path and type reaches the platen.

**Parts:** type bar; guide link; toggle linkage; key lever; face plate; main plate; platen

**Numbers:** 4 types per bar; 4 key rows
