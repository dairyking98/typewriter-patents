## Description (Google Patents OCR, opening)

> Description Translated from German Control device for setting the type of calculation of the cross counters of typewriters The invention relates to a control device for Setting of the calculation type of the cross counters of typewriters, in which the control plate is clamped against a box plate of the steep counter. Devices of this type have already become known, but required use both hands to adjust and lock the control plate. Are known, furthermore Devices in which only one hand to adjust and lock the control plate is required; However, these devices have the disadvantage that the detection the adjusted control plate is unreliable. According to the invention, all these disadvantages are now avoided by the device clamping the control plate against the box plate on a bolt is arranged, which is firmly connected to the control plate. In the drawing, an embodiment of the invention is for example shown.
