## Reading (full text, OCR good)

**Problem:** A full-keyboard front-strike typebar machine with two types per bar needs a case-shift that does not shift the whole basket or carriage and still brings both types to the same print point.

**Solution:** Typebars are mounted in sets on separate shiftable segments, each pivoted on a rod, and an upper-case key automatically drops only the segment of its own bar so the upper-case type reaches the print point.

**How it works:** Forty-two typebars, each with a lower and upper case type in line along the bar, sit in six sets on ball-bearing segments. Each bar is driven by a push link and bell crank from a link that two rock shafts (one upper case key, one lower case key) can pull, with lost motion in the slots so either key works without moving the other. A spring holds each segment against an adjustable stop in its normal (lower case) position. Upper case keys also depress a universal gate bar for their set, which through a lever and link draws the segment down and rotates it about its rod, near dead center so it is locked before the bar strikes. The shifted segment's strike center moves in front of and below the print point, so the paths of the upper-case types converge there. Types have long shanks bent for individual adjustment, and optional type rests travel with each segment.
