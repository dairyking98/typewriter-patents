**How it works (reading):** A settable return zone and a universal rod triggered by punctuation or space keys close the motor circuit to start carriage return from anywhere in that zone.

## Reading (short summary from the opening, OCR fair)

**Problem:** Power-driven carriage return only works from the margin stops, so it cannot return the carriage from any position.

**Solution:** A settable return zone and a universal rod triggered by punctuation or space keys close the motor circuit to start carriage return from anywhere in that zone.
