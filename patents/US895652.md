## Reading (full text, OCR good)

**Problem:** Typebar machines print only one alphabet (e.g. Russian or Latin); changing alphabet means replacing all the typebars, which needs a specialist and much time.

**Solution:** Each typebar carries a separate hinged multi-sided type block that can be turned to present a different alphabet and is held by a spring.

**How it works:** A tetrahedral (or more-sided) type block is journalled between lugs cast at the end of the typebar, with each face carrying a different alphabet or sign set. One journal ends in a square head so the block can be turned with a key. A spiral spring pressing a stem, or a flat spring against the block, holds it in each of its positions. Keys can show the changed character through an opening in the key top, where a letter on a spring lever is moved by finger to the matching position.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ELEM:interchangeable](../features/elem-interchangeable.md), [SHIFT:rotary](../features/shift-rotary.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [USE:special-script](../features/use-special-script.md), [USE:accessory](../features/use-accessory.md)

**Parts:** typebar; lug; tetrahedral type block; journal; square turning head; spiral spring; flat spring; key with changeable legend

**Numbers:** four-sided block (tetrahedral); two types per head in claims

**Improves on:**

- Remington, Underwood, Ideal typebar machines: alphabet changed by turning blocks instead of replacing all typebars
