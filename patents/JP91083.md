## Reading (full text, OCR good)

**Problem:** A single-tray Japanese typewriter is slow and tiring: one hand has to cover all the types over a wide range and the next character cannot start until the single printing device has returned.

**Solution:** Fit one machine with two or more separate sliding type trays, each with its own handle and pivoted typebar that picks a type from the tray and strikes it at one common point on a single platen, so both hands work at once.

**How it works:** Several typebars are pivoted on an arc centred on the platen print point; below each is its own type tray (7) riding on balls on a sliding frame (5) so it moves forward-back and left-right under hand control by a handle (8). A pointer (9) on the tray is placed over the wanted character on a character plate (10); pressing the handle turns a shaft (11) and arm (12) down on a long crank (13), whose motion passes through a hooked piece (16) to a second crank (17) in the base, so the base shaft (18) turns wherever the tray is. A link (22) then lowers a lever (27) on a cam (30) that raises the type-raising lever (29), pushing the selected type up from the tray into the front groove of the typebar (35); the cam then stops the lift, and the link turns a bell crank (25) and link (34) to swing the typebar so the type prints at the fixed point. The typebar's groove top is angled so the type is turned to face upright at the print point, and a spiral groove rotates the type as it rises; the tray is a plate with conical holes in a checkerboard and types with conical feet, and returning types are guided back by their neighbours.
