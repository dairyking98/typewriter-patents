## Reading (opening only, OCR fair)

**Problem:** With a uniform vibrator throw, impressions follow one straight line down the ribbon, so the ribbon wears out in a narrow strip.

**Solution:** Vary the ribbon's widthwise position so type strike several parallel paths, and reverse feed automatically.

**How it works:** Ribbon spools sit on vertical shafts geared through bevel pinions to an endwise-slidable power shaft driven by the carriage spring drum. The vibrator, driven from the universal bar, shifts the ribbon to different heights so impressions follow several parallel paths lengthwise of the ribbon, exhausting the whole inking surface. Shifting the power shaft endwise changes which spool is driven for automatic reversal.

**Features:** [INK:ribbon](../features/ink-ribbon.md), [INK:ribbon-feed](../features/ink-ribbon-feed.md), [INK:ribbon-reverse](../features/ink-ribbon-reverse.md), [INK:ribbon-lift](../features/ink-ribbon-lift.md), [ESC:spring-drum](../features/esc-spring-drum.md), [ESC:escape-wheel](../features/esc-escape-wheel.md), [ELEM:typebar](../features/elem-typebar.md)

**Parts:** ribbon spool; spool shaft; bevel pinion; power shaft; spring drum; vibrator; universal bar; escapement wheel; feed dog

**Improves on:**

- uniform-throw ribbon vibrator: uses the full ribbon width
