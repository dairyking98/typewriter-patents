## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary type mechanisms for printing distinguishing marks, e.g. for accenting, using dead or half-dead key arrangements, for printing marks in telegraph printers to indicate that machine is receiving

**In Google’s translation of the patent’s own words:** The subject of the invention is an accent writing device for typeface.

**How it works (reading):** The driving finger on the swinging switch bracket is pivoted so a slider moved by the accent type levers turns it aside, so it no longer acts on the letter shift; alternatively the bracket is raised out of reach.

## Reading (short summary from the opening, OCR fair)

**Problem:** Pressing an accent key also triggers the letter shift, and the accent type heads should carry more characters.

**Solution:** The driving finger on the swinging switch bracket is pivoted so a slider moved by the accent type levers turns it aside, so it no longer acts on the letter shift; alternatively the bracket is raised out of reach.
