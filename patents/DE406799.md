## Summary

**Category:** related office machine, not a typewriter (key lock for calculator) · **Subject (patent classes):** Interlocking devices, e.g. between keys

**How it works (reading):** Notched key-lock rails and a slidable locking lever let the crank complete without triggering keys when the lever is in release position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Key-lock rails of calculating machines can trigger the set keys at the end of a crank stroke.

**Solution:** Notched key-lock rails and a slidable locking lever let the crank complete without triggering keys when the lever is in release position.
