## Reading (opening only, OCR fair)

**Problem:** The inventor wants a simple, durable, high-class typewriter performing all functions well.

**Solution:** A complete typebar machine (Densmore/Briggs) with spring-drum carriage drive, ribbon spools moved laterally, stem keys with character-disk caps, and hanger mounting details.

**How it works:** Key levers connect by wires and stirrups to typebars on hangers fixed with screws and washers. A spring drum pulls the paper carriage through a feeding escapement and also moves the ribbon spools and carriers sideways. The carriage can be turned up to show the writing. Platen line spacing uses a ratchet wheel with regulating devices. Stem keys have caps holding a character disk. Only the first part of the description is available.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ESC:spring-drum](../features/esc-spring-drum.md), [INK:ribbon](../features/ink-ribbon.md), [INK:ribbon-feed](../features/ink-ribbon-feed.md), [PAP:line-space](../features/pap-line-space.md), [PAP:platen-roller](../features/pap-platen-roller.md), [FRM:writing-visible](../features/frm-writing-visible.md)

**Parts:** key lever; connecting wire; stirrup clip; typebar; typebar hanger; spring drum; paper carriage; platen; ribbon spool; stem key; character disk
