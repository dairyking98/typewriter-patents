## Reading (full text, OCR good)

**Problem:** Key action of keyboard machines was judged by an experienced operator's fingertip feel, which varied from person to person.

**Solution:** A motor-driven notched drum selects levers and fingers so a cam-driven common hammer presses the keys automatically at set force, depth and speed.

**How it works:** A motor drives a notched drum through worm and reduction gears and a clutch, and a rotary cam through a second worm gear. Selector levers, arranged like the keyboard, drop into drum notches in a fixed order and push their selector fingers under the matching test hammers. The cam throws the common hammers up, striking the chosen test hammer, which presses the key. Force is set by a spring, depth by keyboard height or cam profile, and speed by motor or gear ratio.

**Parts:** motor; notched drum; clutch; selector lever; selector finger; common hammer; test hammer; rotary cam; spring

**Numbers:** five key rows

**Improves on:**

- judging keys by an operator's feel: mechanised quantitative test

## Description (English translation of the Japanese text, opening)

> Title. Keyboard testing machine. Nature and object of the invention. This invention is a keyboard testing machine, characterised in that it has a notched drum that sets the order in which the keys of a keyboard machine are tested, and selector levers and selector fingers that make the selection under its control; a common hammer, worked by a separately mounted rotary cam, strikes whichever selector finger has been selected, and the test hammer linked to it then presses the keys of the keyboard machine in any fixed order chosen beforehand, continuously and automatically, so that the keys can be tested for performance under a given pressing force, depth and striking speed. Its object is a testing machine that tests the key action of keyboard machines simply and quantitatively. Brief description of the drawings. The drawings are explanatory sketches of an example of the invention: Fig. 1 shows the arrangement of the mechanism, Fig. 2 the drive, and Fig. 3 the principle of operation. Detailed description.
