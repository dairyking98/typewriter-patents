## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a type lever drive for typewriters, in which the Type stopped before serving and a special device from the Halt position is brought into the Druckstelkmg.

**How it works (reading):** Each type lever is driven by a pin from the key, so the type stops and the key then moves it into print position, with a fixed pivot.

## Reading (short summary from the opening, OCR fair)

**Problem:** Stopping type before printing needs heavy weights to reach the platen, and the type levers lack a uniform pivot so marks are poor.

**Solution:** Each type lever is driven by a pin from the key, so the type stops and the key then moves it into print position, with a fixed pivot.
