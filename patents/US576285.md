## Reading (opening only, OCR fair)

**Problem:** Typebar action should be released by the key trip so the bar returns independently of a still-depressed key.

**Solution:** A trip on each key-lever depresses an intermediate lever that swings the typebar, then slips off so the bar and spacing parts reset while the key is held.

**How it works:** The key-lever carries a spring-held trip. When the key is pressed the trip pushes the rear end of a type-bar-operating lever, which pulls a connecting rod to swing the typebar to the platen and depresses a universal bar that rocks a shaft and moves the spacing dogs. At the end of the stroke the trip releases so the type-bar and universal bar return to normal while the key stays down; a pad stops the key-levers.
