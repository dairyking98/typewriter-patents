## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Feeding to a particular line, e.g. by rotation of platen or feed roller

**How it works (reading):** A stop on the frame and a counter-stop on the roller frame make the frame return to a fixed position where the first line of the form sits in the writing line; height stops set the position of loose sheets.

## Reading (short summary from the opening, OCR fair)

**Problem:** Returning the clamping frame of a roll-form machine to the first writing line takes time and care.

**Solution:** A stop on the frame and a counter-stop on the roller frame make the frame return to a fixed position where the first line of the form sits in the writing line; height stops set the position of loose sheets.

> Description Translated from German Device in typewriters for setting the writing paper to the first line to be described The invention relates to an apparatus for setting the writing paper on the first line to be written on with typewriters, in which the writing paper is clamped in a frame between a stationarily mounted platen and one in front of it that can be displaced in the line direction Type stop mechanism can be moved in the vertical direction for the purpose of line switching, and aims to quickly set the writing paper to the first to be written on Enable line. Typewriters of the aforementioned type are used specifically for writing of roll forms with preprinted use. The forms run from a roll over the clamping frame and are attached to the upper cross rail of the same by a flap held. When the form is finished, the flap is opened, the form pulled through to cut length and finally torn off. To the next To describe the form, the clamping frame must be returned to its original position = which corresponds to the form on the next form.
