## Summary

**Category:** related office machine, not a typewriter (special character counter typewriter) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The present invention relates to a typewriter, in which a special character is printed by hitting a key, which indicates that the counter of the machine at the beginning of the work activity or was set to "o" at the beginning of a special calculation.

**How it works (reading):** The type lever carrying the special character is driven by a spring, which is rewound automatically by the counter drive during the machine movement, so the key only releases it.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing a special symbol by full key force is tiring and slows the machine, because the operator's force is used for the impression.

**Solution:** The type lever carrying the special character is driven by a spring, which is rewound automatically by the counter drive during the machine movement, so the key only releases it.
