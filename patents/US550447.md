## Reading (opening only, OCR good)

**Problem:** Carriages need an automatic return after each line, but the return mechanism must not drag on the carriage while it prints.

**Solution:** An under-machine spring-drum attachment, wound by a cord, that connects to the carriage only for the return and is mechanically disconnected during printing.

**How it works:** Hangers hold a stationary shaft beneath the typewriter. A gear wheel with ratchet teeth on its inner face meshes with the carriage rack (Hammond) or drives a cord (Remington). A pulley drum on the shaft, wound by a cord, tightens an involute spring held in a fixed drum, and a pawl in the pulley drum engages the gear's ratchet. A cam on the fixed drum lifts the pawl out of the ratchet at the end of its travel, so the carriage has no connection to the return mechanism during writing.

**Features:** [ESC:carriage-return](../features/esc-carriage-return.md), [ESC:spring-drum](../features/esc-spring-drum.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [USE:accessory](../features/use-accessory.md)

**Parts:** hanger; stationary shaft; gear wheel; ratchet; pulley drum; spring drum; involute spring; cord; pawl; releasing cam

**Improves on:**

- Hammond and Remington carriage return: adds an automatic return that fully disengages while printing
