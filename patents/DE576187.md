## Reading (opening only, OCR fair)

**Problem:** Misspelt code words in telegrams cannot be corrected by logic, so errors in transmission go undetected.

**Solution:** A typewriter or teleprinter with a check device automatically adds a control letter to each code word, computed from the values of the selected letters by moving a letter disc or band against an indicator.

**How it works:** As each letter is selected, a closed body such as a disc or band with a letter sequence is moved relative to an indicator by an amount equal to the letter's value, alternating direction with each letter. A variant uses two opposing letter sequences with a reversing disc. After the last letter, the letter at the indicator is the control letter, printed at the group's end. The recipient can check the code word against it, and the device can be switched on or off, and also works with the space key and ribbon switching.
