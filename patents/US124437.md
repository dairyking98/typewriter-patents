## Reading (opening only, OCR fair)

**Problem:** Spacing between words in a keyboard writing machine requires the hands, which are busy on the keys.

**Solution:** A foot stirrup attached to a dedicated non-printing key shifts the registering table a longer distance for word spaces.

**How it works:** Key-levers move long vibrating arms carrying type in boxes at their ends; the arms are arranged on an arc and converge on a common point on the sliding registering table, so only one letter can print at a time. Springs hold the arms against an elastic cushion. Every key also pulls a cord that moves a weighted lever and shifts the registering table by one letter step; an inked ribbon is stretched over the table by weighted strings. The stirrup key is attached to an extreme left key, not linked to any type arm, and the foot presses it farther than the finger-keys so the table moves by a word-space.
