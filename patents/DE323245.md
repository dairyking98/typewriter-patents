## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** The intermediate lever is guided on fixed circular arcs and engages slots in the type lever, with the pull rod in a plane parallel to the centre plane.

## Reading (short summary from the opening, OCR fair)

**Problem:** The pull rod motion of the intermediate lever required much force and slowed typing.

**Solution:** The intermediate lever is guided on fixed circular arcs and engages slots in the type lever, with the pull rod in a plane parallel to the centre plane.
