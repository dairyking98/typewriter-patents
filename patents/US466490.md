## Reading (opening only, OCR fair)

**Problem:** Typing is slow because only one character is printed per key stroke.

**Solution:** Several keys, each for a different character position, are pressed together so a whole syllable or word is printed at once, with spacing keys setting how far the carriage advances.

**How it works:** Each lowercase letter has three keys (first, second, third position). A first-position key turns a type wheel to the character; second and third keys rotate separate type segments; each also fires a hammer that strikes the paper against an inked ribbon behind the type from the back. Releasing a key advances the carriage one, two or three spaces according to the position, and extra keys marked 1-4 add spaces. A word like 'the' is printed by pressing t, h, e and a space key together.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Type element:** [Type wheel (types on the rim)](../features/elem-wheel-rim.md), [Type sector or segment](../features/elem-sector-segment.md)
- **Impression:** [Hammer behind the paper](../features/imp-hammer-behind.md)
- **Inking:** [Ink ribbon](../features/ink-ribbon.md)
- **Spacing and escapement:** [Proportional spacing](../features/esc-variable-spacing.md), [Space key or bar](../features/esc-space-key.md)

**Parts:** type wheel; second-position type segment; third-position type segment; hammer; inked ribbon; traveling carriage; spacing key

**Numbers:** three key positions per letter; spacing keys 1 to 4
