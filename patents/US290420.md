## Reading (full text, OCR good)

**Problem:** Hammond's earlier machines swung one type segment either way from a centre position, which made the mechanism complicated.

**Solution:** Two type segments on one shaft, each carrying half the characters and each oscillating in one direction only from a rest position outside the other's field, with its own key-driven lever and stop-arm.

**How it works:** Key levers raise stop pins; two driving levers lie over the key levers so that the farther a key sits from the driving lever's fulcrum, the less the lever moves, and the amount sets how far the segment swings. Each driving lever is joined by a link and pin to its own type segment, so a right-hand key swings the right segment leftwards from its rest position and a left-hand key swings the left one the other way. The segment's pin runs free for a distance, then picks up a stop-arm that is arrested by the selected stop pin, which fixes the segment's position. Segments sit at rest a type-face length from the impression point so neither interferes with the other. A lug and pin lost-motion lets the key be released only half way before another key for the same segment is pressed. The shaft can be raised so the second or third row of type (lower case, capitals, figures) lines up with the impression hammer.
