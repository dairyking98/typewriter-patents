## Reading (short summary from the opening, OCR fair)

**Problem:** Accidental, partial or quick key strokes cause a character to be embossed when it should not be.

**Solution:** A keyboard typograph holds power connections normally inactive, engaging only when the selected key stays depressed until the power shaft reaches a set point in its revolution.

**How it works:** The selected key and a member moved by the power shaft both control the setting of the power transmitting connections, so the key must be held until the shaft reaches the set point.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Selection locked for printing](../features/sel-selector-locking.md)
- **Type element:** [Metal type](../features/elem-metal-type.md)

**Parts:** keyboard; die carrier; stop pins; power shaft; power transmitting connections
