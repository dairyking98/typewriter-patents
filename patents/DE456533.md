**How it works (reading):** A locking element on the adjustable intermediate member interacts with the release device so that the check mechanism stays blocked unless the member is set precisely.

## Reading (short summary from the opening, OCR fair)

**Problem:** A mis-set adjustable intermediate member on a cash register could let the check-issue mechanism run and be damaged.

**Solution:** A locking element on the adjustable intermediate member interacts with the release device so that the check mechanism stays blocked unless the member is set precisely.
