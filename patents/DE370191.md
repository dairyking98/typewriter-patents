## Summary

**Category:** misc / other, not a typewriter patent (lever gear for vibrators) · **Subject (patent classes):** Gearings comprising primarily only links or levers, with or without slides all movement being in, or parallel to, a single plane for conveying or interconverting oscillating or reciprocating motions

**How it works (reading):** A lever linkage with adjustable pivot holes turns one drive stroke into several shaking strokes of the object, so the transmission ratio can be set (the text describes a fourfold and a sixteen-fold version).

## Reading (short summary from the opening, OCR poor)

**Problem:** Vibrating devices need a shaking motion from a single back-and-forth drive, and gear or belt transmissions are used to multiply it.

**Solution:** A lever linkage with adjustable pivot holes turns one drive stroke into several shaking strokes of the object, so the transmission ratio can be set (the text describes a fourfold and a sixteen-fold version).

**Features:**
