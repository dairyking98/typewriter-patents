## Summary

**Category:** related office machine, not a typewriter (printing device, card-controlled machines) · **Subject (patent classes):** Character recognition characterised by the type of writing of printed characters having additional code marks or containing code marks

**How it works (reading):** Four printed index marks at fixed positions identify each character for photoelectric sensing; combinations of marks encode the meaning.

## Reading (short summary from the opening, OCR fair)

**Problem:** Machine-readable index marks on printed characters need consistent positions on the type set.

**Solution:** Four printed index marks at fixed positions identify each character for photoelectric sensing; combinations of marks encode the meaning.

**How it works:** Each type of the set carries one to four index marks at fixed positions relative to a reference point, so a photoelectric sensor reads the character code.
