## Reading (short summary from the opening, OCR fair)

**Problem:** Telegraphers need a uniform word count per line, which requires counting each word as it is written.

**Solution:** A counter in a casing is driven by the spacing mechanism after each word and indicates when a set number of words has been written on a line.
