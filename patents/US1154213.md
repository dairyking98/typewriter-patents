## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In the patent’s own words:** My invention relates to typewritmg machines and more particularly to tabulator mechanism.

**How it works (reading):** A tabulator whose keys can be used either as column selectors or as denominational selectors, with the stop bar limit set variably so any of many columns is reached by one carriage run to a stop.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulator mechanism of the day could select only one kind of position and needed many tabulator keys to reach many columns.

**Solution:** A tabulator whose keys can be used either as column selectors or as denominational selectors, with the stop bar limit set variably so any of many columns is reached by one carriage run to a stop.

**Features:**

- **Spacing and escapement:** [Tabulator](../features/esc-tabulator.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md)
