## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Spring or weight drive stores power that restores the carriage automatically; the store is wound by a treadle, the operator's weight, or a main weight stepped by an escapement key, and released to run the carriage back.

## Reading (short summary from the opening, OCR fair)

**Problem:** The carriage must be returned to its starting position by hand after each line, which tires the operator and costs time.

**Solution:** Spring or weight drive stores power that restores the carriage automatically; the store is wound by a treadle, the operator's weight, or a main weight stepped by an escapement key, and released to run the carriage back.
