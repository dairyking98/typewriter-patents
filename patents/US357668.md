## Reading (opening only, OCR good)

**Problem:** A type lever must lift its type from an ink pad, carry it to the paper, press it there and return it to the pad in a single key stroke.

**Solution:** A type lever that rocks and slides in a fixed keeper fulcrum is jointed to a crank on a rock shaft; a band from the key lever turns the crank half a turn and a spring band returns it.

**How it works:** Depressing the finger key pulls a band wrapped on a rock shaft, turning the crank about half a revolution. The crank moves the jointed type lever, whose free end carries the type in a curve away from the ink pad and up against the platen. Releasing the key lets a spring, acting through a second band on the opposite face of the shaft, turn the crank back and return the type to the pad. The same movement can be reversed so the type rests at the platen, or used for a single lever making repeated impressions.
