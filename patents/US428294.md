## Reading (full text, OCR fair)

**Problem:** Key-lever return springs in typebar machines are bulky or hard to fit, and space-key levers did not move like the type keys; the carriage also needed to be freed from letter-space control at will.

**Solution:** A cheap wire loop spring straddling each key lever, and space-key levers pivoted on the same fulcrum as the type keys with a supplementary spring, operating a double-rack letter-space escapement.

**How it works:** Typebar keys are long levers on a common fulcrum, each held and restored by a wire loop spring that fits between guide pins. Depressing any key rocks a right-angled vibratory frame, which shifts a holding ratchet from the rear toothed rack to the front rack; the rear rack, spring-drawn, moves forward one letter space until a stop, and on release the ratchet swaps back and the front rack with the carriage, driven by a spring-and-rod drive, advances one space. Space-key levers beside the type keys act on the same frame but travel further, taking the ratchet out of both racks so the carriage moves freely. The carriage runs on rails over the top plate with a cylindrical platen, feed roller and ratchet line-spacing.
