## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage return on a telegraphic typewriter must be quick without shock to the machine, and must work whether the machine is transmitting or receiving.

**Solution:** Depressing a return key closes an electric circuit that runs an electric motor, which returns the carriage through a cord, with the motor and carriage bar placed close together.

**Features:** [ESC:carriage-return](../features/esc-carriage-return.md), [USE:telegraph-printer](../features/use-telegraph-printer.md)

**Parts:** carriage; platen; keys; return key; motor; cord; frame posts
