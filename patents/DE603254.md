## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters for ciphering or deciphering cryptographic text wherein the operative connections between the keys and the type-bars are automatically and continuously permuted, during operation, by a coding or key member the connections being mechanical

**How it works (reading):** A set of letter rolls on the paper carriage, stepped as each letter is written, gives cipher values and is attached as a code device to the existing typewriter.

**Problem:** Typewriters need a way to encrypt text for secret transmission without changing the machine much.

**Solution:** A set of letter rolls on the paper carriage, stepped as each letter is written, gives cipher values and is attached as a code device to the existing typewriter.
