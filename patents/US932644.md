## Reading (opening only, OCR fair)

**Problem:** On a typebar machine with a shiftable typebar segment, the force needed to shift between cases should be adjustable.

**Solution:** The typebar segment is supported on parallel leaf springs with adjusting shoes and screw stops to set shift effort and travel.

**How it works:** The type bar segment hangs from parallel leaf springs that guide its case shift. Each spring has a pivoting adjusting shoe turned by a screw, which changes the spring's effective pressure in the lower-case position and so the key pressure needed to shift. Set screws in lugs on the segment meet fixed abutments to limit its shifted positions. Shown on a Monarch-style machine.

**Features:**

**Parts:** type bar segment; leaf spring; adjusting shoe; adjusting screw; set screw; abutment; shift key
