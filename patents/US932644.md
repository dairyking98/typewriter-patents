## Reading (opening only, OCR ['A shifting element hung on parallel leaf springs is a play-free way to shift without sliding bearings.'])

**Problem:** In a typebar machine, how to shift the type bar segment for upper and lower case.

**Solution:** A type bar segment supported on parallel leaf springs and shifted as a whole.

**How it works:** Key levers with sub-levers and pull links drive the typebars, which are carried by hangers on a type bar segment. Parallel leaf springs fixed to the segment and the frame support it and let it move between lower-case and upper-case positions. Shown on a Monarch-like machine.

**Features:** [SHIFT:axial](../features/shift-axial.md), [SHIFT:lock](../features/shift-lock.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ELEM:typebar](../features/elem-typebar.md)

**Parts:** key lever; sub-lever; pull link; type bar; type bar segment; leaf spring
