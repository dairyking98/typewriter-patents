## Summary

**Category:** related office machine, not a typewriter (printing device for punch card machines) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers

**In Google’s translation of the patent’s own words:** The present invention relates to a printing device, which is intended in particular for accounting machines, and aims to simplify the construction in particular in that the same mechanism can be used both for setting the types of a movable type carrier and for the type stop.

**How it works (reading):** A type carrier swung on a moving part is carried by a constantly reciprocating drive and is decoupled and moved to the pressure abutment when an inhibition stops it, so one mechanism both sets and stops the type.

## Reading (short summary from the opening, OCR fair)

**Problem:** The same tabulator mechanism is needed both to set the type carrier and to stop it at the type, which makes the printing device complex.

**Solution:** A type carrier swung on a moving part is carried by a constantly reciprocating drive and is decoupled and moved to the pressure abutment when an inhibition stops it, so one mechanism both sets and stops the type.
