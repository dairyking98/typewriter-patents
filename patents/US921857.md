## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulator keys can show either a punctuation mark or none between denomination groups, but only with a separate key set.

**Solution:** A character disk in the key cup, with a stem and button below the key, is turned to show different characters through a shutter, so one key set reads differently when adjusted.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
