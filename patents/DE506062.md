## Summary

**Category:** related office machine, not a typewriter (type drum for office printing machines) · **Subject (patent classes):** Letterpress printing apparatus specially adapted for office or other commercial purposes with curved printing surfaces, e.g. cylinders

**How it works (reading):** A single type drum carries curved type channels transverse to the drum axis so that both directions of print can be made with the same drum.

## Reading (short summary from the opening, OCR fair)

**Problem:** A type drum with axial type channels prints only across the label strip, while labels with metal fasteners need printing along the feed direction; two drums are needed to do both.

**Solution:** A single type drum carries curved type channels transverse to the drum axis so that both directions of print can be made with the same drum.

**Features:**

- **Type element:** [Multi-row type cylinder](../features/elem-cylinder-multirow.md), [Interchangeable element](../features/elem-interchangeable.md)
