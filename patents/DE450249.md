## Reading (full text, OCR good)

**Problem:** In the main patent DE352315 the sheet type box had milled slots in its legs to guide the types, which was costly and meant a separate box for every type height.

**Solution:** A plain U-section sheet box with no slots; the types are guided only by the end faces of the legs and a cover plate, so one box serves any type size.

**How it works:** A U-shaped sheet-metal type box (web and two angled legs) carries support plates at top and bottom with guide strips, optionally dovetailed. The box is positioned over the cover part of the type bar and fixed with one screw through the bar's top hole. The individual or paired group types slide between the cover part's inner surface and the smooth leg end faces. A common multi-armed leaf spring inside the box presses on projections of each type, holding each type resiliently at rest while letting each be pressed independently. The spring sits under cover strips so it exerts no lateral friction on the types.
