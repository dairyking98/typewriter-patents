## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Mechanical power drives with driven mechanism arranged to be clutched to continuously- operating power source

**In the patent’s own words:** My invention relates to a new and useful improvement in automatic type-writing machines, and has for its object to so construct a type-writer and organize its interdependent mechanisms as to cause their operations to be brought about automatically and by a power outside of the operator, it being only required that said operator lightly manipulate the keys to set the mechanisms in operation.

**How it works (reading):** A power-driven typewriter in which light key touch trips outside power for carriage travel, return and line feed, with differential letter spacing and automatic ribbon traverse.

## Reading (opening only, OCR fair)

**Problem:** Typewriters depend on the operator's force for keying, carriage return and line feed, and waste time on word spacing and ribbon changes.

**Solution:** A power-driven typewriter in which light key touch trips outside power for carriage travel, return and line feed, with differential letter spacing and automatic ribbon traverse.

**How it works:** Keys set mechanisms in motion; an external power source turns a feed screw that drives the carriage step by step through an escapement with rigid and spring-actuated pawls giving single or double width spaces. One key engages a clutch to return the carriage and a stop collar then turns the paper roll for lining. The ribbon spools are shifted crosswise by a ratchet so the whole ribbon width is used. A shoe on the key lever provides word spacing by the same key motion.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [ESC:carriage-return](../features/esc-carriage-return.md), [PAP:line-space](../features/pap-line-space.md), [INK:ribbon-feed](../features/ink-ribbon-feed.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** feed screw; clutch lever; spring-actuated pawl; rigid pawl; paper roll; ribbon spool; key lever; shoe; stop collar
