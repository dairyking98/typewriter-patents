## Summary

**Category:** related office machine, not a typewriter (calculator print spring load) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The subject of the invention is an adjustable spring load designed in the manner of a type for such single item printing media from calculating machines that are to be printed by the Number of correspondingly wide never-vein pressures with finger pieces connected to them ttxn a wave can be swung in the printing position.

**How it works (reading):** Each finger-piece sector gets its own adjustable spring loading, so the spring tension for each item type can be set independently.

## Reading (short summary from the opening, OCR fair)

**Problem:** Single-item printing springs share one shaft, so adjusting one spring means loosening and retensioning all of them.

**Solution:** Each finger-piece sector gets its own adjustable spring loading, so the spring tension for each item type can be set independently.
