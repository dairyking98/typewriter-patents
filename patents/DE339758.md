## Reading (short summary from the opening, OCR fair)

**Problem:** Setting a digit on an adding machine needs a reliable way to bring the rack into engagement with the adding wheel and couple the type setting rod.

**Solution:** A key press shifts parallel slide rails so that a stop moves a segment, engaging a drive rack with the adding wheel and a driving pin with the type setting rod.

## Description (Google Patents OCR, opening)

> Description Translated from German Type setting mechanism for adding machines. The invention relates to a Type setting mechanism for adding machines. The new facility is essentially such that by pressing a key a parallel shift of Slide rails takes place, whereby by pushing a stop the one Slide rail on one segment, one opposite parallel shift, one second pair of slide rails is effected so that on the one hand one with the one slide rail connected drive rack comes into engagement with the associated adding wheel and on the other hand, during the upward movement of this rack, a driving pin into a Recess of the type setting rod arrives and this couples with the drive rod. In the drawing, the invention is shown on an adding machine. The key levers 12 are arranged in rows from o to g such that a row of numbers is housed in a special key body, as shown in Fig. 2 can be seen; the key bodies are attached to the cross braces of the Machine attached.
