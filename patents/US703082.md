## Reading (opening only, OCR good)

**Problem:** With hammer-and-anvil machines, the blow depends on how hard or fast the key is struck, so print is uneven and paper or type can be damaged.

**Solution:** A spring is tensioned by the key stroke and a trigger releases the hammer only after a set tension, so every blow has the same force.

**How it works:** Depressing a key presses a transverse bar on a lever whose rear end rises and tensions a spiral spring tied to the hammer via a tension screw. The hammer is pulled up and caught by a weighted trigger (bell-crank) pawl in a notch. Near the end of the key stroke the lever trips the trigger, releasing the hammer so the spring drives it against the type shuttle and paper. Blow force is set by the spring tension screw, independent of finger force.
