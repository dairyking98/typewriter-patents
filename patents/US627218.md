## Reading (full text, OCR good)

**Problem:** In single-key-lever type cylinder machines the type cylinder had too small a stroke, so the printed line was hidden when the cylinder was in the raised position and impact was too weak for manifolding.

**Solution:** A single key lever with horizontal and vertical swing both rotates the type cylinder (via a toothed segment and pinion) and, when depressed, rocks the cylinder frame a large distance down to the platen.

**How it works:** The key lever 4 is forked onto a crown-wheel segment 10 so it can swing horizontally and vertically. Swinging it horizontally turns the segment, which drives a pinion on a hollow shaft and so rotates the type cylinder to the chosen longitudinal type row; a blade with marked recesses on the top plate indicates the row. A pin through the hollow shaft drives the cylinder yet lets it slide lengthwise for case shifts. Depressing the lever pulls rods and a horizontal bar that rock the cylinder frame against the platen; a toothed controlling wheel engages a knife-edge to finally align the type. A spring returns the frame and an elastic abutment deadens the impact.
