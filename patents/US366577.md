## Reading (opening only, OCR fair)

**Problem:** Improvement on Fitch's US345836 typebar-type machine: spacing, shifting positions of the type, inking and type mounting.

**Solution:** Add a spring-driven fine-toothed carriage rack whose engagement is set by a cam on the type frame so the carriage advances by a different distance per letter, plus raising/lowering frame positions and reversible double type-blocks.

**How it works:** Key-bars operate type-arms whose type-blocks screw onto wire arms and carry three sets of characters on each side; turning the block half-way round brings the second set into use. A pivoted frame carrying the type-arms is moved by control levers so lower-case, characters and numerals print above or below the line (as indices or fractions). A spring-actuated rack on the paper carriage engages a fixed tooth and a pivoted tooth whose starting position is set by a cam slide on the type frame, giving variable spacing per letter and adjustable word spacing. An inking roller on a spring-loaded shaft sits in the path of the descending type and moves away after inking.
