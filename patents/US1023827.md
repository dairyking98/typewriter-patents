## Reading (short summary from the opening, OCR poor)

**Problem:** Tabulating to a chosen column needs more than one operation, and the denomination stops are not selected in a single step.

**Solution:** Denominational devices on track-ways let any denominational position be set so that the column is selected in a single operation.
