## Reading (full text, OCR good)

**Problem:** Simplify the disc-type index machine so it moves exactly, with little friction and little operator force, and let it take a ribbon so carbon copies are not marked by buffers.

**Solution:** A lever hinged to the type disc is swung around a fixed index disc to the wanted character, then pressed down on a sliding shaft, which locks the disc, tilts the paper roller against the type, and on return spaces the carriage one tooth.

**How it works:** The type ring (an electrotype strip of types around its edge, replaceable) sits on a disc that turns freely on an inclined table. A non-rotating sliding shaft carries an index disc with the same characters, and the operating lever, hinged to the type disc, is swung around the index disc so a pointer lines up with the character and the type disc turns with it. Pressing the lever down slides the shaft; a bent locking lever on the type disc drops into a notch in the index disc rim before the blow, locking the selection. Through a collar groove, a lever and bell-crank arms, the shaft tilts the paper roller against the type through a ribbon plate whose slot passes only one type. On the spring return a pawl on the collar trips the spacing lever, which releases and re-locks a pinion so the rack-bar carriage advances one tooth. A cord, lever and spring give constant carriage tension, a thumb latch lifts the rack for return, and ribbon spools are advanced by pawls driven by the roller's motion. Adjustable cushioned buffers on the carriage take the roller blow.
