## Summary

**Category:** related office machine, not a typewriter (cash register print hammer lock)

**How it works (reading):** The locking member for the print hammer is set by a disc frictionally connected to the adjustment lever and swung out through the machine cycle independently of the lever, so the lever can stay in check position for the whole cycle.

## Reading (short summary from the opening, OCR fair)

**Problem:** On the NCR printing unit the setting lever automatically moves from check position to the off position after the first stroke when checks are printed, which is not wanted.

**Solution:** The locking member for the print hammer is set by a disc frictionally connected to the adjustment lever and swung out through the machine cycle independently of the lever, so the lever can stay in check position for the whole cycle.

**How it works:** A spring-loaded disc on the pin of the setting lever is driven by a rod and angle lever linked to the hammer, so the hammer lock moves without moving the lever.

**Parts:** adjustment lever; pawl; notch; locking member; frictional disc; rod; angle lever; pressure hammer

## Description (Google Patents OCR, opening)

> Description Translated from German Printing unit for cash registers or accounting machines The main patent 627 164 relates to a printing unit for cash registers or accounting machines, in which either a check or an inserted slip of paper is printed using the same printing hammer of the same type set. In this case, the check conveying device is stopped by means of a manually operated setting member for a slip print, while the work of the printing hammer is determined by a feeler lever. When printing a check, the setting lever is automatically moved from the check printing position to the switch-off position after the first working stroke of the printing hammer in order to prevent the printing hammer from making the second working stroke. At the end of each machine cycle, the setting lever automatically returns to the check printing position. The invention is intended to allow the automatic adjustment of the setting lever be avoided when printing checks from the check to the shutdown position, so that the setting lever during check printing processes during the entire machine cycle can remain in the check printing position.
