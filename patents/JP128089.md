## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection; Cylindrical Japanese-language typewriter

**In the English translation of the patent’s own words:** This invention relates to a Japanese-script printing machine characterised in that a disc-shaped type magazine is turned in step with a device for selecting the wanted character, and is moved forward or back by one or two spaces of the stored types, so that the wanted type is stopped in a fixed position, and pressing a given key prints that type.

**How it works (reading):** A disc-shaped type magazine is turned by a crank in step with a character index pointer and window, and a shift lever slides it forward or back one or two character spaces so that the wanted type sits under one of a few fixed printing levers.

## Reading (full text, OCR good)

**Problem:** A Japanese-script machine needs thousands of characters, and one key per character is impractical; the inventor wants a few keys to reach many types, with simpler construction.

**Solution:** A disc-shaped type magazine is turned by a crank in step with a character index pointer and window, and a shift lever slides it forward or back one or two character spaces so that the wanted type sits under one of a few fixed printing levers.

**How it works:** A carrier plate that can move only fore and aft holds a rotating disc magazine with many types set radially, with teeth and holes round its edge. A crank handle drives both the pointer of a character index plate and a character table showing in a window, and also turns the magazine through gearing. Stop rods drop into the magazine holes to hold each position. A shift lever moves the carrier, and so the magazine, forward or back by one or two spaces, selecting the middle, front or rear group of types. The selected type is then under an extraction hole beneath the type holder of one of a few fixed printing levers. The operator reads from a mark strip which numbered key prints each character of the displayed section, presses that key, and the lever lifts the type, grips it and strikes it through a ribbon onto the paper cylinder.

## Description (English translation of the Japanese text, opening)

> Japanese-script printing machine. Nature and object of the invention. This invention relates to a Japanese-script printing machine characterised in that a disc-shaped type magazine is turned in step with a device for selecting the wanted character, and is moved forward or back by one or two spaces of the stored types, so that the wanted type is stopped in a fixed position, and pressing a given key prints that type. Its object is to let a printing device worked by one set of keys hold types from two or more rows, so that the number of keys is reduced, the construction is simplified, and typing is made easy.
