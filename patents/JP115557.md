## Reading (full text, OCR good)

**Problem:** On a keyboard Japanese machine, moving the type to the print point, printing and returning should happen mechanically in one smooth sequence from a single key press.

**Solution:** A main shaft turning once per key press carries the type forward, pauses it via a cam-operated clutch, works the print lever in the pause, then returns the type.

**How it works:** Pressing a character key raises push-up rods that engage a pin between a disc and a link joined to the type magazine. A key press clutches the main shaft to a motor-driven gear. The main shaft drives the type-moving shaft through a second clutch, carrying the type to the print point. A cam on the main shaft then disengages that clutch, pausing the movement, while an arm on the main shaft works the print lever. The cam passes, the clutch re-engages and the type returns.

## Description (English translation of the Japanese text, opening)

> Specification. Motion mechanism for a keyboard Japanese-script printing machine Summary of the nature and object of the invention. This invention relates to a motion mechanism for a keyboard Japanese printing machine in which a main shaft, which begins to turn when a character key is pressed, mechanically carries the type to the printing point and back. To this mechanism a device is added, acting with the turning of the main shaft, that interrupts the motion for a certain time at the change-over from the forward stroke to the return stroke; and a device that works the printing lever is also mounted on that main shaft, so that it acts on the printing lever during that pause. Its object is to make the moving of the type and its printing, both from the character key, take place entirely mechanically, in one continuous smooth sequence, and so to increase printing efficiency.
