## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition; Human engineering on planes with different or alterable inclination, e.g. convex plane

**How it works (reading):** Extra keys are set at a different height from the main keys so the touch-typist's reference is unchanged.

## Reading (short summary from the opening, OCR fair)

**Problem:** Extra keys at the row ends confuse touch typists who find their hand position by the end keys.

**Solution:** Extra keys are set at a different height from the main keys so the touch-typist's reference is unchanged.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
