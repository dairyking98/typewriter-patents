## Reading (opening only, OCR fair)

**Problem:** Carriage of an Oliver machine must be freed from letter-spacing to move freely for inserting characters.

**Solution:** A carriage-release that moves the pinion out of mesh with the rack bar.

**How it works:** The pinion of the escapement is held in mesh with the rack-bar yieldingly; a release bar forces it out so the carriage moves either way end to end.

**Features:** [ESC:carriage-release](../features/esc-carriage-release.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [PAP:platen-roller](../features/pap-platen-roller.md)

**Parts:** carriage; pinion; rack bar; release bar; platen; spring

**Improves on:**

- Oliver typewriter: free two-way carriage release
