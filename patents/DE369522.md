## Reading (short summary from the opening, OCR fair)

**Problem:** Existing dot-type typewriters are too intricate to be practical, or their pin bundles break so a single pin cannot be replaced without a whole new bundle.

**Solution:** Each of 88 thin template plates carries a grid of guide slots and transmission pins that drive the print pins; a key lever advances the chosen plate, and plates are interchangeable so a different font can be fitted to the same machine.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
- **Type element:** [Interchangeable element](../features/elem-interchangeable.md), [Flat type plate](../features/elem-plate-flat.md)

**Parts:** 44-key keyboard with shift toggle; 88 template plates a; bearing blocks b b'; key levers c; transmission pins f; push pins h; base plate g

**Numbers:** 44 keys, 88 characters via toggle; plate thickness 0.25 mm; 88 plates about 22 mm stack; 200 pins per plate in 10 rows
