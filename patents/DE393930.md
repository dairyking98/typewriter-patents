## Reading (full text, OCR good)

**Problem:** Mignon-type pointer machines use one chart field per type, so a large chart is needed; the inventor wants fewer fields for easier handling and speed.

**Solution:** Each chart field serves four types on the cylinder, selected by an extra constant rotation, a constant axial withdrawal, both together, or neither.

**How it works:** A 4 x 6 = 24 field letter chart, symmetric about the machine centre so either hand can use it, sets the type cylinder (8 x 12 = 96 fields) through a bevel and spur gear drive and gear segment. The pointer is moved to a field and the other hand hits a push button to print. Pressing a finger button on the pointer pulls a cable that turns a ring gear on the segment by a fixed amount, bringing the next type to the print position. Pressing a lever on the pointer withdraws the cylinder axially against a spring by a fixed amount, bringing the neighbouring type (capital) in. Another lever does both at once, giving the fourth type. Each field carries a lowercase letter, capital, sign and figure. These shifts could also be done electrically.
