## Summary

**Category:** related office machine, not a typewriter (counter moving device for typewriters)

**In Google’s translation of the patent’s own words:** The invention relates to an improvement of the device for moving the counter in typewriters with arithmetic unit according to patent 508 931.

**How it works (reading):** The tie rods of the tab keys drive pawls that engage a locking pin on the rocker arm, which limits the rocker travel to the value of the tab key, and a fork leg holds the counter drive handle.

## Reading (short summary from the opening, OCR fair)

**Problem:** When a lower-order tab key is struck hard, the counter swings past its target column into a higher column, so values are entered in the wrong place.

**Solution:** The tie rods of the tab keys drive pawls that engage a locking pin on the rocker arm, which limits the rocker travel to the value of the tab key, and a fork leg holds the counter drive handle.

## Description (Google Patents OCR, opening)

> Description Translated from German Device for moving the counter on typewriters with arithmetic unit Die. The invention relates to an improvement of the device for moving the counter in typewriters with arithmetic unit according to patent 508 931. In this device, a transmission device is connected between the tab keys and the counter, so that when a tab key is pressed, the counter is automatically moved into the corresponding column. For this purpose a rocker arm with the known driver handle of the arithmetic unit is provided, which is connected by a link to an angle lever under the action of a spring, on one leg of which hook-like rods engage with the tabulator keys. It has now been shown that if a lower-order tabulator key is pressed down vigorously, the swing-sweep that moves the counter can experience such a great acceleration that it is not only shifted to the desired column, but beyond it, i.e. to a higher-order column which of course then brings the numerical values to be entered into the wrong columns.
