## Reading (opening only, OCR fair)

**Problem:** Ciphered texts must be easy for an authorised reader to make and reverse but hard for others.

**Solution:** A code mechanism of stepped disks set to a code word shifts how far the rack-driven rotary type carrier turns for each key.

**How it works:** A rotatable, rockable type carrier on a rod is turned by a pinion and rack, with a notched sheet-metal member shifted by whichever key is pressed. A code mechanism on the carriage has ciphering and deciphering disks with stepped peripheries, set by a code word and fixed with a rod. A feeler rod abuts a disk step according to carriage position and limits the spring-driven rack travel, so the type carrier position depends on key and code. The mechanism can be shifted axially for ciphering or deciphering and is covered by a casing.

**Parts:** type carrier; rod; pinion; rack; code disk; feeler rod; key lever; notched member; casing
