## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Paper-carriage guides or races

**How it works (reading):** A friction roller is fitted beside one guide eye so it takes the carriage weight on that side, with the roller height adjustable and conically shaped to run on the rail.

## Reading (short summary from the opening, OCR fair)

**Problem:** Guide eyes on long carriages create too much friction, while rollers alone let the carriage sway.

**Solution:** A friction roller is fitted beside one guide eye so it takes the carriage weight on that side, with the roller height adjustable and conically shaped to run on the rail.

**How it works:** The roller pin is inclined so the roller can be moved toward or away from the guide rail by adjusting it in its length direction.
