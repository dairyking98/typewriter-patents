> Description Translated from German Device for adjusting the stroke force of the type lever from Power-driven typewriters. The invention relates to a device for setting the stroke force of the type lever of typewriters with power drive by a Camshaft, which acts on a tension member that strikes the type lever. Of the Invention according to are Abstreifglieder, which the engagement duration of the tension member of a regulate each type lever, with the camshaft both individually and by means of of an actuator can be adjusted together. Devices which are used to regulate the stroke force of the type lever both individually and in their entirety are already known for typewriters with different drives. The new device makes it possible to set the stroke force for such typewriters either, for each individual type lever or for all type levers at the same time, in which, as mentioned above, a camshaft acts on tension members which drive the type lever. The device can consist, for example, of a transverse bar, which is arranged around an axis under the coupling members and which carries adjusting members, which allow the individual types to have the same font weight.
