## Summary

**Kind:** typebar machine · **Subject (patent classes):** Character-by-character adjustment

**In Google’s translation of the patent’s own words:** The invention relates to a device for setting the stroke force of the type lever of typewriters with power drive by a Camshaft, which acts on a tension member that strikes the type lever.

**How it works (reading):** A camshaft drives tension members that strike the type levers; stripping members set how long each tension member engages, adjusted individually by pivoting adjusting elements with hole rows, or together through a lever-driven transmission for fine adjustment.

## Reading (short summary from the opening, OCR fair)

**Problem:** The stroke force of each type lever in a power-driven typewriter must be set so that all characters have the same font weight, and an overall setting is also needed.

**Solution:** A camshaft drives tension members that strike the type levers; stripping members set how long each tension member engages, adjusted individually by pivoting adjusting elements with hole rows, or together through a lever-driven transmission for fine adjustment.
