## Summary

**Category:** related office machine, not a typewriter (stencil cutting machine with pointer) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for embossing, e.g. for making matrices for stereotypes

**In the patent’s own words:** My invention relates to improvements in stencil-cutting machines, my object being to provide an apparatus of simple construction and operation and to so combine a pointer with the rotatable member carrying the dies and with a stationary index that said pointer travels with the said rotatable member and the machine can be quickly and accurately operated.

**How it works (reading):** A pointer fixed to the rotating member that carries the female dies, read against a stationary index on the base, so the machine can be set quickly and accurately.

## Reading (short summary from the opening, OCR fair)

**Problem:** Aligning a stencil-cutting die accurately with a stationary index was slow and imprecise.

**Solution:** A pointer fixed to the rotating member that carries the female dies, read against a stationary index on the base, so the machine can be set quickly and accurately.
