## Reading (full text, OCR good)

**Problem:** When the paper carriage is turned up, the operator cannot tell where on the line to set it to add or amend a character.

**Solution:** A second, reversed scale on the carriage works with the fixed scale and index so the carriage can be set to any line position when lifted.

**How it works:** The carriage frame hangs on a hinge rail and carries platen, pressure roller and a front axle with carrying bands. A fixed numbered scale on the main frame is read by an index on the carriage, showing line progress when the carriage is down. A second scale numbered in the opposite direction sits on the carriage next to the writing line, so that with the carriage turned up its marks align with the characters written. The operator reads the reversed mark at a place on the paper and sets the carriage so the index points to the same number on the fixed scale, then strikes the key to add an omitted impression.
