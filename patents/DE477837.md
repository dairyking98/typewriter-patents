## Summary

**Category:** related office machine, not a typewriter (cash register type sets)

**In Google’s translation of the patent’s own words:** The invention relates to a cash register in which single amount printing wheels and total printing wheels work together with a printing device which is able to take impressions of both printing type sets by means of a single counter-pressure bearing and in which these two printing type sets are set by a common set of drive sectors.

**How it works (reading):** The counter-pressure bearing is moved between two type sets about the setting-sector axis and controlled so that it prints on either set, with the sets driven by common sectors.

## Reading (short summary from the opening, OCR poor)

**Problem:** One counter-pressure bearing must print both the amount and total type sets of a cash register.

**Solution:** The counter-pressure bearing is moved between two type sets about the setting-sector axis and controlled so that it prints on either set, with the sets driven by common sectors.
