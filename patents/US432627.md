## Reading (opening only, OCR good)

**Problem:** A machine is wanted that makes stereotype matrices simply, with letters spaced as in set type including justified line ends.

**Solution:** A keyboard-driven matrix-making machine with an oscillating, axially shifting multi-row type wheel and a variable-spacing carriage escapement.

**How it works:** Key levers oscillate the type wheel to bring the desired character into position, and a separate key set shifts the wheel along its shaft to choose capital, small, punctuation or fraction rows. An impression mechanism then drives the type into the matrix surface. The matrix carriage is spaced by an escapement wheel with a regulator giving irregular feed for letters needing different widths, plus extra spacing to even out line ends. Line spacing of the carriage is also provided.

**Features:** [ELEM:wheel-rim](../features/elem-wheel-rim.md), [ELEM:cylinder-multirow](../features/elem-cylinder-multirow.md), [SHIFT:axial](../features/shift-axial.md), [ESC:variable-spacing](../features/esc-variable-spacing.md), [ESC:escape-wheel](../features/esc-escape-wheel.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [PAP:flat-bed](../features/pap-flat-bed.md)

**Parts:** type wheel; wheel shaft; key lever; matrix carriage; escapement wheel; spacing regulator; shifting key; latch key
