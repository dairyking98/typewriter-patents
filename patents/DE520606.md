## Summary

**Category:** related office machine, not a typewriter (zero print apparatus computing machines) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The invention relates to such zero printing apparatus for printing purposes on computing machines, where your type carrier is for: the imprint the \ u11 (zero print) or the non-print of zero (empty print) each have a special one Position with respect to the print line is assigned.

**How it works (reading):** Differential gears connect each type carrier, its switching element and the zero/empty-print selector, so the zero position is set by gearing instead of a special movement, on a calculating machine with nine print places.

## Reading (short summary from the opening, OCR fair)

**Problem:** In known zero-printing devices, setting a type carrier to zero print needs a special movement that is entangled with a ratchet lock.

**Solution:** Differential gears connect each type carrier, its switching element and the zero/empty-print selector, so the zero position is set by gearing instead of a special movement, on a calculating machine with nine print places.
