## Reading (full text, OCR good)

**Problem:** In a Japanese typewriter with a very large character set, finding the wanted type in the magazine is slow, and the exposed type faces get soiled by sleeves and dust.

**Solution:** Cover the sliding type magazine with a fixed index plate of the same characters and add a pointer that follows the magazine forward and back and the frame left and right, so the pointer always shows which type is at the printing point.

**How it works:** The paper-cylinder and printing frame rides on rails and moves only left and right; the type magazine (rows and columns of cells) slides forward and back on ball frames. The right hand moves the frame, the left hand the magazine, to bring the wanted type under the gripping frame. A fixed index plate above the magazine shows the same characters in easy-to-read form, each column reversed in order. A pointer in a trapezoidal guide on the frame has a projection in a cross groove on the magazine's rear edge, so it moves sideways with the frame and lengthwise with the magazine. Pressing the pressing lever lifts the type by an arm into the gripping frame of the printing lever, which inks it on a roller and strikes it on the paper; on release the cylinder turns one character space.
