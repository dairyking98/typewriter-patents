## Reading (opening only, OCR fair)

**Problem:** In a power-driven typebar machine with several type groups per bar, setting the groups by a second spring-triggered drive delays the setting.

**Solution:** The power drive itself both moves the type-group selecting members into position and returns them, with the typebars thrown to print by the same drive.

**How it works:** Each key lever carries a bolt in a slider with two slots, the slider moving with a swivel lever on a cross axis. A pressed key frees a catch pawl so a hook engages a ratchet wheel on the running drive shaft and turns a crank disc, swinging a lifting rod. Only the slider of a depressed key has its recess around the rod's cross bar, so only it is swung with the rod, and its swivel lever, with a differently shaped slot per lever, pivots the group-selecting lever by different amounts. A spring-held lever and a nose release the linkage and later return it, all driven from the power drive.
