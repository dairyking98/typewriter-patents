## Description (Google Patents OCR, opening)

> Description Translated from German IMPERIAL PATENT OFFICE. PATENT LETTERING - M 245397 CLASS 15 #. GROUP Patented in the German Empire on May 2, 1911. The invention relates to a device for collecting the eraser dust for Typewriters. According to the invention, this new device is designed as a container, which can be made of sheet metal, wood, paper mache, celluloid or other material, and is set up so that it can be quickly inserted into the cavity above the type levers Typewriter can be introduced. The device then takes such a position one that when erasing the loosening parts of the eraser and the paper in the container fall into it and in this way the swivel joints of the type lever mechanism and the ribbon or any other drive connections are not soiled. Simultaneously the device serves as a support for the hand when erasing. The container is advantageously provided with an elastic edge, so that it does not cause damage on polished wooden tables.
