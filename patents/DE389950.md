## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates on a key and type lever mechanism for typewriters with the type lever attacking, Longitudinally displaceably guided push rod, which is moved by the key lever.

**How it works (reading):** An angle lever between key lever and type lever, with pivots placed so the weights of the linkage balance, returns the levers to rest without a separate spring.

## Reading (short summary from the opening, OCR fair)

**Problem:** Key and type levers rely on springs or uneven weight to return to rest.

**Solution:** An angle lever between key lever and type lever, with pivots placed so the weights of the linkage balance, returns the levers to rest without a separate spring.

**Features:** [Typebars](../features/elem-typebar.md), [Separate print key or lever](../features/imp-print-lever.md)
