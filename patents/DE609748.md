## Reading (short summary from the opening, OCR fair)

**Problem:** Line-by-line printing needs a full set of type carriers for every position in a line, and fixed-width carriers make the machine complex.

**Solution:** Independent type carriers, assembled per text line and strung on a holder that moves toward the platen, print the whole line with few moving masses.
