## Summary

**Category:** related office machine, not a typewriter (preventing type stop on booking machines) · **Subject (patent classes):** Auxiliary functional arrangements, e.g. interlocks

**How it works (reading):** A stop fixed to the machine frame works with counter cams; when the counter cam lifts a roller, a spring-loaded bounce segment drops to block the type stop automatically.

## Reading (short summary from the opening, OCR fair)

**Problem:** On booking machines, preventing type impression by moving a plate in front of the type stop needs manual changes to segments.

**Solution:** A stop fixed to the machine frame works with counter cams; when the counter cam lifts a roller, a spring-loaded bounce segment drops to block the type stop automatically.

**Features:**

- **Impression:** [Impression adjustment](../features/imp-impression-adjust.md)
- **Uses:** [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** bounce segment; type lever; control cams; counter; frame stop
