## Reading (opening only, OCR fair)

**Problem:** Earlier typebar machine (DE39977, DE44230) had type blocks that were hard to adjust and tie rods hard to connect, and the type-arm frame moved far to change case.

**Solution:** Type blocks fixed with adjustable nuts, tie rods hooked on a pin by turning, and a shifting type-arm frame centred on the small letters.

**How it works:** Key levers are bent and slotted so a pull rod hooks onto a pin and is held by turning it into line. Type blocks bolted with nuts on the arms allow fine adjustment. The type blocks carry three characters, small letters in the middle; a swinging frame carrying the arm guides is moved one way for capitals and the other for figures, with a lever and locking cross piece. A sliding rod carries the inking device.
