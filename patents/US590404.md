## Reading (opening only, OCR good)

**Problem:** Typing tabular columns requires lifting the carriage to find positions.

**Solution:** An auxiliary scale and set of movable pointers mounted on rods beside the main scale mark column positions without lifting the carriage.

**How it works:** Brackets on the frame carry an inner rod and an outer flexible rod. Movable pointers on the rod are set at column positions; an auxiliary scale with pointers (four scale spaces apart) and rows of naughts and periods slides on the rod to align figures. The carriage is moved until the main pointer meets a set pointer. The rod holds pointers away from the keys when not in use, and a version mounts on the carriage.
