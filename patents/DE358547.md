## Summary

**Category:** related office machine, not a typewriter (paper holder for adding machines) · **Subject (patent classes):** Programming-mechanisms for determining the steps to be performed by the computing machine, e.g. when a key or certain keys are depressed in which the operation of the mechanism is determined by the position of the carriage

**In Google’s translation of the patent’s own words:** The invention consists in a new design of such a paper circuit, which is suitable for such machines in which the paper trolley has a number of rotatably mounted stop fingers for the column indexing (tabulation).

**How it works (reading):** A special hand lever releases the sheet return spring first and then the paper carriage, so the paper can be re-set for the next column; tabulating fingers on an oscillating rod engage a fixed plate to fix each column position.

## Reading (short summary from the opening, OCR poor)

**Problem:** The tab stop fingers of the paper carriage and the sheet return spring must be released independently during column indexing.

**Solution:** A special hand lever releases the sheet return spring first and then the paper carriage, so the paper can be re-set for the next column; tabulating fingers on an oscillating rod engage a fixed plate to fix each column position.
