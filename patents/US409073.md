## Reading (full text, OCR good)

**Problem:** Typebar machines need a separate lever and different stroke for each character; the inventor wants a type carrier whose every type is brought to the print point and struck with the same key travel.

**Solution:** A spherical type segment hung on a universal joint at its centre is tilted by three oscillating cross-bars, selected by notched 'wards' on each key lever, so the chosen type comes under the centre and the whole block is then pushed straight down onto the paper.

**How it works:** Three cross-bars, each hinged at a rear shaft, push down through three rods with ball ends on three points of a type block that hangs from a sliding square shaft on a universal joint; a spring holds the shaft and bars up against stops. Each key lever lies across the cross-bars and has a ward (a notch pattern) on its lower edge, so on depression it first presses only some bars, tilting the sphere until its type sits below the sphere centre, then contacts all three and pushes the block bodily down in line with the shaft to print. Because the joint is at the sphere centre, every key has the same travel. In a modification each key can print two types: the spherical segment is rotated by a bell-crank lever through a limited angle (e.g. 45 degrees) about a vertical axis against the plate, and case pairs are placed that angle apart on concentric circles (8, 16, 24 and 32 types), so the same key hits upper or lower case.

**Numbers:** 3 cross-bars at the corners of an equilateral triangle; rotation limit 45 degrees for case change; concentric circles with 8, 16, 24 and 32 types

**Improves on:**

- typebar typewriters: one hanging type block replaces a bar per character and equalises key stroke for all characters
