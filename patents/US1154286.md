## Reading (opening only, OCR fair)

**Problem:** Dead (non-spacing) accent keys needed fixed keys with notches above the universal bar, so accents could not share keys with letters or numerals.

**Solution:** A shift-controlled adjustment piece covers or uncovers the notch in an accent key so the same key acts as a dead key in one case and a normal spacing key in the other.

**How it works:** Shifting the platen raises the case-shifting frame and, through a rod system and rocking shaft, moves a rod carrying an adjustment piece. In the shifted position the notch above the universal bar is uncovered, so a depressed accent key does not move the universal bar and the carriage does not advance. In the normal position the adjustment piece fills the notch and the key operates the bar and feed. A spring in the rod returns the piece after the bar has fully descended.

**Features:** [SHIFT:platen](../features/shift-platen.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [USE:special-script](../features/use-special-script.md)

**Parts:** accent key; universal bar; adjustment piece; rocking shaft; connecting rod; spring; shifting frame; type lever segment

**Improves on:**

- fixed notched dead keys: any key can be a dead key in one case and a normal key in the other
