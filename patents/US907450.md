## Reading (full text, OCR fair)

**Problem:** Centering a short line or heading means counting characters, halving and subtracting from a chosen center on the carriage scale, which is slow and error-prone.

**Solution:** A second, half-length carriage scale numbered in the opposite direction, with each division worth two letter spaces, slides beside the main scale so the operator just sets the carriage to the line's character count to start a centered line.

**How it works:** A bar parallel to the carriage scale carries a sliding sheet-metal auxiliary scale about half as long as the main scale but numbered 0 to 70 right to left, so each division is two letter spaces. The operator slides it until its zero pointer sits at the desired center on the main scale. To write a line of N characters and spaces, the carriage is moved until index N on the auxiliary scale registers with the existing carriage pointer, which puts half the line on each side of the center. Variants put the scale below the main scale or in a slot of a double main scale. A rotatable tubular multiplex scale on a rod has faces for single, double and triple letter spacing so spaced-out headings need no calculation.

**Features:** [Line and point indicator](../features/pap-line-indicator.md), [Attachment or accessory](../features/use-accessory.md)

**Parts:** carriage scale; auxiliary sliding scale; mounting bar; carriage pointer; zero pointer; multiplex tubular scale; rod; bracket arm

**Numbers:** main scale 7 in. long; auxiliary scale 3.5 in. long; scale indices 0 to 70; example: 22-character line centered on 40 runs from 29 to 50

**Improves on:**

- mental centering by counting and halving on the carriage scale: auxiliary reversed half-scale reads off the starting point directly
