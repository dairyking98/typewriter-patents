## Reading (opening only, OCR fair)

**Problem:** Typewriters with chord keys still need one keystroke per type; the maker wants far fewer keys and several characters selected at once for higher speed.

**Solution:** Assign each finger of both hands a key group, with contact groups controlled by two corresponding finger groups so one stroke selects up to four types at once, which a timer then prints one after another.

**How it works:** Keyboards have four finger key groups per hand and a thumb section for functions such as shift, spacing, tab and carriage return. Pressing keys closes contact groups that select the type carriers; a timing controller then prints the selected types in order index, middle, ring, little finger while the carriage steps. Struck keys are locked down until the machine is ready. Index-only strokes need no timer or motor coupling.
