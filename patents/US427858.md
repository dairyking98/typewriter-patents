## Reading (opening only, OCR fair)

**Problem:** Wants one finger key to actuate two or more type-levers in a radial typebar machine (the Hamilton design of US357666).

**Solution:** Rack levers meshing with toothed segments on crank arms move the radial type levers, with arrangements so a key can drive more than one lever.

**How it works:** Horizontal type levers are arranged radially around a circle, each pivoted to a crank arm with a toothed segment on a short shaft. A rack lever meshing with the segment, rocked up by a pin below which a key lever acts, swings the type to the central print point. Key levers lie between a bed plate and an annular plate. The opening only covers this general layout.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [IMP:element-to-platen](../features/imp-element-to-platen.md)

**Parts:** type lever; crank arm; toothed segment; rack lever; key lever; annular plate; bed plate; finger key; pin

**Improves on:**

- [US357666](../patents/US357666.md): adds a way for one key to drive two or more type-bars
