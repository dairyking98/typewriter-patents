## Reading (full text, OCR good)

**Problem:** Typing fixed-form documents such as certificates on the Nippon magazine typewriter needs a different line spacing, line start point and character spacing for each line, which the operator would otherwise judge and set by hand every time.

**Solution:** Notched control discs, geared to a rack on the carriage so they step with the paper cylinder's sideways feed, limit the column-feed pawl stroke (character spacing) and the cylinder's return stop (line start) separately for each line.

**How it works:** The paper-cylinder frame moves sideways under a mainspring through a rack and gears, held and released by a ratchet bar of unevenly spaced teeth and a pair of pawls, so pressing the cross-feed key advances exactly one planned line gap. A control disc geared to a carriage rack turns as the cylinder moves; each notch's depth limits how far the column-feed pawl piece travels, setting how many ratchet teeth the cylinder turns per character for that line. A second disc stops a control arm on the cylinder shaft after a spring-driven sector gear rewinds the cylinder, setting where the next line starts. Discs may carry several offset sets of notches or be swapped for other form layouts, and the ratchet bar can be turned to a different row of teeth.

## Description (English translation of the Japanese text, opening)

> Specification. Typewriter for certificates. Nature and object of the invention. This invention relates to a typewriter for certificates in which a gear is mounted on the paper-cylinder frame and meshes with a rack on the carriage, parallel to the cylinder; a control disc, with notches (or projections) round its edge corresponding to the number and arrangement of the lines of the document to be typed, is joined to that gear and turned by it as the cylinder moves sideways; and the depth (or height) of each notch (or projection) is set according to its line, so as to control the movement of the pawl piece of the column-feed mechanism or of a control arm on the cylinder, so that in every line printing starts at a set point and runs at a set column spacing. Its object is, when typing documents of fixed form such as certificates, to give each line its own spacing down the column and to start each line at a set point automatically, so that such documents are made simply and quickly.
