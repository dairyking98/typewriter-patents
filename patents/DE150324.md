## Reading (short summary from the opening, OCR fair)

**Problem:** Lists or tables of numbers need columns set on the typewriter, and fixed scale stops are slow to set.

**Solution:** Two rows of numbered sliders on an E-section rail above the carriage scale; the slide is set by pointer and each slider carries a digit scheme so column positions can be set quickly.
