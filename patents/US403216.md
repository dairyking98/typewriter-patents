## Reading (opening only, OCR fair)

**Problem:** Orbiting type-wheel typewriters of the earlier Dodson patent (US299754) need a keyboard arrangement able to print many characters without enlarging the wheels or putting too many characters on each.

**Solution:** Several type wheels on separate shafts on a revolving turret, each started by its own tier of latches released by keys, so a key picks which wheel turns once and prints.

**How it works:** A turret revolves inside a circular machine frame. It carries shafts with type wheels in the same plane, each with a starting arm at a different height. Two or more tiers of latches each act on only one arm; striking a key unhooks a latch which starts that wheel, which turns once (or more) and is stopped, printing its character, after which the paper is fed. Keys are grouped by wheel, so adding wheels and latch tiers allows more characters. The embodiment prints the ten Arabic numerals with three rows of keys.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Selection locked for printing](../features/sel-selector-locking.md)
- **Type element:** [Type wheel (types on the rim)](../features/elem-wheel-rim.md)
- **Typebars:** [Typebar action](../features/bar-type-action.md)
- **Spacing and escapement:** [Prints and spaces in one stroke](../features/esc-print-and-space.md)
- **Paper and carriage:** [Paper table and guides](../features/pap-paper-guide.md)

**Parts:** turret; type wheel; wheel shaft; starting arm; latch; tripping rod; key; key lever; cabinet base; circular machine frame; internal gear wall

**Numbers:** ten numeral characters

**Improves on:**

- [US299754](../patents/US299754.md): adds several wheels on one turret selected by tiered latches
- [US401371](../patents/US401371.md): applies that start/stop mechanism in a full machine
