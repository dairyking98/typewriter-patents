## Description (Google Patents OCR, opening)

> Description Translated from German IMPERIAL PATENT OFFICE. The invention relates to an improvement in the arrangement of the type lever on typewriters with an arched type lever bearing segment, which reduces the risk of the type lever colliding, which is particularly large in the type lever mounted in the middle of the type lever bearing segment, and thereby increases the writing speed. This is achieved according to the invention in that the type levers are bent in such a way that the angle enclosed by two type levers arranged on either side of the type lever bearing segment center in the stop position is increased. 1 S In order to simplify the arrangement of the fastening tabs for the type lever on the type lever positionfsegment, which is mounted on balls and therefore laterally connected to the fastening tabs, the type lever is bent outwards so far that each type lever is in the plane of the associated fastening tab.
