## Reading (full text, OCR fair)

**Problem:** A ribbon vibrator that lifts the ribbon to the print point with a fixed throw can only use one width-wise strip of the ribbon, which wastes a two-colour ribbon or leaves part of a plain ribbon unused.

**Solution:** The fulcrum of the ribbon vibrator's operating lever is moved up or down by a hand-set cam, with the actuating link switching to a second lug, so the same throw starts from a different height and presents a different strip of the ribbon.

**How it works:** Key action pulls a universal bar and an actuating link, which pulls down the rear arm of an operating lever and raises the ribbon vibrator. The lever pivots on a pin in a cylindrical fulcrum block that slides vertically in a hollow screw in the top plate. A front push button turns a rock shaft carrying slotted cam arms and a cam plate. The arm slots lift the fulcrum block, raising the lever and ribbon one field higher, while the cam plate swings the link so its upper lug, not the lower one, engages the lever at the same distance from the fulcrum. Throw stays the same but starts higher, so the other ribbon field meets the type. A spring detent holds the button in either position, and an adjustable screw stop limits the lever's upward throw.
