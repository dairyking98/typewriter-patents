## Reading (full text, OCR fair)

**Problem:** In the main patent's high-speed calculator printing unit, the pivoting type sectors were not guided laterally precisely enough, so the types did not strike the platen squarely.

**Solution:** Each type sector's radial guide arm is hinged to a link pivoting about a fixed axis, so the sector follows a controlled curve and meets the platen perpendicularly.

**How it works:** The type carriers are circular-ring sectors with a concentric slot. A spring-loaded lever, once released, engages the slot and hammers the sector against the platen. The sector's axis is a pin on a radial arm, which is hinged to a link pivoting about a fixed axis. At rest the link stands vertically upward, and on release it guides the sector along a curve so it strikes perpendicular to the platen. Link and arm lengths and angles tune the curve.
