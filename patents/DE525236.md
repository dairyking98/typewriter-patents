## Summary

**Category:** related office machine, not a typewriter (typewriter connected to punch machine)

**In Google’s translation of the patent’s own words:** The invention relates to a device on typewriters, in order to be able to operate a punching machine with this at the same time.

**How it works (reading):** The ribbon-change key switches the ribbon to red, and a contact on it operates the punch, so only text written in red is punched.

## Reading (short summary from the opening, OCR good)

**Problem:** Letters typed on a machine cannot be identified when transferred to punched cards, since the values and text look the same.

**Solution:** The ribbon-change key switches the ribbon to red, and a contact on it operates the punch, so only text written in red is punched.

The commercially available Card punching machines of this type are mostly only for the reproduction of numerical values set up. The representation of letters on the punch cards was pretty pretty laborious. With newer machines letters, 'names etc. can also be used transferred by simple means. However, it turned out that there was an identification the values transferred to the punch cards in the letter text is not possible. In order to mark this transmission, according to the invention the button for changing the ribbon on the typewriter to control a die Connection with the punching machine monitoring contact device used so that the punch is only effective when the typewriter is in other than the normal color writes.
