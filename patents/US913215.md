## Reading (full text, OCR fair)

**Problem:** Typebars strike the paper with full force when hit hard, blotting the print and cutting sharp-edged letters like e, o and i through the paper, and they return slowly; fixed stops in the typebar path are noisy and do not speed the return.

**Solution:** A bent adjustable spring on each typebar hits a fixed stop just before the type reaches the paper, acting as a buffer and then as a rebound spring that throws the bar back faster.

**How it works:** A spring is fixed near the type end of each typebar, its free end bent into a hook whose bow projects slightly past the type face. The straight end is threaded with two nuts so the operator can set how far the bow sits ahead of the type. On the stroke the bow hits a projection on a fixed plate first and gives way, so the bar's weight and inertia carry the type the last distance to the paper with only enough force for a clean impression. The compressed spring then pushes the bar back to rest with accelerated motion.

**Parts:** typebar; bent spring; adjusting nut; fixed stop plate; stop projection; actuating rod

**Improves on:**

- fixed stops in the typebar path: a resilient buffer spring on the bar is quieter and also speeds the return
