**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a Type lever drive for typewriters.

**How it works (reading):** The type lever returns to rest through the paper carriage switching device, with pawls on a ratchet and a snap-release rod, so no extra spring is needed.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type lever return normally needed its own spring or power source.

**Solution:** The type lever returns to rest through the paper carriage switching device, with pawls on a ratchet and a snap-release rod, so no extra spring is needed.
