## Reading (opening only, OCR fair)

**Problem:** The operator must take the hands off the keyboard to return the carriage and turn the line spacing between lines.

**Solution:** A spring wound by the letter-by-letter rotation of the paper cylinder is released by one special key, which returns the cylinder to the line start and advances the line in one action.

**How it works:** Each key stroke moves a cross-bar that works a lever and pawl, stepping a ratchet wheel one tooth on the key's return stroke. A clutch couples the ratchet wheel through a square shaft and pinion to teeth on the paper cylinder, so the cylinder turns one letter space per stroke, winding a helical spring. At line end the special key disengages the clutch so the spring turns the cylinder back to its starting position against arms and a rib, while the cylinder is shifted lengthwise by one line distance.

**Features:** [ESC:pawl-rack](../features/esc-pawl-rack.md), [ESC:carriage-return](../features/esc-carriage-return.md), [ESC:spring-drum](../features/esc-spring-drum.md), [PAP:platen-roller](../features/pap-platen-roller.md), [PAP:line-space](../features/pap-line-space.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** paper cylinder; key lever; cross-bar; ratchet wheel; pawl; clutch; square shaft; pinion; helical spring; return key; tilting frame
