**How it works (reading):** The carry control member is movable and lockable along the cross counter's travel, set by hand or automatically, so it engages near the end of the return.

## Reading (short summary from the opening, OCR fair)

**Problem:** On a calculating typewriter the carry-introducing control is fixed, so a short return of a smaller cross counter fails to introduce the carry.

**Solution:** The carry control member is movable and lockable along the cross counter's travel, set by hand or automatically, so it engages near the end of the return.
