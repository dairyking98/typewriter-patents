## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The subject of the invention is a drive device for the type lever of typewriters, in which the type levers the last part of their way up to the stop on the paper roller by their inertia alone return.

**How it works (reading):** Each key lever is rigidly connected to its type lever by a handlebar, so the type lever is driven all the way to the paper roller without loose play, with the universal rail acting only during the momentum phase.

## Reading (short summary from the opening, OCR fair)

**Problem:** Loose joints between key levers and type levers cause rattle and wear, and type levers rely on inertia at the end of the stroke.

**Solution:** Each key lever is rigidly connected to its type lever by a handlebar, so the type lever is driven all the way to the paper roller without loose play, with the universal rail acting only during the momentum phase.

**How it works:** A handlebar on each type lever reaches a position aligned with the pivot when the key is down, so the drive stays connected.
