## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** My invention relates to typewriting machines and more particularly to the type actions of such machines.

**How it works (reading):** Key levers and sub-levers are arranged so the leverage on the type bar is highest at the start of the key stroke and falls as the key descends, giving a uniform action across the whole set of type bars.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type-bar leverage was not accelerated and not uniform across sub-levers and key levers of different lengths.

**Solution:** Key levers and sub-levers are arranged so the leverage on the type bar is highest at the start of the key stroke and falls as the key descends, giving a uniform action across the whole set of type bars.
