## Description (Google Patents OCR, opening)

> Description Translated from German Type setting device, especially for typewriter types The invention relates to a type attachment device, in particular for typewriters, in which the types guided laterally between guide jaws by magnetic force be drawn onto the type edition. The guide jaws of the type setting devices of this type passed ; mostly made of ordinary steel. This material has the disadvantage that it is magnetizable and is not indifferent to solder and flux. It was therefore posed to this Defects. to eliminate, the guide jaws made of V 2a steel. V 2a steel is difficult to be processed and is also against the hydrochloric acid, which mainly forms the soldering water not completely invulnerable, so that it is in the case of soldering devices with guide jaws from this material also requires special care in order to avoid that Soldering fluid reaches the guide jaws. In order to eliminate these disadvantages, are according to the invention Guide jaws made of soapstone, which are easy to machine and non-magnetizable and is completely indifferent to solder and flux.
