## Reading (opening only, OCR poor)

**Problem:** In the earlier machine (patent 896496) the type carriage moves a different distance for each letter, so effort and key travel vary.

**Solution:** Split the type carriage into a lower part that always moves to its far limit and an upper part carrying the type blocks that is stopped at the right position and decoupled.

**How it works:** Type blocks slide crosswise on an upper carriage which rides on a lower carriage along a dovetail guide parallel to the platen, with balls or rollers between them. In rest the two are coupled by ball detents. A key moves the lower carriage to its limit, taking the upper along until a stop set by the key halts the upper carriage at the position for the chosen type block. The detent releases and the lower carriage runs on. Return to the base position is by return elements.
