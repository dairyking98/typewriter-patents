## Reading (full text, OCR fair)

**Problem:** On multi-case typebars, earlier machines bent the type ends or set the types at graded angles, which gave crank-like, blurred impressions and took up room in the typebar basket.

**Solution:** Keep every typebar straight, with its types one behind another in the bar's own radial plane, and change case by shifting the pivots of the drivers radially in that same plane with a common shift plate.

**How it works:** Each key-lever works a bellcrank, then a draw link to a driver pivoted in the middle of a jointed Yost-type typebar, which also hangs from a guide link. The driver's lower pivot sits on a radially arranged support lever. All support levers engage a segmental shift plate, which a shift key moves on parallel links. This moves every support radially and changes the path the bar follows, so the upper-case type instead of the lower-case type reaches the printing point, with each bar staying in its own radial plane. The types rest on a fixed inking pad and print direct, without a ribbon. Each type is on a holder with a pin-and-slot connection, so it can move independently and stay centred on the pad. A cylindrical type guide has walls thin enough that the other type on the bar straddles it. Two sets of staggered hangers front and rear of the segment let many bellcranks fit in the keyboard width.
