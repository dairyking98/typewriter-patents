## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**How it works (reading):** The machine is built so the writing line sits about 30 cm or more above the table surface while keeping a normal keyboard height.

## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriters sit so low that the writing line is near desk level, which harms posture and makes checking text hard.

**Solution:** The machine is built so the writing line sits about 30 cm or more above the table surface while keeping a normal keyboard height.

This low position of the writing line makes checking what has been written very difficult for both the writer and the dictator, so that in numerous cases curvatures of the spine and visual disturbances can be observed in the writers.
