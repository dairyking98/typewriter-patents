## Summary

**Category:** related office machine, not a typewriter (paper carriage return on calculators) · **Subject (patent classes):** Programming-mechanisms for determining the steps to be performed by the computing machine, e.g. when a key or certain keys are depressed in which the operation of the mechanism is determined by the position of the carriage

**How it works (reading):** Moving the carriage left with the motor key swings a double lever that disengages a locking bolt, switching on the carriage return clutch, while the return is in progress the motor key is locked.

## Reading (short summary from the opening, OCR fair)

**Problem:** The paper carriage return key was unwieldy and the return could not be started by the normal motor key.

**Solution:** Moving the carriage left with the motor key swings a double lever that disengages a locking bolt, switching on the carriage return clutch, while the return is in progress the motor key is locked.
