## Reading (opening only, OCR fair)

**Problem:** Ordinary typewriters cannot write in heavy bound record books of county offices and courthouses.

**Solution:** A flat-bed machine with the page lying flat and a two-axis carriage system moving a type block with a hammer over the page.

**How it works:** Rods in the main frame guide a primary carriage that moves the printing mechanism from line to line; a secondary carriage on cross bars moves it along the line. The secondary carriage holds friction-roller bars on which a hollow type block rides. Vertical type stems play through the block head, with conical guiders underneath. A hammer bar inside the block strikes the selected stem; many keys connect through links, bell-crank levers and slide bars (one per key) to hook rods that lift a third set of bell cranks, and an inking pad is operated alongside the hammer.

**Features:** [Flat bed or book typewriter](../features/pap-flat-bed.md), [Book typewriter](../features/use-book-typewriter.md), [Moving print head](../features/esc-moving-print-head.md), [Separate type slugs or plungers](../features/elem-individual-slugs.md), [Hammer behind the paper](../features/imp-hammer-behind.md), [Ink pad](../features/ink-pad.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** main frame; guide rod; primary carriage; secondary carriage; type block; type stem; conical guider; hammer bar; key; bell-crank lever; slide bar; inking pad
