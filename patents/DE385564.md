## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter in the button levers from the subframe and the type levers from an intermediate frame be worn.

**How it works (reading):** The intermediate frame is a horizontal lower rail with a type lever bearing segment on posts, which is easily exchangeable, so the type levers and linkage can be assembled outside the machine and then connected to the button levers.

## Reading (short summary from the opening, OCR fair)

**Problem:** Assembling the type lever set and its linkage in the machine is awkward because the type levers and their intermediate frame must be fitted on the base frame.

**Solution:** The intermediate frame is a horizontal lower rail with a type lever bearing segment on posts, which is easily exchangeable, so the type levers and linkage can be assembled outside the machine and then connected to the button levers.
