**How it works (reading):** Switching means for each type set pick out any impulse of a common timed impulse distributor, so one key selects the matching type in every set; the type seats sit on a drum and hammers press the sheet against the selected type.

## Reading (short summary from the opening, OCR fair)

**Problem:** Selecting single characters from several type sets for printing used to need key or type replacement, and a shared power distributor could not pick one type through a single control member.

**Solution:** Switching means for each type set pick out any impulse of a common timed impulse distributor, so one key selects the matching type in every set; the type seats sit on a drum and hammers press the sheet against the selected type.
