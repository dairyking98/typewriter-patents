## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Detents, brakes, or couplings for feed rollers or platens

**In the patent’s own words:** This invention relates to typewriters, and more particularly to typewriters having mechanism for effecting the return of the paper carriage to the beginning of a new line of print.

**How it works (reading):** Mechanical means automatically lock the keys or printing during the carriage return so no character can be struck until the return finishes. The stated object is cut off in the OCR, so the exact locking element is not clear from the excerpt.

## Reading (short summary from the opening, OCR fair)

**Problem:** A fast operator strikes a key while the carriage return is still moving, so a letter is printed on the newly spaced line and marks it.

**Solution:** Mechanical means automatically lock the keys or printing during the carriage return so no character can be struck until the return finishes. The stated object is cut off in the OCR, so the exact locking element is not clear from the excerpt.
