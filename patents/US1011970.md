## Summary

**Kind:** typebar machine · **Subject (patent classes):** Bearings or hangers for type levers

**In the patent’s own words:** My invention relates to typewriting machines and more particularly to type rests for such machines.

**How it works (reading):** A resilient type rest reacts on the type bars so the rebound is prevented or reduced, instead of a non-resilient lead rest.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type bars rebound off the type rest and can jump from it when others are operated.

**Solution:** A resilient type rest reacts on the type bars so the rebound is prevented or reduced, instead of a non-resilient lead rest.
