## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**In the patent’s own words:** My invention relates to typewriting inachines and more particularly to means for preventing the type faces from being injured by collision between the bars at or near the printing point.

**How it works (reading):** Type bars carry removable type blocks fitted to a conical stem, with needle type faces, and the arrangement is set so bars do not collide at the printing point against the platen.

## Reading (short summary from the opening, OCR fair)

**Problem:** Segmental type bars colliding at the printing point could injure type faces, especially needle-faced types.

**Solution:** Type bars carry removable type blocks fitted to a conical stem, with needle type faces, and the arrangement is set so bars do not collide at the printing point against the platen.
