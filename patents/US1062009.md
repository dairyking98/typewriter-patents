## Reading (opening only, OCR fair)

**Problem:** A power carriage return should be fast on long lines without shock, yet slow and complete for short or varying lines and for paragraph indents.

**Solution:** A key-controlled electric motor whose speed is set by circuit resistance returns the carriage, cutting power after a set number of motor revolutions so momentum completes the return.

**How it works:** A motor bracketed to the typewriter turns a drum that winds a draw band; the band first pulls the line-space lever (turning the platen ratchet) and then draws the carriage to the right. Several keys close the motor circuit and insert different resistances, giving a slow start that is then accelerated, or a slow full return. A cut-out after a set number of revolutions stops power early on long returns. A marginal key sets a stop plunger on the carriage path so the carriage is returned to a chosen starting point such as a paragraph indent, the stop being withdrawn on key release.

**Features:** [Carriage return](../features/esc-carriage-return.md), [Line spacing](../features/pap-line-space.md), [Electric drive](../features/imp-electric.md), [Margin stops](../features/esc-margin-stop.md)

**Parts:** motor; drum; draw band; idler; line-spacing lever; line-spacing wheel; platen; resistance; cut-out device; marginal key; stop plunger

**Improves on:**

- earlier power carriage return machines: speed control, cut-off and selectable stop position
