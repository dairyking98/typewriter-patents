## Reading (short summary from the opening, OCR fair)

**Problem:** Each repeated print in a register drive needed the spring to be re-tensioned between impressions.

**Solution:** A single mainspring is tensioned in advance for a set number of prints, and a setting device limits each re-tension to the spring travel used up.
