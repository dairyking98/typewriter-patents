## Reading (opening only, OCR good)

**Problem:** Changing the typebar guide frame (a different type set) needs a safe, quick lock that cannot be left unlocked.

**Solution:** A sequence-dependent interlock between latch bolts, a locking comb that holds the intermediate levers, and the protective cover.

**How it works:** The typebar guide frame rests on four bearing points on the machine frame. Pivoting latch bolts on each side engage pins on the frame to lock it. A locking comb guides the intermediate lever heads; it must be lifted to let the bolts swing and release the frame. The cover can only be put back when the comb is down, which locks the bolts, so the machine cannot be used unlocked.
