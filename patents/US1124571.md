## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Type

**In the patent’s own words:** My invention relates to type blocks for typewriting and like machines.

**How it works (reading):** A type block with a chemically hardened face and a relatively soft shank, so the shank can be bent to adjust the block on the type bar while the face stays hard.

## Reading (short summary from the opening, OCR fair)

**Problem:** Integral type-block shanks were either hardened so they could not be bent to adjust the block on its bar, or soft so the type faces were easily defaced.

**Solution:** A type block with a chemically hardened face and a relatively soft shank, so the shank can be bent to adjust the block on the type bar while the face stays hard.
