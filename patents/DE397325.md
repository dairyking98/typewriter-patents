## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage step from the escapement is hard to set precisely.

**Solution:** A fixed pawl is adjusted along an arc around the escapement wheel and can be clamped, so the step is set with a movable pawl on the same device.
