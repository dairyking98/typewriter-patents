## Description (Google Patents OCR, opening)

> Description Translated from German Embroidery machine for embroidering several ribbons at the same time. object the invention is an embroidery machine, which for simultaneous fully automatic Embroidering several ribbons is intended to serve. For this purpose are the previously known automatic embroidery machines for various reasons less suitable. According to the present Invention, the intended aim is achieved essentially in that over a fixed tensioning device for the actual ribbons to be embroidered Rod carrying embroidery devices on a longitudinally and transversely movable support is attached, which is stitched by a jacquard work at the same time in the longitudinal and Cross direction is adjusted according to the pattern. The arrangement is advantageous in this way taken that by the jacquard both the longitudinal adjustment and the same time the transverse adjustment is made to a different extent for each stitch of the machine can be, so that it results from the changeable individual components. resulting Stitch within wide limits both in size and in direction The influence of the jacquard changes completely automatically according to the pattern.
