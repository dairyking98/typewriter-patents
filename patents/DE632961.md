**Kind:** a part or mechanism (any kind of machine)

**In Google’s translation of the patent’s own words:** This object is achieved according to the invention in that a number of amount type sets corresponding to the number of colors used is provided and the column selection is effected both by controlling the print hammers assigned to the amount type sets and by shifting the document sideways with respect to the amount type sets .

## Reading (full text, OCR good)

**Problem:** Cash registers and accounting machines that switch ink colour by swapping or advancing ribbons mix colour residues on shared type, so the colours blur over time; and one document column cannot show amounts in different colours.

**Solution:** Use one dedicated amount type set per colour, each with its own ribbon colour, and pick the colour by choosing which set's hammer fires and by shifting the document sideways relative to the type sets.

**How it works:** Several type-wheel groups sit on one axis: date, account number, and two amount sets (positive in blue, negative new balance in red). The machine's rack gearing sets both amount sets to the same amount at once. Each set has its own print hammer, and only one of the two amount hammers is made effective, so the amount is printed by the set that matches its sign. A ribbon strip with a blue and a red zone separated by a colour-barrier piece runs in front of the sets. A paper trolley carrying the receipt shifts column by column according to the transaction type, so a negative result can be lined up with the red set in the same column.
