## Reading (full text, OCR fair)

**Problem:** Motor-driven type drums carrying several equivalent character groups (fonts, sizes, cases) take too long and wear too much if each height change returns to the bottom position, and lever or coarse/fine key schemes cannot reach all groups with one set of character keys.

**Solution:** Two groups of special height keys, one choosing the font or size group and one choosing the type row within the group, drive a motor-powered rake and hook that lift the drum to the right row without returning to the bottom each time.

**How it works:** A continuously running motor drives the type drum through a friction clutch; the stopping position of its shaft encodes the key combination read from rails under the keys and cam-driven contacts. An electromagnet then catches a ratchet to stop the shaft and clutches a work shaft. A spring-loaded rake of graded teeth and steps is connected by a rod to a ring on the drum. An electromagnet-controlled hook releases the rake so the drum drops to its lowest position; a torque-limited clutch then lifts it again until a step selected through an eccentric on the shaft meets a lever plate, which picks the group. The spring pulls the drum down slightly until the hook falls onto the tooth of the chosen row, which sets the exact print height. A second key picks a row within the group, and a cam and lever can return the drum to lower case automatically after each letter unless a hold key keeps the setting for digits.

**Numbers:** 5 font or size groups with 3 type series each; 32 contact combinations, 8 used for height switching; 6 key rails

**Improves on:**

- height switches for type drums that return to the lowest position before each setting: reaches each row directly through coarse and fine steps
- two-type-set drums with hand lever: keys on the keyboard, no hand taken off, compatible with punched tape control
