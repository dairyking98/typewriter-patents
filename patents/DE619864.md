## Summary

**Category:** related office machine, not a typewriter (punch card printer with rotating type drum) · **Subject (patent classes):** Control for hammer-impression mechanisms

**In Google’s translation of the patent’s own words:** The present invention relates to a printing punch card machine with a rotary Type drum, on which number and letter types in a row one behind the other are attached in a group arrangement.

**How it works (reading):** Double card hole sensing: one sensing set times the hammer coupling and a second set locks the escapement to select a type within a group on the rotating drum.

## Reading (short summary from the opening, OCR fair)

**Problem:** Card-controlled printing needs both number and letter types selected reliably from one drum.

**Solution:** Double card hole sensing: one sensing set times the hammer coupling and a second set locks the escapement to select a type within a group on the rotating drum.
