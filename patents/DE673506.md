## Summary

**Category:** related office machine, not a typewriter (calculating machine with printing unit)

**In Google’s translation of the patent’s own words:** The invention relates to a calculating machine, cash register or the like with printing unit and adjusting members for single item transactions and for multi-item systems and a counter showing the number of trades introduced into the machine.

**How it works (reading):** The business counter is advanced only when a non-zero value is transferred to the type carrier and an amount key or the multi-item sum member is set, so idle strokes are not counted.

## Reading (short summary from the opening, OCR fair)

**Problem:** Existing counters count every key press or idle stroke, so the number of customer transactions is not recorded correctly in multi-item sales.

**Solution:** The business counter is advanced only when a non-zero value is transferred to the type carrier and an amount key or the multi-item sum member is set, so idle strokes are not counted.
