## Reading (opening only, OCR good)

**Problem:** Interchangeable type blocks need a keyboard that shows the right characters.

**Solution:** The keyboard is split into a fixed group and a removable plate of characters matching each type block.

**How it works:** In the Lambert machine one multiple key tilts on a universal joint so pressing a labeled point brings that type of the block to the print line and then prints. The type block is clamped in a socket and swappable. A plate with the differing characters, secured by pins and spring latches, replaces part of the key top, giving about fifteen differing characters.
