## Reading (full text, OCR fair)

**Problem:** A simple, cheap typewriter is wanted in which one key can print a small letter, a capital or a figure without a separate set of types for each.

**Solution:** A single type wheel on a sliding horizontal shaft is turned through up to about 180 degrees either way by cams on the key levers, and a cam-slotted positioning hub shifts its starting angle so the same key prints lower case, capitals or figures.

**How it works:** Each key lever carries a bent cam rod; half the keys push a rod one way, half the other, rocking a shaft whose segmental rack turns a pinion on the type-wheel shaft, so the wheel rotates to the key's letter. The characters are laid out in repeating groups of small letter, figure, capital, so a stud riding in a three-part cam slot in the rack hub (moved by capital and figure finger keys, lockable by pawls) rotates the wheel's start position to select the case. A second cam on the same key then rocks a lever that slides the wheel shaft axially so the tilted wheel touches the paper roll at one point through a ribbon and frisket. A spring returns the wheel to rest. On release a pawl and rack step the paper carriage, with a per-key cam varying the step for wide and narrow letters, and the same rock shaft ratchets the ribbon drums.
