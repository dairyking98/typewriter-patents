## Reading (opening only, OCR fair)

**Problem:** A lighter, cheaper typewriter with few keys was desired.

**Solution:** Machine with 26 type levers on pivots sharing one strike point, triple type blocks shifted by moving the type frame, and variable letter spacing.

**How it works:** Flat-steel type levers on pointed pivots in a frame all strike one point; each type has capital, small letter and figure, selected by sliding the frame on rods with two levers and stops. Wooden key levers pull tie rods to the type levers. A rubber platen roller backs the type. A spring pulls the paper carriage, governed by a rack, wheel and rocker mechanism with four ratchet wheels that allots wider spacing to w and m than i.
