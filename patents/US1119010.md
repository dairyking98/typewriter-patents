## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriter tabulator stops have to be set to a fixed carriage position and cannot be moved to a new place without rebuilding the mechanism.

**Solution:** An air-cylinder piston, connected to the spacing lever, drives the carriage through a tabulator bar and rods, using the existing tabulator keys, so the carriage is stopped at any chosen place.

**Features:**

- **Spacing and escapement:** [Tabulator](../features/esc-tabulator.md), [Mainspring-drawn carriage](../features/esc-spring-drum.md)
