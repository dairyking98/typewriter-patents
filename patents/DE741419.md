## Summary

**Category:** related office machine, not a typewriter (keyboard for matrix setting and line casting) · **Subject (patent classes):** Devices or arrangements for assembling matrices and space bands; Keyboards; Syllable, line, or like type selection

**In Google’s translation of the patent’s own words:** The invention relates to a key system for a matrix setting and line casting machine for setting syllables and words.

**How it works (reading):** A single key drives a spring-loaded rotating drum on which several cams close the trip circuits one after another, with set time intervals for a syllable or word.

## Reading (short summary from the opening, OCR fair)

**Problem:** Syllable keys for matrix casting machines suffer from wrong contact timing and wear of contact springs.

**Solution:** A single key drives a spring-loaded rotating drum on which several cams close the trip circuits one after another, with set time intervals for a syllable or word.
