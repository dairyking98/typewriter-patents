## Reading (opening only, OCR good)

**Problem:** On the Remington the rack-bar release arm is at the rear and hard to reach.

**Solution:** An independent release-key extending to the front of the machine lets one hand disengage the hinged rack-bar from the feed dogs and run the carriage either way.

**How it works:** The carriage rack-bar is hinged so it can be lifted clear of the rigid and flexible dogs. A separate release key reaches forward over the keyboard to a point within the operator's hand, and when pressed lifts the rack-bar so the carriage may travel freely without the line-space lever or platen turning.

**Features:**

- **Spacing and escapement:** [Carriage release](../features/esc-carriage-release.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md)

**Parts:** carriage; hinged rack-bar; rigid dog; flexible dog; line-space lever; release key

**Improves on:**

- Remington rear release arm: release key moved to the front, reachable from the keyboard
