## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to typewriter improvements or r1rl.

**How it works (reading):** Make all key levers the same length and mount them on a removable frame, with shaft positions so unused shafts are removed, giving a straight keyboard.

## Reading (short summary from the opening, OCR fair)

**Problem:** Keyboard lever frames were angled from the centre line, so the keyboard was curved and a removable frame could not hold all lever parts.

**Solution:** Make all key levers the same length and mount them on a removable frame, with shaft positions so unused shafts are removed, giving a straight keyboard.

**Features:** [Interchangeable element](../features/elem-interchangeable.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md)
