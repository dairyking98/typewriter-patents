## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In the patent’s own words:** The invention relates to an improved tabulating mechanism for typewriting machine's.

**How it works (reading):** Adjustable stops in each column group are selected by a column key lever, so one key both releases the carriage and arrests it at the chosen decimal position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Decimal tabulation and column skipping need separate key sets, so one key cannot both release the carriage and stop it at a decimal position in the chosen column.

**Solution:** Adjustable stops in each column group are selected by a column key lever, so one key both releases the carriage and arrests it at the chosen decimal position.

**Features:** [Tabulator](../features/esc-tabulator.md), [Margin stops](../features/esc-margin-stop.md)
