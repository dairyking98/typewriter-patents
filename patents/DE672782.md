**How it works (reading):** One amount type set is used across several posting columns; types are doubled into printing blocks with two printing points so the control strip prints each line one below another while the receipt prints the complementary partial impressions.

## Reading (short summary from the opening, OCR fair)

**Problem:** Column-by-column printing with several amount type records side by side makes control strips wide and hard to read.

**Solution:** One amount type set is used across several posting columns; types are doubled into printing blocks with two printing points so the control strip prints each line one below another while the receipt prints the complementary partial impressions.

In addition to the amounts, the imprints contain these are specified in more detail and are given in certain print columns. There are Machines of this type are known, in which the column-wise impression of the various Amounts are achieved by setting several amount type records in the same way are arranged side by side, their selection by the drive of the desired Column corresponding print hammer takes place. These machines are not just the accounting receipts, but also the control strip printed in columns.
