## Reading (full text, OCR good)

**Problem:** Typing columns of figures of different denominations (units, tens, hundreds) so each denomination lines up vertically takes time and care, because the operator must space the carriage to each column position by hand.

**Solution:** A bank of auxiliary denomination keys, each releasing the carriage feed and letting a carriage-mounted stop run against a plunger one letter-space thick, so the carriage stops at a preset column offset.

**How it works:** Auxiliary keys sit below the normal keyboard, each linked by a key bar and rod to a sliding plunger one letter-space thick. Pressing a key projects its plunger, which lifts an arm on the pivoted bar carrying the feed-rack teeth, so the carriage runs under its spring. An adjustable stop on the carriage arm hits the projected plunger and halts it, a rubber block cushioning the impact. The stop is set once for the units column; the tens, hundreds and tenths keys then stop the carriage one, two or minus one spaces off that point. Several stops give several columns per sheet.

**Features:** [ESC:carriage-release](../features/esc-carriage-release.md), [ESC:tabulator](../features/esc-tabulator.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [ESC:margin-stop](../features/esc-margin-stop.md), [USE:accessory](../features/use-accessory.md), [USE:calculating](../features/use-calculating.md)

**Parts:** auxiliary key; key bar; plunger rod; plunger; slotted guide pin; casing; pivoted feed-tooth bar; feed rack; stop arm; adjustable stop; rubber cushion block

**Numbers:** each plunger one letter-space thick

**Improves on:**

- manual or two-step carriage spacing to column positions: one key press releases and arrests the carriage at the right denomination column
