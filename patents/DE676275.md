## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Carriage return or release devices therefor with special means to maintain character-spacing or back- spacing elements in engagement during case-shift or like movement

**In Google’s translation of the patent’s own words:** The invention relates to an improved lock that both the car locked in the run-off position on the trolley bed and read the locking pawls in any position other than this position of the car.

**How it works (reading):** Locking pawls linked to the carriage bed locking pins can move only in the end position of the carriage, so the bed can be released only there.

## Reading (short summary from the opening, OCR fair)

**Problem:** The carriage bed can be removed in a non-end position, which lets the carriage slide off and damages the drawstring.

**Solution:** Locking pawls linked to the carriage bed locking pins can move only in the end position of the carriage, so the bed can be released only there.
