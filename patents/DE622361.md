## Reading (opening only, OCR good)

**Problem:** Accent (dead key) typewriters used nested shift rails, which was complicated and fixed the dead keys to certain places.

**Solution:** Two concentric shift rails both act on one common lever that drives the ribbon lift, while only the ordinary rail releases the carriage escapement.

**How it works:** Ordinary typebars have a nose that moves the first shift rail and a step that keeps them off the second rail. Accent typebars have an indentation and a different nose that moves only the second rail. Both rails press the same shoulder on a lever linked to the ribbon lift, so ribbon lifting always happens equally. Only the ordinary rail releases the carriage step, so accents do not space.
