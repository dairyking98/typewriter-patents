## Reading (opening only, OCR good)

**Problem:** Earlier paragraphing stops needed both hands, released the escapement and let the carriage run to a stop, and only fit particular machines.

**Solution:** A thumb-operated stop on the front of the machine arrests the carriage at a preset point as the operator pushes it right, and drops out when the thumb lifts.

**How it works:** The carriage front scale bar, hinged and spring-held, carries a serrated edge. A slide locked to it by teeth can be set at any position along the bar. Pressing the thumb-piece engages the slide with a fixed part so the carriage stops there while being moved right. Releasing the thumb disengages the stop automatically so the carriage moves on.

**Features:** [ESC:margin-stop](../features/esc-margin-stop.md), [ESC:tabulator](../features/esc-tabulator.md), [PAP:line-indicator](../features/pap-line-indicator.md), [USE:accessory](../features/use-accessory.md)

**Parts:** scale bar; slide; thumb-piece; spring; fixed pointer; carriage

**Improves on:**

- earlier paragraphing stops: one-handed, self-releasing, fits any sliding-carriage machine
