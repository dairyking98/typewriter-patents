The invention aims for Such machines: to create a facility that does not jump off when it bounces off Cross counter showing zero makes it impossible to print the clear character. this is achieved according to the invention in that the manually operated device to unlock the clear signal pressure lock is adjustable in an intermediate position, in which they release a limited way of the clear character key, so that Disengagement of the arithmetic unit lock enables, but prevents the printing of the clear character will.
