## Summary

**Category:** related office machine, not a typewriter (calculating typewriter cross counter lock) · **Subject (patent classes):** Conditional arrangements for controlling subsequent operating functions, e.g. control arrangement triggered by a function key and depending on the condition of the register

**How it works (reading):** The clear-key unlock is adjustable to an intermediate position that frees the arithmetic lock but blocks printing of the clear character.

## Reading (short summary from the opening, OCR fair)

**Problem:** Clear key can be printed when the cross counter shows zero, and the lock release is incomplete.

**Solution:** The clear-key unlock is adjustable to an intermediate position that frees the arithmetic lock but blocks printing of the clear character.

**Features:** [Typewriter with adding machine](../features/use-calculating.md), [Selection locked for printing](../features/sel-selector-locking.md)

## Description (Google Patents OCR, opening)

> Description Translated from German Set up on calculating typewriters or similar office machines The invention relates to a device on calculating typewriters or the like Office machines in which one of the longitudinal counters arranged on the paper trolley cross-counter carried along within the arithmetic area when jumping back, if it does not show zero, leave a clear pressure lock in the locked position and where the clear character pressure lock is operated by a hand operated device unlockable and the arithmetic unit lock engaged when the transverse counter jumps back can be disengaged by pressing the clear character key. The invention aims for Such machines: to create a facility that does not jump off when it bounces off Cross counter showing zero makes it impossible to print the clear character. this is achieved according to the invention in that the manually operated device to unlock the clear signal pressure lock is adjustable in an intermediate position, in which they release a limited way of the clear character key, so that Disengagement of the arithmetic unit lock enables, but prevents the printing of the clear character will.
