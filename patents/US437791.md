## Reading (opening only, OCR fair)

**Problem:** The stylus-positioned type bar of Odell's machine needs automatic inking and a paper guide that work with the frame's vibration.

**Solution:** An inking roller on a spring-armed frame is linked to the pivoted type-bar frame so each stroke rolls the roller across the type bar face.

**How it works:** A pivoted type-bar frame carries a laterally sliding type bar positioned by a stylus engaging recesses in a letter plate; its vibration also feeds the platen carriage by pawls. A vertical frame pivoted on the base carries spring arms holding a textile-wrapped ink roller, which projects into a cutaway in the underside of the type-bar frame. A link rod from the frame's depending arm moves the roller frame back and forth as the type-bar frame is depressed and raised, inking the exposed type face. Screws adjust the stiffness of the spring arms so the roller yields to the irregular surface.

**Features:** [SEL:stylus-plate](../features/sel-stylus-plate.md), [SEL:pointer-hole](../features/sel-pointer-hole.md), [ELEM:linear-bar](../features/elem-linear-bar.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [SEL:linear-slider](../features/sel-linear-slider.md), [INK:roller](../features/ink-roller.md), [ESC:print-and-space](../features/esc-print-and-space.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** base plate; platen carriage; letter plate; type-bar frame; type bar; stylus; ink roller; spring arm; link rod; adjusting screw
