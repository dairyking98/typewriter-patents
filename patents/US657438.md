## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** My invention relates to certain impr0vements in type-writing machines in which the type is visible.

**How it works (reading):** An intermediate two-armed lever and a rod connect each key lever to its type-bar, so the key and type-bar motions are coupled with a rounded end in a cavity.

## Reading (short summary from the opening, OCR poor)

**Problem:** In the existing key-lever arrangement the key levers move on vertical lines while the type-bars must move on radial lines, so the linkage between them is not aligned.

**Solution:** An intermediate two-armed lever and a rod connect each key lever to its type-bar, so the key and type-bar motions are coupled with a rounded end in a cavity.
