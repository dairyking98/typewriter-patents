## Summary

**Category:** related office machine, not a typewriter (calculating machine lock) · **Subject (patent classes):** Conditional arrangements for controlling subsequent operating functions, e.g. control arrangement triggered by a function key and depending on the condition of the register

**How it works (reading):** The ribbon carrier is shifted so the process following an overdraw prints in a different colour, marking the overdraw in the record.

## Reading (short summary from the opening, OCR fair)

**Problem:** An overdrawn subtraction in an adding machine is not noticed until the total is printed.

**Solution:** The ribbon carrier is shifted so the process following an overdraw prints in a different colour, marking the overdraw in the record.

**Features:**

- **Inking:** [Two-colour ribbon](../features/ink-ribbon-color.md)
- **Uses:** [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** ribbon carrier; motor key lock; locking arm; calculating wheel; switching lever
