**How it works (reading):** Type faces carry parallel rows of sharp tips that perforate the paper, which lies in matching grooves on the printing substrate, so each impression is a set of holes; the digit outlines are chosen so no digit image can be altered into another.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cash-register impressions must be hard to forge by erasure or alteration.

**Solution:** Type faces carry parallel rows of sharp tips that perforate the paper, which lies in matching grooves on the printing substrate, so each impression is a set of holes; the digit outlines are chosen so no digit image can be altered into another.
