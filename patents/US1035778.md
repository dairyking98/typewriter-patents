## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In the patent’s own words:** My invention consists in providing the tabulating mechanism with several sets of column stops, the - number of the said sets depending of the character of the tabulating work which is intended to be done on the particular machine.

**How it works (reading):** Tabulator with several sets of column stops and a scale disk, so the operator selects a set for each sheet or arrangement.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulating needs a change of column arrangement without re-setting the column stops.

**Solution:** Tabulator with several sets of column stops and a scale disk, so the operator selects a set for each sheet or arrangement.
