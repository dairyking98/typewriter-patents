## Reading (full text, OCR good)

**Problem:** Returning and releasing the vertical (line) feed of a Japanese-script typewriter's paper cylinder took separate actions, which was awkward and unsafe.

**Solution:** One handle lever on the feed spring shaft carries a release button that lifts the feed pawl out of its gear, so the same handle can freely turn the cylinder either way.

**How it works:** A handle lever is fixed on the power shaft carrying the spring that drives the vertical feed, with a sector gear meshing through gears to the paper cylinder. A button and sheath on the lever are pushed outward by a spring. Gripping and pressing the button toward the shaft presses one end of a release lever, whose other end pin turns a bent piece on the control shaft and lifts the feed pawl from the feed gear. The cylinder is then free to be set to any position with the handle. Releasing the button re-engages the pawl.

## Description (English translation of the Japanese text, opening)

> Vertical-feed return device for a Japanese-script typewriter. Nature and object of the invention. This invention relates to a vertical-feed return device for a Japanese-script typewriter, in which a handle lever is fixed on the shaft that carries the spring that is the turning power of the vertical feed; the lever carries a gear linked to the paper cylinder, and a release lever and a control button are fitted on it, linked together, with a spring between the control button and the handle lever. When the control button is gripped and pressed toward the shaft's axis, the release lever takes the feed pawl of the vertical feed out of its gear, lifting the limit on the turning and its direction, so that the turning by the control button can be made freely forward or back. The object is to make the one-action return and the release free to do with a single handle, so that the device is easy and safe to use. Brief description of the drawings.
