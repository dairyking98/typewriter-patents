**How it works (reading):** An intermediate setting mechanism, moved by cam disks against resilient tactile stamps, sets the print stops for the position to be printed, so the same stops print the individual items, intermediates and totals.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing summands and totals on Thomas-type calculators needs a separate set of stops and release for each step, and the stop settings can be disturbed.

**Solution:** An intermediate setting mechanism, moved by cam disks against resilient tactile stamps, sets the print stops for the position to be printed, so the same stops print the individual items, intermediates and totals.
