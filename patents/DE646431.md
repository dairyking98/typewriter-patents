## Summary

**Category:** related office machine, not a typewriter (printing tabulating machine item offsetting) · **Subject (patent classes):** Methods or arrangements for effecting co-operative working between equipments covered by two or more of main groups G06K1/00 - G06K15/00, e.g. automatic card files incorporating conveying and reading operations

**In Google’s translation of the patent’s own words:** The present invention relates to a printing tabulating machine and aims to increase the reliability of the Item offsetting at a good working speed of the machine.

**How it works (reading):** The adding-wheel setting movement is made dependent on the actual occurrence of an impression (not only on the type carrier position), so the adder is set only when the printing has happened.

## Reading (short summary from the opening, OCR fair)

**Problem:** On a printing tabulator at high speed the printed item can disagree with the item added on the adder, so printed payroll records may not match the totals.

**Solution:** The adding-wheel setting movement is made dependent on the actual occurrence of an impression (not only on the type carrier position), so the adder is set only when the printing has happened.

**Features:** [Typewriter with adding machine](../features/use-calculating.md), [Tabulator](../features/esc-tabulator.md)
