## Summary

**Category:** related office machine, not a typewriter (line setting, cash registers) · **Subject (patent classes):** Feeding to a particular line, e.g. by rotation of platen or feed roller

**How it works (reading):** The line-advance and return release is controlled by the machine gear, so certain runs advance one line and others return the table to rest.

## Reading (short summary from the opening, OCR fair)

**Problem:** Automatic line advance on a cash-register printing table was applied uniformly and could not differ per machine operation.

**Solution:** The line-advance and return release is controlled by the machine gear, so certain runs advance one line and others return the table to rest.

**How it works:** Gear-dependent control of automatic line indexing and printing-table release on an accounting machine; plates and cams switch line advance per operation.

**Features:** [Line spacing](../features/pap-line-space.md), [Typewriter with adding machine](../features/use-calculating.md)
