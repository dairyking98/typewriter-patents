**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing downwardly on flat surfaces, e.g. of books, drawings, boxes, envelopes, e.g. flat-bed ink-jet printers; Syllable, line, or like type selection

**In Google’s translation of the patent’s own words:** The subject of the invention is a line typewriter that writes on a flat plane and relates in particular to such machines of this type that are used for Accounting work is intended.

**How it works (reading):** Type discs carry control and print marks on the tooth tips so the same teeth lock the set position, repeat the mark on consecutive lines, and drive exchangeable addition and subtraction counters; the print line sits below the disc axis for flat printing.

## Reading (short summary from the opening, OCR fair)

**Problem:** Accounting work needs a line typewriter that prints on a flat plane and can repeat print marks, lock them, and drive counters.

**Solution:** Type discs carry control and print marks on the tooth tips so the same teeth lock the set position, repeat the mark on consecutive lines, and drive exchangeable addition and subtraction counters; the print line sits below the disc axis for flat printing.
