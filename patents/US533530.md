## Reading (full text, OCR good)

**Problem:** On Dick's earlier index-lever machine the lever had to be registered accurately over a sector plate with one narrow space per character, which slowed operation.

**Solution:** Divide the type wheel into groups (capitals, small letters, figures), each in the same order, and give the index wheel a matching section per group, so each character space on the board is a wide target shared by the groups.

**How it works:** A type wheel with loose vertically moving type, struck by a hammer, is geared to a larger index wheel turned by hand. A fixed arc-shaped character board holds letters in one row and figures and punctuation in a row behind. The index wheel has three sections, each with a finger piece and an index line. Setting the capitals section's line opposite a space prints the capital, setting the small letters section's line opposite the same space prints the small letter, and the figures section prints the character shown behind it. The groups on the type wheel follow the same order as the board, so each target is wider and registration is looser.
