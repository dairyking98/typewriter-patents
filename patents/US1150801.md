## Reading (opening only, OCR fair)

**Problem:** Typebar actions need a light, quick touch, and the type bars and key tension should be adjustable or removable as a group.

**Solution:** Drive each typebar from its key lever by an intermediate link with an initial positive engagement and then a lost-motion connection, mount the bars in an adjustable detachable segment, and tension all keys with one spring comb.

**How it works:** Key levers pivot in the frame and typebars pivot in a segment held by screws in slots. An intermediate link is pivoted to each key lever and its upper arm engages a lug on the typebar arm; the first part of the stroke uses the full leverage near the pivot to start the bar quickly, then a lost-motion connection carries it to the platen. On return a lug on the bar arm engages the link's rear edge. Keyhole slots in the links release headed studs on the key levers, so the segment and bars can be removed. A spring comb with fingers bearing on the key levers sits in a bar that moves toward or away from the levers to change all key tensions at once.
