## Reading (short summary from the opening, OCR fair)

**Problem:** Brushing a round type set needs a brush that reaches every type, with the type-levers held still.

**Solution:** A brush revolving on a horizontal divided shaft on side brackets contacts the full type set each revolution, with an adjustable bar retaining the typelevers.
