## Summary

**Category:** related office machine, not a typewriter (accounting machine with item setting)

**How it works (reading):** A lock blocks the drive when the paper carriage stands in a column behind the one for the second entry, so no machine cycle can run until the two entries agree.

## Reading (short summary from the opening, OCR fair)

**Problem:** On an accounting machine a second item entry can be completed even when it does not match the first, so wrong work is finished and has to be corrected later.

**Solution:** A lock blocks the drive when the paper carriage stands in a column behind the one for the second entry, so no machine cycle can run until the two entries agree.
