## Reading (opening only, OCR poor)

**Problem:** On a platen-shift typewriter the platen must stay in exact alignment with the typebar while shifting, and it tends to rebound after returning from the shifted position.

**Solution:** A single parallel-link lever system, worked by the shift key, both shifts the platen and keeps it aligned, and a lock rod catches the system at its return to stop rebound.

**How it works:** The platen hangs on end brackets or links with a counterbalance spring, and its frame carries a roller running on a cylindrical rail. A pivot rod with bell-cranks and hooked pull-rods, driven by a rocking bell-crank linked to the shift key bar, moves a four-bar link system A-B-C-D so the platen point moves from opposite one type to the next while line CD stays parallel to AB. Set screws set the end positions. A second key locks the shift key bar down with a nose and catch for caps-only writing. A spring-pressed lock rod touches a pin of the bell-crank when the platen is home, preventing rebound until the next upward shift.
