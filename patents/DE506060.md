> Description Translated from German Type lever guide for typewriters The invention aims to to design the known type lever guides for typewriters so that a The type lever between the guide parts and the Previously occurring wear of the type lever at the sliding points is avoided. For this purpose, the type lever guide for typewriters is in accordance with the invention provided with a device through which the type lever when passing the guide must be oiled at the sliding points. For this purpose, the type lever guide has openings at the guide points Bores in which an oil-soaked wick or similar is housed, this wick being expedient within a corresponding suction tube small oil containers arranged in the type lever guide can be supplied, to enable a permanent oil supply. In the drawing is an embodiment of the device according to of the invention in Fig. i in a side view and in Fig. 2 in a front view partly shown in section. In the two guide parts a and b of the type lever guide bores c and d are provided which open out on the guide surfaces e, f of these guide parts.
