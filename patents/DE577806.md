## Summary

**Category:** related office machine, not a typewriter (typewriter for non-decimal calculation)

**In Google’s translation of the patent’s own words:** The invention relates to typewriters, in particular for Calculation quantities not based on the decimal system.

**How it works (reading):** The drive part's angular rotation of the numeric roller is set by striking one key, so non-decimal values need no extra drive members.

## Reading (short summary from the opening, OCR fair)

**Problem:** Accounting amounts not in base ten need special drive members that take much space.

**Solution:** The drive part's angular rotation of the numeric roller is set by striking one key, so non-decimal values need no extra drive members.

**Features:**

- **Selection:** [Keys drive the element by racks or gears](../features/sel-differential-drive.md)
