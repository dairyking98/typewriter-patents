## Reading (full text, OCR good)

**Problem:** A typebar machine needs a key for every case and character, so it is complex and limited in range; the inventor also wants a simple mechanical way to write in cipher.

**Solution:** Mount all typebars on a rotatable ring so turning the ring brings different typebars (lower case, capitals, figures) into engagement with the same single set of key-levers.

**How it works:** Typebar brackets are fixed to a ring that turns about the print point. Each typebar has projections that engage indentations in a guided, positive-acting key-lever connection that moves it both to and from the paper. Turning the ring by a lever shifts which typebar sits at each key-lever, so lower case, capitals or numerals print from one alphabet of keys. A spring returns the ring to normal and a latch on inclines centres it. A gage-ring holds the bars level when idle so they slide in and out of engagement. Turning the ring by a pre-agreed rule gives cipher text, reversed the same way.
