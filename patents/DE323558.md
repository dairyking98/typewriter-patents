## Summary

**Category:** related office machine, not a typewriter (cash register with control boxes)

**How it works (reading):** Each buyer's removable box holds a control strip around a pressure plate, and the box swings against the type carrier when the register is operated so the set numbers print on the strip; a stop plate feeds the double sales slip.

## Reading (short summary from the opening, OCR fair)

**Problem:** Credit sales must be recorded on a duplicate slip and a control strip for each buyer, and kept separate from the cash register's other records.

**Solution:** Each buyer's removable box holds a control strip around a pressure plate, and the box swings against the type carrier when the register is operated so the set numbers print on the strip; a stop plate feeds the double sales slip.
