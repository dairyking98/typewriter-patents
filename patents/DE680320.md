## Summary

**Category:** related office machine, not a typewriter (printing table, booking machines)

**In Google’s translation of the patent’s own words:** The present invention relates on booking machines, in which documents can be inserted evenly, which in addition to the setting on a certain line also the setting on a require certain column of the row.

**How it works (reading):** Two independent tables: the line is set by hand, the column is set automatically by control discs and a tactile organ, and the column table returns to centre after each print.

## Reading (short summary from the opening, OCR fair)

**Problem:** In booking machines the line and column printing tables depend on each other, so setting one forces re-setting the other.

**Solution:** Two independent tables: the line is set by hand, the column is set automatically by control discs and a tactile organ, and the column table returns to centre after each print.

It is also known two to arrange movable printing tables in mutually perpendicular directions, of which one the setting of the receipt to be printed on the print line, the other takes over the setting of the receipt on the printing column.
