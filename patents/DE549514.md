## Description (Google Patents OCR, opening)

> Description Translated from German Accounting device on typewriters The use of simple calculating machines with addition and subtraction units on typewriters is known. The arithmetic units known under the name "Type-Adder" are attached to the front wall of the typewriter in such a way that their push rods act on the key levers for the numbers 2 to o and on those for the letter 1. The invention solves the problem of maintaining this commercially available arithmetic unit, but only changing the typewriter while leaving the main keyboard in such a way that the characters customary according to the booking method can be written. This posting method uses upright numbers for the credit items and inclined numbers for the debit items. In order to be able to use this method, according to the invention, the upper row of keys has, in addition to other types, the numerals 2, 3, .4 ... 9, i, o, which correspond exactly to the numerical sequence of the keys of the arithmetic unit. The use of the letter 1 as one is no longer an option with the new booking facility, since it uses two groups of digits, while the previous use of the arithmetic unit only enabled writing with one group of digits.
