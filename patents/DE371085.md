## Summary

**Category:** related office machine, not a typewriter (type segment calculating writer) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The present invention relates to a typenergy writing device of this type, in which the automatic 0 position is carried out with simple aids in such a way that any adverse reaction to other operations that may have to be carried out with the Lasahinc is avoided will.

**How it works (reading):** Spring-loaded segments automatically return from the blank position to zero when the lowest order is set, using an eccentric and a common zero-sector.

## Reading (short summary from the opening, OCR poor)

**Problem:** Type segments below the set-up segment had to be returned to zero by hand in calculating machines.

**Solution:** Spring-loaded segments automatically return from the blank position to zero when the lowest order is set, using an eccentric and a common zero-sector.
