## Reading (opening only, OCR fair)

**Problem:** Converting a Yost-type front-strike machine with a shifting platen to one whose type-lever assembly shifts normally requires redesigning the type lever mechanism.

**Solution:** Mount the type lever segments on a frame that tilts vertically, with intermediate levers and parallel guide arms arranged so the tie rods are not strained in their length during shift.

**How it works:** Each key lever pulls a rod to an intermediate lever on a fixed bearing, which drives a drive lever and type lever through a two-part rear pull rod. The type lever segments, joined by connecting arms and side arms, form one frame that can move vertically for case shift. Parallel guide arms between frame and machine support it and run parallel to the pull rods, so the connection points move transversely to the type lever travel. Springs on lever arms return the frame to rest and the type guide at the printing point shifts with it.
