## Reading (opening only, OCR good)

**Problem:** Typebar actions need uniform key leverage and dip across a fanned keyboard, with gradual acceleration of the typebar and a quick return.

**Solution:** Each second-order key lever carries a pivoted angular sub-lever and pull link that give gradual acceleration, rocking on a fulcrum plate with means to keep it from jumping off.

**How it works:** Key levers fan out from one fulcrum bar to four banks. Each has an ear received between the two riveted plates of an angular sub-lever, whose rocker arm bears on a fixed fulcrum plate. A pull link from the sub-lever drives the front-strike typebar so it accelerates as it nears the platen. Retaining means stop the rocking levers leaving their fulcrum and speed typebar return.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** key lever; sub-lever; pull link; fulcrum plate; fulcrum bar; typebar; return spring
