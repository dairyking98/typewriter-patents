## Reading (full text, OCR fair)

**Problem:** A machine for writing with type needs three things: bring any type to one common point, make a legible impression there, and move the paper across by the right interval, plus a way to return the paper and set line spacing.

**Solution:** A single flat plate bearing all the type is moved in a vertical and a horizontal direction by two oscillating rods, whose throw is set per key by adjusting screws, so any character arrives at one fixed point where a spring-driven hammer strikes the paper and carbon against it.

**How it works:** Wooden key levers lie under two oscillating rods; each key has screws set under projections on one or both rods, and pressing a key pushes the rods by set amounts, so the type plate moves up or down and left or right (diagonally if both) until the wanted character is under the hammer. Rubber joints and a bell-crank link let the two motions move independently. Springs and tongues on the rods return and steady the plate when the key is released. A hammer, cocked by a third rod and rubber spring, is let slip near the end of the key travel and strikes through carbon and writing paper held in a clamp. The same key motion oscillates an escapement crutch on a wheel driven by a rubber spring, so the paper frame steps one place per key; two levers free the escapement, run the frame back and index the line.
