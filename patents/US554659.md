## Reading (full text, OCR good)

**Problem:** In stylus-operated index typewriters the way the operator holds the stylus influences where the type wheel stops, so positioning is inaccurate.

**Solution:** Put the index-engaging foot on the link between stylus and type wheel, not on the stylus, so the stylus is only a handle and the stop position is the same however it is held.

**How it works:** A spring-loaded revolvable type segment or wheel has an arm that sweeps over an index plate; the stylus pulls the arm against the spring through a loosely hooked link. The link ends in a short cross-bar foot, perpendicular to the link direction, that is placed against one of the posts set at intervals in the index, which locates the type at the print point. Because the foot is an arc about the link, any part touching the post gives the same position. For a full wheel, a gear segment drives a gear on the wheel shaft, and the spring pull takes up lost motion in the gearing. A flat radial fret can replace round posts.

**Parts:** type segment; type wheel; arm; annular spring; stylus; link; foot; index plate; post; gear segment; gear wheel

**Numbers:** link pull about 1 to 2 ounces; posts about 1/16 inch high; foot about the same height as posts

**Improves on:**

- Deming application Serial No. 495,803 (1894) stylus index typewriter: engaging foot moved from the stylus to the link so hand grip no longer affects position
- Edison mimeograph typewriter: mentioned as the full-circle wheel type that the gearing variant suits
