## Description (Google Patents OCR, opening)

> Description Translated from German Calculating machine -with a printing device consisting of type wheels. Calculating machines with a printing device consisting of type wheels are known, where the type wheels have eleven value places, namely the digits o to g and an empty field, and also connected to eleven-toothed drive wheels. The rotation these type wheels from the empty field position to the zero or another value position takes place in these devices by special ones that intervene in the type wheels Gears on drive slides, which are shifted accordingly when zeros are printed and afterwards have to be brought back to their original position. The additional rotation of the type wheels takes place according to the invention also through the toothing of the drive slide, but this is with the slide not firmly connected, but slidably mounted on them, so that when stationary Shift a rotation of the type wheels from the empty field hunt into the zero position Operation of a switching device is possible without the drive slide itself have to be moved.
