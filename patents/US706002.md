## Reading (short summary from the opening, OCR fair)

**Problem:** Keyboard characters are hard to remember when they are grouped only by raised frets, so the inventor wants a colour grouping that suggests the characters.

**Solution:** The keyboard is divided into coloured sections, each holding a set number of keys arranged by frequency and convenience, so that the colour suggests the characters in it.
