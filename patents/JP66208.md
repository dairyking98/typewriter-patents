## Reading (full text, OCR good)

**Problem:** A printing device for a very large number of types needs a stop for every type, making it large and costly.

**Solution:** Limit the stop arm to a half-circle arc with stop pins for only half the types, and turn the type wheel either clockwise or anticlockwise so each pin serves two types.

**How it works:** Pressing a key pulls one stop pin down so it enters a slot in a half-round stop plate. The same key stroke then swings an arm that meshes a gear with the type wheel shaft and turns the wheel. A collar on the shaft carries one of two stop arms, left or right, depending on the turning direction; the arm's tip hits the raised pin and stops the wheel, while a spring in the drive lets the key keep moving. The further key travel then cocks a hammer lever through a pawl, which slips and releases a spring-driven hammer to strike the type at the printing centre, and a strong spring and rebound spacing prevent double strikes. Keys come in A and B pairs sharing one cross shaft and pin, A sending the wheel one way and B the other.

## Description (English translation of the Japanese text, opening)

> Specification. Printing device for a typewriter. Nature and object of the invention. This invention relates to a typewriter printing device in which the swing of the stop arm is limited to an arc of half the circumference of the type wheel, and any type on the wheel is brought to the printing centre by stop pins, set within that arc, numbering half the types on the wheel; in this way all the types can be printed. Its object is to reduce the size, and lower the cost, of a printing device that prints a great many types quickly. Brief description of the drawings. The drawings show one example of a mechanism using the device of this invention. Fig. 1 is a plan, Fig. 2 a side view, Fig. 3 a perspective view of the stop-arm hub.
