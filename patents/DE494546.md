## Summary

**Category:** related office machine, not a typewriter (full keyboard for printing calculators) · **Subject (patent classes):** Keyboards with one set of keys for each denomination

**In Google’s translation of the patent’s own words:** The subject of the invention is a new full keyboard for calculating machines with printing mechanism, with which through while the depressed keys stops for the type bars are set the type rods in turn bring about the signal box adjustment.

**How it works (reading):** Key-shaft stops are undivided wires or rails that converge in a tight bundle like typewriter shift rods to the type boxes, and they pass through a removable guide basket fixed to the frame.

## Reading (short summary from the opening, OCR fair)

**Problem:** Full keyboards for printing calculators take up space below the keys, and their stop mechanism is hard to remove for service.

**Solution:** Key-shaft stops are undivided wires or rails that converge in a tight bundle like typewriter shift rods to the type boxes, and they pass through a removable guide basket fixed to the frame.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)
