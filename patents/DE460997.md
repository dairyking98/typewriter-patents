## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter with a rotatable stop lift], which can be moved in the path of the edge stops or the table stops and is brought into its rest position by a retraction device.

**How it works (reading):** An extra retraction device returns the rotatable stop lever only when it sits in the path of the tabulator stops, while the edge-stop path keeps its blocking device.

## Reading (short summary from the opening, OCR fair)

**Problem:** Long carriages hit the table stops hard and the stop lever's return spring would have to be strengthened, which overloads the linkage.

**Solution:** An extra retraction device returns the rotatable stop lever only when it sits in the path of the tabulator stops, while the edge-stop path keeps its blocking device.
