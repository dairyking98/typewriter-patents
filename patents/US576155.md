## Reading (full text, OCR fair)

**Problem:** Key-tripped latches of this class need auxiliary springs to throw the latch forward, and can re-fire if the key is still held down when the starting-arm pushes the latch back.

**Solution:** A single resilient tripping rod, pulled down by a key lever, first unhooks the latch and then pushes it forward, while a second spring catch holds the pushed-back latch out of action until the key is released.

**How it works:** A key lever pulls a spring-steel tripping rod down; its inclined tip bears on the rear end of a reciprocating latch and forces it sideways off its fixed catch. As the latch unhooks, the stored spring in the rod pushes it forward, where it meets a starting-arm on a turret shaft and sets that shaft turning. The arm then pushes the latch back. If the key is still down, a second spring catch on the latch engages another fixed catch and parks the latch inert. On key release a return spring lifts the latch and a hook stop lifts the spring catch free, so the latch re-seats on its main catch ready for the next stroke.

**Parts:** latch; fixed catch; spring catch; tripping rod; key lever; starting arm; return spring; turret; support

**Improves on:**

- key-tripped latch mechanisms with auxiliary springs: one resilient actuator both releases and projects the latch, with no extra springs
