## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Side-stop mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to an adjusting device for the edge stops of typewriters with a release lever arranged on the carriage to release the carriage rack from the indexing wheel as well as with an edge stop rod movable with the carriage, whose Edge stops are released at the same time as the carriage rack is released, so that they can be adjusted by moving the carriage.

**How it works (reading):** An extra edge stop release lever, pressed together with the carriage release, frees the edge stop rod so the stops can be slid by moving the carriage, while a locking device on the machine frame holds each stop against movement in one direction.

## Reading (short summary from the opening, OCR good)

**Problem:** Edge stops on a typewriter carriage are hard to reset quickly because they cannot be moved on their own without the carriage release.

**Solution:** An extra edge stop release lever, pressed together with the carriage release, frees the edge stop rod so the stops can be slid by moving the carriage, while a locking device on the machine frame holds each stop against movement in one direction.
