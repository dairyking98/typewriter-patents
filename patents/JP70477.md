## Reading (full text, OCR good)

**Problem:** A single electromagnet core that turns a type wheel to a chosen type would, if held back by the stop, not complete a full stroke, so the hammer blow it drives would vary with the type chosen.

**Solution:** When the wheel stops at the printing point, the planetary link between core and wheel is automatically released so the core always makes the same full stroke and its end works the hammer.

**How it works:** A key closes a switch that energises a stop magnet (one of a half circle) and a left/right reversing magnet, then the main magnet draws its core in. The core pulls a stud through a helical-grooved tube, turning a sun gear, a planet gear held by a spring-loaded locking lever, and the type wheel. When the lever meets the raised stop pin it tips back out of the planet's teeth, freeing the gear train so the wheel stays put while the core finishes its stroke. The core's rack drives a bent lever that compresses a spring on the hammer shaft and releases it onto the type at the printing point; a balanced rear spring returns the shaft and prevents double strikes. An over-centre snap contact then switches to the return magnet, and key release resets the cut-out.

## Description (English translation of the Japanese text, opening)

> Specification. Electromagnetic printing machine. Nature and object of the invention. This invention relates to a printing machine whose main movements are made electromagnetically. With one main electromagnet core it turns the type wheel and brings the wanted type, arranged on the wheel's surface, to a set printing point. As soon as the wheel stops there, the link between the core and the wheel is automatically broken and the core is left free, so that, wherever the wheel has stopped, the core always makes the same fixed stroke, and at the end of that stroke it works the electromagnetic hammer and prints.
