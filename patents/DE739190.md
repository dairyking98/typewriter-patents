## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers

**In Google’s translation of the patent’s own words:** The present invention relates to printing "business machines with a number of individually adjustable type carriers and aims to achieve better adaptability to changing uses.

**How it works (reading):** A blocking bar stops at a space in the print position, so the print-hammer blocking devices for non-value type carriers take effect; blocking members can be set by identification holes in punched cards.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing business machines cannot print words and numbers from the same type carriers in one zone, because the number-print control suppresses letters and automatic zero printing conflicts with it.

**Solution:** A blocking bar stops at a space in the print position, so the print-hammer blocking devices for non-value type carriers take effect; blocking members can be set by identification holes in punched cards.

**Features:** [Selection locked for printing](../features/sel-selector-locking.md), [Separate print key or lever](../features/imp-print-lever.md)
