## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** The swing weight is placed in a toggle linkage that is detached from the key drive, so the weight stretches the knee lever at the end of the type lever stroke for a slow but forceful type stop.

## Reading (short summary from the opening, OCR fair)

**Problem:** Swing-weight quieting used on sliding carriages slows down type-lever machines when the weight is put into the key drive.

**Solution:** The swing weight is placed in a toggle linkage that is detached from the key drive, so the weight stretches the knee lever at the end of the type lever stroke for a slow but forceful type stop.

**How it works:** The toggle pair is straightened by the swing weight after the key movement, giving a low-speed final stroke.
