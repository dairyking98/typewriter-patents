## Summary

**Category:** related office machine, not a typewriter (booking machine line spacing mechanism) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers; Record carriers for use with machines and with at least a part designed to carry digital markings characterised by the shape

**How it works (reading):** The line-feed adjusting member, linked to the gear-type control, is set by hand for the normal position, and changes automatically with the gear type (e.g. post print vs. sum print), with a separately adjustable stroke.

## Reading (short summary from the opening, OCR poor)

**Problem:** The line-space ratchet on a booking machine gives one line distance for both addition and subtraction, though the sum rows should be set apart from the posting rows.

**Solution:** The line-feed adjusting member, linked to the gear-type control, is set by hand for the normal position, and changes automatically with the gear type (e.g. post print vs. sum print), with a separately adjustable stroke.
