## Reading (opening only, OCR fair)

**Problem:** The main patent's automatic line switching always advances unless the line setting is changed, but on stock-balance machines posting several columns side by side line advance should happen only for certain entries.

**Solution:** The automatic line-feed is made ineffective in dependence on the line-number keys and amount keys for certain postings (first sales item, new stock).

**How it works:** Units and tens line-key banks move slides that act through arms on a rod with a roller. The roller enters a cam-groove drum turning once per machine cycle; the groove shifts the drum axially, which through a push rod shifts a pinion carrying a single-tooth index disc into the plane of the table rack so it steps the table one line. If the roller is not inserted, no line step occurs.
