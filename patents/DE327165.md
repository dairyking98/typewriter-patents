## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies

**How it works (reading):** Several independent, individually removable type sets are built in side by side, and a lever switches between them in mid-writing.

## Reading (opening only, OCR fair)

**Problem:** Earlier machines with 180 types (or 30 bodies of 6 types) need three hand movements to change type set, and the types are permanently built in, so no extra fonts or languages can be added.

**Solution:** Several independent, individually removable type sets are built in side by side, and a lever switches between them in mid-writing.

**How it works:** Each type linkage (typebar action) carries ten types on a thin sheet-metal wheel sector arranged on an arc about a pivot. The sector, a strut, a control link and two support legs form a pentagon hinge that swings about a main pivot, guided by a control roller on a curved guide plate so each type reaches the printing point in turn. Each linkage hangs in a type frame clamped to the housing that can be removed after releasing a pre-stretcher. The writing rod is split into a front type set and rear key levers that separate for changing. Two sets are shown; a lever in the middle of writing selects between them.
