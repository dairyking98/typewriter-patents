## Reading (short summary from the opening, OCR poor)

**Problem:** Keys require too much force to strike carbon copies, and power typewriting machines are not practical.

**Solution:** A power attachment operates the key levers of an ordinary machine so the keys only select the type bar and start the power.

**Features:**

- **Impression:** [Electric drive](../features/imp-electric.md), [Separate print key or lever](../features/imp-print-lever.md)
