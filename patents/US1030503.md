## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** This invention relates to improvements in the type actionsof typewriting machines, it being especially applicable to visible writing machines of the style called front strike machines.

**How it works (reading):** The type bar actions are rebuilt so the parts are relieved of torsional strain and the keys depress equally, with means on the type bars and type bar rest to stop any bar from rebounding into another's path.

## Reading (short summary from the opening, OCR fair)

**Problem:** Front-strike type bar actions suffer torsional strain, unequal key depression, and type bars rebounding into the path of others.

**Solution:** The type bar actions are rebuilt so the parts are relieved of torsional strain and the keys depress equally, with means on the type bars and type bar rest to stop any bar from rebounding into another's path.
