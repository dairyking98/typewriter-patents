## Summary

**Category:** related office machine, not a typewriter (cancellation device for booking machines)

**In Google’s translation of the patent’s own words:** The invention relates to a facility for canceling booking engines.

**How it works (reading):** A separate cancellation setting means selects only the cancel adder, the amount is set by a separate numbering-style setting means, and an interlock lets the numbering device run only in the cancel position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cancelling postings on booking machines needed intricate multi-part linkages to disengage the sales totalizers during cancellation.

**Solution:** A separate cancellation setting means selects only the cancel adder, the amount is set by a separate numbering-style setting means, and an interlock lets the numbering device run only in the cancel position.
