## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to typewriters in which the type lever in one inclined, low-lying segment and supported by tie rods of the same length with the upper ends of upright intermediate levers are connected, which according to the Sides of the machine to increase in height and turnable at the bottom close to the machine floor are stored.

**How it works (reading):** Intermediate levers are linked to the key levers by a fixed connection and a spring acts through an intermediate piece, so the type lever returns in a straight line without bounce.

## Reading (short summary from the opening, OCR good)

**Problem:** Type levers rebound slightly from their rest support after striking, so the return is not clean.

**Solution:** Intermediate levers are linked to the key levers by a fixed connection and a spring acts through an intermediate piece, so the type lever returns in a straight line without bounce.
