## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** My improvements relate to that class of type-writers in which an inking-ribbon is employed and between which and the paperroller the paper is located, so that an impression of the type is left upon the paper by the type forcing the inking-ribbon in contact with the paper and against the paper-roller.

**How it works (reading):** Stack the typebars in one vertical plane so each bar moved carries all bars in front of it, whose hooked ends cover the types of the preceding bars.

## Reading (opening only, OCR fair)

**Problem:** Keys and typebars take a lot of space.

**Solution:** Stack the typebars in one vertical plane so each bar moved carries all bars in front of it, whose hooked ends cover the types of the preceding bars.

**How it works:** Typebars of increasing length pivot at different distances from the paper roller and all strike the same spot. A separate key engages the cam-shaped end of each bar. Pressing the second bar carries the first bar into its hooked free end, which hides the first bar's type so only the second prints. The third bar's larger hook receives the second bar and covers both earlier types. A spring on the first bar returns the whole stack when the key is released, a guide centres the bars, and a stop limits the spring travel.

**Features:** [Typebars](../features/elem-typebar.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Ink ribbon](../features/ink-ribbon.md), [Portable or compact](../features/frm-compact-portable.md)

**Parts:** typebar; hooked free end; key; spring; guide; stop; paper roller; side plate
