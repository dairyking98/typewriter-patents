## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition

**How it works (reading):** A 42-key keyboard in 5 equal-height rows with only 8 main keys per row, so each finger always has one diagonal row.

## Reading (opening only, OCR good)

**Problem:** Normal 10-per-row keyboards overload the index and little fingers in ten-finger typing.

**Solution:** A 42-key keyboard in 5 equal-height rows with only 8 main keys per row, so each finger always has one diagonal row.

**How it works:** Keys form 8 diagonal rows, each worked by one finger (little finger left to little finger right) with thumbs on space. Rare characters get an extra key beside the top two rows. All keys are at the same height so fingers move between rows without hitting each other.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** key; diagonal key row; space key

**Numbers:** 42 keys; 5 rows; 8 main keys per row
