## Summary

**Category:** related office machine, not a typewriter (lock for cash registers)

**How it works (reading):** Radial cam tracks on the setting dial lock the mode lever, and the two-armed lever advances a counter on each subtraction.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cash registers need to stop incompatible operating modes and to record subtractions so that income cannot be hidden as expenses.

**Solution:** Radial cam tracks on the setting dial lock the mode lever, and the two-armed lever advances a counter on each subtraction.

## Description (Google Patents OCR, opening)

> Description Translated from German Barrier for cash registers Cash registers must have devices that prevent improper use, mainly for fraudulent purposes. Therefore, among other things, provision must be made that a certain operating mode of the cash register, once it has been initiated, makes any other operating mode impossible, that is, if, for example, an amount is to be added, no organ of the cash register can be set in such a way that a subtraction process can be performed would correspond. Furthermore, for the same reason, namely for control purposes, the control strip, which is to be removed from the till at the end of business, must be able to determine the significance of each individual process, for example an income as income, an expense as an expense; a partial total as a partial total, etc. In particular, there must also be an inevitability that precludes taking in an amount and booking this income as an expense and hiding it from the principal. All of these objects and a few others are achieved by the present invention with simple, reliable and inexpensive means to manufacture.
