## Reading (full text, OCR good)

**Problem:** Keyboard typewriters waste space or look uneven because every character advances the carriage the same amount, and carriage return and line feed need separate operations.

**Solution:** A carriage escapement where a moving dog skips a number of rack teeth set by how far each notched key depresses a common bar, giving proportional letter spacing, with a central key that releases the dogs and line-spaces the roller in one motion.

**How it works:** A spring pulls the carriage back, while a fixed dog stops it from returning and a second spring-loaded dog on a bell-crank lever rides the rack. Every key presses a common bar under the keyboard to move the bell-crank, and notches cut into each key stem of different lengths make narrow letters push the bar only one tooth and wide letters three, so the stronger dog spring pulls the carriage forward that many teeth on release. A central key lowers a lining-bar plate whose arm lifts both dogs off the rack so the return spring brings the carriage back, while a flexible pawl on the plate turns a ratchet on the paper roller one or two notches according to a sliding stop. A second slide can decouple the arm so the roller turns without releasing the dogs. The pawl can be split into two half-tooth parts so a missed tooth costs only half a space.
