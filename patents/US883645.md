## Summary

**Category:** related office machine, not a typewriter (key lock for keyed printing machines) · **Subject (patent classes):** Interlocks between keys, e.g. without detent arrangements

**How it works (reading):** Key-locking devices are linked to the key connecting links so that adjacent keys cannot be depressed simultaneously while single keys still operate freely.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adjacent keys of a key-operated machine can be struck together by mistake, and the prior star-wheel detent locks are objectionable because they lock adjacent keys on the first depression and so limit operating speed.

**Solution:** Key-locking devices are linked to the key connecting links so that adjacent keys cannot be depressed simultaneously while single keys still operate freely.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Selection locked for printing](../features/sel-selector-locking.md)
