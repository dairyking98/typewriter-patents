## Reading (short summary from the opening, OCR fair)

**Problem:** Front-strike type action has too many jointed connections between key levers, universal bar and type bars, and the bars rebound.

**Solution:** Type action for visible front-strike typewriters with fewer joints between key levers and type bars, plus means to lock the type bars against rebound and restoring springs that are easier to apply.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [IMP:element-to-platen](../features/imp-element-to-platen.md)
