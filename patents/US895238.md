## Reading (opening only, OCR fair)

**Problem:** Ordinary typewriters space every letter equally, so the writing does not look like printed matter.

**Solution:** The escapement is made variable, with tumblers and a limber pawl, so the carriage feed matches the width of each type and case.

**How it works:** A shaft connected to the escapement wheel and a limber pawl whose rocker extension meets sets of tumblers allow different amounts of carriage travel per character. Tumblers can be shifted to suit upper and lower case, with a double-shift variant and a latch to prevent carriage recoil on setting back. Keys can be marked with the spacing for their letters. Only the opening is available.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [ESC:escape-wheel](../features/esc-escape-wheel.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [SHIFT:platen](../features/shift-platen.md)

**Parts:** escapement wheel; limber pawl; tumbler; rocker extension; shaft; latch; key

**Improves on:**

- fixed-pitch typewriter escapement: letter spacing follows type width
