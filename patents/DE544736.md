## Description (Google Patents OCR, opening)

> Description Translated from German Cash register for issuing several checks in one checkout process Die Invention relates to cash registers capable of issuing multiple checks are set up within a checkout corridor, and relates to the special task two checks issued one after the other in the same checkout aisle after different ones Transport destinations zti. A device of this type is known which is used in card sorting machines Usual flap controls are used to set up different for the successively declining checks Ways to open up. With this facility, two checks are sent one after the other to the same Cut off point and therefore fall downwards from the same point, so that the inclined surface the flap must cause the deflection of the falling document. According to the invention, several checks are sent to different destinations promoted by creating different cut-off points, each lie directly above the waste channel. An inventive embodiment of the solution idea can be seen in the fact that a single knife in special timing and in cooperation with a counter knife within the same checkout aisle on two has a cutting effect at different points.
