## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Bearings with rolling contact, for exclusively rotary movement with bearing balls essentially of the same size in one or more circular rows for both radial and axial load with a single row of balls with angular contact

**In the patent’s own words:** My invention relates to typewriting machines and more particularly to type actions.

**How it works (reading):** Type action with uniform leverage for all keys, each action removable as a unit, and let-off uniform relative to the printing stroke.

## Reading (short summary from the opening, OCR fair)

**Problem:** Keys have non-uniform leverage and dip, and escapement let-off varies with key stroke.

**Solution:** Type action with uniform leverage for all keys, each action removable as a unit, and let-off uniform relative to the printing stroke.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [IMP:impression-adjust](../features/imp-impression-adjust.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)
