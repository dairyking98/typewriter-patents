## Reading (opening only, OCR good)

**Problem:** Producing several duplicate manuscripts normally needs one operator per machine.

**Solution:** A single supplemental keyboard connected by bars and rods to the keys of two or more Remington typewriters so one operator types them all at once.

**How it works:** Each typewriter key is bolted to a transverse bar under the machine, which stands on hinged blocks to leave room for the bars to move. Coupled bars join the corresponding bars of the machines and are linked by rods or strings to lettered key levers on a separate keyboard. Pressing a supplemental key operates the same key on every machine. Spacing keys are connected the same way. Blocks and strips let the machines be uncoupled and used alone.
