## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Printing on disk-shaped media, e.g. CDs

**In the patent’s own words:** My present invention relates to a platen for type-Writing machines of that class which print upon a sheet supported in a flat or spread-out condition upon a flat stationary platen over which the machine is movable both laterally and longitudinally.

**How it works (reading):** The flat platen carries main tracks that support the movable machine frame, extended beyond the printing area over a platen extension, so the machine can be lifted clear without disturbing the paper.

## Reading (short summary from the opening, OCR fair)

**Problem:** On flat-platen machines the sheet can be displaced when the machine is moved off the printing area to replace or adjust the work sheet.

**Solution:** The flat platen carries main tracks that support the movable machine frame, extended beyond the printing area over a platen extension, so the machine can be lifted clear without disturbing the paper.

**Features:** [PAP:flat-bed](../features/pap-flat-bed.md), [USE:book-typewriter](../features/use-book-typewriter.md)

**Parts:** flat platen; main tracks; platen extension; machine frame; carriage
