## Reading (full text, OCR good)

**Problem:** Shifting between upper and lower case with a plural-faced type head needed too many operating parts.

**Solution:** A rocking two-faced type head on each typebar is deflected to its second face by striking a single movable arc-shaped stop plate common to all typebars.

**How it works:** Each typebar has a rocking type head pivoted at its free end, with two faces at an angle so only one can strike the platen, and a convex bearing face that takes the strike load off the pivot. A spring holds the head with the lower-case face in printing position. A lug on the head engages a segmental plate on a pivoted shifting arm, which a case key can swing into the path of the bars. When the lug hits the plate the head rocks against its spring to present the other face, and the spring snaps it back as soon as it is released. The arc plate is concentric with the common printing point so all bars grouped around the ring can use the one stop.

**Parts:** typebar; rocking type head; return spring; lug; shifting arm; arc-shaped stop plate; typebar supporting ring

**Numbers:** 2 type faces per head
