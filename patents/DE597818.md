**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried on sliding bars or rods

## Reading (full text, OCR fair)

**Problem:** Typewriters with swinging key or type bars need considerable height.

**Solution:** Horizontally sliding type rods are driven by horizontally sliding key rods through gears, giving a flat machine.

**How it works:** Push-button rods slide horizontally close above the base. Gears engage racks formed on the key rods and type rods. Pushing a key rod therefore moves a type rod toward the platen, and a spring returns the parts.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ELEM:linear-bar](../features/elem-linear-bar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [FRM:compact-portable](../features/frm-compact-portable.md)

**Parts:** key rod; push button; type rod; gear; rack; spring; paper roller

**Improves on:**

- typewriters with swinging type bars or key bars: all parts slide horizontally so the machine is flatter
