## Summary

**Category:** related office machine, not a typewriter (printing device for tabulating machines) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers by rack-type printers

**In Google’s translation of the patent’s own words:** The present invention relates to a printing device for tabulating machines and similar machines in which reciprocating type carriers within them Movement limit can be determined, so that any types provided on them for Imprint can be made, as is the case with tabulating and similar machines Item and totals printing is required.

**How it works (reading):** A spring, also driven directly, strikes the end of the stroke so the type-carrier frame is returned to rest together with the other parts.

## Reading (short summary from the opening, OCR fair)

**Problem:** On tabulating printing devices the type-carrier frame lags behind the drive on its return, causing shock loads and forcing slower speed.

**Solution:** A spring, also driven directly, strikes the end of the stroke so the type-carrier frame is returned to rest together with the other parts.
