## Summary

**Category:** related office machine, not a typewriter (keyboard for calculating machines)

**In Google’s translation of the patent’s own words:** The invention relates to a keyboard for calculating machines, adding machines and the like aims to obtain a compact and yet simple structure of the keyboard in particular.

**How it works (reading):** Each key is U-shaped and penetrates the key frame so that its spring and operated rails sit in separate spaces, with pins that lock the rails so only one key can be depressed; the display uses a series of digits in which each number builds on the previous one.

## Reading (short summary from the opening, OCR fair)

**Problem:** A key can jam when pressed off-centre, and the display rail and adjustment rails must fit in a compact keyboard while still allowing large digits.

**Solution:** Each key is U-shaped and penetrates the key frame so that its spring and operated rails sit in separate spaces, with pins that lock the rails so only one key can be depressed; the display uses a series of digits in which each number builds on the previous one.
