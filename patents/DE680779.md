## Summary

**Category:** related office machine, not a typewriter (serial number printing, registering machines)

**How it works (reading):** Several serial-number type sets are provided, one per transaction type; a key-driven shift rod brings only the selected set into the printing aisle.

## Reading (short summary from the opening, OCR fair)

**Problem:** Registering machines count transactions per type but record no serial number per transaction type, so single entries are hard to find.

**Solution:** Several serial-number type sets are provided, one per transaction type; a key-driven shift rod brings only the selected set into the printing aisle.
