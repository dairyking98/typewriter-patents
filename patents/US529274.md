## Reading (opening only, OCR good)

**Problem:** Remington-type machines need the hands to return the carriage and make the line space at the end of each line.

**Solution:** A knee lever returns the carriage to the right, and a trip rod automatically turns the platen for a line space when the end of the line is reached.

**How it works:** A knee lever hangs below the machine and turns cranked shafts that tilt a long crank arm linked to the carriage rail, throwing the carriage back. A spring-pressed pawl on a tilting arm engages the platen ratchet wheel; the arm connects by a link to a slide lever. When the carriage reaches the line end, the slide lever strikes an adjustable tripping spring on a trip rod and pulls the arm down so the platen turns one line. The trip rod is on a bell crank joined by a wire to the platen key so the key can also trigger it. A further arm keeps the attachments in position when the platen is shifted for upper case.

**Features:** [USE:accessory](../features/use-accessory.md), [ESC:carriage-return](../features/esc-carriage-return.md), [PAP:line-space](../features/pap-line-space.md), [SHIFT:platen](../features/shift-platen.md)

**Parts:** knee lever; crank shaft; long crank arm; tilting arm; pawl; ratchet wheel; slide lever; trip rod; tripping spring; bell crank; platen key

**Improves on:**

- Remington typewriter with hand carriage return: knee operation frees the hands and line space is automatic
