## Reading (full text, OCR good)

**Problem:** On a tray-type Japanese typewriter, finding the wanted type among thousands by looking at the types themselves takes skill and causes mistakes.

**Solution:** Lay two sliding index plates with alternating windows and index faces over the flat type tray, and move them with a pawl on sloped projections so that only the lengthwise column holding the wanted type is exposed.

**How it works:** Two plates sit on top of the sliding type tray; each has windows two tray columns wide alternating with index faces of equal width, arranged so the lower plate's faces show through the upper plate's windows. Each plate has V-shaped projections with sloping sides along one edge. Pressing the print lever raises an operating pawl, whose position is guided by a toothed bar with one tooth per tray column, so it pushes on the slope of one projection and shifts one plate to expose the right column. A second toothed bar with one tooth per crosswise row is lifted by an added rocking lever and engages a knife-edge bar, which links to the pawl. Sprung rollers in V notches at the plate ends return the plate when the lever is released.

## Description (English translation of the Japanese text, opening)

> Specification. Index-plate operating device for a Japanese-script typewriter. Nature and object of the invention. This invention relates to an index-plate operating device for a Japanese-script typewriter, in which two index plates are laid one on the other. Each plate is made of windows, through which any chosen number of lengthwise columns of the flat type tray can be exposed, alternating with index faces of the same width; the plates lie so that the index faces of the lower plate show through the windows of the upper plate. On the side of each plate, opposite each index face, an operating projection with sloping faces is formed. An operating pawl, worked by pressing the end of the press lever, is guided by a toothed bar and acts on the slopes of these projections, so that the plates are moved. The object is to arrange suitably, with a very simple construction, that only the lengthwise column of the type tray holding the wanted type is exposed. Brief description of the drawings.
