## Reading (opening only, OCR fair)

**Problem:** Typewriter-adding machines needed changing parts to switch between addition and subtraction, and the clerk had no overview of the setting.

**Solution:** Decimal and column tabulator keys preset the calculating machine for addition or subtraction per column automatically, with ribbon colour tied to the mode.

**How it works:** A typebar typewriter with number and letter keys and a spring-drum carriage drives a motor-powered calculating unit. Each number key moves a pin on an indicator wheel, which sets the escapement shaft to turn the calculating wheels by the corresponding digit. Tab keys select the column and set addition or subtraction, with a ribbon actuator moved between black and red positions.
