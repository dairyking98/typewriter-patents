## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition

**In the patent’s own words:** This invention consist of a set of operating-levers serving as keys, a set ofindependently' oscillating frames, a series of files of movable wedges, and an auxiliary rocking frame, so organized as to be applied to and operate a set of levers like those of a typewriter.
