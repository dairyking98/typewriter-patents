## Reading (opening only, OCR fair)

**Problem:** A typewriter needs one key per character; the inventor wants to operate many levers by only a few keys.

**Solution:** Six keys tilt graded nested frames that move files of wedges, so key combinations select one of 26 type levers.

**How it works:** Six keys are hinged to the frame, spring-held. Six rectangular frames graded in size are nested in one plane and journaled so each descends with its key. Each frame is jointed to the shanks of one wedge in each of 26 files; files slide in a slotted guide plate. Pressing a combination of keys puts the wedges of the 26 files in different relative positions so that one file's wedges line up, and an auxiliary hinged rocking frame with a counterbalance operates the single selected lever like those of a typewriter. Adjustable studs set the frames.

**Features:** [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [SEL:differential-drive](../features/sel-differential-drive.md), [ELEM:typebar](../features/elem-typebar.md)

**Parts:** key; nested frame; wedge; file of wedges; slotted guide plate; rocking frame; counterbalance; stop plate; set-screw stud

**Numbers:** 6 keys; 26 files of wedges; 6 wedges per file
