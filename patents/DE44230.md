## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**How it works (reading):** Spring carriage rack with fixed and cam-positioned tooth giving width-dependent spacing, a movable type frame for index positions, a spring-held inking roller and reversible type blocks.

## Reading (opening only, OCR fair)

**Problem:** Improvement on Fitch's earlier machine: variable letter spacing, above/below-line setting of type, inking and type-block mounting.

**Solution:** Spring carriage rack with fixed and cam-positioned tooth giving width-dependent spacing, a movable type frame for index positions, a spring-held inking roller and reversible type blocks.

**How it works:** Same machine as US366577. A fine-pitch toothed rack pivoted to the paper holder is pulled by a spring; a fixed tooth engages it when depressed and a rotatable tooth set by a grooved slider on the type frame decides how far the holder moves, according to the letter width. Levers move the type-bearing frame so small letters and digits print above or below the line. An inking roller on a small squared axis is held by a spring in the path of the falling type and pushed aside after inking. Type blocks have three sets of characters on each side, with a second style by turning the block half-way round on the finely threaded wire arm.
