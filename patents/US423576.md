## Reading (full text, OCR good)

**Problem:** Existing typewriters and typographic machines are complex and costly; the inventor wants a simpler, cheaper, sturdier machine.

**Solution:** A pivoted sector-shaped lever carrying a curved row of type blocks is swung by whichever key is pressed (via an inclined slot in the key) to bring the chosen type under a single impression rod.

**How it works:** Lever B pivots in the case and has a sector end with a concentric guideway holding all the type blocks, each held by gravity or spring. Each key has an inclined slot straddling the lever's shank; pressing the key swings the lever by an amount set by the key's distance from the pivot and the slot's incline (some slots slant the other way), aligning one type with the impression lever D. The inner end of the key then presses lever D, pushing that type against the paper. The key's inclined outer edge also pushes a feed bar whose pawl advances a sliding rack, which through a pinion drives a second rack that moves the paper drum; keys for wide letters push the bar farther. Springs return everything, and a spacing key moves only the feed bar.
