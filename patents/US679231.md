## Reading (full text, OCR good)

**Problem:** In ordinary typewriters each key releases the carriage to a spring that moves it one space; the inventor wants a simpler, cheaper way to space, and a way to return the carriage to the next line automatically.

**Solution:** Each keystroke directly pushes the carriage one space by a pawl on a lever, against a spring that is arranged to return the carriage, with a second pawl holding the position.

**How it works:** Every key lever engages a pivoted frame that pulls down a rod, which rocks a lever carrying a spring-loaded pawl. The pawl pushes the carriage rack bar forward one tooth against the tension of a convolute return spring, and a travel limit (a small projection in a notch) restricts the stroke to exactly one space. A second spring pawl on a sliding bar lets the rack advance but stops it from running back. When the lever is released, the pawl slips back over one tooth. A separate release key slides the bar and rod bodily rearward so both pawls leave the rack, and the return spring pulls the carriage back to the line start. An adjustable loop clamped on the carriage has an inclined face that trips the same bar at a chosen position, starting the return automatically. A worm and thumbwheel adjust the return spring tension.

**Parts:** key lever; pivoted frame; carriage-advancing rod; advancing lever; advancing pawl; holding pawl; rack bar; sliding bar; release key; return spring drum; strap; worm wheel; thumbwheel; adjustable stop loop

**Improves on:**

- Conventional spring-driven escapement where each key releases the carriage: the key itself pushes the carriage one space against a return spring, so no escapement wheel is needed
