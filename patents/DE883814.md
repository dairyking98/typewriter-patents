**How it works (reading):** Make the type bar itself a partial cover on the type box so types and springs are held in while it is open.

## Reading (opening only, OCR good)

**Problem:** Spring-loaded types in a booking-machine type capsule fall apart when the capsule is opened to replace a broken spring or clean it, so only trained staff could do it.

**Solution:** Make the type bar itself a partial cover on the type box so types and springs are held in while it is open.

**How it works:** The type box holds spring-loaded individual types. The type bar is shaped in its upper part to exactly cover the free part of the box, and a head part engages a recess in the box like a bayonet. One screw fixes the bar to the box. Loosening the screw lets the capsule be pulled away upward, while a narrow cover keeps springs and types from falling out and still guides them.
