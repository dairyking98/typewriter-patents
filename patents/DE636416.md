## Summary

**Kind:** a part or mechanism (any kind of machine)

**In Google’s translation of the patent’s own words:** This purpose is shown in FIGS 5 illustrates.

**How it works (reading):** The clear-character printing unit is moved to its ready position through the counting-wheel sensor only when an amount is introduced into the counter, so the clear character prints only after a real amount has been entered.

## Reading (short summary from the opening, OCR fair)

**Problem:** The clear-character printing unit of an accounting machine prints the clear character even when no amount was entered, for example when text is written in a column whose counter is on.

**Solution:** The clear-character printing unit is moved to its ready position through the counting-wheel sensor only when an amount is introduced into the counter, so the clear character prints only after a real amount has been entered.

**Features:**

- **Uses:** [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** cross counter; feeler on counting wheels; clear-character printing unit; pivotable frame; reversing gear
