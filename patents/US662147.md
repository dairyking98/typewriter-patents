## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** for rendering ink-ribbon inoperative

**In the patent’s own words:** This invention relates more particularly to the ribbon-moving mechanism of that class of type-writing machines in which the writing is done in view of the operator.

**How it works (reading):** Throw the ribbon carrier varying distances from normal so each impression falls at a different place across the ribbon width, using all of it.

## Reading (opening only, OCR fair)

**Problem:** With a ribbon carrier that always moves the same distance, impressions follow one narrow straight line on the ribbon, which wears out and runs dry quickly.

**Solution:** Throw the ribbon carrier varying distances from normal so each impression falls at a different place across the ribbon width, using all of it.

**How it works:** On a Felbel front-strike machine, horizontal key levers drive bell-cranks and links that swing horizontal type-bars in radial slots of a segment. A ribbon carrier near the print point is projected to carry the ribbon over the printing point and then returns, leaving the writing visible. The throw is varied, with an adjusting device linked to the universal-bar frame, so impressions make a wavy path across the ribbon. A modification and a shifting type segment are also shown. The full action is not in the opening text.
