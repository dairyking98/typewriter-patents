## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In Google’s translation of the patent’s own words:** The invention relates to a tabulator on typewriters, in which the stops by means of the setting rod moved by the setting button be moved with the interposition of a setting lever in the stop rail.

**How it works (reading):** A locking lever on the tab set rod is swung in by the set button so the carriage release is blocked until the set lever has returned.

## Reading (short summary from the opening, OCR good)

**Problem:** Tab set lever could still be out of position when a neighbouring stop, released by the carriage, struck and jammed it.

**Solution:** A locking lever on the tab set rod is swung in by the set button so the carriage release is blocked until the set lever has returned.
