## Reading (short summary from the opening, OCR fair)

**Problem:** Type actions need uniform leverage, uniform key dip and a durable roller bearing support for many type bars.

**Solution:** Roller-bearing supports mount a large number of type bars on a segment with uniform leverage and touch.
