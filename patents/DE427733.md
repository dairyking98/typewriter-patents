**In Google’s translation of the patent’s own words:** The invention relates to a device for typewriters for underlining and line drawing, in which a slider sitting on the paper trolley is an underline type which is pressed against the paper roller by the type lever.

**How it works (reading):** A slide on the paper carriage carries an underline type and a second line type, and the slide position selects which type lies in front of the type lever so the dead key prints the underline or the vertical line.

## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriters lacked a way to underline and to draw vertical lines to the top edge of the sheet with the usual dead key.

**Solution:** A slide on the paper carriage carries an underline type and a second line type, and the slide position selects which type lies in front of the type lever so the dead key prints the underline or the vertical line.
