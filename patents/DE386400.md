## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Fount-change arrangements

**How it works (reading):** The shift key returns immediately when released, and a locking lever holds the platen frame shifted until the next type key trips a gravity-return frame.

## Reading (opening only, OCR fair)

**Problem:** Existing shift devices either hold the shift key down until a stop, or use a hard-to-move tilting key combining shift and spacing.

**Solution:** The shift key returns immediately when released, and a locking lever holds the platen frame shifted until the next type key trips a gravity-return frame.

**How it works:** Pressing shift key b (which also takes the space key and spaces one step) or key s (shift only) pulls a rod that shifts the platen frame; a slot lets the key return at once. A locking lever hooks over a frame pin and holds the shifted position. A lever under the shift key lifts a frame that lies under the type key levers. The next type key pushes the frame, which swings back by gravity, helped by a spring-loaded ball on a wedge projection, and its extension unhooks the locking lever, releasing the shift. The text is cut off before the end.
