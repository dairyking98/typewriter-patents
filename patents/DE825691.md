**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition

**How it works (reading):** Equip a typewriter's type set and keyboard with phonetic (International Phonetic Association) characters, alone or together with ordinary characters, so phonetic text can be typed and reproduced directly.

## Reading (opening only, OCR good)

**Problem:** Phonetic transcription for texts has to be drawn by hand as a template for the typesetter, which is laborious.

**Solution:** Equip a typewriter's type set and keyboard with phonetic (International Phonetic Association) characters, alone or together with ordinary characters, so phonetic text can be typed and reproduced directly.

**How it works:** Each key and type carries two phonetic characters (one above the other, using ordinary shift) for German, English and French sounds plus accents and separators. A second scheme puts three characters on each key and type (phonetic plus normal), needing double shift. Only the keyboard and type set change; the rest of the typewriter is unchanged. Sounds can be grouped by sound class or frequency. Typed text is then photographed, stereotyped or copied lithographically.

**Features:** [USE:special-script](../features/use-special-script.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ELEM:typebar](../features/elem-typebar.md), [SHIFT:triple](../features/shift-triple.md)

**Parts:** keyboard; type set; key

**Numbers:** 2 characters per key (scheme I); 3 characters per key (scheme II)

**Improves on:**

- hand-drawn phonetic templates for typesetting: phonetic characters typed directly
