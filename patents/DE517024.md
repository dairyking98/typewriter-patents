## Summary

**Category:** related office machine, not a typewriter (booking key control for calculating typewriters) · **Subject (patent classes):** Auxiliary functional arrangements, e.g. interlocks

**In Google’s translation of the patent’s own words:** The invention relates to a control device for typewriters or calculating typewriters for the fact that the correct counter is switched on when a booking key is pressed will.

**How it works (reading):** Key levers for each posting symbol are blocked by a locking bar unless the matching counter is switched on, so the wrong column cannot be posted.

## Reading (short summary from the opening, OCR fair)

**Problem:** The clerk must avoid posting an item to the wrong counter when several counters sit side by side in a narrow form.

**Solution:** Key levers for each posting symbol are blocked by a locking bar unless the matching counter is switched on, so the wrong column cannot be posted.

**Features:** [USE:calculating](../features/use-calculating.md), [SEL:selector-locking](../features/sel-selector-locking.md)

**Parts:** key levers K L H; tie rods 4 5 6; blocking rail 13; springs
