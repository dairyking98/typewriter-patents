## Summary

**Category:** related office machine, not a typewriter (key-machine control device, typewriters or calculators) · **Subject (patent classes):** Controlling or analysing mechanical parameters involving printing of test patterns

**In Google’s translation of the patent’s own words:** The invention relates to a control device for machines to be operated by keys, like typewriters, calculators, etc.

**How it works (reading):** Phonograph pins and diaphragms on the key levers reproduce the spoken name of the key pressed, so the typist can check by ear; the same idea is applied to calculating machines.

## Reading (short summary from the opening, OCR fair)

**Problem:** Bells on typewriters do not reliably tell the typist which key was struck, because the sounds are too similar.

**Solution:** Phonograph pins and diaphragms on the key levers reproduce the spoken name of the key pressed, so the typist can check by ear; the same idea is applied to calculating machines.

**Features:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Attachment or accessory](../features/use-accessory.md)
