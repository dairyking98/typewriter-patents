Especially with machines with visible writing, where the heads of the type levers carrying the types on an almost flat, flat support rest, it is necessary to bend the type lever sharply. On the other hand, seduces the favorable, level resting position to be particularly vigorous when cleaning, whereby the ends of the type lever are slightly bent «-ground. This has the advantage that when cleaning the types no bending of the type lever can occur, even if the cleaning is still like this done thoroughly. If, however, z.
