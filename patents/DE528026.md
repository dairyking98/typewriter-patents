## Summary

**Category:** related office machine, not a typewriter (cash register duplicate receipts)

**How it works (reading):** The original is made in one checkout pass and each duplicate in a further pass: a repetition organ re-prints the stored entries while the adder is switched off, so the value is added only once.

## Reading (short summary from the opening, OCR fair)

**Problem:** Duplicate receipts with an ordinary cash register need costly extra printing and paper-conveying devices.

**Solution:** The original is made in one checkout pass and each duplicate in a further pass: a repetition organ re-prints the stored entries while the adder is switched off, so the value is added only once.
