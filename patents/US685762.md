## Reading (short summary from the opening, OCR fair)

**Problem:** A book type-writer on a flat platen needs several characters per type-bar, and the existing setup did not easily allow one bar to print more than one character.

**Solution:** The type-heads are shifted on each type-bar to select a printing base, so one bar prints several characters; the type-bars hang concentrically around a circular opening in the carriage so all types print at a common centre.

**How it works:** A tripping or shifting mechanism moves the type-head on the type-bar from one printing base to another before the bar swings to the platen.
