**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** An automatic printing-preventing device uses a movement-receiving arm and a motor frame actuated by an electromagnet to block a second character.

## Reading (short summary from the opening, OCR fair)

**Problem:** Letters can be printed over one another at the end of a line.

**Solution:** An automatic printing-preventing device uses a movement-receiving arm and a motor frame actuated by an electromagnet to block a second character.
