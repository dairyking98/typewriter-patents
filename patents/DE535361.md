## Reading (opening only, OCR fair)

**Problem:** On shorthand machines with ten keys per hand, two shift keys per group take up key positions, so fewer letters are available and more letters must be formed by combining characters.

**Solution:** Each key group has only one shift key, leaving seven character keys and two vowel keys, with a shared number shift across the whole keyboard.

**How it works:** Each hand has eight finger keys (an inner and an outer row of four) and two thumb keys. In each group only one finger key, the outer index key, is a shift key; the two thumb keys are vowel keys. A number or character shift key spans the keyboard width and is common to both groups. Each finger key's type lever carries three characters (two consonants and a number or sign), selected by shifting the lever; the middle character is obtained by pressing the group's shift key with the letter key and the top by pressing the number key. Consonants not on the keys are formed by combining, for example PB for G. Strips of paper are written syllable by syllable and advanced a line with each stroke.

**Parts:** finger key; thumb key; shift key; number shift key; type lever; paper strip; roller

**Numbers:** ten keys per hand; eight finger keys and two thumb keys per group; three characters per type lever; vowels doubled from 3 to 8 with a second vowel type

**Improves on:**

- shorthand machines with two shift keys per key group: one shift key per group frees a key for characters
