## Summary

**Category:** misc / other, not a typewriter patent (film projector printing band) · **Subject (patent classes):** Projectors combined with typing apparatus or with printing apparatus

**How it works (reading):** A stop holds the print strip and loops it; when the loop grows, a peeling device releases the strip for each new section, so the projector sees stationary frames.

## Reading (short summary from the opening, OCR fair)

**Problem:** A continuously running printer streams stock quotes past a projector, so the eye tires from the moving print.

**Solution:** A stop holds the print strip and loops it; when the loop grows, a peeling device releases the strip for each new section, so the projector sees stationary frames.
