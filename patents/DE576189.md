## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** The type carrier stays permanently coupled to a crank, and the crank passes through a stretched toggle at printing, so the type presses on the platen quietly and the drive returns smoothly on a single rotation direction.

## Reading (short summary from the opening, OCR fair)

**Problem:** Differential-gear and spring-return type carrier drives move harshly, so the type drum is neither harmonic nor quiet in operation.

**Solution:** The type carrier stays permanently coupled to a crank, and the crank passes through a stretched toggle at printing, so the type presses on the platen quietly and the drive returns smoothly on a single rotation direction.
