## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary type mechanisms for printing distinguishing marks, e.g. for accenting, using dead or half-dead key arrangements, for printing marks in telegraph printers to indicate that machine is receiving

**In the patent’s own words:** My invention relates especially to what t) is commonly termed dead key mechanism fortypewriting machines, that is, to mechanism for enabling the type controlled by said key to print without causing or permitting a letter space movement of the car- 1p;

**How it works (reading):** A supplemental universal bar, close to the main one, is driven by dead keys to vibrate the ribbon, and a locking device blocks the escapement dog rocker so the carriage does not feed.

## Reading (short summary from the opening, OCR fair)

**Problem:** Dead keys must actuate the ribbon vibrator through the universal bar yet not operate the escapement, which the shared universal bar would otherwise do.

**Solution:** A supplemental universal bar, close to the main one, is driven by dead keys to vibrate the ribbon, and a locking device blocks the escapement dog rocker so the carriage does not feed.

**Features:**

- **Inking:** [Ink ribbon](../features/ink-ribbon.md)
- **Spacing and escapement:** [Prints and spaces in one stroke](../features/esc-print-and-space.md)
