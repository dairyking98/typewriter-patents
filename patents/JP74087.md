## Reading (full text, OCR good)

**Problem:** Striking type faces with a hammer damages them, characters are hard to find when inverted, and printing is noisy.

**Solution:** A solenoid holder on the printing bar magnetically picks a loose type from a tray, then is turned 180 degrees while the bar swings up so the type face strikes the paper, with no hammer.

**How it works:** Types lie face down in a tray, with the character marked upright on their back for the user. Pressing key lever (2) turns shaft (3), sector gear (5) and a disc with pin (6); the pin presses arm (26), which closes the battery circuit to solenoid (18) in the holder (17) and pushes the spring-loaded iron core (20) down so it magnetically grabs the type (50), then slips off so the core returns with the type fully in the holder. Further travel engages the sector gear with gear (10) on the printing bar (8), swinging it up to the printing surface. Meanwhile a toothed rim (22) rolls on a fixed toothed rim (12), turning pulleys and a band (24) so the holder turns 180 degrees about its axle (16), putting the type face square onto the paper. On release everything returns, the circuit opens and the type drops back into the tray.

## Description (English translation of the Japanese text, opening)

> Nature and object of the invention. This invention concerns a printing mechanism in which depressing the key lever closes the electric circuit of a solenoid that is fitted to the printing bar and forms the type holder, and at the same time pushes down the iron core inside the solenoid, so that the type, stored face down in the type tray, is attracted by magnetism; the core is then drawn back so the type is taken fully into the holder, and the printing bar is raised while the holder is turned through 180° about a horizontal axis, so as to strike the printing surface. Its object is a printing mechanism that does not damage the type faces, makes finding the characters easy by showing them the right way round whatever the size of the type, and prints quietly and simply.
