## Reading (opening only, OCR good)

**Problem:** The writing is hidden unless the carriage is raised.

**Solution:** A typebar machine on a curved frame plate in which key and type levers swing the types upward to strike the platen directly in front of the operator, and rest lowered so the writing is visible.

**How it works:** Type bar hangers on a curved plate hold right-angled arms, joined by rods to right-angled key levers, so a downward key push swings the type in an arc to the paper. An inking pad or roller worked by the spacing bar inks the types, with a type-cleaner. Upper case is made by tilting the carriage in an arc, and hangers are adjustable for wear.

**Features:** [FRM:writing-visible](../features/frm-writing-visible.md), [ELEM:typebar](../features/elem-typebar.md), [SHIFT:platen](../features/shift-platen.md), [INK:pad](../features/ink-pad.md), [INK:roller](../features/ink-roller.md), [ESC:space-key](../features/esc-space-key.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** bed frame; carriage; platen roller; curved plate; type-bar hanger; right-angled arm; type bar; key lever; spacing bar; inking pad; type cleaner
