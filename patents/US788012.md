## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage return and platen line-spacing are separate operations that cost more to make and install.

**Solution:** A carriage-return mechanism that also spaces the platen, with a spring motor and an electric motor for return; the return key is disengaged so the operator can hold it.

**How it works:** A carriage-return mechanism that also spaces the platen, with a spring motor and an electric motor for return; the return key is disengaged so the operator can hold it.
