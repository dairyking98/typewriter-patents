**How it works (reading):** The attachment points of the handlebars on the side type levers are shifted rearward so all type levers reach the same distance from the platen.

## Reading (short summary from the opening, OCR fair)

**Problem:** In a type-lever segment driven by intermediate levers, the side type levers reach the dead-centre position sooner than the middle ones, so the impact is uneven.

**Solution:** The attachment points of the handlebars on the side type levers are shifted rearward so all type levers reach the same distance from the platen.
