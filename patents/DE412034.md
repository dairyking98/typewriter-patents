## Reading (short summary from the opening, OCR good)

**Problem:** Type-lever drive by interlocking teeth is known, but the mechanism needs a compact layout and easy repair.

**Solution:** The type lever swings in the same plane as the key lever, driven by a partial toothing that gives only the start of the stroke, then flies free and is returned by a nose; both levers sit on one small base plate that can be removed as a unit.

**How it works:** The key lever gear segment engages the type lever toothing for the initial acceleration, then the type lever swings free to the paper; a nose returns it.
