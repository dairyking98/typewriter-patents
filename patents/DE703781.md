## Reading (opening only, OCR fair)

**Problem:** On syllable typewriters where several types strike together, the key order and type order are normally tied; the inventor wants keys placed for the strongest fingers while the printed letter order still follows the language.

**Solution:** Make the order of the types on the platen differ from the order of the keys, so adjacent keys can print their letters in swapped order via crossed linkages.

**How it works:** A keyboard of four horizontal key rows is laid out so frequent letters sit under the strong fingers, while the type order follows the language (e.g. FT printed although the F key is right of T). Each key sits on a vertical key rod guided in two parallel plates and returned by a spring. Transverse arms on the rod push a rod onto a pressure plate of a cam turning on an axis; the cam is linked by a tie rod to a type lever returned by a spring. In another form the cross arm of one key reaches around the arm of its neighbour so the left key drives the right-hand type and vice versa. Several types come to the stop at once for a syllable.

**Features:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Typebars](../features/elem-typebar.md)

**Parts:** key; key rod; guide plate; cross arm; cam; tie rod; type lever; platen; return spring
