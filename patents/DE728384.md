## Summary

**Category:** related office machine, not a typewriter (calculating machine with lockable actuators)

**In Google’s translation of the patent’s own words:** The invention relates to a calculating machine in which individual actuators can be locked by a lock.

**How it works (reading):** A common lock controls several locking devices that each hold a group of actuators, so one key governs all of them.

## Reading (short summary from the opening, OCR fair)

**Problem:** Calculating machine keys need protection against unauthorised use, but single locks are not enough.

**Solution:** A common lock controls several locking devices that each hold a group of actuators, so one key governs all of them.
