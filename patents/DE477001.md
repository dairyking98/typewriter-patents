## Description (Google Patents OCR, opening)

> Description Translated from German Counter drive for typewriters The invention relates to a counter drive for typewriters and the like, in which a value output member drives the vertical counters and the transverse totalizers. According to the invention, the reversing gear for the vertical counter and the transverse summing unit around the value output member at an angle to one another arranged. The value transfer element acts directly on the reversing gear. Through this a simple device is obtained which does not require intermediate gears, which complicate the manufacture of the machine and thus make it more expensive, also a lot Remove seat and bring play into broadcast; thus easily sources of error develop. The value transfer element advantageously consists of several tooth sectors, their arrangement, being formed in one piece, is extremely simple. These Tooth sectors are arranged displaceably on the shaft that drives them, thereby making it possible to disengage the various tooth sectors from the Bring associated reversing gears without a special storage of each tooth sector is required, the position of the tooth sectors in relation to one another indifferent is.
