## Description (Google Patents OCR, opening)

> Description Translated from German The invention relates to the type linkage of typewriters. In particular, it is a type of linkage with a pin on a linkage and a guide slot for this pin on a cooperating with the former Linkage. The invention aims to perfect this connection and to design so that the slit walls Form smooth surfaces for the pin sliding in this slot and on its walls. The invention further aims for this Provide slot guide processing means in order to adjust the type linkage after to facilitate its composition. The drawing shows in Fig. 1 in longitudinal section the typewriter the drive connection of a middle type lever according to the invention. Fig. 3 is a corresponding side view showing the last machining tool in the opening into which the Slot opens.
