## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing musical scores

**In Google’s translation of the patent’s own words:** The invention relates to a Type arrangement in the known typewriters in which the type body carrier and the workpiece carrier are adjustable with respect to one another, and it aims to provide a to create such an arrangement of the print images on the type bodies that a reduction the number of type bodies required in the previous arrangements without affecting the accuracy and speed of the printing work.

**How it works (reading):** Auxiliary signs such as flags, dots and crosses are placed to the side of the pressure centre on each type body with the main note, so any main note can print with its auxiliary signs without moving the carrier.

## Reading (short summary from the opening, OCR fair)

**Problem:** Note typewriters need many type bodies, because note heads and auxiliary signs placed beside the pressure centre need separate type bodies or separate carriage settings.

**Solution:** Auxiliary signs such as flags, dots and crosses are placed to the side of the pressure centre on each type body with the main note, so any main note can print with its auxiliary signs without moving the carrier.
