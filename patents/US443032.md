## Reading (opening only, OCR good)

**Problem:** Capital letters printed from a typebar machine are hard to tell apart, and a distinguishing mark in another colour is wanted.

**Solution:** An annular ink pad has a hole holding a separate threaded ink pad of different colour, aligned with the one type that prints the capital-marking character.

**How it works:** The main ring of felt sits on a flanged plate under a cover plate and is screwed into a recess in the machine top plate. The annular row of types returns across the exposed underside of the pad after each print. One type carries a distinguishing mark, and the felt above it is cut away and replaced by a cartridge-shaped threaded casing holding felt with a different coloured ink. The casing's thread allows its height to be set so it touches that type independently of the main pad. A pin locates the plates.

**Features:**

- **Type element:** [Typebars](../features/elem-typebar.md)
- **Inking:** [Ink pad](../features/ink-pad.md), [Two-colour ribbon](../features/ink-ribbon-color.md)

**Parts:** annular felt pad; metal plate; cover plate; retaining ring; supplemental pad; threaded casing; locating pin; type
