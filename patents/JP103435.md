## Reading (full text, OCR good)

**Problem:** Forms such as postal life insurance documents need slightly different groups of entries printed at two set places on each of many sheets, which is slow by hand.

**Solution:** A hand-slid frame carries a rising and falling holder of many types over an ink roller and presses them down all at once, while a geared link moves the paper table to a second position after every pass and suppresses chosen type groups on one of the two impressions.

**How it works:** A sliding frame on rails carries four parallel arms that hold a type holder level, with many type groups set side by side. The operator moves a knob along; a roller on one arm follows a fixed guide groove, level at first so the type faces pass the ink roller and are inked, then bending downward so the holder descends and all types print at once on the first set position. On that stroke an arm on the holder rests on a flange of the paper table and, through a claw and stud, lifts one sub-holder of types against spring strips so that group does not print. On the return stroke a feed lever turns a four-roller large gear by a quarter turn, which through a half-diameter gear, an arm and a crank link moves the paper table, diagonally guided by a lug in a slot. At the second impression the flange no longer catches the arm so all groups print; the next return restores the table.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. A printing machine characterised in that: a sliding frame, which always keeps level a type holder that rises and falls and carries many types set side by side, and a paper table are carried separately on a base frame and are linked so that two back-and-forth strokes of the sliding frame give one back-and-forth stroke of the paper table; each stroke of the sliding frame makes the type holder rise and fall once, so that many types print together each time; and in each printing the types not wanted are automatically kept from going down and do not print. The object: a machine that, without any conscious choosing of types, by two very simple mechanical operations, prints groups of types, slightly different from each other, at two different set positions on the same sheet.
