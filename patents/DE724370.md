## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Apparatus for condensed record, tally strip, or like work using two or more papers, or sets of papers, e.g. devices for switching over from handling of copy material in sheet form to handling of copy material in continuous form and vice versa or point-of-sale printers comprising means for printing on continuous copy material, e.g. journal for tills, and on single sheets, e.g. cheques or receipts

**In Google’s translation of the patent’s own words:** The aim of the invention is the device described in the main patent such train that the return of the auxiliary paper car automatically, in each case pre-settable position of the main paper trolley.

**How it works (reading):** A release element on the main carriage engages a link on the machine frame at any preset position of the main carriage, releasing the coupling so the auxiliary carriage returns.

## Reading (short summary from the opening, OCR fair)

**Problem:** The auxiliary paper carriage can only return from a fixed position, and only one column arrangement can be divided.

**Solution:** A release element on the main carriage engages a link on the machine frame at any preset position of the main carriage, releasing the coupling so the auxiliary carriage returns.

**How it works:** A release element on the main carriage releases the auxiliary carriage at any preset position.
