## Summary

**Category:** misc / other, not a typewriter patent (roller bearing) · **Subject (patent classes):** Bearings with rolling contact, for exclusively rotary movement with bearing balls essentially of the same size in one or more circular rows for radial load mainly with a single row or balls; Bearings with rolling contact, for exclusively rotary movement with bearing balls essentially of the same size in one or more circular rows with loose spacing bodies, e.g. balls, between the bearing balls; Loose spacing bodies with other rolling elements serving as spacing bodies, e.g. the spacing bodies are in rolling contact with the load carrying rolling elements

**In the patent’s own words:** This invention relates to improvements in roller-bearin gs, and refers more specifically to improvements in the arrangement of the balls or roller elements within the box or casing.

**How it works (reading):** Balls and rollers arranged in a bearing so contacting surfaces do not slide against each other.
