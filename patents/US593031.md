## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** This invention relates to that class of typewriting machines in which the writing is visible and in which each type-bar is provided with two types for large and small letters, respectively, or for different characters.

**How it works (reading):** Oscillate the platen vertically on swinging arms and angle the two type faces on each bar so each strikes along a radius of the platen.

## Reading (opening only, OCR fair)

**Problem:** In visible-writing typebar machines with a swinging platen, the type faces do not strike the platen squarely in both shift positions.

**Solution:** Oscillate the platen vertically on swinging arms and angle the two type faces on each bar so each strikes along a radius of the platen.

**How it works:** Typebars hang from a segmental plate; two type (upper and lower case) per bar. The platen is carried on swinging arms pivoted to a rear cross-rod and rides on a rail of a vertically movable frame raised by a lever, shifting the platen in a curve. The type faces are arranged at right angles to the platen radii in both positions. A simplified returning mechanism of slides and knuckle joints connects keylevers, typebars and return slides.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [SHIFT:platen](../features/shift-platen.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [FRM:writing-visible](../features/frm-writing-visible.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** base plate; segmental plate; typebar; key-lever; swinging arm; platen; vertically movable frame; shift lever; return slide
