## Reading (full text, OCR good)

**Problem:** In Blacio's earlier machine (US350717) the operator had to select a character with one hand, hold the type segment there, and print with the other hand, and had to change hands again to space, which caused errors and limited speed.

**Solution:** Couple the character-indicating lever to the impression mechanism so that bringing the index lever to a character and pressing it down both prints and spaces, leaving the other hand free only for spacing.

**How it works:** A hinged index plate with radially placed characters sits above a toothed feed-bar, and a pivoted type segment carrying a flexible type plate rides with it. A pointer on the type segment tells which type is at the print position. A printing lever carries a hammer, a registering finger that enters a peripheral hole in the type plate to lock it, and a feed dog that engages the feed-bar teeth. Pressing the index lever (over the chosen character) acts through a secondary lever on the rocking lever, depressing the printing lever so the finger locks the segment, the hammer strikes the type against a flat printing bar behind the paper, and the dog steps the segments forward one tooth. A spring on the printing lever lifts it and re-seats the dog. For a space, a thumb-piece hooked over the lever-bar stops short of the hammer stroke.
