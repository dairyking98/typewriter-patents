## Reading (short summary from the opening, OCR fair)

**Problem:** Two-row key levers print a single character per key, and conventional special-type levers are no faster.

**Solution:** A second, secondary type carrier on the same segment is struck by the same key, so two different characters print on one position with one keystroke.
