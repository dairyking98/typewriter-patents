## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**How it works (reading):** The guide fork is placed on the type lever shaft at the level of the type body, which avoids grinding, and for double types the lowercase character sits on the outside so it stays visible.

## Reading (short summary from the opening, OCR good)

**Problem:** Guiding the type lever at the type block needs exact grinding of the block to the guide, and vibrations from the guide pass into the type block.

**Solution:** The guide fork is placed on the type lever shaft at the level of the type body, which avoids grinding, and for double types the lowercase character sits on the outside so it stays visible.

## Description (Google Patents OCR, opening)

> Description Translated from German Type lever guide. For most typewriter lever guides the type lever is guided at the pressure point below the type body. It is Although already known to provide the guide directly on the type block, but the type block and the guide must be ground exactly on one another. The present invention differs therefrom in that the guide on the type lever shaft, i.e. not on the type block, but at the level of the latter, takes place. It is thereby the transmission of the guides below the Type block occurring vibrations of the type lever on the type block avoided, and it still takes place on the type lever shaft, so that the expensive and cumbersome Grinding in is not required, as the type lever in the event of any inaccuracies can easily be bent into the correct position.
