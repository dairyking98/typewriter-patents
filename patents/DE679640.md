## Reading (opening only, OCR fair)

**Problem:** In punched-tape-controlled typewriters with adding units, the carriage carrying the adders had to return to a base position before moving to a new setting, wasting travel.

**Solution:** A control device lets the carriage go directly to the adder named by a code hole in the tape and stops it when that adder reaches the computing zone.

**How it works:** A typewriter with letter and number keys has a carriage with the platen and a frame carrying standing adding units, plus further adders for cash and credit sums. A motor drives the carriage and the perforated tape. A sensing element reads the identification hole, and a control device that follows the carriage drive direction stops the carriage as soon as the selected adder reaches the standby position. Hand levers select adding, subtracting or idle for each main wheel.
