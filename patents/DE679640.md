## Description (Google Patents OCR, opening)

> Description Translated from German OIL 1 - ISSUED ON AUGUST 12, 1939 The present invention relates to a typewriter with perforated tape control, which is equipped with a number of adding units, which through identification holes in the perforated tape for the Recording of number sizes can be selected. The known machines of this type are, however, set up so that there is no possibility consists of a certain position of the car carrying the adding units compared to that with the engine connected keyboard to a certain setting position determined by a new control hole in the perforated strip. With previously known Rather, it was unavoidable for machines that the carriage carrying the adding units was initially in a certain basic position was transferred before he could take the path to the new setting. This working method is evident in such Cases represent a significant disadvantage where it is a question of moving the car from one storage location to a nearby one 2 g adjustment position to be transferred, since in this case the carriage has to carry out a more or less long path in two opposite directions of movement, although depending on the situation, only a very slight lateral move…
