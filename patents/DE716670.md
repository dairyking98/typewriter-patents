> Description Translated from German Process for the production of key plates provided with directional markings for typewriters or the like. The invention relates to a method of manufacture of key plates for typewriters with alignment marks. Typewriters and other keyed machines. For the quick insertion of key plates in the key plate It is important that the alignment of the key pads not be too difficult because it wastes a lot of time. To easily insert the button plates To achieve this, alignment marks have already been provided on the button plates. These However, alignment marks arranged on the sides of the key plates had to be in order to make the key image not to disturb, be made very small, whereby when inserting the key plate considerable care had to be taken. The reason for this was the attachment the alignment mark below the button plate is more advantageous. This attachment of the Markings made below the button plates, especially if the button plates consisted of relatively thin cardboard, considerable difficulties, so that this training could practically not be introduced.
