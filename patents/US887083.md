## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Auxiliary type mechanisms for printing distinguishing marks, e.g. for accenting, using dead or half-dead key arrangements, for printing marks in telegraph printers to indicate that machine is receiving

**In the patent’s own words:** The purpose of the invention is to enable a plurality of characters to be printed in the same vertical alinement and to avoid the necessity of retracting the carriage after the first of these characters has been printed.

**How it works (reading):** A member is projected into the path of the escapement dog so that it cannot fully release the escape pinion when a silent key is struck.

## Reading (opening only, OCR fair)

**Problem:** After accent or silent keys the carriage must not advance, otherwise it has to be retracted to print several characters in one position.

**Solution:** A member is projected into the path of the escapement dog so that it cannot fully release the escape pinion when a silent key is struck.

**How it works:** On an Oliver-type machine the universal bar raises the escapement dog from the pinion tooth on each key press. For silent or accent keys a member is projected against the dog so it only rises part-way. The lost motion at the type bar link lets the type still print. The pinion turns only until its tooth hits a shoulder, so no letter space occurs.
