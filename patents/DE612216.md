**Category:** related office machine, not a typewriter (line feed for cash register print table)

**In Google’s translation of the patent’s own words:** The invention relates to cash registers and accounting machines with a printing table that receives the receipts and which is placed on the respective one to be printed Line of the receipt is set.

**How it works (reading):** The printing table is shifted one line automatically during certain aisles, through a differential gear whose input comes from the drive that sets the amount type wheels, and it returns to the originally set line after printing.

## Reading (short summary from the opening, OCR fair)

**Problem:** A booking spanning several machine aisles needs a second line selection to print consecutive lines, so the operator must re-select the line.

**Solution:** The printing table is shifted one line automatically during certain aisles, through a differential gear whose input comes from the drive that sets the amount type wheels, and it returns to the originally set line after printing.
