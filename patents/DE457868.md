**How it works (reading):** Each key has an extra overtravel that closes electrical contacts when the value is set, and a lock holds the key in the set position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Calculators needed their results transferred to a second machine such as a typewriter or punch card without re-keying.

**Solution:** Each key has an extra overtravel that closes electrical contacts when the value is set, and a lock holds the key in the set position.
