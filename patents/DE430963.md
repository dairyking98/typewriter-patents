## Reading (short summary from the opening, OCR fair)

**Problem:** Known devices that shift the paper carriage by several letter spaces used a control lever that moved on an arc, so the carriage jump was hard to set accurately.

**Solution:** The control part sits on a frame that swings in a horizontal plane and is linked by a rod to a rack on the carriage, so moving the control part moves the carriage by the same length each time; a gear meshes with the rack.
