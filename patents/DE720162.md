## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Construction of universal bars

**How it works (reading):** A package of leaf springs of decreasing length, clamped at one end, engage the universal rail one after another so the return force builds gradually.

## Reading (short summary from the opening, OCR fair)

**Problem:** A single return spring on the universal rail either brakes the stop or returns the keys slowly.

**Solution:** A package of leaf springs of decreasing length, clamped at one end, engage the universal rail one after another so the return force builds gradually.

**Features:** [Spring-powered blow](../features/imp-spring-energy.md), [Typebars](../features/elem-typebar.md)

**Parts:** leaf spring package; universal rail; type levers; key levers
