## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies on spherical, truncated-spherical, or like surfaces

**In the patent’s own words:** The object of our invention is the production of an inexpensive, simple, and durable type-writingmachine;

**How it works (reading):** A keyed type-wheel machine in which depressing a key turns the wheel shaft by a given amount via position plates, and a type hammer then drives the selected type out against the platen while advancing the carrier.

## Reading (opening only, OCR fair)

**Problem:** An inexpensive, simple and durable typewriter is wanted, improving on two earlier Schuckers key-rotated type-wheel machines.

**Solution:** A keyed type-wheel machine in which depressing a key turns the wheel shaft by a given amount via position plates, and a type hammer then drives the selected type out against the platen while advancing the carrier.

**How it works:** In the earlier machines each key (directly or through a slide-bar traveler with a deflecting arm) rotated a wheel shaft in one direction or the other by a fixed amount through a position plate. The type wheel on that shaft is thus placed relative to the platen, and a type hammer, moved by the key, throws the chosen type radially outward. The same motion drives connective mechanism that advances the platen carrier a set amount. This patent combines features of both prior machines with 14 sheets of drawings.

**Features:** [ELEM:wheel-rim](../features/elem-wheel-rim.md), [SEL:differential-drive](../features/sel-differential-drive.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [IMP:hammer-behind](../features/imp-hammer-behind.md), [ESC:print-and-space](../features/esc-print-and-space.md)

**Parts:** key; slide-bar traveler; deflecting arm; wheel shaft; position plate; type wheel; type hammer; platen carrier

**Numbers:** 14 sheets of drawings

**Improves on:**

- Schuckers application Serial No. 310,393: combines its features with those of the second machine
- Schuckers application Serial No. 316,308: keeps the keys acting directly on the wheel shaft, with further simplification
