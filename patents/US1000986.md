## Reading (full text, OCR fair)

**Problem:** An 84-character front-strike machine with one type per bar needs a typebar action that fits a standard-size frame, has uniform key leverage and dip, is free of torsional strain, and can be assembled outside the machine.

**Solution:** Key-driven bell-crank levers are mounted in a removable auxiliary frame and pull each typebar by straight draw-links in fore-and-aft planes, with the key arms of adjacent keys stacked on wide shared sleeves.

**How it works:** Each finger key stem turns a forward bell crank whose wide sleeve is on a pivot rod in an auxiliary frame of parallel plates. A link joins its upright arm to a rear bell crank on a knife-edge bearing, which draws a horizontal two-part adjustable link to the typebar, so all pull is straight fore and aft. The rear bell cranks also bear on a universal bar that rocks the feed dogs to step the carriage by escape wheel, spring drum and rack, and a space bar works the same bar through its own bell cranks. Typebar hangers sit in an interlocking two-piece segment and are staggered so all bars have the same length. A button on the carriage disengages a clutch to free the carriage.

**Features:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Typebars](../features/elem-typebar.md), [Element struck to the platen](../features/imp-element-to-platen.md), [Separate print key or lever](../features/imp-print-lever.md), [Escape-wheel escapement](../features/esc-escape-wheel.md), [Mainspring-drawn carriage](../features/esc-spring-drum.md), [Space key or bar](../features/esc-space-key.md), [Carriage release](../features/esc-carriage-release.md), [Adjustment and wear take-up](../features/frm-adjustment-wear.md), [Visible writing](../features/frm-writing-visible.md), [Frame construction](../features/frm-frame-construction.md)

**Parts:** finger key; key stem; bell crank lever; knife-edge bearing; connecting link; adjustable horizontal link; typebar; typebar hanger; two-piece typebar segment; auxiliary frame; pivot rod; universal bar; feed dog; escape wheel; spring drum gear; clutch section; space bar; return wire spring; felt buffer

**Numbers:** about 84 characters, one type per bar; 7 keys per fore-and-aft row
