## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In the patent’s own words:** The present invention relates to tabulating IO devices for type-writing.

**How it works (reading):** Several rows of column stops are carried on a rotatable rod, each row projecting in a different direction; rotating the rod brings one set into use.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulation needs many column stops reset for each form, and resetting them for each change of form is slow.

**Solution:** Several rows of column stops are carried on a rotatable rod, each row projecting in a different direction; rotating the rod brings one set into use.

**Features:** [ESC:tabulator](../features/esc-tabulator.md), [ESC:margin-stop](../features/esc-margin-stop.md)
