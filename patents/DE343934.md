## Summary

**Category:** related office machine, not a typewriter (electric type printing device) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection the plane of the type or die face being parallel to the axis of rotation, e.g. with type on the periphery of cylindrical carriers

**How it works (reading):** The type drum rotates continuously; a brief capacitor-discharge-driven hammer inside the drum pushes the type body outward, and springs return it at once, so the type does not drag across the paper.

## Reading (short summary from the opening, OCR fair)

**Problem:** Fast type drum printing smears or wipes paper, because the hammer's impact lasts too long and the type stays in contact with the paper.

**Solution:** The type drum rotates continuously; a brief capacitor-discharge-driven hammer inside the drum pushes the type body outward, and springs return it at once, so the type does not drag across the paper.
