## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection; Cylindrical Japanese-language typewriter

**In the English translation of the patent’s own words:** This invention relates to a Japanese-script typewriter in which: inside a type cylinder in which a great many types are arranged, a projection cylinder, carrying as many projections as there are [types in a] longitudinal column, set spirally so as to go once round, is fitted so as to turn independently of the type cylinder;

**How it works (reading):** A type cylinder with many sliding types, turned to the wanted row by a cam/key system, has an inner spiral projection cylinder that pushes out only the wanted type when the paper cylinder, carried on a sliding frame, is swung down.

## Reading (full text, OCR good)

**Problem:** A Japanese typewriter needs a simple, light-acting and smooth mechanism with clear printing, selecting among a very large number of characters.

**Solution:** A type cylinder with many sliding types, turned to the wanted row by a cam/key system, has an inner spiral projection cylinder that pushes out only the wanted type when the paper cylinder, carried on a sliding frame, is swung down.

**How it works:** Types sit in through-holes of a large type cylinder, retracted by springs. Pressing the key for the character's transverse row pushes its operating plate under a latch; the rocking frame, swung down by the working plate, acts on that plate's staggered cam on the main shaft and turns the type cylinder to that row (a ratchet and cam-driven pawl then lock the cylinder). The operator slides a frame carrying the paper cylinder along the cylinder, reading a pointer on a numbered scale for the column; this turns a grooved shaft that rotates the inner projection cylinder, whose spiral projections bring one projection opposite the wanted type. Pressing the working plate slides an operating shaft whose slanted-slot advancing plate pushes that projection and type out, while a link swings the paper cylinder down to print. A variant replaces keys and cams by a hand-turned character cylinder marked with the type layout. Line feed is by gear and rack or ratchet.
