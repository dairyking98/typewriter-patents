## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition

**In the patent’s own words:** My invention relates to that class of typewriters in which the writing-surface is stationary, while the type is located upon a carriage which travels over the writing-surface.

**How it works (reading):** Keep the five-key keyboard stationary, with the type carriage over stationary paper, plus a synthetizer to use a normal keyboard.

## Reading (opening only, OCR good)

**Problem:** On travelling-type machines, keyboard rides with the carriage so the hand follows.

**Solution:** Keep the five-key keyboard stationary, with the type carriage over stationary paper, plus a synthetizer to use a normal keyboard.

**How it works:** The type box travels over a stationary writing surface, positioned by five keys singly or in combination. A synthetizer links a standard keyboard to those five keys. Parts fold into a portable shape.

**Features:** [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [ESC:moving-print-head](../features/esc-moving-print-head.md), [PAP:flat-bed](../features/pap-flat-bed.md), [FRM:compact-portable](../features/frm-compact-portable.md), [SEL:differential-drive](../features/sel-differential-drive.md)

**Parts:** stationary keyboard; carriage; type box; guide; line-spacer; paper feed; synthetizer; synthetizing lever

**Numbers:** 5 keys

**Improves on:**

- Carmona Serial 716,835: keyboard separated from carriage
