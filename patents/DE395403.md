## Summary

**Category:** misc / other, not a typewriter patent (kinematographic toy) · **Subject (patent classes):** Control devices operated by the film strip during the run

**In Google’s translation of the patent’s own words:** The invention relates to a self-acting device in order to bring the picture L to a standstill at a certain point in a cinematic) graphic presentation apparatus and to automatically switch it on again after a certain point has elapsed.

**How it works (reading):** A touch organ dropping into a recess lets a rotating arm with a cam count revolutions and then return the gripper carrier and its sleeve, so the band starts again after a set interval.

## Reading (short summary from the opening, OCR fair)

**Problem:** A toy cinema projector must stop the picture band at a set point, then restart it automatically after a set time.

**Solution:** A touch organ dropping into a recess lets a rotating arm with a cam count revolutions and then return the gripper carrier and its sleeve, so the band starts again after a set interval.
