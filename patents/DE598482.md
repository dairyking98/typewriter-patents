## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection the plane of the type or die face being parallel to the axis of rotation, e.g. with type on the periphery of cylindrical carriers

**How it works (reading):** Drive the strike movement only through a double roller-lever transmission that accelerates the stroke, and use a very thin non-rigid type jacket sliding over a core cylinder, in a machine built like a standard four-row typebar machine.

## Reading (opening only, OCR fair)

**Problem:** Earlier type cylinder or type wheel machines were too slow and weak in impression because the rigid type carrier had a high moment of inertia, while type bar machines had won on speed and familiar operation.

**Solution:** Drive the strike movement only through a double roller-lever transmission that accelerates the stroke, and use a very thin non-rigid type jacket sliding over a core cylinder, in a machine built like a standard four-row typebar machine.

**How it works:** The machine has a normal platen with a visible front stroke and a four-row keyboard with a simple shift. The type carrier is a thin cylinder jacket that turns and slides over a core cylinder acting as the impact body. The key stroke is carried to the carrier only by a roller lever transmission, in particular a double one, which multiplies speed by roughly 1:3 to 1:4 so the carrier hits at high final speed. The four-row jacket is raised by one type row with every second key, and the shift key moves the whole carrier up by two rows. The patent says this lifting needs no electric power because the jacket's mass and stroke are tiny.

**Parts:** type jacket; core cylinder; roller lever transmission; four-row keyboard; shift key; paper roller

**Numbers:** acceleration ratio 1:3 to 1:4 from the roller lever; jacket moment of inertia about 0.2 g/cm2 (OCR uncertain); four type rows

**Improves on:**

- earlier rigid type wheel machines: jacket mass is a fraction of the earlier carrier so speed and impact are higher
- type boat or segment carriers: avoid the large radius that cancelled the mass saving
