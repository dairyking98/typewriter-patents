## Reading (full text, OCR fair)

**Problem:** Electromagnetically printed machines with a type drum used hammers between the magnet armature and the type block, which added parts, return means, noise and faults.

**Solution:** The radially sliding type blocks in the drum are themselves the electromagnet armatures, pulled straight to the paper with no hammer.

**How it works:** A drum, rotatable and liftable as in the Hammond machine, has radial cutouts each holding a sliding type block with its type on the outer face. A keyboard sets the drum so the chosen type is in the ready position; there a contact spring on the block drops into a notch in the base and closes the circuit of an electromagnet, while blocks passing at speed skip over the notch and do not. The magnet pulls that block outward so the type hits the paper on the roller, and the block's movement breaks the circuit. At the same time a contact piece closes a second circuit that energizes a return magnet, which pulls a rail by cord into a groove in the blocks and draws the block back to rest. Variants use an endless chain or a straight-moving frame of blocks under the platen, where gravity returns the blocks.
