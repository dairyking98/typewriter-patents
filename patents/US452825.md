## Reading (opening only, OCR good)

**Problem:** Typebars rebound from the rest on return and collide with an ascending typebar.

**Solution:** A coiled spring connects the typebar, between fulcrum and type end, to the connecting rod, so it pulls the bar home quickly and damps the rebound.

**How it works:** The typebar is pivoted in a hanger and its short bent arm joins a connecting rod to the key-lever. A coiled spring joins the typebar at a point between fulcrum and type end to the connecting rod. Raising the bar stretches the spring; on release it draws the rod and key-lever up and helps gravity return the bar against the type rest, then holds it without rebound.
