## Summary

**Category:** related office machine, not a typewriter (cash register drive for two receipts) · **Subject (patent classes):** Output mechanisms with visual indication, e.g. counter drum

**In Google’s translation of the patent’s own words:** The invention relates to a drive device for such cash registers, in which in a single operation by means of the same printing device one after the other two different print receipts can be printed.

**How it works (reading):** The checkout drive stops automatically after the first document is printed, the line selector is set for the second document, and a release device restarts the run.

## Reading (short summary from the opening, OCR fair)

**Problem:** Two documents printed in one run must use the same line, because the checkout cannot be stopped to change the line selection for the second document.

**Solution:** The checkout drive stops automatically after the first document is printed, the line selector is set for the second document, and a release device restarts the run.
