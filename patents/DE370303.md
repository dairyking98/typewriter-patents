## Reading (short summary from the opening, OCR poor)

**Problem:** Accounting booking slips must be written in a fixed grid with pre-printed ordinal numbers, and carbon copies are unreliable for this use.

**Solution:** A typewriter is set up for multi-line accounting slips where the first column is pre-printed or set by special keys, and several typebar sets strike together so that each booking entry is written once into the grid.
