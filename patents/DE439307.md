## Summary

**Category:** related office machine, not a typewriter (electromagnetic key-set lock) · **Subject (patent classes):** Arrangements wherein a dial or the like is mechanically coupled to a line selector

**In Google’s translation of the patent’s own words:** The invention relates to an electro-key of the relevant key set triggered magnetic locking device for key-operated will.

**How it works (reading):** An electromagnet, energised when any key is pressed, pulls a locking member that holds the pressed key in working position and locks the others until the circuit completes.

## Reading (short summary from the opening, OCR poor)

**Problem:** Keys in a key set should stay locked in rest position until a switching process started by the pressed key has finished.

**Solution:** An electromagnet, energised when any key is pressed, pulls a locking member that holds the pressed key in working position and locks the others until the circuit completes.
