## Reading (opening only, OCR fair)

**Problem:** Typebar machines with two or more types per bar need a smooth, low-friction way to shift the type ring.

**Solution:** The type ring is shifted along grooved bearing plates running on balls, with a spring return.

**How it works:** A frame holds longitudinal grooved plates facing matching plates on the type ring; steel balls in the grooves carry the ring, two on one side and one on the other. One frame is adjustable by a set screw, and its resilient uprights set the ball tension. A shift key works a lever and sleeve that slide the ring, and a coiled spring returns it.
