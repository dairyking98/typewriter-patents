## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Key actions for specified purposes

**How it works (reading):** The vertical bar acts as a single return spring placed at a set distance from the key lever attack point, so that when the downshift key is pressed the spring pulls the pawl toward the rack and on return holds it, removing the second spring.

## Reading (short summary from the opening, OCR fair)

**Problem:** The downshift needs a second spring to hold the reset pawl against the rack, and the return spring must be very strong, so fitting the springs is difficult.

**Solution:** The vertical bar acts as a single return spring placed at a set distance from the key lever attack point, so that when the downshift key is pressed the spring pulls the pawl toward the rack and on return holds it, removing the second spring.
