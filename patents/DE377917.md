## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Carriage return or release devices therefor

**How it works (reading):** The universal rail (switch bracket) with its drive parts is fixed to the carriage guide beam, which can be lifted as one unit with the carriage, spring housing and return gear, so the parts can be assembled and adjusted outside the machine.

## Reading (short summary from the opening, OCR fair)

**Problem:** Repairs on a type lever machine are hard because the carriage-side parts are fixed to the frame, and splitting the machine in two needs a transfer device.

**Solution:** The universal rail (switch bracket) with its drive parts is fixed to the carriage guide beam, which can be lifted as one unit with the carriage, spring housing and return gear, so the parts can be assembled and adjusted outside the machine.
