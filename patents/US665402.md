## Reading (opening only, OCR good)

**Problem:** Fractions crowd into one digit space in printing-telegraph stock quotations, are hard to read, and wear faster.

**Solution:** Put extra digit type at right angles on the type wheel so they print sideways in a full-size slot and stand for eighths.

**How it works:** A type wheel has one peripheral row. Alphabet and digit type sit with their feet parallel to the shaft. A second group of digits 1-7 is turned so the feet run around the periphery, printing on their sides yet taking the same line space. Each sideways digit stands for an eighth, and the denominator is dropped.

**Parts:** type wheel; shaft; upright type group; sideways digit type

**Numbers:** digits 1-7 sideways for eighths; one-eighth steps

**Improves on:**

- telegraph printing of small fractions: full-size sideways digits replace crowded fractions
