## Summary

**Kind:** typebar machine · **Subject (patent classes):** Preventing rebound or clash of levers or type members

**How it works (reading):** A separate, stronger rail runs under all key levers and is moved by the release button, pulling the knocked-together type levers apart without touching the universal rail.

## Reading (short summary from the opening, OCR fair)

**Problem:** Releasing type levers that jam together by using the universal rail bends that rail, which is too weak for the task and disturbs carriage and ribbon movement.

**Solution:** A separate, stronger rail runs under all key levers and is moved by the release button, pulling the knocked-together type levers apart without touching the universal rail.
