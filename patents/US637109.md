## Reading (opening only, OCR fair)

**Problem:** The Arabic alphabet has about 638 shapes and connecting letters of varying width, which is impractical for type-writers and presses.

**Solution:** Redesigned Arabic letters, shaped so they can be assembled from fewer type faces and joined in a word.

**How it works:** Letters are redrawn so each fits the typewriter or printing type. The figures show them on a type-wheel, a type-bar and a type-plate or segment. Each letter has four positional forms (initial, medial, final, isolated), some letters never join onward.

**Features:** [USE:special-script](../features/use-special-script.md), [ELEM:wheel-rim](../features/elem-wheel-rim.md), [ELEM:typebar](../features/elem-typebar.md), [ELEM:sector-segment](../features/elem-sector-segment.md)

**Parts:** type face; type wheel; type bar; type plate

**Numbers:** about 638 characters in current Arabic alphabet; 4 forms per letter
