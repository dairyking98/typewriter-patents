## Reading (opening only, OCR fair)

**Problem:** In reversed carriage feed, a rigid front dog can strike the side of a rack tooth when keys are struck rapidly, stopping the carriage short so the next letter prints over the previous.

**Solution:** Reversed feed construction where the dogs cannot jam against a tooth side on return.

**How it works:** Reversed feed frees the carriage so it moves while the type strikes. A normal front dog holds the rack; when a key is struck the dogs shift, the front dog leaves the rack and the rear spacing dog enters. On release the front dog returns into a notch. The invention changes the dog arrangement so the detaining dog cannot be arrested by a tooth side. Description truncated.

**Features:**

**Parts:** front detaining dog; spacing dog; feed rack; key lever; universal bar

**Improves on:**

- Webb reversed feed Serial 375,787 (1890): prevents dog jamming on rapid striking
