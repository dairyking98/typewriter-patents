## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Fount-change arrangements

**How it works (reading):** The intermediate-lever bearing is made vertically adjustable so it can be set to the segment after the segment is adjusted.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adjusting the type-lever segment height moves the intermediate-lever attachment point, so keys stop short against their rest.

**Solution:** The intermediate-lever bearing is made vertically adjustable so it can be set to the segment after the segment is adjusted.
