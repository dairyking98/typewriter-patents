## Reading (opening only, OCR fair)

**Problem:** On typebar machines with several type groups per bar, selecting the group and striking by finger alone makes the keystroke heavy, and a power drive struggles with the different travel for each group.

**Solution:** Couple both the bar-driving members and the group selector to a power drive, with the group set by spring force and the return by the power drive storing that spring force.

**How it works:** A continuously running drive shaft carries a one-turn clutch per four keys (11 clutches for 44 keys), each with a loose lifting disc and a fixed ratchet wheel. A key moves an angle lever that frees a catch pawl so it engages the ratchet and the disc turns once, even if the key is held down. The disc drives the type bar to the platen. Selection of the type group is set by spring force on the selector, and on return the power drive re-tensions that spring.

**Features:** [Typebars](../features/elem-typebar.md), [Electric drive](../features/imp-electric.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Three or more cases](../features/shift-triple.md)

**Parts:** drive shaft; lifting disc; ratchet wheel; catch pawl; angle lever; key lever; type group selector; spring

**Numbers:** 44 keys; 11 clutches; 4 keys per clutch
