## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Paper-carriage guides or races

**In Google’s translation of the patent’s own words:** The invention relates on a storage of the paper trolley of typewriters on the rear Carriages in which the bearings in a known manner each consist of a lower sliding guide and an upper roller guide.

**How it works (reading):** Each rear roller is eccentrically mounted so it can be set vertically, and a screw adjusts it horizontally, giving two-way adjustment against the sliding guide.

## Reading (short summary from the opening, OCR fair)

**Problem:** Paper carriage rollers can only be adjusted along their horizontal axis, so accurate guidance on the sliding guide is not possible.

**Solution:** Each rear roller is eccentrically mounted so it can be set vertically, and a screw adjusts it horizontally, giving two-way adjustment against the sliding guide.
