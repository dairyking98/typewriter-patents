## Summary

**Category:** related office machine, not a typewriter (cash register print hammer)

**How it works (reading):** A slip-insertion stop is linked to the three-position setting lever (check, off, slip) so that in check mode an inserted slip is moved out of the hammer path after its first print, while in slip mode it stays in the path and prints twice; check and inserted note can print in the same aisle.

## Reading (short summary from the opening, OCR fair)

**Problem:** In the main patent a check or slip is printed by one hammer, but a slip inserted for check printing is not printed correctly, and the hood that closed the slip insertion opening is absent in this variant.

**Solution:** A slip-insertion stop is linked to the three-position setting lever (check, off, slip) so that in check mode an inserted slip is moved out of the hammer path after its first print, while in slip mode it stays in the path and prints twice; check and inserted note can print in the same aisle.

**How it works:** The setting lever, held by a notch and pawl, drives a cam slot and arms that move the slip conveyor into or out of the hammer path.

**Features:**

- **Impression:** [Separate print key or lever](../features/imp-print-lever.md)
- **Paper and carriage:** [Paper table and guides](../features/pap-paper-guide.md)

**Parts:** print hammer; setting lever; slip conveyor; pawl; notch; insertion opening

**Numbers:** three setting positions
