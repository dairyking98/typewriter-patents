## Reading (short summary from the opening, OCR poor)

**Problem:** Ordinary typewriters need one key stroke per letter, so printing words is slow; the inventor wants to simplify and speed up typewriting.

**Solution:** Combined keyboard sectors, each carrying type on its face or edge with an angular key sector, let several letters or a whole word be set in position and then printed together.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
- **Type element:** [Type sector or segment](../features/elem-sector-segment.md)
- **Impression:** [Separate print key or lever](../features/imp-print-lever.md)
