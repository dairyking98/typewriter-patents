## Reading (opening only, OCR good)

**Problem:** Carriage of the Calligraph vibrated at speed and had too much friction with two guide rods; it needs release for free sliding.

**Solution:** Hang the carriage on a hinge rod set behind the single guide rod so that gravity re-engages the rack with the spacing pawl, while pulling it forward releases the rack.

**How it works:** A yoke slides steadily on the rear guide rod B and has lugs holding the carriage back rod D which forms the hinge. The carriage frame extends so rod D is behind the vertical plane of B, so gravity rotates the yoke until the racks engage the spacing pawl on the spacing lever. Pulling the front handle toward the operator rocks the carriage so the racks clear the pawl and it slides freely left or right, even overprinting a line; letting go returns it by gravity. The return stops against screws on the yoke or the paper table so the pawl is not worn.
