## Reading (short summary from the opening, OCR fair)

**Problem:** The highest counter position cannot be used to enter a value because it is locked to the next digit.

**Solution:** The drive member of the highest counter position is limited by angular rotation limiting parts, so the highest point can be driven without changes to the counter.

**How it works:** Angular rotation limiting parts on the highest counter drive member allow it to be driven.

## Description (Google Patents OCR, opening)

> Description Translated from German Counter for typewriters The invention relates to a counter for typewriters according to patent 72i 6o7. The device described in the main patent has the disadvantage that the highest point of the counter cannot be used because it is written out of a value from a digit that had to be locked to the next higher digit thereby, through the intermediary of the tens transmission wheel, the digit role of the point, from which it was written out to stop in the zero position. In order to overcome this disadvantage, are in the main patent Versions have been proposed in which the highest point is also to be drawn and consequently could also be used to bring in a value. These However, versions again had the disadvantage that the counters were significantly modified had to be, which was cumbersome and expensive. All these disadvantages are now eliminated according to the invention in that that a drive member of the highest counter position with the angular rotation of the drive member limiting parts is provided.
