**How it works (reading):** Movable bridges arranged under the keys replace the key levers: longitudinal and transverse bridges cross under each key, and a key drives only the bridges at its intersection and returns to rest, so the same keys can count, set or print.

## Reading (short summary from the opening, OCR fair)

**Problem:** Key machines need one key lever per key, and the key levers take up space and parts.

**Solution:** Movable bridges arranged under the keys replace the key levers: longitudinal and transverse bridges cross under each key, and a key drives only the bridges at its intersection and returns to rest, so the same keys can count, set or print.
