## Reading (opening only, OCR good)

**Problem:** Typebars hinged on a circle diverge too slowly near the print point, so adjacent bars can clash.

**Solution:** Hinge each typebar on an axis with progressively greater inclination to the circle's plane so the bars swing in oblique planes.

**How it works:** A circular segment holds 26 cylindrical supports in perforations inclined progressively up to about sixty degrees. Each support has two parallel disks between which a disk carrying the typearm pivots. A short arm on the disk is pushed by a rod to drop the arm to the common print point, where a notch guides it; supports can rotate to let arms yield sideways. Flat springs retain the supports.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [ELEM:alignment-lock](../features/elem-alignment-lock.md)

**Parts:** circular segment; type-arm support; parallel disks; pivot disk; type arm; actuating rod; flat spring; guide notch

**Numbers:** 26 type-arms; 13 per side; about 60 degrees maximum inclination
