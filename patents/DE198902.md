## Reading (full text, OCR fair)

**Problem:** Earlier cylinder typewriters that select the character by rotating the type cylinder and then swinging it against the platen used complicated gear to produce both the rotary setting and the striking swing.

**Solution:** A single striking frame carrying the cylinder is driven by a toothed segment that is held by a latch until the key lever has first finished setting the cylinder rotation, then released so the same key stroke swings the cylinder to the print point.

**How it works:** The type cylinder sits on an axis that also carries a cylinder with helical guide grooves; a pin on a slider engages the groove, and raising or lowering the slider turns the type cylinder. The slider is moved by a swinging frame D, whose travel is set by how far a depressed key lever pushes it: each key lever has two lugs of different length acting on cross webs of the frame D. Frame D is linked to a second swinging frame E with a toothed segment meshing with a gear on the pivot of the striking frame C that carries the cylinder. A spring-loaded pawl G holds frame E still while the cylinder is being set. Once the key lever has moved far enough for the setting, it pushes down a rail G2 with a wedge-shaped thumb that withdraws the pawl, so further key travel rotates the segment, swings the striking frame and hits the selected type at the print point. A toothed disc on the cylinder axis meets a knife-like stop to secure the exact print position.

**Improves on:**

- earlier cylinder typewriters with separate rotary setting and swing mechanisms: one key stroke does both in sequence through a latched striking frame, simplifying the linkage
