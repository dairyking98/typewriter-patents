## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Side-stop mechanisms

**How it works (reading):** A movable line-end marker carrying a set number of type characters is clamped to the paper holder so its position shows where the line should end; two such markers can be set against each other, or printing rollers with grooves can serve the same purpose.

## Reading (short summary from the opening, OCR poor)

**Problem:** Operators miss the bell that signals the line end, so they type past the wanted line length; a visible limit is easier to notice than an audible one.

**Solution:** A movable line-end marker carrying a set number of type characters is clamped to the paper holder so its position shows where the line should end; two such markers can be set against each other, or printing rollers with grooves can serve the same purpose.

**Features:** [PAP:line-indicator](../features/pap-line-indicator.md), [ESC:margin-stop](../features/esc-margin-stop.md)
