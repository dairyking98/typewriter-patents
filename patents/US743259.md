## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** The object of this invention is to provide an improved form of shifting means in which a shiftable device may be set in a plurality of positions, and which when set'in anyone of a certain number of positions can be shifted to any of the other positions by certain actuating means, and which shifting means will automatically return to the said set position when the actuating means is released.

**How it works (reading):** Several shift-key levers rock a shaft that raises a semiring to tilt each typebar's pivoted head to one of three characters, with a yielding adjustable member that indexes and locks the position.

## Reading (opening only, OCR fair)

**Problem:** A shiftable type carrier with several characters needs a way to be set in any of several positions, shifted to others, and returned automatically, with an indicator of the set position.

**Solution:** Several shift-key levers rock a shaft that raises a semiring to tilt each typebar's pivoted head to one of three characters, with a yielding adjustable member that indexes and locks the position.

**How it works:** Three shift-key levers on a common axis, each with a return spring, rock a shaft whose crank lifts a semiring on guides. The semiring lies in the path of the tail piece of each typebar's pivoted head, so the distance it is raised sets which of three characters faces the platen. The lowest position is normal. A yieldable adjustable member points to the shift lever that would give the current position and can be locked at each position. Modifications use cam links and slotted adjust levers.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Selection locked for printing](../features/sel-selector-locking.md)
- **Type element:** [Typebars](../features/elem-typebar.md)
- **Shift and cases:** [Three or more cases](../features/shift-triple.md), [Shift by turning the element](../features/shift-rotary.md)

**Parts:** shift-key lever; retractile spring; rock-shaft; crank; semiring; typebar; pivoted type head; tail piece; yieldable adjustable member; locking means; cam link

**Numbers:** three characters per type head
