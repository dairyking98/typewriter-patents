## Description (Google Patents OCR, opening)

> Description Translated from German Typewriter for sheet music and related characters subject The invention relates to a typewriter for notes and associated with them. sign with rotary adjustment of the platen with the help of a reaching under the typewriter Pendulum frame on which a lever system operated by a foot lever acts, wherein the rotation of the platen for each music paper by an adjustable stop bar for the lever can be adjusted. There are already known typewriters in which the rotary setting the platen is done by means of one or more swing arms, which with the help a lever system operated by a button. The one to set the platen serving buttons are operated with one hand, so that for writing only the other hand is free. In contrast, the platen according to the invention has a frame, which reaches down under the typewriter, on which frame a lever system acts, which is operated by the foot lever. This allows the levers with larger Rashes are carried out, which guarantee a more precise adjustment of the platen.
