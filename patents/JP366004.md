## Reading (full text, OCR good)

**Problem:** A moving body (machine-tool rotary table) that must move a fixed distance and stop overshoots, bounces or drifts when simply run against a stop.

**Solution:** Carry the body past the set position at high speed, then creep it backward onto a spring-loaded stop in a sawtooth step, holding it there with continuing electrical back-torque.

**How it works:** Two motors with different pinions drive a differential gear whose moving gear turns the table shaft. With both motors forward the table turns fast (speeds add, 100+85). At the set position a spring stop drops into a sawtooth step on the table rim; the faster motor is then reversed so the table creeps backward at the difference speed (85-100 = -15) until the step catches on the stop. The motors keep running so the back force holds the step pressed to the stop until the next forward move. For straight travel the stop is withdrawn to return.

**Parts:** motor; pinion; differential gear; table; sawtooth step ring; spring stop; limit switch; control gear

**Numbers:** speed ratio 100:85; 90 degree stops; four steps

## Description (English translation of the Japanese text, opening)

> Title. Device for stopping a moving body at a set position. Brief description of the drawings. The drawings show the device applied to stopping a rotating body at set positions. Fig. 1 is the layout of the device; Fig. 2 is a plan of the main part of the rotating body. Nature, action and effect of the utility model. This device concerns a body that moves through a fixed distance at a time and then stops. When stopping, the body is first carried past the set position and then brought slowly and gently back, so that it comes to rest against a stop at the set position; it stops there surely and without shock. While it is stopped, a backward force is applied electrically and continuously, keeping it pressed against the stop and so holding the position. It is for any machine tool or production machine that must move a fixed distance and stop, such as the rotary table of a jig borer (中グリ盤) or turret lathe, or the straight-moving table of a press. It is described here as applied to the rotary table of a machine tool.
