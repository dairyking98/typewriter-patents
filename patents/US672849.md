## Reading (opening only, OCR fair)

**Problem:** Typebars need to shift for upper and lower case, with temporary shifts to the other case.

**Solution:** A division of Granville's earlier machine, shifting the typebars to set either upper or lower case, with temporary opposite-case shift.

**How it works:** The typebars can be set and held in upper or lower case position; from either position the parts can be temporarily shifted into the other for a few letters.

**Features:** [SHIFT:lock](../features/shift-lock.md), [ELEM:typebar](../features/elem-typebar.md), [ELEM:individual-slugs](../features/elem-individual-slugs.md)

**Parts:** typebar; shift mechanism

**Improves on:**

- [US570433](../patents/US570433.md): typebars shift and can be set for either case
