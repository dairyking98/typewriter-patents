## Reading (full text, OCR fair)

**Problem:** A type-wheel typewriter with a pointer over a character field and an adding machine need a way to couple so the digits set on the adder are typed, yet the typewriter can still be used alone.

**Solution:** A detachable pliers-and-flap coupling links the adder's adjusting slide to the typewriter's setting pointer so the pointer follows the digit rack pulled on the adder.

**How it works:** Digits are pulled on the adder's racks, one decimal place at a time. Driver pawls behind a nose on each rack take the adjusting slide along against a spring. The slide, joined by pliers on a fold-down arm to the typewriter's setting pointer, moves the pointer to the same digit on the number row of the writing field, and the print key then prints it. A key lever lifts the pawls, so the spring returns the slide and pointer to zero. Folding the arm down uncouples the pliers and frees the pointer for normal writing.
