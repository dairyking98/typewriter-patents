## Description (Google Patents OCR, opening)

> Description Translated from German Typewriter. Typewriters are known with writing rollers of such a length that two writing sheets can be used next to one another, in which one or the other writing sheet can be written on alternately. Uni to create this possibility also for machines in which paper webs consisting of connected forms or other writing sheets are written on and the platen is set up in such a way that it can be swiveled up from its working position in order to loosen the writing sheets and the carbon paper sheets in between, so that the latter can be withdrawn after writing on a part of the sheets, as far as they are to be separated from the paper webs, according to the present invention the platen is divided so that the individual parts can be used independently of each other, so that one or the other alternately Set of sheets of paper can be written on and the part written can be separated without affecting the other set of sheets.
