## Reading (short summary from the opening, OCR fair)

**Problem:** Stereotype plates had to be made by hand setting type, which is slow and labour-intensive.

**Solution:** A matrix machine with a matrix bed that moves through sequenced selections of type and character dies, which are impressed into a suitable medium to form the matrices for plates.

**Features:**

- **Type element:** [Flat type plate](../features/elem-plate-flat.md), [Separate type slugs or plungers](../features/elem-individual-slugs.md)
- **Impression:** [Hand presses the type through](../features/imp-press-through.md)
