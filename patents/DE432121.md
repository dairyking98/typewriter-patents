## Summary

**Kind:** typebar machine · **Subject (patent classes):** Character-by-character adjustment

**In Google’s translation of the patent’s own words:** The invention relates to an improvement of the arrangement described in the main patent.

**How it works (reading):** Each type lever gets its own adjusting member with a resilient disc and eccentric on an axle, so each one can be set on its own; the arms and axles form a rigid whole.

## Reading (short summary from the opening, OCR poor)

**Problem:** In the main patent 432120 the individual stroke-force adjusters are tied to central rods, so checking one setting means pushing the rods back into the frame.

**Solution:** Each type lever gets its own adjusting member with a resilient disc and eccentric on an axle, so each one can be set on its own; the arms and axles form a rigid whole.
