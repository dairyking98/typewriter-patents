## Reading (opening only, OCR fair)

**Problem:** Typewriters need one key per character; an operator should be able to work a large set of levers with a few keys.

**Solution:** Chord a few keys: each key shifts a slide, and a tumbler-rod for a given lever can only drop when notches in all slides line up beneath it.

**How it works:** A small set of operating keys (about six) each moves its own transverse slide endwise to the right. Each slide has notches; a tumbler-rod rests on all slides and can fall only where every slide has a notch beneath it. Notch layout is arranged so that each combination of depressed keys aligns the notches under exactly one tumbler, which then moves its lever (a typewriter key lever). Adjusting screws set the rock frame and slide position; a modification of slides and rods is shown. Only the opening is available.

**Features:** [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [SEL:dummy-keyboard](../features/sel-dummy-keyboard.md)

**Parts:** operating key; slide; notch; tumbler-rod; lever operated; rock frame; base

**Numbers:** six operating keys
