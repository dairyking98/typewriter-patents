## Reading (short summary from the opening, OCR fair)

**Problem:** The operator had to lift a hand from the keyboard to return the carriage and turn the paper roller at each line end, interrupting writing.

**Solution:** The carriage automatically returns to a set starting point and the paper roller advances a set amount at line end, with the operator still able to move either one manually.
