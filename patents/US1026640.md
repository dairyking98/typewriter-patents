## Reading (short summary from the opening, OCR fair)

**Problem:** The tabulator must be operated with the fingers off the keyboard, which slows tabulated work.

**Solution:** An auxiliary tabulator key is added to the machine so it can be struck with the palm or flat of the hand, as a simple attachment.
