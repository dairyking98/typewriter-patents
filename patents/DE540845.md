## Reading (full text, OCR fair)

**Problem:** Printing a justified-looking letterpress-style text needs the print base to advance by the width of each letter; earlier mechanisms for width-dependent advance were too intricate to be practical.

**Solution:** A motor-driven type wheel is braked on the selected letter and a toothed wheel with tooth gaps of depth proportional to type width lets a spring-driven pin both centre the type and set the proportional advance of a stretchable printing band.

**How it works:** A constantly driven shaft carries the type wheel, a brake disc, and a contact arm that sweeps a contact ring wired to letter buttons. Pressing a button closes a circuit when the arm reaches that letter's contact; an electromagnet releases a spring brake that stops the wheel on the letter. The same magnet releases a pawl so a shaft shifts axially and frees a spring-loaded pawl, which drives a pin into the tooth gap of a toothed wheel on the type wheel; this centres the type exactly at a pressure roller that presses the stretchable band against the type. The pin's travel, set by the gap depth, fixes the swing of the pawl, and on the return stroke the pawl advances the ratchet and the band by an amount proportional to the letter width. The brake is then released again.
