## Reading (opening only, OCR fair)

**Problem:** Each finger key should be independent with the same leverage and stroke.

**Solution:** Type-bars end in type sleeves rotated by shift keys so each bar carries multiple characters.

**How it works:** Independent finger keys act on typebars, whose ends carry rotatable type sleeves turned by two shift keys through a curved rack. A locking bar moved by a toggle holds the sleeves, and a letter-space mechanism advances the carriage.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SHIFT:rotary](../features/shift-rotary.md), [SHIFT:triple](../features/shift-triple.md), [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [SEL:selector-locking](../features/sel-selector-locking.md)

**Parts:** finger key; type-bar; type sleeve; curved rack; locking bar; toggle; bed plate; top plate; carriage

**Improves on:**

- [US585838](../patents/US585838.md): each key independent with equal leverage
