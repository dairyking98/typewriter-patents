## Summary

**Kind:** a part or mechanism (any kind of machine)

**In Google’s translation of the patent’s own words:** The object of the invention is an improvement the adjustability and structural design of the switching device of such typewriters, where both ratchets are on a common axis.

**How it works (reading):** The loose pawl is a stamped U-shaped part pivoting and sliding on a common axis with the fixed pawl, its limit positions set by independent stops, and a torsion and compression spring tension set by an adjusting ring.

## Reading (short summary from the opening, OCR fair)

**Problem:** The loose pawl of the carriage switching device has a massive hub and only slides axially, so the rack must first be lifted by a special lever before the carriage can be lifted.

**Solution:** The loose pawl is a stamped U-shaped part pivoting and sliding on a common axis with the fixed pawl, its limit positions set by independent stops, and a torsion and compression spring tension set by an adjusting ring.
