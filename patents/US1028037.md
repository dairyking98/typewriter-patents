## Reading (short summary from the opening, OCR poor)

**Problem:** Producing a wide range of characters from a fixed set of type-producing elements needs a mechanism that selects combinations of elements rather than one element per character.

**Solution:** Key levers select selecting bars, and selected character-forming elements are associated in composite groups, one combination of elements forming each character, pressed against an inked ribbon onto paper.
