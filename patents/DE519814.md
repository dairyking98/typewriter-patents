## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In Google’s translation of the patent’s own words:** The invention relates to a tabulator for typewriters with a set key and an individual delete key for the column stops rotatably mounted on a rod.

**How it works (reading):** The individual delete key lever connects directly to a push rod with an angled slot and nose, which turns the erroneously set column stop back to its out-of-use position.

## Reading (short summary from the opening, OCR fair)

**Problem:** The single-tab delete device on known tabulators is complicated, with a multi-part rod linking the delete key to the stop.

**Solution:** The individual delete key lever connects directly to a push rod with an angled slot and nose, which turns the erroneously set column stop back to its out-of-use position.
