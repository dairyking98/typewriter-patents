## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection; Cylindrical Japanese-language typewriter

**In the English translation of the patent’s own words:** Its object is that, simply by moving over the character index plate, forward, back, left and right, the same control lever that rocks the paper cylinder to print, the type wanted is brought at once to the printing position, so that typewriters of this kind print much faster.

**How it works (reading):** One control lever, moved over a character index plate, both selects the type (left/right turns the type cylinder by cords, forward/back moves the paper cylinder along the cylinder) and, pressed down, rocks the paper cylinder onto the type to print.

## Reading (full text, OCR good)

**Problem:** In Sakai's earlier typewriter (JP26053) the type cylinder was turned and slid by means separate from the print lever, so the operator needed both hands or had to change hands, and selecting a type took much handling and time.

**Solution:** One control lever, moved over a character index plate, both selects the type (left/right turns the type cylinder by cords, forward/back moves the paper cylinder along the cylinder) and, pressed down, rocks the paper cylinder onto the type to print.

**How it works:** A multi-row type cylinder lies front-to-back in a flat box frame; a paper cylinder sits above it at right angles, mounted on carriage plates that slide front and back and on rockers that tilt it down. The pressing lever slides on a guide rod; sliding it sideways moves a floating bar, which by cords over four corner pulleys turns the type cylinder to set the row. Moving the lever forward or back moves the carriage plates and the paper cylinder along the type cylinder to set the column. The pointer bar's index hole reads the index plate, whose character order matches the types. Pressing the lever lifts a rod that, through balance levers, links and swing pieces, rocks the paper cylinder onto the type; a spring returns it, bringing the fresh print to the front where it can be seen. Separate fittings, not shown, turn the paper cylinder one character space per print and shift it one line.

## Description (English translation of the Japanese text, opening)

> Specification. Typewriter. Nature and object of the invention. This invention is an improvement of the typewriter in which a paper cylinder is set above a freely turning type cylinder (印版筒, "printing-plate cylinder") and at right angles to it, the paper cylinder being free to turn, slide and rock, and is made to print by being rocked against the type cylinder when the control lever is pressed down. In it, sliding the control lever in the direction at right angles to the type cylinder (that is, left and right) turns the type cylinder to the left or right, which sets the row (行) of type to be printed; and the control lever and the paper cylinder are linked so that they move together forward and back but independently left and right, so that moving the control lever forward and back moves the paper cylinder forward and back and sets the column (列) of type to be printed. Its object is that, simply by moving over the character index plate, forward, back, left and right, the same control lever that rocks the paper cylinder to print, the type wanted is brought at once to the printing position, so that typewriters of this kind print much faster.
