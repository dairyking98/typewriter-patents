> Description Translated from German IMPERIAL PATENT OFFICE. PATENT LETTERING Vr 288929 CLASS \ 5g. GROUP Patented in the German Empire on February 17, 1914. The present invention relates to a fastening of the type block on the type lever Typewriters, calculating machines, etc. According to the invention, the connection is made of the type lever shaft with the type block by injection molding. The type lever and the Type blocks to be connected to it are precisely defined in an injection mold mutual position used, in such a way that there is air between the shaft and type block is; So it is not, as with soldered-on type levers, the type block on the Type barrel fixed with friction. The air that the type lever shaft in the cutout of the 1 S type block is required to compensate for any inequalities in the position of the slot in the type block or in the bend of the lever shaft. Next are according to the invention on the part of the type lever shaft on which the type block is attached, recesses running in the longitudinal direction of the shaft plate are provided, which leave only narrow webs between them and towards the middle of the shaft to become a little narrower in width.
