## Reading (opening only, OCR good)

**Problem:** Typing speed is limited by one key per letter.

**Solution:** A keyboard of twelve key blocks whose keys each carry two syllables or words built from a vowel and consonant pairing.

**How it works:** The keyboard has twelve rows by sixteen keys in an inclined bank, arranged in blocks. Each block pairs the five vowels with four consonants in alphabetical order, so a key carries syllables such as ab and bat. Other blocks hold numerals, fractions, signs and symbols. Diagonal blocks are coloured black for ready distinction.

**Features:**

- **Selection:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** key; key block; keyboard

**Numbers:** 12 rows; 16 keys per row; 20 keys in block 1; 12 blocks

**Improves on:**

- Smith-Premier keyboard: similar inclined key banks, but with syllable keys
