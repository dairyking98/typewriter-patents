## Description (Google Patents OCR, opening)

> Description Translated from German Type lever drive for writing, calculating and similar machines The subject of the invention is a type love drive for writing, writing arithmetic and similar machines, in which the pressing into a ready position Type brought in front of the platen to the roller through a kinematic one Chain between key and type lever switched on energy source takes place in order to achieve a type imprint that is as quiet as possible. With the usual ones Machines of this type were usually toggle levers between the type lever head and the frame turned on with swing weights, which latter stretched the knee lever and with it caused the imprint. The side type levers were always replaced by the knee lever pressed obliquely against the roller, so that the imprint of the different types does not always took place in the same goodness. It has also already been suggested that a Arrange catch lever with swing weight, whose flywheel completes the impression. However, this does not result in a low-noise impression, since both the Impact of the type lever on the catch lever as well as when the type is imprinted on the Roller every noise is produced.
