**In Google’s translation of the patent’s own words:** The invention relates on a new type guide for type bar typewriters of the type in which the type sliding on the guide plate with shortly before the stop a spur arranged at the base of the type grips under a bridge ledge.

**How it works (reading):** A second spur at mid-height of the type, just below the lowest character, engages a slotted guide with lateral guide surfaces, so the type is guided without shading the print point.

## Reading (opening only, OCR fair)

**Problem:** On typebar machines where the type foot slides on a guide plate and a spur catches under a bridge, holding only the foot is not enough for a clear impression, especially with play in the guide comb. A second guide at the head would shadow the print point and spoil visibility.

**Solution:** A second spur at mid-height of the type, just below the lowest character, engages a slotted guide with lateral guide surfaces, so the type is guided without shading the print point.

**How it works:** The type is riveted to a typebar guided in a radial comb and driven toward the platen by a key lever; it slides on a base plate. An angled guide piece at the print point has a bridge web over an opening and a slot with sloping lateral guide surfaces. The spur on the type foot enters the closed opening, guiding the type in all directions, while the middle spur enters the slot for lateral guidance. If the type arrives off course it touches a sloping surface and is slid into the opening or slot as it advances.
