## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Actions or mechanisms not otherwise provided for for aligning characters for impression

**How it works (reading):** Key levers and segmental type bars pivot on a wire, with a type guide whose rounded portions run concentric with the pivot so the bars are held in their vertical travel and swing to the print point.

## Reading (short summary from the opening, OCR poor)

**Problem:** The type bars must be guided so they swing accurately to the printing point, and the guide must not let them stray.

**Solution:** Key levers and segmental type bars pivot on a wire, with a type guide whose rounded portions run concentric with the pivot so the bars are held in their vertical travel and swing to the print point.
