## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a type lever drive for typewriters.

**How it works (reading):** The rear end of the type lever and a connecting plate are shaped to hook together and lie in the same plane within the unchanged segment slot, so the key action is soft and each type lever can be taken out individually for service.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type-lever drives using a longitudinal slot make the key stroke hard, and earlier soft drives with a connecting wire or plate prevented removing type levers individually from the segment.

**Solution:** The rear end of the type lever and a connecting plate are shaped to hook together and lie in the same plane within the unchanged segment slot, so the key action is soft and each type lever can be taken out individually for service.
