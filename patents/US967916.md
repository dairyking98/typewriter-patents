## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition; Constructional details or processes of manufacture of the input device

**In the patent’s own words:** This invention relates to the keyboard construction of typewriting machines and this application is a division of our application filed March 30, 1905, Serial Number 252,818.

**How it works (reading):** A stepped keyboard plate carries the key levers, which connect to type bars through operating links, so the key arrangement can be used with other type-bar actuating devices.

## Reading (short summary from the opening, OCR fair)

**Problem:** The keyboard construction of the typewriter needed improvement; this divisional application claims the keyboard arrangement separately.

**Solution:** A stepped keyboard plate carries the key levers, which connect to type bars through operating links, so the key arrangement can be used with other type-bar actuating devices.
