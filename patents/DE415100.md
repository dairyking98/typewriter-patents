## Description (Google Patents OCR, opening)

> Description Translated from German Pedal lever arrangement for sheet music typewriters. The invention relates on typewriters for sheet music printing, which are arranged vertically above an adjustable type disk for the cross slide serving as workpiece carrier own, which is kept slidable up and down, and the lowest Type to be colored before printing. In the case of the known typewriters for printing notes, the inking of the print type set down in each case is only made while the type disc executes its downward movement. For this reason it must move back and forth of the paint carriage take place intermittently at high speed, which results in has that the machine is exposed to vibrations that continue when the Type of printing sits down on the printing sheet, so that a pure and sharp print cannot be achieved. In the subject matter of the invention, on the other hand, the type disk remains so long in their rest position until the inking of the print type set down has taken place, so that the required movements of the paint slide can perform in peace.
