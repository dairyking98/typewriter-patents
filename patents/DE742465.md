## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Driving mechanisms for functional elements of tabulation devices, e.g. of carriage skip

**In Google’s translation of the patent’s own words:** The invention relates to on a typewriter with a decimal tabulator.

**How it works (reading):** A special key stores each keyed value in a memory device, and the decimal tab key that matches its digit count is then driven automatically to print the stored value.

## Reading (short summary from the opening, OCR fair)

**Problem:** Operators must key the number of digits before a value and then press the matching decimal tab key, which is error-prone.

**Solution:** A special key stores each keyed value in a memory device, and the decimal tab key that matches its digit count is then driven automatically to print the stored value.
