## Reading (opening only, OCR fair)

**Problem:** On shorthand typewriters, holding shift keys costs time (about two or three keystrokes) and makes blind typing hard.

**Solution:** Put consonant signs on the type levers already combined with the following e-group vowel, with a and o vowels on separate types, so no shift is needed.

**How it works:** Each consonant type carries the mark for the vowel group e, so the consonant and following e-vowel print as one sign. The a and o vowels sit on special types and are written as independent characters, giving up to six vowel distinctions instead of three. Ordinary printing types are also placed on the type levers and can be written by a font shift with a locking device. This makes one machine for shorthand and ordinary writing, and a portable machine for long letters with just one or two shifts.

**Features:** [Shift lock](../features/shift-lock.md), [Typebars](../features/elem-typebar.md), [Shorthand machine](../features/use-stenotype.md)

**Parts:** type lever; shift key; locking device; consonant sign type; vowel type

**Numbers:** up to six vowels instead of three; shift costs about 2 to 3 keystrokes

**Improves on:**

- typewriter shorthand with switching between vowel groups: no shift keys held down; shorthand is slightly longer but faster to write
