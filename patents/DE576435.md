## Summary

**Category:** related office machine, not a typewriter (text-writing booking machine)

**How it works (reading):** Several adjustable type sets are used, one of which is set from the selected counter and cooperates with the typewriter carriage to print the value on the document.

## Reading (short summary from the opening, OCR fair)

**Problem:** A calculating machine prints only one set of type, so the same entry cannot also be printed in the typewriter document in the correct columns.

**Solution:** Several adjustable type sets are used, one of which is set from the selected counter and cooperates with the typewriter carriage to print the value on the document.

**Features:**

- **Paper and carriage:** [Paper table and guides](../features/pap-paper-guide.md)
- **Uses:** [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** type sets; amount keys; paper carriage; typewriter keyboard
