**How it works (reading):** The type-lever carrier slides in a guide opposite the machine frame, so the frame and platen stay fixed while the type levers are brought to the printing position.

## Reading (short summary from the opening, OCR poor)

**Problem:** Fold-away typewriters must either raise the whole machine into use or swing it on arms, which is cumbersome and gives no firm position.

**Solution:** The type-lever carrier slides in a guide opposite the machine frame, so the frame and platen stay fixed while the type levers are brought to the printing position.
