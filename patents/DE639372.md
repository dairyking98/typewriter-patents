## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies

**How it works (reading):** Before soldering each type to its lever, the paper-roller stop point is measured in a work frame, a replacement roller body is set to that measured position, and the types are aligned with adjustable marks against it and then soldered.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type pieces must align exactly to their type levers, but the lever frame and paper roller position vary from machine to machine, so fixed alignment jigs cannot guarantee the type position.

**Solution:** Before soldering each type to its lever, the paper-roller stop point is measured in a work frame, a replacement roller body is set to that measured position, and the types are aligned with adjustable marks against it and then soldered.
