> Description Translated from German Line shift wheel clutch. It is known on typewriters. so-called Use piercing rollers, which are used to adjust the platen for adjustment to release the paper for switching from the gear wheel and back with it couple. The known piercing rollers of this type are mostly based on it; that the one Usually the right button of the platen shaft is pushed in axially, which means the decoupling takes place .. If the button is then released, it occurs automatically the clutch on again, These piercing rollers have the great disadvantage that: during When adjusting the platen, always have one hand of the clerk in the clutch the release position must hold. Free handling of the platen by both Sides is therefore not possible because one hand always maintains the trigger got to. The purpose of the invention is to remedy this deficiency, and this happens because the disengagement and engagement of the line index wheel with the platen connecting coupling with the help of an externally rotatable on the platen axis in the longitudinal direction of which the control sleeve is displaceable in both coupling positions is automatically recorded.
