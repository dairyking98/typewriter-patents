## Reading (short summary from the opening, OCR fair)

**Problem:** In a rotating die-head stamping machine the character dial turns with the die head, so the operator confuses and mis-stamps characters.

**Solution:** A fixed character dial sits above the die head, and a pointer rotates with the head to show on the fixed dial which die is in position; the plate is also advanced a set distance each stroke.

**Features:** [SEL:pointer-chart](../features/sel-pointer-chart.md), [ELEM:disc-face](../features/elem-disc-face.md)
