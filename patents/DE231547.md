## Reading (opening only, OCR fair)

**Problem:** Setting the character-wheel sectors of a syllable typewriter and printing them gives uneven key touch across keys.

**Solution:** Each key group turns its type sector through a differential gear arrangement, and a roller then lifts the printing frame, with touch resistance equalised across keys.

**How it works:** Eight keyboards, one per simultaneously printed letter, each turn a character-wheel sector, with nested hub sleeves in a swingable printing frame. Each key's rod turns shaft h through a rail, and, via an inclined shoulder rail, shaft n later or earlier depending on the key position. An angle lever carries a bevel gear forming a differential with two gear sectors; one sector is locked by a pin and the other released by a lifting thumb, so the crown gear stops at the angle set by the key. Near the end of the shaft rotation a roller lifts the printing frame, printing all set types at once. Types sit on semicircular rails fixed by arms to nested tubes with gears.

## Description (Google Patents OCR, opening)

> Description Translated from German IMPERIAL Syllable typewriters are already known with several key groups lying next to one another, as well as character wheel sectors arranged accordingly. All types of a group on a wheel sector correspond to the keys of the associated key group. The character wheel sectors, which are arranged next to one another, are mounted in a swingable pressure frame, with the hub sleeves of the character wheel sectors nested one inside the other. Printing is done by bringing the desired types to the printing point by turning each character wheel sector through the appropriate angle and then printing all types by vibrating the frame. The invention relates to a new device for setting the rotation of the character wheel sectors and for printing the types placed opposite the printing points for zo such syllable typewriters. The device is designed to equalize the touch resistance for all keys as much as possible, so that even writing is achieved. The device designed according to the invention is shown in the drawing.
