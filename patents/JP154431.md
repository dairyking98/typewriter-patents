## Reading (full text, OCR good)

**Problem:** Existing type stores are bulky and the types, gripped one at a time to print, break.

**Solution:** A type store of many resiliently mounted cylindrical disc elements, each holding one radial row of types, is turned as a whole to bring the type to the top and a lifter raises only the chosen element against the paper cylinder.

**How it works:** Each element is a ring-plate disc with a radial row of types held by a ring, and many are mounted on a common shaft through rubber rings so they turn together but can be lifted individually. A search lever, with a sighting hole over a character plate, moves the paper cylinder sideways via a grooved bar and, moved forward and back, turns the store through a rack and pinion. Sideways movement of the lever also brings a lifter under the correct element. The printing key presses a cam that first rotates the paper cylinder against a stop to lock it, then a second cam raises the lifter so the top type prints on the underside of the paper cylinder. On release the lifter drops and the return of a friction-ring and ratchet feeds the paper cylinder one character space.

## Description (English translation of the Japanese text, opening)

> Nature and object of the invention. A typewriter characterised in that one row of types is held radially in each of a number of cylindrical type-store elements (discs); the elements are mounted resiliently on a common shaft to make up the type store; turning the store as a whole brings the wanted type to the printing line; an element lifter is brought under the element containing the wanted character; and working the lifter moves only that element, selectively, to print. The object is to make the type store small and, since the types need not be gripped one by one to print, to prevent them breaking. Brief description of the drawings. Fig. 6: front view of the paper cylinder, partly in section. Detailed description. The type store is made up of many cylindrical elements, and by lifting such an element as a whole the machine prints without having to grip the types one at a time.
