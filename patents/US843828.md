## Reading (opening only, OCR fair)

**Problem:** On front-strike machines with a vibrating ribbon, silent accent keys that skip the universal bar would leave the accent unprinted, since the same bar lifts the ribbon.

**Solution:** Let accent keys operate the universal bar (so the ribbon vibrates) but also set an extra detent that holds the carriage still, so the next letter prints beneath the accent.

**How it works:** Accent-type keys are struck first. They still actuate the universal bar and the ribbon vibrator, but also set a normally idle detent, independent of the spacing dogs, that holds the carriage stationary. The ordinary letter key is struck next and the carriage then feeds as usual. Accent and letter register on the same spot.

**Features:** [INK:ribbon-lift](../features/ink-ribbon-lift.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [ELEM:typebar](../features/elem-typebar.md)

**Parts:** accent-type key; universal bar; ribbon vibrator; carriage detent; spacing dog

**Improves on:**

- under-strike silent accent keys: keeps ribbon vibration while still suppressing carriage feed
