## Summary

**Category:** related office machine, not a typewriter (keyboard for booking machines) · **Subject (patent classes):** Arrangements of keyboards, e.g. key button disposition

**How it works (reading):** The space key is a bow or closed frame running along the sides of the keyboard, so it can be struck from any hand position.

## Reading (short summary from the opening, OCR good)

**Problem:** The space key is at the front of the keyboard, so the hands must reach back for it.

**Solution:** The space key is a bow or closed frame running along the sides of the keyboard, so it can be struck from any hand position.
