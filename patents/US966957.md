## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Sub-levers of varying length, from centre to sides, end in an arc matching the arc of the type bars, linking the key levers to the type bars held in a slotted segment, so the bars swing up and rearward to the printing position.

## Reading (short summary from the opening, OCR poor)

**Problem:** The first 3000 characters state no clear defect; the aim is an efficient type action for a front-strike or shifting-basket machine, and the OCR is badly garbled.

**Solution:** Sub-levers of varying length, from centre to sides, end in an arc matching the arc of the type bars, linking the key levers to the type bars held in a slotted segment, so the bars swing up and rearward to the printing position.
