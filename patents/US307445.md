## Reading (opening only, OCR good)

**Problem:** Not a letter printer: a power-driven machine for making type indentations in papier-mache or similar material (stereotype matrix), which needs each type spaced by its width.

**Solution:** A revolving rod cylinder and a geared type ring turn in unison; key cams push the chosen rod onto the type and hold it for a time set by the character width to draw the strip the right distance.

**How it works:** Sliding rods in a pulley-driven cylinder are geared through bevel gears to a vertical-shaft type ring turning at the same speed, so each rod reaches the print point with one type. A key cam hits the rod's cam pin, slides it out and presses the papier-mache strip onto the type, embedding it. The strip is gripped between rod and type and pulled along while the key's differently long dwell face holds the rod down, giving each type its own width of space. A returning cam withdraws the rod; a pedal lever raises the ring to bring another row of type to the print point. A variant uses fixed cams with faces of type width to give a shorter cylinder and a denser keyboard.
