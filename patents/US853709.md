## Summary

**Category:** related office machine, not a typewriter (typewriting attachment for adding machines) · **Subject (patent classes):** Character or syllable selection controlled by recorded information characterised by the provision of additional devices for producing a punched or like record, e.g. simultaneously

**In the patent’s own words:** My invention relates to a typewriting attachn'ient for adding machines and more particularly to that class of attachment illustrated in the patent to Edwin B.

**How it works (reading):** The adding machine is set on a frame with adjustable set screws so it can be moved toward or away from the typewriter, and its platen works with either the adder or the typewriter depending on position.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typewriting attachment for an adding machine must let the adding machine's platen co-operate with the adder in one position and with the typewriter in another.

**Solution:** The adding machine is set on a frame with adjustable set screws so it can be moved toward or away from the typewriter, and its platen works with either the adder or the typewriter depending on position.
