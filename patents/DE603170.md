## Summary

**Category:** related office machine, not a typewriter (adding machine coupled to multiplier) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**How it works (reading):** The whole tapping device can be uncoupled from the sensing rails by pressing a button, so the rails can be set regardless of the tapping setting.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tapping devices on the multiplier machine block the adding machine's sensing rails, so those rails cannot be set.

**Solution:** The whole tapping device can be uncoupled from the sensing rails by pressing a button, so the rails can be set regardless of the tapping setting.
