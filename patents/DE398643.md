## Reading (short summary from the opening, OCR fair)

**Problem:** Shift keys are tiring and slow because the operator must hold them down while typing capitals.

**Solution:** A thumb-driven slide, latched by a pawl, sets a stop that rotates the type head to the upper case; the latch releases when the type lever falls so the shift returns on its own.

## Description (Google Patents OCR, opening)

> Description Translated from German Switching device for typewriters. The invention relates to on a switching device for typewriters with rotatably arranged on the type lever Type head that is activated by a stop set by the shift key on the Print point is switched. It consists in the fact that a spring-loaded Slide that can be moved by a thumb that can be rotated by hitting the toggle button and when it is moved it sets the stop acting on the type head, in its position by a pawl that engages in notches on the slide, is secured, while when the type lever falls, a spring-loaded steliende segment-shaped bar triggers the pawl so that the slide is in its rest position can return. This makes the shift keys just as easy and can be struck briefly like the write keys, thus creating a coherent Keyboard as with the piano and herewith also a uniformly rhythmic, faster and more correct writing than before. Holding down the Shift key there is no need to print the types, and the fingers are immediately after light, briefly press the shift key free for the remaining keys.
