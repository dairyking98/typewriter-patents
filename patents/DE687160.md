## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriters with many counters are limited because the number key drives the whole counter train.

**Solution:** Two calculating gear sets: the steep counter is driven by number keys and the cross counter is set by keys then driven by a stored energy device.

Moving a large number of counters the required keystroke would be undesirably, especially unevenly, have increased. Such machines have therefore not been able to establish themselves. It has also already been proposed both for driving the steep counters as well as to use electric motors to drive the Ouer counters. With these Machines were simply set the counters by moving the number key, but not driven. The construction of such machines is under these circumstances very involved. The invention has set itself the task of creating a machine; which is simpler in structure than the previous machines and in particular in relation to is not limited to the number of possible cross counters.
