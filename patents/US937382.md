## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** for rendering ink-ribbon inoperative

**In the patent’s own words:** My invention relates more especially to the ribbon mechanism at typewriting machines.

**How it works (reading):** An automatic crosswise ribbon feed working with the lengthwise feed, so a ribbon with several printing fields can be moved to cover the print point with any chosen field, and the crosswise feed can be dropped when not wanted.

## Reading (short summary from the opening, OCR fair)

**Problem:** Visible-writing machines must move the ribbon off the print point between strokes, and a multi-colour ribbon cannot select a chosen field across the print point.

**Solution:** An automatic crosswise ribbon feed working with the lengthwise feed, so a ribbon with several printing fields can be moved to cover the print point with any chosen field, and the crosswise feed can be dropped when not wanted.

**Features:** [INK:ribbon-feed](../features/ink-ribbon-feed.md), [INK:ribbon-color](../features/ink-ribbon-color.md), [FRM:writing-visible](../features/frm-writing-visible.md)
