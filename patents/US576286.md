## Reading (opening only, OCR fair)

**Problem:** Typebar and spacing parts should return to rest in advance of the finger key being released, in a ring-of-typebars machine.

**Solution:** Each key-lever pulls a radial type-bar-operating lever and a second trip pushes the universal bar; both release at a set point so the bar returns while the key is still down.

**How it works:** Key-lever depression pulls a link that tips a radial lever, whose vertical trip lifts the typebar to the platen. A separate trip on the key-lever pushes the universal bar down, rocking the shaft and operating the feed dogs to space the carriage. At a predetermined moment the typebar is freed from its lever and the universal bar is freed from the key-lever, so both return before the key is released.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [IMP:element-to-platen](../features/imp-element-to-platen.md)

**Parts:** key-lever; link; type-bar-operating lever; trip; typebar; universal bar; rock-shaft; spacing dog; spring drum; type-ring
