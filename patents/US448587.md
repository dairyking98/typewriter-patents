## Reading (short summary from the opening, OCR fair)

**Problem:** The feed mechanism of earlier matrix machines moved before the die stroke, requiring a timing sequence; speed and matrix quality are wanted.

**Solution:** An escapement for a matrix machine in which stops variably limit the carriage travel so each character gets its own feed length, with the feed and depressing device electrically controlled.

**How it works:** Die groups with the same space width give the same feed length; the escapement and stops set carriage movement, and the feed is electrically controlled from the character selector.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [IMP:electric](../features/imp-electric.md), [SEL:pointer-hole](../features/sel-pointer-hole.md)
