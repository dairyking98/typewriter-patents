## Reading (opening only, OCR good)

**Problem:** On writing punch-card machines the individually movable type pins sit stacked between cheek plates, so swapping a set of types (for example number types for letters) means they lose their guide and fall apart.

**Solution:** Mount the type pins and their springs in a comb-shaped holder frame that is a unit insert dropped between the cheeks of the forked head of the type carrier rail.

**How it works:** Each type carrier rail has a forked head of two cheek plates. A comb-shaped holder frame has guide holes for the individual type pins, each with its own spring pressing against a stop head on the pin. The stop heads slide in lateral slots and are struck from behind to push a type to the impression position. The filled frame is held in position by lugs and resilient projections and secured by a clamping member and a cap slid over the crimped edge lips. The whole set of types can then be exchanged without removing the rail from the machine.

**Features:** [ELEM:individual-slugs](../features/elem-individual-slugs.md), [ELEM:interchangeable](../features/elem-interchangeable.md), [FRM:cleaning-access](../features/frm-cleaning-access.md), [IMP:hammer-behind](../features/imp-hammer-behind.md)

**Parts:** type carrier rail; forked head; cheek plate; comb-shaped holder frame; type pin; spring; stop head; clamping member; cap

**Numbers:** 9 types per insert

**Improves on:**

- punch-card machines with removable cheek plate: types stay together in a replaceable frame instead of falling apart
