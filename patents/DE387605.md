> Description Translated from German Device for parking the printing unit on calculating machines with setting disks of variable number of teeth. The invention relates to a device for Placing the printing unit on a calculating machine with adjusting disks of variable Number of teeth that can only be obtained by moving the rubber roller that causes the printing to the side can be turned off. At the same time, this will make the result printed on the paper brought sideways in a position that allows easy reading. The invention is in the drawing in a as an an example Serving embodiment shown. One link d is provided with an angled protruding arm g, into whose longitudinal slot g1 a pivot pin lal, seated on a two-armed drive lever h, protrudes.
