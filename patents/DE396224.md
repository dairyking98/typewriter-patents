## Summary

**Category:** related office machine, not a typewriter (punched-card characters for adding machines) · **Subject (patent classes):** Character or syllable selection controlled by recorded information characterised by form of recorded information by punched records, e.g. cards, sheets by strips or tapes

**How it works (reading):** Each punch row carries a value in a binary-like series (1, 2, 4, 8, 16) so each character is a unique sum of hole values, giving the maximum number of distinct characters per row count.

## Reading (short summary from the opening, OCR fair)

**Problem:** Characters on punched tape are assigned arbitrary hole combinations, so codes conflict and waste combinations.

**Solution:** Each punch row carries a value in a binary-like series (1, 2, 4, 8, 16) so each character is a unique sum of hole values, giving the maximum number of distinct characters per row count.

**Features:**

- **Uses:** [Printing telegraph](../features/use-telegraph-printer.md), [Typewriter with adding machine](../features/use-calculating.md)

**Numbers:** five rows give 32 combinations
