## Reading (full text, OCR good)

**Problem:** Ordinary typebars swing through about 90 degrees to the platen, so the type travels a long, curved path (slow, with friction and jar), and shortening it usually needed jointed levers.

**Solution:** Pivot rigid typebars in a segmental arc below the platen, with their type heads facing the printing point, so each type makes only a short, nearly straight stroke; a platen carriage shifts up or down for three-case type.

**How it works:** Plain flat typebars stand upright in front of the platen, pivoted on an arc-shaped rod and guided in converging slots of a comb plate; the type blocks sit on stems at varied angles so each faces the printing point. Key levers pass between the bars and push them forward through pins in notches. Each type block carries three types stacked vertically, and a shift key raises or lowers the platen carriage on cam slots to one of three heights. A universal bar operated by any key or the space key rocks a two-detent escapement that lets the spring-driven carriage rack advance one tooth. The same motion vibrates the ribbon frame and steps the ribbon feed; fixed notched guide plates align the type stems at the print point. The key levers rest on a spring-cushioned U-frame fulcrum.
