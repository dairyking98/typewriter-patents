## Reading (opening only, OCR fair)

**Problem:** Typebar release independent of key travel in a ring typebar machine.

**Solution:** Each key-lever carries a pivoted arm to which the typebar's connecting rod is attached, and a spring-held hook trip catches the arm and lets go at a set point.

**How it works:** Key-levers pivot at the rear on a fulcrum rod. An arm on each key-lever carries the connecting-rod to a typebar; a perpendicular trip beside the key-lever hooks over the arm's front end and is held by a spring. Depressing the key lifts the arm and swings the typebar to the platen while a universal bar spaces the carriage. The trip then slips off so the typebar falls back by gravity (or a return spring) even with the key held.
