## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** The invention consists in the combination, substantially as hereinafter more fully set forth, with the keys, of mechanism operated by the depression of a key to effect the longitudinal movement of the carriage after each impression to form the proper space between successive letters.

**How it works (reading):** Sliding bars each carrying one or more independent loose types move radially on a plate to a common centre when a key is pressed, and a rod beneath strikes the type up through a perforation to print.

## Reading (opening only, OCR fair)

**Problem:** The inventor aims for a typewriter in which a key brings the chosen type to a common centre and at the same time releases the impression force and spacing, with line-end lock and alignment aids.

**Solution:** Sliding bars each carrying one or more independent loose types move radially on a plate to a common centre when a key is pressed, and a rod beneath strikes the type up through a perforation to print.

**How it works:** A series of bars with a perforation under each type slide in guides along lines radiating from a common centre. Each key moves its bar so the corresponding type lies at the centre, and in the same stroke starts the spacing and impression mechanisms. A vertical rod under the plate lifts through the perforation to strike the type against the paper. A spring-wheel and rack drive the carriage with an escapement wheel and two linked pawls that allow spacing only after the impression and return. Further parts include inking, a carriage stop that blocks printing at line end, pawl release for line spacing, a type remover and an indicator of the next print position.

**Features:** [ELEM:individual-slugs](../features/elem-individual-slugs.md), [ELEM:plate-flat](../features/elem-plate-flat.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [IMP:hammer-behind](../features/imp-hammer-behind.md), [IMP:spring-energy](../features/imp-spring-energy.md), [ESC:print-and-space](../features/esc-print-and-space.md), [ESC:escape-wheel](../features/esc-escape-wheel.md), [ESC:spring-drum](../features/esc-spring-drum.md), [ESC:margin-stop](../features/esc-margin-stop.md), [PAP:line-space](../features/pap-line-space.md), [PAP:line-indicator](../features/pap-line-indicator.md), [INK:ribbon](../features/ink-ribbon.md)
