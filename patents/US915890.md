## Reading (full text, OCR fair)

**Problem:** Embossed (raised) code impressions are wanted for automatic telegraph transmitters, and the code signs are wider than normal letters so a standard Hammond shuttle and escapement do not suit.

**Solution:** Modify the Hammond typewriter so a two-row code shuttle is lifted automatically by half the keys and the escapement is switchable between single and double letter spacing, with a convertible anvil so ordinary shuttles still work.

**How it works:** The special shuttle has the alphabet in two rows, each letter with raised dots and dashes as its code sign. A second lifting frame lies beside the trip frame; alternate key levers are long and extend under it. A long key first lifts the anvil post (and with it the shuttle) to put the lower row at the print point, then trips the hammer and escapement; short keys leave the shuttle low and print from the upper row. A rubber cushion in the post and an adjustable stop soften the lift. A pivoted variable stop on the hammer lever tail can be set to strike a fixed stop or clear it, giving single or double letter space, with a cam arm on the escapement lever keeping the pawl engagement identical in both settings. Turning the anvil post half a turn (or pulling pins that hold a key-struck bar) disconnects the extra lift so an ordinary shuttle works with the normal fig and cap keys.
