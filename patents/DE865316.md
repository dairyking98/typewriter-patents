## Summary

**Kind:** typebar machine · **Subject (patent classes):** for rendering ink-ribbon inoperative; Means to give uniformity of impression

**In Google’s translation of the patent’s own words:** The invention relates to an adjusting device for the type lever stop force and the ribbon fork lift on power-driven typewriters.

**How it works (reading):** An adjusting device changes the type impact force together with the ribbon stroke, using a graduated plate between an adjustable cam actuator and the member that controls the clutch duration, so the two settings compensate each other.

## Reading (short summary from the opening, OCR fair)

**Problem:** On power typewriters the ribbon lift is derived from the type lever stroke, so a larger or smaller ribbon stroke changes how hard the type strikes, making print weight uneven.

**Solution:** An adjusting device changes the type impact force together with the ribbon stroke, using a graduated plate between an adjustable cam actuator and the member that controls the clutch duration, so the two settings compensate each other.
