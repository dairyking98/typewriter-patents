## Reading (opening only, OCR good)

**Problem:** The carriage must be run back without operating the paper-feed mechanism, and the movable feed dog needs accurate adjustment.

**Solution:** A side release key lifts the dog-carrying frame or rack bar, and a set-screw with slide adjusts the movable dog throw.

**How it works:** A rock-shaft release key on carriage brackets presses a rod on the frame carrying the rack bar so the rack disengages from the rocker dogs. The rocker has a rigid dog and a movable dog; a collared set screw moves a slide that limits the movable dog throw for fine adjustment.

**Features:** [ESC:carriage-release](../features/esc-carriage-release.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** carriage; rack bar; rocker; fixed dog; movable dog; release key; rod; set screw; slide

**Improves on:**

- Jenne applications 259,768 and 261,408: adds a side release key and dog throw adjustment
