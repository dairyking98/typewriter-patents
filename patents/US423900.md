## Reading (full text, OCR good)

**Problem:** Typewriters needed a ribbon, hid the printing from the operator, and spaced every letter the same regardless of its width.

**Solution:** A visible-writing typebar machine with thin two-part bell-crank typebars each carrying several types selected by a stepped stop, a screw-and-rack carriage whose step per key is set by adjustable screws, and an ink pad swept over the types by the space key.

**How it works:** Each key lever pulls through a spring and rod on a bell-crank that carries a second bell-crank bearing two or three types; a vertically shifted stepped stop piece (steps 1, 2, 3) limits how far the first crank swings, which chooses which type of the bar strikes the top of the platen. Pressing any key also raises a bar fitted with one set screw per key; the bar's rise drives a ratchet and pawl that turn a screw engaging a rack on the platen carriage, so the step per letter can be tuned to letter width. A spring drum assists the carriage and a string reverses the screw to draw the carriage back, lifting the pawl. An ink roller or pad swept over all the types by a cam each time the space key is pressed replaces the ribbon, and the platen is turned for line spacing as the carriage returns.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [SHIFT:axial](../features/shift-axial.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [INK:pad](../features/ink-pad.md), [INK:roller](../features/ink-roller.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [ESC:spring-drum](../features/esc-spring-drum.md), [ESC:variable-spacing](../features/esc-variable-spacing.md), [ESC:space-key](../features/esc-space-key.md), [ESC:carriage-return](../features/esc-carriage-return.md), [PAP:platen-roller](../features/pap-platen-roller.md), [PAP:line-space](../features/pap-line-space.md), [PAP:feed-rollers](../features/pap-feed-rollers.md), [PAP:paper-guide](../features/pap-paper-guide.md), [FRM:writing-visible](../features/frm-writing-visible.md)

**Parts:** key lever; bell-crank typebar; stepped stop piece; ink roller; cam; platen carriage; rack; worm screw; ratchet wheel; pawl; set screw bar; spring drum; platen; guide wheel; spring brake

**Numbers:** 3 stop steps per bar; one set screw per key lever

**Improves on:**

- ribbon-inked typewriters: direct printing with a roller or pad inking the types, with writing in sight
