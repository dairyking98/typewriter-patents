## Reading (short summary from the opening, OCR fair)

**Problem:** Printing strength depends on how hard the operator strikes the keys, so impressions are uneven.

**Solution:** A spring mechanism between keys and type bars is tensioned by the key and then tripped, so the type always strikes with the same force.

**Features:**

- **Type element:** [Typebars](../features/elem-typebar.md)
- **Impression:** [Spring-powered blow](../features/imp-spring-energy.md)

**Parts:** Fig. 1 single key arrangement
