**How it works (reading):** A sensing feeler rides on a disk with incisions of different radial depths, one per type width; the depth sets how far the threaded carriage shaft advances via the ratchet, so spacing follows each character's width.

## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage spacing for a rotatable type disk runs in any direction, so the usual fixed-key spacing method does not fit.

**Solution:** A sensing feeler rides on a disk with incisions of different radial depths, one per type width; the depth sets how far the threaded carriage shaft advances via the ratchet, so spacing follows each character's width.
