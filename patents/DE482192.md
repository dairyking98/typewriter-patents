## Summary

**Kind:** typebar machine · **Subject (patent classes):** Syllable, line, or like type selection

**How it works (reading):** Each key moves a rod with projections; cross rails with recesses are shifted by longitudinal rails with eccentrics driven by racks and an adjustable lever, so the same keys act on different cross rails after adjustment, letting interchangeable fonts be used in one line.

## Reading (short summary from the opening, OCR fair)

**Problem:** Keyboards of typewriters need many key-driven rods to select each character, and changing between fonts is difficult; several fonts side by side in one line is not possible.

**Solution:** Each key moves a rod with projections; cross rails with recesses are shifted by longitudinal rails with eccentrics driven by racks and an adjustable lever, so the same keys act on different cross rails after adjustment, letting interchangeable fonts be used in one line.

**Features:** [SEL:keyboard-full](../features/sel-keyboard-full.md), [SEL:chart-interchangeable](../features/sel-chart-interchangeable.md), [SEL:differential-drive](../features/sel-differential-drive.md)

**Parts:** key; rod with projections; cross rails with recesses; longitudinal rails; eccentrics; gear and rack adjustment lever
