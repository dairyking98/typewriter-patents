## Reading (short summary from the opening, OCR good)

**Problem:** Table printing machine could not select the right fields of a punch card for each change of print field without operator care.

**Solution:** Exchangeable drive elements set the field selector automatically so that the printed field follows the card program without operator attention.

**Features:** [Interchangeable chart](../features/sel-chart-interchangeable.md), [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** punch card evaluation device; selector; exchangeable drive elements; table strip
