## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Appliances specially adapted for applying liquid, e.g. using roller or ball using a roller, a disc or a ball; Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers using printers

**In the patent’s own words:** My invention relates to that class of typewriting machines wherein a printing-sheet is interposed between the type and the platen of the machine for the purpose of producing an impression upon the paper by the action of the type.
