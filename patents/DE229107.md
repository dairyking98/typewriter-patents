## Reading (short summary from the opening, OCR poor)

**Problem:** Switching a typewriter carriage to script (gearshift) mode should need only one key press, but the pawl stops the next ratchet tooth immediately, so the switch is not reliable.

**Solution:** The pawl stays in engagement with the ratchet wheel until a control element on the paper carriage releases it, letting one or more teeth pass; a flexible stop limits the pawl's travel. This is an addendum to DE226459.
