## Reading (opening only, OCR fair)

**Problem:** Proportional carriage stepping devices are complex, wear unevenly, or offer only two step sizes.

**Solution:** Several stepping pawls on one bolt in slotted holes, with slot lengths graded by one step unit, engage a coarse rack so each character's selector picks its own carriage step.

**How it works:** Pawls are mounted on a bolt through elongated holes of equal length and their teeth are spaced in evenly graded distances, so each travels a different amount before taking the rack. The slot length allows a shift equal to the rack pitch minus one step unit. A selector lever for each width class chooses which pawl acts, set by the actuated key. For carriage return or tabulation all pawls are lifted out together. The example is a power-driven typewriter.
