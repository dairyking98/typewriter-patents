## Summary

**Category:** related office machine, not a typewriter (printing unit, booking machines) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The invention relates to another embodiment of the printing unit shown in patent specification 679 638 for booking and similar machines.

**How it works (reading):** An additional frame inside the main frame lets some or all type sets print in a row or in a column at each print point, selected by setting means.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type sets in a fixed frame print only in columns, so the same machine cannot print a row of postings.

**Solution:** An additional frame inside the main frame lets some or all type sets print in a row or in a column at each print point, selected by setting means.
