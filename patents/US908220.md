## Reading (opening only, OCR fair)

**Problem:** Stop-type tabulators arrest the carriage by impact stops, which is rough and wears.

**Solution:** Tabulate by releasing the letter-spacing feed and letting individual column trip elements re-engage it at the chosen point, with a brake controlling carriage speed.

**How it works:** A release lever disengages the feeding mechanism; denominational trip elements set by keys or selectors sit along an adjustable column-locating element. When the moving carriage reaches the set column, the tappet of the element trips and re-engages the feed, which arrests the carriage. A brake under the same selectors controls speed while released. Shown on a book (flat-bed) typewriter.

**Features:**

- **Spacing and escapement:** [Tabulator](../features/esc-tabulator.md), [Carriage release](../features/esc-carriage-release.md)
- **Paper and carriage:** [Flat bed or book typewriter](../features/pap-flat-bed.md)
- **Uses:** [Book typewriter](../features/use-book-typewriter.md), [Attachment or accessory](../features/use-accessory.md)

**Parts:** release lever; trip device; denominational releasing element; column locating element; brake; letter-spacing mechanism

**Improves on:**

- stop-type tabulators: uses the letter-spacing feed instead of impact stops to arrest the carriage
