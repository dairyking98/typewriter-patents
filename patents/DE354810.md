## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Keyboards with one set of keys for each denomination

**How it works (reading):** Each key lever is made of three one-sidedly coupled single levers, so a new key can be set before the previous digit is transferred.

## Reading (opening only, OCR fair)

**Problem:** In key-set adding machines a new digit cannot be set until the previous digit has been fully transferred to the counter, which slows calculation.

**Solution:** Each key lever is made of three one-sidedly coupled single levers, so a new key can be set before the previous digit is transferred.

**How it works:** Number keys turn angle levers that preset stops in the path of a two-part shift rail (main rail plus auxiliary rail with a slot), so the rail travel can exceed the key pitch. The rail stroke, driven from the machine drive, rotates spring-driven toothed sectors into the counter gears by the key's numeric value. A catch rail holds the preset levers in position until the transfer completes, allowing the next key to be set early. A repeat key lets a set number be transferred again without resetting.

**Features:**

- **Selection:** [Keys drive the element by racks or gears](../features/sel-differential-drive.md)

**Parts:** number key; three-part key lever; angle lever; main shift rail; auxiliary rail; stop; toothed sector; counter gear; catch rail; repeat key

**Numbers:** slot length four units; digit 9 slot nine units

**Improves on:**

- earlier two-part key levers: three-part levers let a new key be set before the earlier digit is transferred
