## Reading (short summary from the opening, OCR fair)

**Problem:** Column-stop tabulation must work independently of the carriage release device.

**Solution:** Stop devices on the frame move into the path of carriage dogs set at chosen spacings; the selected stop device is set by its key to fix the column position.

**How it works:** Stop devices on the frame move into the path of carriage dogs set at chosen spacings; the selected stop device is set by its key to fix the column position.
