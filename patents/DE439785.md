## Summary

**Category:** related office machine, not a typewriter (accounting machine with punched-card text)

**How it works (reading):** Each account sheet carries a hole pattern identifying the account name; a punch-card-controlled text writing device reads the pattern and types the other account name automatically while the operator only keys the amounts.

## Reading (short summary from the opening, OCR good)

**Problem:** Double-entry bookkeeping by hand is slow and error-prone, since each posting must be copied to the other account and the journal.

**Solution:** Each account sheet carries a hole pattern identifying the account name; a punch-card-controlled text writing device reads the pattern and types the other account name automatically while the operator only keys the amounts.
