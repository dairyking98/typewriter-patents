**Category:** related office machine, not a typewriter (type wheel adjustment for cash registers)

**In Google’s translation of the patent’s own words:** The invention relates to an adjustment device on cash registers with several identical rows of type wheel sets arranged next to one another, at the shafts that each carry a number of sets of type wheels and the setting the type wheels mediating shafts fixed around the adjusting hollow shaft system are stored around.

**How it works (reading):** Type wheels of one value point are fixed to their shaft and the others turn freely, so one adjusting shaft serves each value point.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adjusting several sets of type wheels side by side needed a separate shaft for each digit position.

**Solution:** Type wheels of one value point are fixed to their shaft and the others turn freely, so one adjusting shaft serves each value point.

**How it works:** Shafts carry type-wheel sets; fixed and free wheels are arranged so each value point is adjusted by one shaft, reducing shaft count to three rows.

**Features:** [Type wheel (types on the rim)](../features/elem-wheel-rim.md), [Typewriter with adding machine](../features/use-calculating.md)
