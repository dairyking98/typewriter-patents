## Reading (full text, OCR good)

**Problem:** A single typebar cannot be removed without disturbing its neighbours, and the pivot-to-type distance is hard to set so every type strikes the platen at the same point.

**Solution:** Pivot each typebar through an angular pivot that enters keyhole slots in the segment, and make the bar two sliding sections whose type section self-centres against a beveled gage pin entering a guide aperture.

**How it works:** The typebar's angular pivot slides into keyhole-shaped slots in the segment, widened inside so it can turn, and a toothed cover plate closes the slot ends. To remove a bar, the cover plate is moved and the elbow lever unhooked, and the bar is drawn out rearward. The bar is a pivot section and a type section joined by a screw in a longitudinal slot, with interfitting ribs for stiffness. With the screw slightly loose, the bar is swung to the platen and a beveled pin near the type enters a guide on the typebar guide, wedging the type section to the exact position; the screw is then tightened.
