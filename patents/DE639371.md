## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies

**In Google’s translation of the patent’s own words:** The invention relates to a device for placing types on type carriers of typewriters or the like, in which the stops for striking the type edge to set the baseline of type groups of the same font or different fonts that refer to the reference edge of their types among themselves have different positions of the font baseline, perpendicular to the font baseline are adjustable.

**How it works (reading):** The stops are set to the position for each type group automatically, the stops carry a device that indicates the position, so setting is fast and incorrect settings are prevented, with no limit on the number of type groups.

## Reading (short summary from the opening, OCR fair)

**Problem:** Setting the baseline stops for each type group on a type carrier is manual and slow, needs a sample type lever, and fails for many groups.

**Solution:** The stops are set to the position for each type group automatically, the stops carry a device that indicates the position, so setting is fast and incorrect settings are prevented, with no limit on the number of type groups.

**Features:** [ELEM:alignment-lock](../features/elem-alignment-lock.md), [ELEM:interchangeable](../features/elem-interchangeable.md)

**Parts:** dovetail-guided sliding shaft; adjustment rail; baseline stops; spring bolt lever; indicating device
