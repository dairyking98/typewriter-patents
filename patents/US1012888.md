## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Platens with balancing means

**In the patent’s own words:** Subject of the present invention is (listllll guished essentially from certain systems previously known in which the platen is displaced with regard to the carriage which supports it.

**How it works (reading):** The platen carriage is moved horizontally relative to the rack, using levers, so the spacing between letters can be varied and then restored.

## Reading (short summary from the opening, OCR fair)

**Problem:** Letters cannot be spaced closer or wider than the fixed escapement spacing, which is needed for compound letters.

**Solution:** The platen carriage is moved horizontally relative to the rack, using levers, so the spacing between letters can be varied and then restored.

**Features:**

- **Spacing and escapement:** [Proportional spacing](../features/esc-variable-spacing.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md)
