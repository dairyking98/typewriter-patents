## Reading (short summary from the opening, OCR poor)

**Problem:** Code impressions from a telegraph controller also need printed characters on the same sheet, in matching line order.

**Solution:** A perforating machine with a type wheel and punching device impresses code holes and printed characters on one sheet, operated by electric circuits.

**How it works:** A type wheel positions the printed character while a punch linked to the wheel makes the code perforation; electric circuits operate the machine.

**Features:** [USE:telegraph-printer](../features/use-telegraph-printer.md), [IMP:electric](../features/imp-electric.md)

**Parts:** type wheel; punching device; electric circuits
