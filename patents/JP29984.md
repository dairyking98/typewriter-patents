## Reading (full text, OCR good)

**Problem:** Kanji are very numerous, and printing them needs a way to reach any of about 3,000 with few keys, surely and quickly.

**Solution:** A large type cylinder is first brought to the right radical group by a radical key, then to the right line and column by position keys, with motors and hammer doing the work.

**How it works:** About 3,000 kanji are engraved on a type cylinder on a square main shaft that can turn and slide, twenty to a line, four lines to a group, grouped by radical. Pressing a radical key raises a hammer that makes one tilting pawl on the control drum stick out; the shaft turns until that catch meets a stop, which also closes a circuit starting a motor that pushes the cylinder forward on a cord against a spiral spring. As it moves, an index plate for that group rises inside the cylinder showing the group's characters. A line key swings aside stops so the right line is chosen, and the operator presses the position key for the column, which releases a latch so the spring draws the shaft back until a collar meets the lifted bar of that key. A second motor then throws up the hammer to print, and further parts return the drum and provide backspace and a no-print advance.

## Description (English translation of the Japanese text, opening)

> Specification. Kanji typewriter. Nature and object of the invention. Pressing a radical key (扁字鍵, a key for one group of characters classed by radical) makes the catch part of a tilting pawl, mounted on one edge of the control drum (司動筒), stick out, and at the same time moves the pawl that held the main shaft, to which the drum is fixed, from turning. The shaft is left free to turn; when it has turned a certain amount, the catch meets a stop and the turning stops. A motor in a circuit closed at the same moment pushes the type cylinder (文字筒), fixed to the end of the main shaft, forward. During this travel an index plate (指字版) rises, by which the operator finds where the wanted character is; he presses a position key (正字鍵), and the type cylinder is drawn back to the proper position. When this is done, another motor in a circuit then closed throws up the hammer and prints. The invention relates to this kanji typewriter. Its object is to print kanji, of which there are a great many, surely and quickly with as few keys as possible. Brief description of the drawings.
