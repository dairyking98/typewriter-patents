## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** My invention relates to typewriting machines and more particularly to repulsers for causing the type bars to be quickly removed from contact with the platen after each imprint.

**How it works (reading):** A set of repulsers mounted in chambers on a common support, which quickly return the type bars away from the platen after each imprint.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type bars must be quickly removed from contact with the platen after each imprint, and earlier repulsers were not simple or efficient.

**Solution:** A set of repulsers mounted in chambers on a common support, which quickly return the type bars away from the platen after each imprint.
