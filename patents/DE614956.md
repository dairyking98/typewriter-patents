## Summary

**Category:** related office machine, not a typewriter (registering machine with card punch)

**How it works (reading):** Punch rows are selected during each print stroke, and a tabulator switch advances the card carriage electrically so several card fields are punched together.

## Reading (short summary from the opening, OCR fair)

**Problem:** Punching statistical cards column by column after each registration slows the recorder and risks wrong punching if the crank returns too fast.

**Solution:** Punch rows are selected during each print stroke, and a tabulator switch advances the card carriage electrically so several card fields are punched together.

**Features:** [USE:calculating](../features/use-calculating.md), [ESC:tabulator](../features/esc-tabulator.md)
