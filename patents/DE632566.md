**In Google’s translation of the patent’s own words:** The present invention relates to a printing tabulator having movable Type carriers, each of which contains a number of types7 which are identified by one of the type carriers assigned hammer can be struck.

**How it works (reading):** Each type carrier is printed only through card holes, and the hammer-lock readiness is produced only when the carrier is set to a non-zero type and is cancelled at the carrier's null positions; each carrier also carries a second zero type for total printing and one for item printing.

## Reading (short summary from the opening, OCR fair)

**Problem:** In known printing tabulators the hammer lock is prepared for every non-zero setting, but the lock is not reset when the carrier's null type prints, so hammers for zeroed carriers strike blindly and stress the transmission.

**Solution:** Each type carrier is printed only through card holes, and the hammer-lock readiness is produced only when the carrier is set to a non-zero type and is cancelled at the carrier's null positions; each carrier also carries a second zero type for total printing and one for item printing.

**How it works:** The type carrier's null type, when it reaches the printing position, returns the locking mechanism to rest so that blind hammer strokes are avoided.
