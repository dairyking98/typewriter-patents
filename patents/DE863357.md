## Reading (opening only, OCR fair)

**Problem:** In telegraph printers the type wheel stays still after printing, so if the same character is printed repeatedly it is not re-inked by a roller, and the last typed letter is hidden under the wheel.

**Solution:** After each impression the type wheel is shifted axially so the last-printed type brushes over an ink body beside the print point and the printed letter is uncovered.

**How it works:** The type wheel shaft is moved sideways after printing so the character passes over the ink body and is re-inked while also exposing the paper strip. Multi-row wheels already shift sideways to select rows, so a summation translator adds the inking movement to the row shift, and its end member shifts the wheel. A lever on the shaft end, connected to the shaft rotatably but axially fixed, is moved by two push rods, one for case change and one for the inking movement. Signal type determines whether the shift member stays latched (letters) or reciprocates each press (figures).

In known telegraph devices, the type wheel remains stationary after the imprint and is then immediately moved into the next imprint position. If the same character is printed several times in a row, there is no rotation of the type wheel in between. If the type wheel is constantly rotating, it is easy to colorize the type that was last printed. For this purpose, you usually run a paint roller on the type wheel. With such a simple device, inking is not possible in the case described above, because when the same type is imprinted several times, no rotary movement and thus no re-inking of the type takes place.
