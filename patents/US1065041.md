## Reading (opening only, OCR fair)

**Problem:** The platen can only be set in whole steps of the line-space ratchet, so a printed line cannot be brought exactly into register with the printing line.

**Solution:** A friction-driven twirler knob lets the platen turn to any position independent of the ratchet, while normal spacing still works through the friction.

**How it works:** The platen is fixed to the twirler knob shaft; the spacing ratchet wheel with its spring-loaded detent is fixed to a hub of the left-hand knob, which turns loosely on the shaft held by lugs and a loose disk. A vulcanized-fiber washer is pressed between the knob counterbore and a metal disk by a helical spring in a cap, so friction is enough to turn the ratchet wheel when either knob is rotated for normal spacing. Holding the ratchet and turning harder slips the friction so the platen can be set to any fraction of an inch. A threaded cap and screw adjust the spring tension.
