## Reading (opening only, OCR fair)

**Problem:** Typewriters are heavy, costly and have many keys.

**Solution:** A light cheap machine with typebars of graded length striking one spot, several characters on each type body chosen by moving part of the cap frame, and interchangeable character sets.

**How it works:** Flat steel type levers of increasing length pivot in a movable frame with screw-adjustable pivots, each removable for cleaning. Their type bodies form vertical steps and all strike the same spot. Several characters per body are chosen by shifting part of the cap frame. A ribbon regulator with indicator and spacing disks with a rod and clutch head move the carriage.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ELEM:interchangeable](../features/elem-interchangeable.md), [SHIFT:platen](../features/shift-platen.md), [FRM:few-parts](../features/frm-few-parts.md), [FRM:compact-portable](../features/frm-compact-portable.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md), [FRM:cleaning-access](../features/frm-cleaning-access.md), [INK:ribbon](../features/ink-ribbon.md), [ESC:variable-spacing](../features/esc-variable-spacing.md)

**Parts:** type lever; type body; movable frame; pivot set-screw; spacing disk; spacing rod; ribbon indicator
