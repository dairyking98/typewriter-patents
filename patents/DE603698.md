## Summary

**Category:** related office machine, not a typewriter (teleprinter receiving mechanism) · **Subject (patent classes):** Apparatus or circuits at the receiving end using mechanical translation and type-bar printing

**How it works (reading):** Clutch control steers the drive to one of several code rods, which are then brought under pressure, instead of scanning.

## Reading (short summary from the opening, OCR fair)

**Problem:** Selector-bar scanning through all code bars is complex for teletypewriter selection.

**Solution:** Clutch control steers the drive to one of several code rods, which are then brought under pressure, instead of scanning.
