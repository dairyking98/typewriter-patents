## Summary

**Category:** related office machine, not a typewriter (typewriter linked to card punch)

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter with transmission elements by which when pressing keys on the machine at the same time punch selector a Card punching device can be adjusted.

**How it works (reading):** The punch key is locked until the clear-character key moves, and a bent keylever tab lets the punch key be pressed independently.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typewriter keyboard could start a card punch cycle prematurely when punch keys were pressed.

**Solution:** The punch key is locked until the clear-character key moves, and a bent keylever tab lets the punch key be pressed independently.
