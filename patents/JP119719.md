## Reading (full text, OCR good)

**Problem:** A Japanese-script typewriter has to be switched easily between vertical and horizontal typing, which need the paper cylinder to feed in different directions after each character.

**Solution:** A single rod that moves at every key stroke is shifted by a three-position handle so that its motion works only the vertical-feed mechanism, only the horizontal-feed mechanism, or neither.

**How it works:** The paper cylinder (5) sits in a frame (2) that slides sideways, pulled left by a cord (4) and take-up device, while a spring urges the cylinder to turn. Each feed mechanism is a brake plate with a spring-driven sector gear and an auxiliary brake plate that act as an escapement on a gear; the sector gear's swing is set by a stop, which sets the step. In the vertical feed, a movable frame (6) swung by the push rod (53) frees the cylinder gear train for a step whose size depends on which of several pins (30) of different length meets an ear (32) on the sector gear. In the horizontal feed, a rocker (58) tips a brake plate (33) so the sector gear steps the sliding frame through a rack (9), the step set by a stepped character-spacing rod (44) moved by a handle (47) along a scale (48). A swinging rod (51) driven by a crank (52) on the printing key raises the push rod (53) at every stroke; handle (57), marked vertical, off and horizontal on a dial plate (64), puts the push rod under the movable frame, hooks it to the rocker, or leaves it idle so the machine prints in place.

## Description (English translation of the Japanese text, opening)

> Specification. Vertical/horizontal typing change-over device for a Japanese-script typewriter. Nature and object of the invention.
