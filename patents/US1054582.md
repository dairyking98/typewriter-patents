## Reading (short summary from the opening, OCR fair)

**Problem:** A printing machine must work by hand from a keyboard or from perforated strip, with the fewest holes per character.

**Solution:** A Siemens and Halske machine whose controlling shaft, set by the keyboard or register, determines the operation, and a controlling disk on a type wheel selects the type and prints it with an auxiliary force.

**How it works:** The controlling shaft is driven and stopped at a position set by the keyboard or perforated strip; in each position the typewheel brings a different type to the hammer and the controlling disk gives the operation.

**Features:**

- **Type element:** [Type disc (types on the face)](../features/elem-disc-face.md)
- **Impression:** [Hammer behind the paper](../features/imp-hammer-behind.md)
- **Uses:** [Printing telegraph](../features/use-telegraph-printer.md)

**Parts:** controlling shaft; controlling disk; type wheel; printing hammer; keyboard; perforated strip
