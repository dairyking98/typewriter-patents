## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed

**How it works (reading):** Individual special characters, including an upright hexagon, are added to the type set so they can be struck in sequence with ordinary characters using the existing switching means, without changing the lever count.

## Reading (short summary from the opening, OCR fair)

**Problem:** Ordinary typewriters cannot print the benzene-ring and other chemical structure symbols, since the common type characters and line types do not combine into them.

**Solution:** Individual special characters, including an upright hexagon, are added to the type set so they can be struck in sequence with ordinary characters using the existing switching means, without changing the lever count.
