## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters for ciphering or deciphering cryptographic text wherein the operative connections between the keys and the type-bars are automatically and continuously permuted, during operation, by a coding or key member the connections being mechanical

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter for the production of secret writing with between the key levers and the type lever interchangeably switched transmission links.

**How it works (reading):** Key levers drive type levers through sets of interchangeable intermediate levers with cams at different distances from the fulcrum; swapping the lever sets changes which key drives which type lever, so the cipher can be varied and then reset for ordinary writing.

## Reading (short summary from the opening, OCR fair)

**Problem:** Cipher writing needs the key-to-type mapping to vary, but a fixed linkage cannot be remapped.

**Solution:** Key levers drive type levers through sets of interchangeable intermediate levers with cams at different distances from the fulcrum; swapping the lever sets changes which key drives which type lever, so the cipher can be varied and then reset for ordinary writing.
