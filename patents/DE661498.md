## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Programming-mechanisms for determining the steps to be performed by the computing machine, e.g. when a key or certain keys are depressed in which the operation of the mechanism is determined by the position of the carriage

**In Google’s translation of the patent’s own words:** The invention relates to an apparatus for typewriters, in particular for typewriters, for automatic Repeat the step switching of the paper cart by means of stops, riders or the like, which can be switched off automatically by actuating means of the machine.

**How it works (reading):** An intermediate link in the stepping stop system can be switched on and off by hand with a locking hook, so the repeat is set without the key.

## Reading (short summary from the opening, OCR fair)

**Problem:** An automatic repeat of carriage stepping needed a special key on each new line.

**Solution:** An intermediate link in the stepping stop system can be switched on and off by hand with a locking hook, so the repeat is set without the key.

**Features:** [Pawl-and-rack escapement](../features/esc-pawl-rack.md), [Tabulator](../features/esc-tabulator.md)
