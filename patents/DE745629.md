## Summary

**Category:** related office machine, not a typewriter (electric teletypewriter simplified mechanism) · **Subject (patent classes):** Printing mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to an electric teletypewriter and its purpose is to simplify the mechanical structure of such a machine and to enable the same to work quickly.

**How it works (reading):** Types are fixed on a chain or band moved past the paper, and staggered electromagnets select each type so that several letters can be written in one pass.

## Reading (short summary from the opening, OCR fair)

**Problem:** Electric teletypewriter with types on a wheel is slow because only one type can strike at a time.

**Solution:** Types are fixed on a chain or band moved past the paper, and staggered electromagnets select each type so that several letters can be written in one pass.
