## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a type lever drive for typewriters with switchable Type lever segment, in which the drive from the button levers arranged on a common straight shaft via front Handlebars, front intermediate levers, Mktelenker, rear intermediate levers and rear Handlebar is done on the type lever.

**How it works (reading):** Rear intermediate levers sit on a common straight fixed shaft, graduated in length so the rear link travel is equal for all levers in both segment positions.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type lever drive for switchable segment machines is bulky and gives unequal key resistance and stroke between segment positions.

**Solution:** Rear intermediate levers sit on a common straight fixed shaft, graduated in length so the rear link travel is equal for all levers in both segment positions.
