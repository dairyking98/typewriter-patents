## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Ink ribbons having arrangements to prevent undesired contact between the impression-transfer material and machine parts or other articles

**How it works (reading):** A cloth ribbon inked on one side only, with the back coated against ink soak-through, so the type meets only one clean inked face and more permanent inks can be used.

## Reading (short summary from the opening, OCR fair)

**Problem:** Textile ribbons inked on both sides clog the type, blur the print and wear the type faces, and they limit the inks that can be used.

**Solution:** A cloth ribbon inked on one side only, with the back coated against ink soak-through, so the type meets only one clean inked face and more permanent inks can be used.
