## Reading (full text, OCR fair)

**Problem:** In a typebar action fed by key levers of three different lengths, the type bars should swing with minimum force and through uniform arcs although the key levers move through unequal arcs.

**Solution:** Each key lever drives a vertical bell crank by a thrust link, and the bell-crank arm lengths and angles are varied across the series so every link works at right angles to its arms and all type bars swing the same distance.

**How it works:** Folded, resilient key levers pivot on a shaft and are joined by a thrust link to the short arm of a bell crank pivoted beneath. The bell crank's long vertical arm, which grows longer from the centre of the arc outward to match the raised bases of the type bars, pulls a horizontal link to the type bar. Arm lengths, bell-crank angles and key-lever arm angles differ by position so each link stays at right angles to the parts it drives, while the upper ends of the vertical arms all move the same distance. Levers, bell cranks and combs form a unit frame inserted into the machine as a whole.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [FRM:frame-construction](../features/frm-frame-construction.md), [FRM:few-parts](../features/frm-few-parts.md)

**Parts:** key lever; bell crank; thrust link; pull link; type bar; type bar segment; guide comb; unit frame; return spring; platen

**Numbers:** key lever arm to short bell-crank arm length ratio about 3 to 2 (example)
