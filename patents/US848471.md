## Reading (short summary from the opening, OCR fair)

**Problem:** Keys all look and feel alike, so a learner cannot tell which key is which by touch.

**Solution:** Each key is mounted to oscillate about an axis set at a different direction, so the way a key tilts identifies it; keys are grouped in regular patterns such as hexagons.

**How it works:** Each key sits on a bar and rocks on a small axis that can be parallel, perpendicular or inclined to the front edge; a spring or counterweight keeps the key level.

**Features:** [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** key; bar; axis; spring or counterweight
