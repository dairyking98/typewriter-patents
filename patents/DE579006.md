## Summary

**Category:** related office machine, not a typewriter (punch tape control machine)

**In Google’s translation of the patent’s own words:** The invention relates to a machine that is controlled by a combination of points or holes.

**How it works (reading):** A guide symbol's position and length set the field to be evaluated, so only the needed part of the strip is read.

## Reading (short summary from the opening, OCR fair)

**Problem:** Strip-reading machines for ticket control strips stopped when a symbol group was missing, so step-by-step advance failed on sparse strips.

**Solution:** A guide symbol's position and length set the field to be evaluated, so only the needed part of the strip is read.
