**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Regulating touch, key dip or stroke, or the like

**How it works (reading):** Return spring anchors move on an arc so the spring tension changes mainly near the print point, leaving the start of the stroke light.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type lever return spring tension changes the whole stroke, so a stronger spring also needs more impact force.

**Solution:** Return spring anchors move on an arc so the spring tension changes mainly near the print point, leaving the start of the stroke light.
