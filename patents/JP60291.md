## Reading (full text, OCR good)

**Problem:** Typebar machines with several types per bar need a heavy shift and two keystrokes; the inventor wants any of many Japanese characters printed by one light press of one key.

**Solution:** A type bar carries a sliding type plate of six types in a row that is flung outward by centrifugal force and checked by a control catch, whose distance from the pivot is set by the key's own stop screw, so each key brings its particular type to the print point.

**How it works:** Pressing a finger key moves a common bar down to a stop screw (one per key row) and, through levers, rods and a bell crank, slides a control linkage up a slot to a set height. At almost the same time the key flange presses a key lever that turns the type bar toward the paper cylinder. The type plate slides out along the bar and flies outward by centrifugal force until its bent end is held by the control catch at the end of the light control lever. The catch's distance from the type bar pivot depends on the linkage position, so the chosen type of the six on the plate (イロハニホヘ) lands at the printing point. On release the catch distance shortens, pulling the plate back, and a pulley on its end runs along a curved plate to stop it without vibration. Key stems have slots so unpressed keys in the same column stay still.
