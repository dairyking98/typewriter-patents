## Reading (opening only, OCR fair)

**Problem:** Syllable-writing machine needs to print several characters (a syllable) at once from separate keyboards.

**Solution:** Eight separate keyboards each oscillate shafts that, through differential gearing, first bring type levers to the print point and then strike, so several characters print simultaneously.

**How it works:** Each of the eight keyboards has finger keys on rods ending in enlarged parts with an arm and an indentation. Depressing a key oscillates one shaft at once and a second shaft later, delayed by an oblique line of indentations according to key position. An angle lever on the second shaft carries a bevel pinion meshing with two toothed segments (a differential gear) and a roller that acts on a rail of the printing frame near the end of the stroke. A catch on the shaft stops the segment so that the type lever is brought to the print point, then the printing frame strikes.
