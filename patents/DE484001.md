## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters for ciphering or deciphering cryptographic text

**In Google’s translation of the patent’s own words:** The invention relates to an encryption device with periodic change of the basic position for typewriters with a character field, Setting pointer and type roller, with which the rows of letters of the character field consist of endless belts guided over rollers.

**How it works (reading):** Letter rows of the character field are endless belts, shifted by a hand crank in alternation with the write key, giving a periodic key change.

## Reading (opening only, OCR good)

**Problem:** A cipher typewriter with pointer and type roller needs many key positions and a forced periodic change of the base setting without burdening the key.

**Solution:** Letter rows of the character field are endless belts, shifted by a hand crank in alternation with the write key, giving a periodic key change.

**How it works:** The machine has a character field, setting pointer and type roller with one print key. The lower-case letters sit on endless belts in a visible cipher field, normally matching the roller; belts can be shifted vertically and the whole field laterally, set by key numbers on number rollers. After a set number of letters the key locks until the crank has been turned once, which steps the belts, some more than others, so the setting recurs only after a long period shown by a counter.
