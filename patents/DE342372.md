## Summary

**Category:** related office machine, not a typewriter (calculating machine automatic zero printing) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**How it works (reading):** Each type disk carries a spring-loaded zero-type rod, pushed into printing position by the impression movement only where needed, so the rods are not all moved on each setting.

## Reading (short summary from the opening, OCR fair)

**Problem:** Zeros behind a set number are printed by setting each zero individually, and on existing machines all zero-type bars move when a higher digit is set.

**Solution:** Each type disk carries a spring-loaded zero-type rod, pushed into printing position by the impression movement only where needed, so the rods are not all moved on each setting.
