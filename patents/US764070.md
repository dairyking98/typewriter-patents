## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Locking devices actuated when platen reaches the end of a line

**In the patent’s own words:** This invention relates to type-writing machines, and has special reference to that type of attachments which are designed to lock the entire type and key action when the carriage has reached the end of the line being printed.

**How it works (reading):** A line-lock attachment for the Oliver machine locks the key-levers at line end while the type-action can be released to finish a word; the stop is only lightly filed.

## Reading (short summary from the opening, OCR good)

**Problem:** Typing past the end of a line overprints letters because nothing stops the key action.

**Solution:** A line-lock attachment for the Oliver machine locks the key-levers at line end while the type-action can be released to finish a word; the stop is only lightly filed.
