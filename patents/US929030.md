## Reading (full text, OCR fair)

**Problem:** On visible-writing typebar machines the narrow ribbon rests below the printing point; shifting the ribbon together with the platen for capitals needs extra mechanism, and the raised ribbon catches on the printing-point pointer when it drops.

**Solution:** Lift the ribbon from the same rest position on every keystroke, with a second shift-key-controlled cam that increases the lift for upper-case type, and add a wire guide on the pointer so the ribbon cannot catch.

**How it works:** Depressing any printing key presses on wires attached to a rock shaft carrying an upright cam. The cam's inclined upper end rocks forward against a roller on a U-shaped lifting frame, raising rods and ribbon guides and so the ribbon to the printing point, and it falls back when the key is released. A second cam plate is riveted loosely to the first with a slot. The shift key, through a hooked lug and lever, raises this plate so the cam lifts the ribbon higher for the upper-case type on the typebar. The platen is still shifted separately by the shift key, but the ribbon is not shifted with it. A single-prong pointer carries a light resilient wire that holds the ribbon away so it does not catch on the pointer when lowering.
