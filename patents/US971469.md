## Reading (opening only, OCR fair)

**Problem:** When a pivoted type basket is shifted for upper case, the angle of the segment to the platen changes and typebar alignment suffers.

**Solution:** Suspend the type basket on two sets of parallel bars so the segment shifts to upper or lower case while staying in parallel planes.

**How it works:** An auxiliary sheet-metal frame sits in the main frame. The type basket carries a vertical segment of typebars, each bearing upper and lower case letters, and is hung from legs pivoted to pairs of parallel bars at each side. The bars guide the segment as it is shifted, keeping it in parallel planes. Key levers swing rock levers of different lengths, which move push rods with right and left threaded length adjustment, and these move rods connected to the typebar heels through a guide plate. Stops limit the basket shift.
