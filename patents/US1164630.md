## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Stops or stop-racks

**In the patent’s own words:** Object of the present invention is to provide an improved machine of this character having means for returning the typewriter carriage to any predetermined point intermediate the point to which it has been advanced and the initial or starting position.

**How it works (reading):** A return mechanism brings the carriage back from any point to the start or to a chosen intermediate stop, with an interlock that stops the advance drive while the return runs.

## Reading (short summary from the opening, OCR fair)

**Problem:** A calculating typewriter carriage must return to the start or any chosen point, and the advance and return drives must not run together and break parts.

**Solution:** A return mechanism brings the carriage back from any point to the start or to a chosen intermediate stop, with an interlock that stops the advance drive while the return runs.
