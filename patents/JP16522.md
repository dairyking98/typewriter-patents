## Reading (full text, OCR good)

**Problem:** Ordinary keyboards need one key lever per key, and keys must be released in rhythm before the next is struck.

**Solution:** Put one rocking bar under each row and each column of keys, each key sitting at a crossing of a row bar and a column bar and moving both, so a coordinate pair selects the character.

**How it works:** In the 45-key example, nine-key rows each have a rocking bar and five-key columns each have another. A key shaft carries one projection per bar crossing beneath it, so pressing it moves its row bar and its column bar. The bar motions are passed on by valves, switches, levers, cords or gears. For a type cylinder the row bars could shift it lengthwise and the column bars turn it, picking any one of nine-by-five types. Hooks with torsion springs can hold the bars down until a crossed release bar frees them all together, so keys can be held for a whole word and bars return before the keys are let go.

## Description (English translation of the Japanese text, opening)

> Keyboard. This invention relates to the keyboard mechanism of machines which bring particular units (for example figures, types, stamps, signals and the like), or groups of such units, into a particular state of action or into a position where they can be seen, as in typewriters, calculating machines, typesetting machines, cash registers, "line and junction selectors" and other machines. Its object is to provide a keyboard mechanism in which, instead of the key levers usually joined to the keys, movable bars (橋片, literally "bridge pieces") are placed under the keys; pressing a key moves the bar, and the bar returns to its old position independently of the key. In this way, rather than as many levers as there are keys, one bar is used for each row and for each column of keys. Each key is placed at a crossing point of a row bar and a column bar and has actuating projections, so that when it is pressed it moves the two bars, the row bar and the column bar, either at the same time or one after the other.
