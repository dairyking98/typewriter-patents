## Reading (short summary from the opening, OCR fair)

**Problem:** Key touch is set by changing dog-rocker or key-lever springs, and heavy tension bends the light key-levers and upsets the spacing-dog action, so a skilled mechanic must readjust the linkage.

**Solution:** The inventor changes how the finger resistance is set so touch can be tuned without overloading the light key-levers; the full solution lies beyond the first 3000 characters and is not shown here.
