## Reading (short summary from the opening, OCR poor)

**Problem:** Morse code tape punches are slow and costly, and no simple typewriter-keyboard device printed Morse code directly on paper strip.

**Solution:** A modified Morse strip printer with fixed types spaced at the dot pitch, movable types between them chosen by the typed character to connect dots into dashes, and a shield that blocks types not required.
