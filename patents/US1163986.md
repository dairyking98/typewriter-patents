## Reading (opening only, OCR fair)

**Problem:** A shift key that moves the carriage-feed universal bars along the key levers (or perforator bars) fails if a key is struck before the shift has fully completed, giving wrong feed or wrong punched holes.

**Solution:** Make the shift movement that changes the key-lever/universal-bar cooperation take place in a direction toward or away from the key-lever projections, so partly-made shifts cannot foul.

**How it works:** The machine has key levers with projections selecting universal bars, which set the carriage feed per character width (or punch holes in a band). The older design slid the bars along the levers to a second set of projections, which jammed if a key was pressed early. Here the shifting movement is made toward or from the projections instead. Only the opening is available; the rest of the mechanism is not shown.

**Parts:** key lever; universal bar; shift key; feed-controlling device; paper carriage; perforating band
