## Reading (opening only, OCR fair)

**Problem:** One machine should write both oriental script, which needs a multiple carriage step for some letters, and Western script, which needs a single step, without special modifications.

**Solution:** The multi-step preparatory jumper is placed in the removable type lever basket while the members it actuates stay in the machine frame, so swapping the basket changes the spacing behaviour.

**How it works:** A control member on a cross-axis in the frame is moved by an angle lever from a locking-script key, which also has a caps-lock style latch. Moving the control member sets the deflection of the loose escapement tooth so the escape wheel jumps two tooth pitches. A letter key struck on the Western basket then advances the carriage two steps while the key is held. A switching bridge in the basket sets the double step from the key levers. A further key presses the script key and the shift key together, giving a double step with the platen shifted, for block or poster capitals.
