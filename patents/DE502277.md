## Summary

**Category:** related office machine, not a typewriter (paper tape switching for adding machines) · **Subject (patent classes):** Line-spacing devices for feeding tape

**How it works (reading):** A toothed rack on the pivoting pressure roller carrier engages the drive gear one way only, so each return to start feeds one fixed tape step.

## Reading (short summary from the opening, OCR fair)

**Problem:** Paper tape feed on adding machines and cash registers must advance the same step length each time.

**Solution:** A toothed rack on the pivoting pressure roller carrier engages the drive gear one way only, so each return to start feeds one fixed tape step.
