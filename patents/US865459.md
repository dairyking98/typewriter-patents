## Reading (opening only, OCR fair)

**Problem:** Typewriter keyboards need hand and finger movement to reach every key.

**Solution:** Reduce the keyboard to 22 keys placed under the resting hand, with ten keys each working three levers by depress, push or pull.

**How it works:** A first set of ten keys is pressed with the fingertips, a second set of ten sits under the second phalanges and is pivotally mounted on a sleeve so it can be pressed, pushed forward or pulled back, and two thumb keys complete the set. Pushing or pulling swings the key so a roller engages one of a pair of bell-crank levers, each lying on a different key lever. Together the keys operate 42 key levers, which drive the impression mechanism in any known way. Return springs and guide frames with slots serve the key levers.

**Features:**

- **Selection:** [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md)

**Parts:** finger key; multiple-operation key; thumb key; sleeve; bell-crank lever; roller; key lever; guide frame; return spring

**Numbers:** 22 keys; 42 key levers; 3 operations per multiple key
