## Description (Google Patents OCR, opening)

> Description Translated from German Type lever linkage for typewriters. The invention relates to a Type lever linkage for typewriters, their key levers and intermediate levers a slot and pin connection are connected to one another. With type lever linkages of this type, an annoying message arises when writing Noise when, as is the case with known designs, the key lever or the lever connected to the stop button and the intermediate lever moved by it of the type linkage lie in two mutually parallel planes. This also lies the point of application of the 7u transferring force laterally offset against the key lever, so that a tilting moment arises, which causes a side tension in the intermediate lever, so that this receives a sideshift, which when striking and releasing the Button produces an annoying clattering or rattling noise. This deficiency is avoided according to the invention in that the Point of application of the transmission of motion in the same plane of vibration with the intermediate lever and the Key lever or the one moved by the pressed key Lever is misplaced.
