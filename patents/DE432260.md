**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Multiple-action keys, e.g. keys depressed by two or more amounts or movable in two or more directions to effect different functions or selections

**How it works (reading):** Each type lever carries an auxiliary lever so any two key levers pressed in either order print one character.

## Reading (opening only, OCR fair)

**Problem:** Paired-key typewriters allow few combinations and need simultaneous pressing.

**Solution:** Each type lever carries an auxiliary lever so any two key levers pressed in either order print one character.

**How it works:** Type levers on a common axis have rotatable equal-armed auxiliary levers whose bent ends lie under the arms of key levers. Pressing both of an assigned pair lowers the auxiliary lever and takes the type lever down; pressing only one merely turns the auxiliary lever idle. A second form uses a sliding cross arm with slanted ends that is pushed aside by a single key but held when two keys come down. Ten keys give 45 characters instead of 25.
