## Reading (full text, OCR fair)

**Problem:** In the photographic type-disc typesetter of patent 342311 the text is only visible after development, so spelling mistakes can be neither prevented nor corrected.

**Solution:** Add a mechanical printing type behind each transparent type on the same disc that prints a visible control line on a paper tape before the lamp exposes the film.

**How it works:** Each position of the type disc carries a transparent type for the lens and lamp, plus an ordinary printing type on the periphery in line with it. A paper writing tape, threaded through eyelets on a fork on a shaft, is indexed past the print point from one spool to another. A control lever turns the shaft, the fork draws the tape to the print point and a hammer on the shaft strikes it from behind against the inked type; a spring then returns it so the typed character can be read at once. The same lever, through a switch blade and lost-motion claw coupling, closes the lamp circuit only afterwards, so errors can be corrected before exposure. The lever also advances the tape via bevel gears and a ratchet.
