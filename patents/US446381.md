## Reading (full text, OCR fair)

**Problem:** When typing columns, the operator had to lift the carriage or remember the scale positions where each column begins.

**Solution:** Fit the frame's tabulating scale with slidable, removable pointer buttons that mark column start positions against the carriage pointer.

**How it works:** A slotted, indented scale on the machine frame is graduated to match the carriage scale. Pointer buttons with a shank through the slot and a spring or felt washer behind the head slide freely but stay where set. The operator sets one pointer opposite each column start; as the carriage travels, its indicator reaches each pointer to show where to begin typing. Pointers with spring arms can be pinched together and removed when not needed.

**Features:** [ESC:tabulator](../features/esc-tabulator.md), [PAP:line-indicator](../features/pap-line-indicator.md), [USE:accessory](../features/use-accessory.md)

**Parts:** frame; carriage; carriage scale; tabulating scale with slot; carriage pointer; adjustable pointer button; spring washer; spring arm

**Improves on:**

- Remington carriage scale and tabulating scale: adds movable markers so column starts need not be remembered or checked by lifting the carriage
