## Reading (opening only, OCR fair)

**Problem:** Producing and reading secret writing normally takes mental work.

**Solution:** Shift the pointer/scale (or the type arrangement) of an ordinary typewriter by a set number of places so typing the plain text prints a cipher, and shift back to decipher.

**How it works:** On a keyboard machine the scales A showing the letter for each key are moved one or more places left or right relative to the keys; typing the plain word then prints different letters (patent becomes IOEQVE for a two-place shift left). Moving the scales back the same distance and typing the cipher prints the original. A second form uses typebars made as five-sided prisms that rotate about their axes, each face carrying the alphabet shifted by a different amount, face 1 being normal. For the Columbia (type wheel and pointer) machine the pointer is made adjustable on its axis by a perforated plate and pin so its relation to the disc of types can be offset. Shift amounts and type order can be varied to vary the cipher.
