## Reading (short summary from the opening, OCR fair)

**Problem:** In a combined typewriter and computing machine, the operator could shift the carriage back for a new line without turning up the paper, or write a new item on the same line, which destroyed the result.

**Solution:** A combined typewriter and arithmometer in which the numeral keys drive the computer; the text is cut off before the mechanism that prevents the line error is described, so the fix is not visible in the first 3000 characters.

- **Spacing and escapement:** [Carriage return](../features/esc-carriage-return.md)
