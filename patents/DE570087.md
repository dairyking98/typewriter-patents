## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Teaching typing

**In Google’s translation of the patent’s own words:** The invention relates to a device for learning to write typewriter, in particular of blind typing.

**How it works (reading):** A replica keyboard of lamps mounted on the copy holder lights the matching key when a key is pressed, using contacts under each key.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typist learning blind typing must look back and forth between the copy and the keys, which slows typing.

**Solution:** A replica keyboard of lamps mounted on the copy holder lights the matching key when a key is pressed, using contacts under each key.
