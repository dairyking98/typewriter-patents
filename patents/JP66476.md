## Reading (full text, OCR good)

**Problem:** Printing from a very large number of types on a cylinder is slow, hard on the eyes and inaccurate when the operator must hunt for the type to bring to the print point.

**Solution:** A concentric index cylinder, carrying the same characters as the type cylinder in a mirrored axial order, turns with the type cylinder but does not slide, so a sight window that slides with the type cylinder points at a character on the index cylinder exactly when the corresponding type is at the print point.

**How it works:** The type cylinder sits on a shaft with sliding pieces that engage grooves inside the index cylinder, so the two turn together while the type cylinder can slide along the shaft and the index cylinder cannot. A handwheel at the shaft end turns and slides the shaft, so the type cylinder both rotates and moves axially. A bell crank and arm carry a sight window that moves axially with the shaft but does not turn. The operator moves the handwheel until the wanted character, written on the index cylinder in syllabary order, shows in the window, which brings its type to the fixed print point. Pressing a handle turns a cross shaft, bell crank and link to swing a hammer that strikes the type, and a spring returns it. The paper board advances one space per character.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention relates to a printing machine in which, to bring any type on a type cylinder to the printing point, a type-index cylinder concentric with the type cylinder is provided; the two can turn at the same time about the same shaft, but of the two only one can move along the shaft and the other cannot; a separate type-indicating mechanism is provided, and between it and the index cylinder a relative displacement is produced equal to the relative displacement that arises along the axis between the type cylinder and the index cylinder; so that, by making the indicating mechanism point to any character on the index cylinder, the corresponding type on the type cylinder is brought to the printing point. Its object is a printing machine that, in printing from a very large number of types, prints any type quickly, lightly and accurately. Brief description of the drawings. The drawings show one example of a mechanism applying the invention.
