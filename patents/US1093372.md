## Reading (full text, OCR good)

**Problem:** Typewriter keys carry one fixed character, so a keyboard cannot be used to write secret code messages without the operator knowing the code.

**Solution:** Each keytop is a reversible two-sided cylinder carrying a normal character and a code character, turned 180 degrees with a special operating key so the same fingering types a coded letter.

**How it works:** Each key is a rotatable member made of two disks, one bearing the normal character and a detachable one bearing the code character, mounted in a two-half cup-shaped socket riveted to the key lever. Normally a spring-loaded plunger, held by an arm of a gravity tumbler, locks the key against turning. The operator inserts a separate operating key through a wall opening; its tooth trips the tumbler, releasing the plunger, and the square end then enters a square hole in the key's central wall. Turning the operating key 180 degrees brings the code disk to the open top of the socket; the plunger spring and tumbler relock it. The code disks are replaceable so the code can be changed.

**Numbers:** rotation of 180 degrees between normal and code characters
