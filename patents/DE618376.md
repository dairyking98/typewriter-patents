## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Drive each type carrier by a flywheel that the key turns 180-360 degrees one way only, using its inertia to press toggle-like and then move on to a second rest position.

## Reading (opening only, OCR fair)

**Problem:** In quiet hand typewriters that turn the blow into pressure, the type moves slowly near the platen and also starts its return slowly, so it clears the way late for the next type.

**Solution:** Drive each type carrier by a flywheel that the key turns 180-360 degrees one way only, using its inertia to press toggle-like and then move on to a second rest position.

**How it works:** Pressing a key moves a rack through a lever transmission, which rolls on a gear on the flywheel and turns it until a pin hits a cushion. A connecting rod from a point on the wheel's rim moves the type carrier first fast and then slowly against the platen as the toggle straightens. The wheel does not reverse, so the return starts at speed, and the wheel stops at a second rest position. The next press turns it back the opposite way. A weak spring holds each rest position.
