## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Line-spacing mechanisms

**In the patent’s own words:** The invention relates particularly to the application of power-driven carriage-return mechanism to typewriters of that type which, like the Underwood typewriter, for example, have a laterally moving line-spacing lever through which the power of the carriage-return mechanism is applied to space the line and return the carriage.

**How it works (reading):** Power carriage return is applied so that it does not disturb the line-spacing lever, with the pawl engagement timed by an adjusting mechanism.

## Reading (short summary from the opening, OCR poor)

**Problem:** A carriage-return cord attached to the line-spacing lever interferes with the line-spacing pawl and its timing.

**Solution:** Power carriage return is applied so that it does not disturb the line-spacing lever, with the pawl engagement timed by an adjusting mechanism.
