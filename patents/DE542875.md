The invention relates to a type lever for typewriters with several side by side and at the same time types to be printed. The purpose of this facility is the writing the date, for example, which always requires six to eight characters with a keystroke. Type lever with several types, e.g. B. to write whole syllables, are known, as has already been proposed, individual types on the type lever interchangeable close. According to the invention, by combining these known devices a type lever created which is suitable for a number of characters with to bring a stop to the print, the characters individually interchangeable are attached to the type lever head, so that when writing the date z. B. the substitution of the types can be carried out easily and without the aid of tools. For this purpose, the correspondingly widened type lever head is on the face with round or prismatic guide grooves in which the type blocks provided with guide strips inserted -and through a transverse- be held by the type lever head going round bolt.
