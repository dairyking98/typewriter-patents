## Reading (opening only, OCR fair)

**Problem:** Bar typewriters needed to be simple, small, cheap and fast, with self-inking type and alignment that wear does not spoil.

**Solution:** Radially arranged type carriers resting on a circular inking pad swing along cam paths through a central type guide to the print point.

**How it works:** Each type carrier has an arm bearing the type, and a slotted cam-like tail that works on a fixed ring in a central post. A key lever lifts the inner end of an actuating lever, which pivots the carrier so that the tail turns on the ring and throws the type inward along a set curved path. At rest the type faces touch a ring-shaped inking pad inside the type ring. A flaring type guide at the impression point directs each type to the paper for alignment. A fulcrum ring strung through the lever eyes supports all the actuating levers in radial slots.
