## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Positive-feed mechanisms automatically operated in response to carriage return

**In the patent’s own words:** This invention relates to means to return the carriage of a type writer from its position at the end of a line to a position at the beginning of the next line.

**How it works (reading):** Electrically actuated carriage return device, set to a line length, that can be attached to an existing machine.

## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage must be returned by hand at line end, and existing machines cannot easily be fitted with automatic return.

**Solution:** Electrically actuated carriage return device, set to a line length, that can be attached to an existing machine.
