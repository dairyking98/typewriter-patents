## Reading (opening only, OCR fair)

**Problem:** A machine to write with type on paper or other material, with letter spacing that suits each letter's width.

**Solution:** Keyed weighted type-levers strike a common point while a rock-shaft moves a frame by a distance set by the length of a per-key lever, giving proportional spacing.

**How it works:** Keys (levers D) operate type-levers through rods; the types are rotatable on round shanks to be set parallel, and a ring cushion stops the type from sinking into the material. A rock-shaft driven by levers and rods moves a frame N by a one-way clutch gripping a rod, and the length of each lever (or rod) sets how far it moves, matching the width of the type. A hollow slotted shaft acts as a stop-motion that blocks keys when the frame reaches the end of the line. The table carrying the paper is shifted by a knob with notched catch for line spacing, and several copies can be taken with interleaved carbon or inked ribbon.
