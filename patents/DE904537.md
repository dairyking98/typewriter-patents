## Reading (opening only, OCR fair)

**Problem:** Shorthand typewriters with grouped keys need an improved way to select one of several types on a type body sector from combined key presses.

**Solution:** Key levers with differently shaped control grooves set a rocker, whose adjustment angle swings a type body sector to select a type, with the number of groove combinations exceeding the number of keys.

**How it works:** Eleven groups of three closely spaced consonant keys (plus vowel keys for the thumbs and a space key) are pivoted on a common axis. Pressing one key or several together moves a rocker according to the combined control grooves of the key levers. The rocker angle sets the type body sector, which is then moved linearly to print the selected type or syllable on a narrow paper strip over a platen. The strip is stored in a container below and advanced by a key-driven pawl on a ratchet wheel; a ribbon on reels inks the type. Details of the printing stroke are beyond the shown text.
