## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage shifting requires the operator to move the fingers off the keyboard, and disengaging the escapement from the rack to shift freely is awkward.

**Solution:** Position the carriage shifting actuating element inboard on the keyboard, so it can be operated with the same hand that strikes the keys, with means to disengage the escapement pinion from the carriage rack bar.

**How it works:** A carriage shift actuator is placed where the hand already rests, so one hand can shift the carriage without leaving the keys. Operating it also disengages the escapement pinion from the carriage rack bar so the carriage can move freely in either direction.

**Features:**

- **Spacing and escapement:** [Pawl-and-rack escapement](../features/esc-pawl-rack.md), [Carriage release](../features/esc-carriage-release.md)

**Parts:** carriage shifting element; escapement pinion; carriage rack bar; keyboard

**Improves on:**

- carriage shift requiring hand removed from keyboard: actuator placed inboard so one hand does both key strike and shift
