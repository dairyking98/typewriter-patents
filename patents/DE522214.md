**In Google’s translation of the patent’s own words:** The invention relates to an error display device for typewriters with movable Counter.

**How it works (reading):** A pivoting frame is moved by a wrong key press so that the next key is locked; the lock releases only after the wrong key has returned, so the typist must correct the error before writing on.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typist can strike a wrong number key in an adding typewriter without noticing, and the wrong figure is entered in the calculation.

**Solution:** A pivoting frame is moved by a wrong key press so that the next key is locked; the lock releases only after the wrong key has returned, so the typist must correct the error before writing on.
