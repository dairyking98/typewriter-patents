## Reading (opening only, OCR fair)

**Problem:** A cipher attachment must work with any typewriter keyboard layout.

**Solution:** A frame over the keyboard carries auxiliary finger-pieces whose positions are adjustable to match the key diagram, so each presses a different key for enciphering.

**How it works:** A main frame is mounted above the keyboard on adjustable uprights. Side rails with slots carry transverse key supports, one per row. Guide blocks slide along each support and are clamped with serrated clamp bars. Auxiliary keys with flat shanks pass through the guide blocks and act on the typewriter keys beneath.
