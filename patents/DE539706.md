## Reading (short summary from the opening, OCR fair)

**Problem:** Very large types for posters need a large type lever segment, which would make the machine too big and the drive conditions difficult.

**Solution:** The type and key levers are carried on horizontal parallel bearings in a housing that slides parallel to the platen, so each type lever can be brought into the printing position; the levers can be spaced wide to take large types.

**How it works:** A housing with side plates runs on rollers along the frame; key levers and type levers rotate about two horizontal axes, and a switch lock on the carriage holds them in position.
