## Reading (opening only, OCR fair)

**Problem:** Typists wanted both three-character-per-bar typewriter writing and single-character (e.g. another script or purpose) typing from one keyboard.

**Solution:** Stack two typewriters so each key of the upper three-character machine drives a key lever of the lower single-character machine, whose lever frame slides sideways when the shift key is pressed.

**How it works:** The upper machine has three-character typebars; the lower has single-character type levers with key levers pivoted in a laterally sliding frame pulled left by a tension spring. Each upper key presses on its lower key lever. The upper shift lever, when pressed, rides a stop along an inclined cam edge on the frame and shifts it, so the lower key levers change to different push rods for the shifted characters. Releasing returns the frame by spring.
