## Reading (short summary from the opening, OCR fair)

**Problem:** Removed carbon-interleaved manuscripts are hard to replace in the machine so the copies line up with the original.

**Solution:** A detachable pivoted paper support with a channel-shaped guide and slotted adjustable plate, held by a set screw, that engages the sheet edge so the stack returns to the same position.

**Features:** [PAP:paper-guide](../features/pap-paper-guide.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** detachable paper support; channel-shaped edge guide; slotted adjustable plate; set screw; forwardly bent arm
