## Summary

**Kind:** typebar machine · **Subject (patent classes):** Mechanical power drives with driven mechanism arranged to be clutched to continuously- operating power source by snatch rolls; Levers mounted on fixed pivots

**How it works (reading):** Switching the power source off sets each intermediate link back to rest, so keys pressed with the motor off cannot leave a type lever in the striking position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Keys could be pressed with the motor stopped, leaving intermediate links in working position so that type levers struck the platen when the motor started.

**Solution:** Switching the power source off sets each intermediate link back to rest, so keys pressed with the motor off cannot leave a type lever in the striking position.
