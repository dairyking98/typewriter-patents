## Reading (opening only, OCR good)

**Problem:** Typebar machines need a ribbon; the inventor wants type that print directly with ink.

**Solution:** A movable inking pad or roller is swept across the type face by a key-driven cam and then retires so the type can print.

**How it works:** A typebar machine has bell-crank type levers on pivoted supports and a stepped stop piece that picks which of several characters a key prints. An ink pad or roller on a bent rod is joined to a rotary cam. Pressing a key lever (possibly the space key) rides a rod up the cam so the pad passes across the type face. On release a spring turns the cam back and the pad retires from the type path.

**Features:** [INK:pad](../features/ink-pad.md), [INK:roller](../features/ink-roller.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [USE:accessory](../features/use-accessory.md)

**Parts:** type bell-crank lever; oscillating support; key lever; rod; stop piece; inking pad or roller; bent rod; rotary cam; spring

**Numbers:** three steps on the stop piece

**Improves on:**

- inking ribbon: prints directly from inked type without a ribbon
