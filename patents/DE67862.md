## Reading (full text, OCR fair)

**Problem:** Ordinary typewriters print each letter directly as the key is pressed, so speed is limited to one letter per keystroke; the inventor wants several letters struck in one go and regular spacing for letters of unequal width.

**Solution:** A continuously driven type wheel and a rotating scanning arm pass over a ring of key-set angle levers, so keys are only pre-set and the machine itself prints each selected letter in alphabetical order, letting several letters of a word be set at once.

**How it works:** A belt-driven shaft turns a horizontal type wheel shaft and a vertical shaft carrying an arm and a hammer rod. Pressing a key (or energising an electromagnet) lifts an angle lever on a ring bearing into the path of the rotating arm. As the arm passes a raised lever it lifts a sleeve, which advances the paper cylinder by a letter space via a gear and one-way coupling, then releases the hammer arm. The hammer tip drops into a notch in a locking disc beside the type wheel to hold the wanted type exactly at the print point, and pushes the slightly sprung shaft down so the type wheel strikes the paper on the cylinder, after which springs and the arm reset everything. Letters whose positions follow alphabetical order (a, then p, then s for 'paragraph') can be keyed together and printed in one revolution, a bell signalling the start of each revolution. Letter spacing is made proportional by giving each angle lever an upright leg of a length matching the letter width, so the arm and sleeve lift further for wide letters.
