**In Google’s translation of the patent’s own words:** The invention relates to an adjustable crank in which the variable length by Training of the crank pin as an eccentric is achieved in such a way that the eccentric in Any angular position from ο to 360 'can be locked using evenly distributed locking devices is.

**How it works (reading):** The crank pin is an eccentric carried in a ball race with grooves that lock at chosen angles, so the stroke is set by re-engaging a pin.

## Reading (short summary from the opening, OCR fair)

**Problem:** A crank's stroke can only be changed by rebuilding, and the connecting rod bearing is bulky.

**Solution:** The crank pin is an eccentric carried in a ball race with grooves that lock at chosen angles, so the stroke is set by re-engaging a pin.
