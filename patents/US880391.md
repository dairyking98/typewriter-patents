## Reading (opening only, OCR fair)

**Problem:** Full keyboard fingering is slow and bulky.

**Solution:** Reduce the number of keys by pairing key levers with one type bar through stirrups and a shift.

**How it works:** Key levers operate type bars in pairs through stirrup mechanisms. Shifting changes which character prints. A ribbon frame with spool cups and compact rectangular frame are included.

**Features:** [SEL:keyboard-few-keys](../features/sel-keyboard-few-keys.md), [ELEM:typebar](../features/elem-typebar.md), [SHIFT:axial](../features/shift-axial.md), [FRM:compact-portable](../features/frm-compact-portable.md), [INK:ribbon](../features/ink-ribbon.md)

**Parts:** frame; platen; type bar; key lever; stirrup; ribbon frame; spool cup
