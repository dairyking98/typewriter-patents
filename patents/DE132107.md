## Summary

**Kind:** type-element machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies mounted on carriers rotatable for selection the plane of the type or die face being parallel to the axis of rotation, e.g. with type on the periphery of cylindrical carriers

**How it works (reading):** Two independent concentric button levers each set and print their own type carrier, so both hands work and two characters can print at once.

## Reading (full text, OCR good)

**Problem:** A single button lever for a type drum uses only one hand and requires long setting movements.

**Solution:** Two independent concentric button levers each set and print their own type carrier, so both hands work and two characters can print at once.

**How it works:** Two button levers sit on concentric axes (one hollow), each turned against a housing scale to rotate its own type carrier so a type lies before an angle lever. Pressing the lever lifts the axis, whose collar raises the angle lever and pushes the type to the paper. Springs return the axes and types. Capitals and figures can go on one carrier and lower case on the other. Types on the two carriers can be angled to print side by side, and a slide with sector and rod drives a pawl on the carriage rack to advance one or two letter widths.
