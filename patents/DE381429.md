## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing musical scores

**How it works (reading):** Setting keys act via key bars on one setting lever each, which move a common oscillating shaft to adjust the platen height, all in one unit with the typewriter.

## Reading (short summary from the opening, OCR fair)

**Problem:** Earlier note typewriters needed a separate height adjuster bolted beside the machine, which was bulky and hard to transport.

**Solution:** Setting keys act via key bars on one setting lever each, which move a common oscillating shaft to adjust the platen height, all in one unit with the typewriter.

- **Selection:** [Keys that only set the element](../features/sel-dummy-keyboard.md)
