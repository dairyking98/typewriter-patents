## Reading (short summary from the opening, OCR fair)

**Problem:** Carbon copies on a record sheet need a line-spacing gauge so the paper can be returned to the same position for each new sheet.

**Solution:** A scale and pointers on the platen shaft and a disk, set at zero and returned to the saved angular distance to set the platen for each new sheet.

**Features:**

- **Paper and carriage:** [Line and point indicator](../features/pap-line-indicator.md), [Roller platen](../features/pap-platen-roller.md)
