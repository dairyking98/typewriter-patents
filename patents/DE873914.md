**How it works (reading):** Stepped stops are set against a stop link so one adjusting member can be brought to many positions with compact stops, for symbol-card decoding.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adjusting members of office machines with stepped stops fail when type carriers need 40 or more positions, because the stop rods become long and slow.

**Solution:** Stepped stops are set against a stop link so one adjusting member can be brought to many positions with compact stops, for symbol-card decoding.
