## Reading (opening only, OCR fair)

**Problem:** On a front-strike machine the platen shift must move ribbon spools and vibrator too, with controllable locking and stops.

**Solution:** Platen shift keys depress the platen frame, ribbon vibrator, spools and line indicator together, using gravity for balance, with a cam-locked hook and adjustable stops.

**How it works:** Shift keys act via an actuating rod on the swinging platen carriage frame, shifting platen, ribbon vibrator, ribbon spools and printing-point indicator in the same direction. A cam-controlled locking hook holds the platen in normal position and a spring releases it. The operator can lock the platen in shifted position. Adjustable stops set the platen's rest position and lever-type clips lock the cylindrical platen in its frame.

**Features:** [SHIFT:platen](../features/shift-platen.md), [SHIFT:lock](../features/shift-lock.md), [INK:ribbon-lift](../features/ink-ribbon-lift.md), [PAP:line-indicator](../features/pap-line-indicator.md), [PAP:platen-roller](../features/pap-platen-roller.md), [ELEM:typebar](../features/elem-typebar.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** platen frame; shift key; actuating rod; locking hook; cam; adjustable stop; ribbon vibrator; ribbon spool; platen lock lever; line indicator
