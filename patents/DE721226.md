## Summary

**Category:** related office machine, not a typewriter (card punching machine) · **Subject (patent classes):** Numerical control [NC], i.e. automatically operating machines, in particular machine tools, e.g. in a manufacturing environment, so as to execute positioning, movement or co-ordinated operations by means of program data in numerical form characterised by positioning or contouring control systems, e.g. to control position from one programmed point to another or to control movement along a programmed continuous path using an incremental digital measuring device for point-to-point control the positional error is used to control continuously the servomotor according to its magnitude with a combination of feedback covered by G05B19/232 - G05B19/235

**How it works (reading):** One set of registration organs is shared by all columns: a key sets the selection once and the machine steps through the columns one after another.

## Reading (short summary from the opening, OCR poor)

**Problem:** Card punching machines need a full set of registration organs per column, which is costly.

**Solution:** One set of registration organs is shared by all columns: a key sets the selection once and the machine steps through the columns one after another.

**How it works:** Single registration set serves all columns, stepped column by column after one key setting.

**Features:**

- **Selection:** [Selection locked for printing](../features/sel-selector-locking.md), [Small keyboard with shift rows](../features/sel-keyboard-few-keys.md)
