## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter of the latter type.

**How it works (reading):** Each type rocker arm is hinged to a stretching lever system so that, on the way from rest to standby, centrifugal force adds to the lever action and presses the type against the paper roller without a striking sound; a sliding type carrier carries several rows of types (for example Latin and Russian).

## Reading (short summary from the opening, OCR fair)

**Problem:** Quiet typewriters that bring the type to the roller on a swing weight still strike a sound, and the type carrier is hard to make work with two alphabets.

**Solution:** Each type rocker arm is hinged to a stretching lever system so that, on the way from rest to standby, centrifugal force adds to the lever action and presses the type against the paper roller without a striking sound; a sliding type carrier carries several rows of types (for example Latin and Russian).
