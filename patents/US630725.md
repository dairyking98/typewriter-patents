## Reading (opening only, OCR good)

**Problem:** Tabulating columns of figures or dollars takes time because the operator must count spaces and move the carriage for each number.

**Solution:** An attachment with numbered keys that set the carriage stop at the correct column so figures align automatically.

**How it works:** A frame clamped to the machine holds a row of side-by-side space-controlling blocks, each linked by draw-rod and angle lever to a numbered key at the front. Tappets clamped on a graduated bar on the carriage run against the blocks. Pressing a key sets its block and a lever with a spring-loaded pinion engages the swinging rack bar, moving the carriage to the chosen column. A tension screw regulates the carriage speed so it stops without banging and noiselessly.

**Features:**

- **Spacing and escapement:** [Tabulator](../features/esc-tabulator.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md)
- **Uses:** [Attachment or accessory](../features/use-accessory.md), [Typewriter with adding machine](../features/use-calculating.md)

**Parts:** spacing block; block frame; draw rod; angle lever; key; graduated bar; tappet; lever; pinion; rack bar; tension screw; spring

**Improves on:**

- Manual counting of spaces for columns: keys position the carriage directly
