## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tabulating

**In the patent’s own words:** This invention relates to attachments to typewriter machines for tabulating purposes, that is to say, for the purpose of enabling the carriage to be automatically stopped at certain spaces when released, as is needed in such work as copying statistical tables.

**How it works (reading):** An attachment fitted to an existing machine with a set of keys, each stopping the carriage at a chosen scale space through key bars, a cam shaft and a carriage-releasing lever.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tabulating on existing typewriters needs stops at set spaces, which the machine lacks.

**Solution:** An attachment fitted to an existing machine with a set of keys, each stopping the carriage at a chosen scale space through key bars, a cam shaft and a carriage-releasing lever.
