## Reading (opening only, OCR good)

**Problem:** Changing a typebar machine between universal and German keyboards (dead key, umlauts) required replacing all keys and type levers because the whole layout shifted.

**Solution:** Put the extra dead or umlaut keys at the side, outside the unchanged main keyboard, in room freed by moving shift and control keys, so the combs and lever bearings are the same for all variants.

**How it works:** The main keyboard stays unchanged. An extra key is placed at the right of the keyboard, with another dead key if needed, in space gained inside the frame by relocating shift and control buttons. Because the comb chambers and lever bearing millings are all the same width, a finished machine is converted between layouts by swapping about six keytops and reversing six type levers.

**Numbers:** six type levers and six key buttons to convert

> Description Translated from German Typewriter keyboard with double shift. The invention refers to a new double-shift keyboard for typewriters -and consists in that another key (letter or dead key) on the side is arranged outside the otherwise unchanged keyboard and the room for this within the machine frame, by moving the switch and Control buttons was created. This makes it possible to do without changing the main keyboard to attach either a dead key or additional characters or keys for the umlauts. This new arrangement enables the previous keyboard against the new one without getting used to the previous keyboard Needs to retrain the writer or constantly abuse himself. In addition, the chambers of the combs , in which the types or type rods are guided, as well as the millings of the intermediate lever bearings can be made the same width, so that a machine that has already been assembled or is already in use can easily be equipped with one or more machines the other keyboard can be retrofitted.
