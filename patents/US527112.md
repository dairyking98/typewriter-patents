## Reading (opening only, OCR good)

**Problem:** Writing and reading cipher messages on a typewriter takes mental effort converting letters.

**Solution:** Removable false index caps on the keys show a different letter than the type prints, using a reciprocal cipher so the same keyboard enciphers and deciphers.

**How it works:** Small disks bearing the substitute letters clip onto the key tops with rubber rings, covering the true legends. The operator types the plain text by the cap letters and the machine prints the cipher letter, and typing cipher text through the same keys yields plain text because the substitution is reciprocal. The caps are joined by a flexible tape or thin rubber strip so a row can be fitted at once, and the caps can be swapped to change the cipher.
