## Reading (full text, OCR fair)

**Problem:** Letter boards with one field per character are large (84 fields); an earlier two-characters-per-field design needed a third hand action with a push button on the pointer.

**Solution:** Several writing keys per letter field, where the extra keys also move the type cylinder (rotationally or lengthwise) through a gear, so case is chosen by which key is struck.

**How it works:** The type cylinder axis is carried in a swivel frame moved by a handle fixed to a setting pointer with a ball head over a letter board. The first key lever drives only the strike mechanism. A second key lever hinged to it also drives an adjusting rod and angle lever that slides a gear on the cylinder axis; a pin in a cam groove then offsets the cylinder rotation. Marked 'small' and 'large', the key chosen sets the character of the field. Alternatively the extra motion can be axial by fixing the gear to the axis.

**Parts:** type cylinder; cylinder axis; swivel frame; setting pointer; letter board; key lever; second key lever; adjusting rod; angle lever; gear with cam groove; return spring
