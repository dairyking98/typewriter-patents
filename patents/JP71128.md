## Reading (full text, OCR good)

**Problem:** Japanese typewriters show type faces inverted (mirror image) so the user must pick out reversed characters, and loosely held type is struck unevenly.

**Solution:** Type bars carry an upright index character on top and the printing type on the bottom; a lever lifts the chosen bar into a gripping sleeve that turns it about 90 degrees as it rises so it strikes the paper squarely.

**How it works:** Type bars hang by claws over partitions in a magazine that can be turned and slid on rails, with the upright index characters facing up. The operator brings the gripping sleeve over the wanted index character and strikes the handle down. A T-lever roller runs up a slope on a push-up lever, which pushes the type into a bottomed square hole in the sleeve, and a spring-loaded presser then grips it. The sleeve top is a slotted bar sliding on a fixed pin, so as the rocking lever swings in an arc the sleeve and type gradually rotate 90 degrees until the face prints against the paper roller. An inking-pad roller is carried on a hooked lever, and on release the type returns by the reverse sequence.

## Description (English translation of the Japanese text, opening)

> Specification. Printing mechanism for a Japanese-language typewriter. Nature and object of the invention. This invention relates to a printing mechanism for a Japanese typewriter in which type bars stored in a suitable type magazine carry an upright index character on their top face and the printing type on their bottom face. The tip of a rocking lever is pivoted to a type-gripping part, and the top of the gripping part forms a slotted bar. As the handle comes down, this bar slides back along a fixed guide pin passing across its slot, and as the rocking lever rises it gradually turns the direction of the type face; when the lever has turned about ninety degrees the type face has also turned about ninety degrees, and prints in that position. Its object is to do away with the inconvenience of picking out inverted (mirror-image) types, as in the Japanese typewriters hitherto, so that the wanted type can be found by an upright index character and picked out and printed, and to make the printing accurate and clear.
