**How it works (reading):** The return spring of the typewriter support plate is coupled to a locking pawl that is connected by cable to the table top, so the pawl locks the plate by itself when the table top is released.

## Reading (short summary from the opening, OCR fair)

**Problem:** A typewriter table whose support plate is balanced by a spring loses balance through the travel, so the table can slam shut and injure the user.

**Solution:** The return spring of the typewriter support plate is coupled to a locking pawl that is connected by cable to the table top, so the pawl locks the plate by itself when the table top is released.
