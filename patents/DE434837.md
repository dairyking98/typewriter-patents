## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Fount-change arrangements

**How it works (reading):** One common movable stop bar, positioned by one shift key, limits the swing of all typebars so that either type of the two on a bar prints.

## Reading (opening only, OCR fair)

**Problem:** Typebars with several types switch by moving the pivot, needing as many key levers as types.

**Solution:** One common movable stop bar, positioned by one shift key, limits the swing of all typebars so that either type of the two on a bar prints.

**How it works:** The key lever is linked to an angle lever with a forked arm carrying the typebar with two types. The bar has a nose that meets a curved stop bar common to all bars. With the stop in place, the swing is limited and one type hits the platen; raising the stop by the shift key lets the nose pass to a second stop, so the bar swings further and the other type prints.

**Features:** [Typebars](../features/elem-typebar.md), [Shift by turning the element](../features/shift-rotary.md)

**Parts:** key lever; angle lever; typebar; stop lug; common stop bar; shift key; tension spring

**Improves on:**

- typebars with movable pivot for shift: shift moves one stop for all bars, not each pivot

## Description (Google Patents OCR, opening)

> Description Translated from German Switching device for typewriters. They are typewriters known, in which the switch to the different arranged on a type lever Types is brought about by relocating the fulcrum of the type lever. These Typewriters have the disadvantage that just as many key levers are provided must be available as types. The construction of such typewriters was due to the large number of key levers that work together more complicated, and therefore these typewriters have not proven their worth. To remedy this disadvantage is the purpose of the invention, essentially consists in that the path of movement of the type lever by hitting one of its Arms is determined on a common stop for all type levers, of which Position is influenced by a shift key lever. This arrangement will achieved that for switching all type levers only one shift key and a switch lever is necessary, which makes the construction of the machine rather simple and at the same time becomes operationally reliable.
