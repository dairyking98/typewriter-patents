**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for portability, i.e. hand-held printers or laptop printers

**How it works (reading):** All key levers carry an identical arc-shaped nose with an elongated hole for the lower end of the pull rod, and the intermediate-lever suspension points are placed so the tie rods hang in one plane, so one part shape serves all levers.

## Reading (short summary from the opening, OCR fair)

**Problem:** Tie-rod eyes on key levers had to be shaped or aligned differently for each intermediate lever position, which made tooling and assembly costly.

**Solution:** All key levers carry an identical arc-shaped nose with an elongated hole for the lower end of the pull rod, and the intermediate-lever suspension points are placed so the tie rods hang in one plane, so one part shape serves all levers.
