## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** Each type lever has a slot engaged by a pin on the key lever and a common pin, so the intermediate piece is dropped; a spring returns the lever and each lever can be pulled out individually.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type-lever machines need an intermediate piece between key lever and type lever, adding cost and losing power; individual levers are hard to remove for cleaning.

**Solution:** Each type lever has a slot engaged by a pin on the key lever and a common pin, so the intermediate piece is dropped; a spring returns the lever and each lever can be pulled out individually.

This training has the advantage that the under the pulling effect a spring standing type lever individually and without the need to remove a specific one such lever, the other type lever or the relevant key lever is affected can be pulled out of the machine, be it for purpose cleaning the type or to repair or replace the lever. The compact shape that the machine receives is also advantageous especially when it comes to machines of the smallest size. The main advantage, however, is that the type lever when striking the keys get a very large acceleration. The lever rotates when it is hit the key first with increasing, then with decreasing speed, as a result the lever returns to the rest position very quickly.
