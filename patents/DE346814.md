## Description (Google Patents OCR, opening)

> Description Translated from German Type lever typewriter. The subject matter of the invention differs from the well-known typewriters, in which the key and type levers in radial slots of a sector-shaped carrier are mounted, in that each individual type lever has a slot in which two pins engage, namely the pin, which is common to all type levers, and also a pin on the key lever. This training has the advantage that the under the pulling effect a spring standing type lever individually and without the need to remove a specific one such lever, the other type lever or the relevant key lever is affected can be pulled out of the machine, be it for purpose cleaning the type or to repair or replace the lever. The compact shape that the machine receives is also advantageous especially when it comes to machines of the smallest size. The main advantage, however, is that the type lever when striking the keys get a very large acceleration. The lever rotates when it is hit the key first with increasing, then with decreasing speed, as a result the lever returns to the rest position very quickly.
