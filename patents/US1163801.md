## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Detents, brakes, or couplings for feed rollers or platens

**In the patent’s own words:** My invention relates to typeWriting machines, and is herein disclosed as applied to a Monarch type'writing machine, which, in the present instance, is Asomewhat reconstructed in order to adapt it to be connected to computingr mechanism driven by a source of power.

**How it works (reading):** A set of spacing keys shifts the carriage back by a chosen number of letter spaces, and each back-space also line-spaces the platen so the sheet feeds forward; the mechanism is attached to a Monarch machine driven by computing gear.

## Reading (short summary from the opening, OCR fair)

**Problem:** Entering numbers needs the carriage to back-space a set number of letter spaces, and the work sheet must also advance each time the carriage is brought back.

**Solution:** A set of spacing keys shifts the carriage back by a chosen number of letter spaces, and each back-space also line-spaces the platen so the sheet feeds forward; the mechanism is attached to a Monarch machine driven by computing gear.
