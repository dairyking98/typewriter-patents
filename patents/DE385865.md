**How it works (reading):** The type is clamped against a support matrix and the lever head, and a mechanical lifting device pushes the type or die along the lever so it sits at the correct font height from the pivot point.

## Reading (short summary from the opening, OCR fair)

**Problem:** Driving slotted type onto type levers by hand, then judging height against a normal type, is cumbersome and imprecise, and line straightness suffers.

**Solution:** The type is clamped against a support matrix and the lever head, and a mechanical lifting device pushes the type or die along the lever so it sits at the correct font height from the pivot point.
