## Reading (full text, OCR good)

**Problem:** A typewriter type carrier should hold many types in a small space, and the striking mechanism should be much simpler.

**Solution:** Pivot many type holders round the lower rim of a drum, each holder carrying several rows of types on one vertical centre line and also acting as the striking bar, with the drum able to turn and move up and down.

**How it works:** The drum has many holders pivoted side by side at its lower rim, each holding three types (capitals, small letters, figures and signs) on one vertical line, bound by a wrapping strip with spacers. The operator turns the drum with a handle to the wanted letter using an index dial on top, and raises or lowers a hollow shaft to bring the wanted row to the print position. Pressing a printing rod through the hollow shaft swings the selected holder, with all its types, against the platen. Springs return the holder, and a spring detent stops the drum running free.

## Description (English translation of the Japanese text, opening)

> Nature and object of the invention. A type magazine for a typewriter, characterised by many holders pivoted round the lower rim of a drum, each holder carrying types in several rows on one vertical centre line, the types swinging as one unit with the holder, and the drum supported so that it can turn and move up and down. The object is to hold many types in a small carrier, and, by making the type holders serve also as the striking bars, to simplify the mechanism greatly. Brief description of the drawings. The drawings show the type magazine in outline. Fig. 1: vertical section. Fig. 2: plan, partly cut away. Detailed description. This magazine is meant mainly for English-letter typewriters. Many type holders, which are also the striking bars, are pivoted side by side round the drum, and each holds types in several rows on one vertical centre line. Built this way, it holds many types in a fairly small space and makes the printing mechanism much simpler. An embodiment is described with the drawings. 1 is the drum that forms the body of the magazine; 2 are the many type holders set side by side round it.
