## Reading (full text, OCR good)

**Problem:** Patent 35670's machine for printing selected characters on many sheets at once printed one character at a time and was aimed at Japanese; Western text needs faster line-at-a-time printing.

**Solution:** Many side-by-side sliding type boxes, each holding the whole character set in one row, are set by hand handles to line up a whole line of types, which electromagnet push-rods strike upward at once onto a rotating wheel of paper sheets.

**How it works:** Each long type box holds one of every character in divided cells and slides forward and back under a top plate. A handle on each box moves along a character board; setting it beside a character brings that type to the printing window, so one type per box forms a line. Pushing the print button energises electromagnets whose levers drive push-rods that strike the whole line up through the window against the paper, with a ribbon between. A second button steps a ratchet so the wheel carrying many sheets brings the next sheet to the printing position, and the line is printed again on each sheet in turn. A magnet-released spring-loaded cross bar returns all handles at once, and a side-feed rack can shift the wheel to print a line in two halves.

## Description (English translation of the Japanese text, opening)

> Specification. Rotary typewriter. [Addition to Patent No. 35670.] Nature and object of the invention. This invention is an improvement on Patent No. 35670. It relates to a rotary typewriter in which many long type boxes, each able to slide forward and back by a handle, are set side by side, and each box holds, one to a division and in a single row, the types of every character and sign that may be needed; moving a handle to the place on the character board beside its path that points to the wanted character brings the corresponding type to the printing position. A printing mechanism is placed below, and above it a rotating wheel fitted with devices for holding many sheets of paper round its circumference. The type boxes are moved one after another to the required positions, and when the wanted types have been lined up at the printing position, working a hand grip with push-buttons strikes the whole line of types at the printing position upward at once, electrically, and prints it on the paper; the wheel then turns automatically step by step, so that the types are printed on several sheets in turn.
