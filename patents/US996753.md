## Reading (opening only, OCR fair)

**Problem:** A ribbon wears along a single path and one colour is wasted.

**Solution:** A ribbon guide moves crosswise to the platen as the ribbon feeds, giving a serpentine type path across the whole ribbon width, or sets fixed paths for multi-stripe ribbons.

**How it works:** The ribbon guide covers the print point and shifts with the platen on a front-strike machine. Key-operated means withdraw the guide to expose the print point. An automatic crosswise feed zigzags the guide while the ribbon feeds lengthwise so the types hit a wavy line from edge to edge; the crosswise feed can be disengaged and the guide held in set positions to use different coloured stripes.

**Features:**

- **Shift and cases:** [Shift by moving the platen](../features/shift-platen.md)
- **Inking:** [Ink ribbon](../features/ink-ribbon.md), [Ribbon feed](../features/ink-ribbon-feed.md), [Ribbon lift](../features/ink-ribbon-lift.md), [Two-colour ribbon](../features/ink-ribbon-color.md)
- **Paper and carriage:** [Roller platen](../features/pap-platen-roller.md)

**Parts:** ribbon guide; platen; ribbon; crosswise feed device; key-operated withdrawal lever

**Improves on:**

- straight-path ribbon feed: guide traverses so wear spreads across the full ribbon width
