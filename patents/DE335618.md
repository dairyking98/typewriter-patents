> Description Translated from German Typing calculator with keyboard and facilities for automatic Imprint of zeros. The present invention relates to a writing calculating machine with automatic device for printing the zeros belonging to a number and the purpose of such a design of a machine of this type that with simpler Construction each time actually only those zeros are printed which are in lower parts of the number than the highest digit. if each time you press a key, the corresponding lower parts of the number Type carrier are automatically set to zero, then there is still no guarantee that zeros are not included in the final printout, which are in higher numbers than the highest digit of the number to be printed. It has to do with the fact that under certain circumstances accidentally Type carrier set to a number subsequently by means of a correction movement must be returned to the empty position.
