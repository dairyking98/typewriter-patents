## Summary

**Category:** related office machine, not a typewriter (writing calculating machine zero printing) · **Subject (patent classes):** Devices for printing the point

**In Google’s translation of the patent’s own words:** The present invention relates to a writing calculating machine with automatic device for printing the zeros belonging to a number and the purpose of such a design of a machine of this type that with simpler Construction each time actually only those zeros are printed which are in lower parts of the number than the highest digit.

**How it works (reading):** The print hammer drive elements of each type carrier are linked by an intermediate gear so that only zero-set carriers below the highest set digit are driven and printed, the rest returning to rest.

## Reading (short summary from the opening, OCR fair)

**Problem:** Zeros printed by a calculating typewriter must be limited to those below the highest digit, and zero-set type carriers must not print higher-order zeros.

**Solution:** The print hammer drive elements of each type carrier are linked by an intermediate gear so that only zero-set carriers below the highest set digit are driven and printed, the rest returning to rest.

**Features:** [Typewriter with adding machine](../features/use-calculating.md), [Spring-powered blow](../features/imp-spring-energy.md)
