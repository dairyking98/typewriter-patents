## Reading (full text, OCR good)

**Problem:** Japanese typewriters with thousands of characters had to move the magazine or type bar and pick up a type for every character, so two different characters could never be printed in succession without moving the machine.

**Solution:** Set many rim-typed magazine discs side by side on an arc shaft, each with its own key and type bar, so that once the magazines are turned to one row, any of the types in that row can be printed one after another from the keys.

**How it works:** Each magazine is a hollow disc holding several tens of loose types round its rim, held by spring fingers (the chrysanthemum plate). A handle moves a toothed rack that turns all the magazines together, and an indicator drum with a pointer shows which row of types is under the type bars. Pressing a key turns a sector plate in the magazine, which pushes a small bar up a groove and lifts the type below the bar into the type hole at the front of its type bar. The same key motion turns a flat disc whose link slides a type holder into the type's groove to clamp it, and locks the disc to the type bar. Further key travel swings the type bar through 90 degrees so the type strikes the platen; on release everything returns and the type goes back to the magazine.

## Description (English translation of the Japanese text, opening)

> Specification. European-style Japanese-language typewriter. Nature and object of the invention. In this invention, type magazines in the form of round discs, each holding several tens of types round its rim, are set side by side, as many as needed, on a circular (arc) shaft; a separate type bar for each magazine is likewise arranged on a circular shaft; and by striking separate keys, equal in number to these, the wanted characters can be printed one after another without moving the magazines or the type bars. In Japanese typewriters up to now, the magazine or the type bar has to be moved for each character and the type picked up for each character; no machine has ever been able to print two or more different [printed 異タル, read 異ナル] characters in succession without being moved. In this machine the type bars do not move at all; only the magazines turn, and when they are stopped at one place, all the types lying in that one row can be printed in succession as wished. This is a special arrangement, achieved for the first time by the layout of the magazines in this machine.
