## Summary

**Category:** related office machine, not a typewriter (automatic text typing operator) · **Subject (patent classes):** Arrangements for producing a permanent visual presentation of the output data, e.g. computer output printers

**How it works (reading):** A machine stores one text record and several heading records, which are alternately operated and interpolated under operator setting so that the attached typewriter writes each letter automatically.

## Reading (short summary from the opening, OCR poor)

**Problem:** Form letters with different addressee headings must be typed one by one, and the inventor wants a typewriter to write them automatically from stored records.

**Solution:** A machine stores one text record and several heading records, which are alternately operated and interpolated under operator setting so that the attached typewriter writes each letter automatically.
