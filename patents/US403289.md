## Reading (full text, OCR good)

**Problem:** Because the latch's out-and-back stroke takes under a fiftieth of a second, it can return before the operator lifts the key, and the tripping point then fouls the returning latch pawl.

**Solution:** A two-part latch pawl with a slack connection, so the lever the key strikes can swing out of the way when the latch returns while the key is still down.

**How it works:** A spring-driven latch in a revolving turret carries a pivoted pawl that hooks a frame notch. A lever is loosely pivoted to the pawl with limited travel in both directions and held up by a spring. A key drives a tripping bar whose point strikes the lever end, first swinging the lever down against its pin, then swinging the whole pawl off the notch so the latch flies forward. The lever springs back above the tripping point, so when the starting arm returns the latch before the key is released, the lever end passes over the point without interference. On key release the point rises past the lever. A variant replaces the tripping bar with a toothed wheel advanced by a pawl and ratchet on the key stem, so the next tooth is always ready. The latch is a wheel-starting device for Dodson US299754 type machines.
