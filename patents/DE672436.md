**How it works (reading):** Key-lever bearing points are set at heights that follow the curvature of the type-lever bearing rows, with one bearing column per key, so the key levers drive the type levers directly.

## Reading (short summary from the opening, OCR fair)

**Problem:** On machines with an inclined type-lever segment, direct key-to-lever transfer is hard because key bearings are placed independently.

**Solution:** Key-lever bearing points are set at heights that follow the curvature of the type-lever bearing rows, with one bearing column per key, so the key levers drive the type levers directly.
