The present invention relates to automatic printing machines and more particularly on accounting machines which are set up so that they can use both letters of the alphabet as well as numbers. The usual form of accounting machines, in which both letters and numbers can be printed, has very long type bars or type bars, which on different sides with types are equipped so that they are both reciprocated and rotated in use must be in order to bring one of the types arranged on them to the imprint. Such machines with reciprocating Type carriers have the disadvantage that they cause strong impacts during operation the back and forth movement of the type carriers have to endure. Present The invention aims to address these disadvantages of known letters and numbers printing machines by using the per se known rotating type drums to avoid.
