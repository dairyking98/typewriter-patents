## Summary

**Category:** related office machine, not a typewriter (card-controlled printing accounting machine)

**In Google’s translation of the patent’s own words:** The present invention relates to automatic printing machines and more particularly on accounting machines which are set up so that they can use both letters of the alphabet as well as numbers.

**How it works (reading):** A continuously rotating type drum carries swinging type carriers in rows, and each carrier holds several types, so letters and numbers fit on a drum of the same size as the numeral-only machine; a card-controlled engagement element swings the chosen carrier to the platen abutment.

## Reading (short summary from the opening, OCR fair)

**Problem:** Accounting machines that print both letters and numbers use long reciprocating type bars that jolt the machine, and a drum large enough for letters would be costly.

**Solution:** A continuously rotating type drum carries swinging type carriers in rows, and each carrier holds several types, so letters and numbers fit on a drum of the same size as the numeral-only machine; a card-controlled engagement element swings the chosen carrier to the platen abutment.

**Features:** [Multi-row type cylinder](../features/elem-cylinder-multirow.md), [Typebars](../features/elem-typebar.md), [Element struck to the platen](../features/imp-element-to-platen.md)
