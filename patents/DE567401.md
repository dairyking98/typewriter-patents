## Summary

**Category:** related office machine, not a typewriter (printing machine with adding mechanism)

**How it works (reading):** Each type lever carries several adjustable types, and a second selector sets the wanted type into the printing position as the lever passes.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing numbers and letters on a type-lever drum needs either a larger drum or lower speed.

**Solution:** Each type lever carries several adjustable types, and a second selector sets the wanted type into the printing position as the lever passes.
