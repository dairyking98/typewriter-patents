## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Stabilising means therefor using a scissor mechanism as stabiliser

**In the patent’s own words:** This invention relates to a finger button base and-particularly to a device of this class which is adapted to be used in connection with a typewriter.

**How it works (reading):** A triangular base of three bent tongues on the key lever end supports the button, holding it level.

## Reading (short summary from the opening, OCR fair)

**Problem:** Button bases on key levers work loose and become wobbly.

**Solution:** A triangular base of three bent tongues on the key lever end supports the button, holding it level.
