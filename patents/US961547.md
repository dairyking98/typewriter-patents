## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage margin stops must be set for line length, and the old stops are not easily set from the keyboard.

**Solution:** Marginal stops on both sides of the carriage are set and operated from the key board through a rotating ratchet bar with a handle, so the line length is regulated.

**Features:** [ESC:margin-stop](../features/esc-margin-stop.md), [PAP:platen-roller](../features/pap-platen-roller.md)
