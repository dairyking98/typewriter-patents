## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing in Braille or with keyboards specially adapted for use by blind or disabled persons

**How it works (reading):** The writing frame's vertical outer surfaces carry an offset edge, and the frame slides into a guide subframe that carries the line-spacing marks, so the offset is set once.

## Reading (short summary from the opening, OCR fair)

**Problem:** Line-spacing offsets for double-sided braille must be set separately for each line of the writing frame.

**Solution:** The writing frame's vertical outer surfaces carry an offset edge, and the frame slides into a guide subframe that carries the line-spacing marks, so the offset is set once.

**Features:** [USE:blind](../features/use-blind.md), [PAP:paper-guide](../features/pap-paper-guide.md)

**Parts:** writing frame with offset edge; guide device subframe
