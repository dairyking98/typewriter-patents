## Summary

**Category:** misc / other, not a typewriter patent (weaving loom shuttle drive) · **Subject (patent classes):** Smallware looms, i.e. looms for weaving ribbons or other narrow fabrics

**How it works (reading):** Adjustable stops on a spindle set the lever's travel so the shuttle drive engages only at the rear position.

## Reading (short summary from the opening, OCR fair)

**Problem:** The shuttle drive must act only when the drawer is fully back, but the store drive starts too early.

**Solution:** Adjustable stops on a spindle set the lever's travel so the shuttle drive engages only at the rear position.
