## Reading (full text, OCR fair)

**Problem:** Ordinary typewriters need too much attention and long finger travel to write mechanically and unconsciously, as with a pen; blind typing needs short key paths and few keys.

**Solution:** A type-cylinder machine in which the keys only trigger a clutch and set binary-weighted stops, while the carriage mainspring does the cylinder setting and the printing blow, so ten shallow main keys plus two bar keys suffice.

**How it works:** The carriage mainspring drives a gear train through a rack and a ratchet to a crank that oscillates a main shaft; an arm on this shaft carries the type cylinder, which can rotate and slide on its tube, and throws it against the platen roller. A key releases a two-armed locking member, the crank makes half a turn and prints, and a second catch holds the carriage still during the blow. Levers R1 to R4 select cylinder rotation by 1, 2, 4 or 8 type pitches, by uncoupling notched tube sections whose cutouts allow different relative angles, and these add up to 15 pitches. Levers L1 to L4 do the same for axial displacement through a screw-threaded hollow shaft and slide. Ten main keys (T1 to T10) pick the position in a row, bar-like keys T11 and T12 pressed with the same finger select the second or third row, T13 and T14 work other displacements, and a space key lets the carriage run one space without turning the cylinder. Because the spring supplies all the force, the key travel is only 2 to 3 mm and all keys can lie in one plane.
