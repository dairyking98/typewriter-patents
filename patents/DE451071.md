## Summary

**Category:** related office machine, not a typewriter (cash register lock and release)

**In Google’s translation of the patent’s own words:** The invention relates to a locking and unlocking device for driving cash registers, in which the release 'of the machine transmission when a release button is pressed is regulated by a feeler stamp scanning the print slip, in such a way that that if the print slip is not inserted, the machine transmission will not be released.

**How it works (reading):** A feeler stamp scans the slip; if the slip is present, the release lever moves to release the checkout gear, and if not, the release button only increases the stroke of the feeler without releasing the gear.

## Reading (short summary from the opening, OCR fair)

**Problem:** A cash register can be operated without a receipt slip inserted, so the checkout runs when no slip is present.

**Solution:** A feeler stamp scans the slip; if the slip is present, the release lever moves to release the checkout gear, and if not, the release button only increases the stroke of the feeler without releasing the gear.
