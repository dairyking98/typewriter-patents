## Reading (opening only, OCR poor)

**Problem:** A typewriter should work either manually or by key-controlled power, switched by one lever, and the carriage should be able to feed more than one space after the last letter of a word.

**Solution:** Auxiliary levers and an escapement on a Remington-type machine let one shifting lever set manual or power operation, with the space key providing a multi-space feed.

**How it works:** Each key lever has an auxiliary lever on the same rod engaging a slot in the typebar lever. A single lever shifts the machine between direct manual operation and power operation controlled by the key. A line-lock lets the key actuate the typebar either way near the line end. A space bar and escapement with a movable pawl allows the carriage to feed more than one space when a printing key is depressed, so the last letter and the word space occur in one stroke.
