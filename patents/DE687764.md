## Summary

**Category:** related office machine, not a typewriter (print unit element type selection for tabulating machines)

**In Google’s translation of the patent’s own words:** The invention relates on a printing unit on tabulating machines, calculating machines and the like, in which the individual elements of the printing unit at any point in relation to the printing material can be used, with the means for selecting the types on each element are arranged.

**How it works (reading):** Type wheels with ten characters are selected by levers and pawls so any group of elements can print independently of others.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing units on tabulating machines cannot choose arbitrary print groups without moving the platen or using hammers.

**Solution:** Type wheels with ten characters are selected by levers and pawls so any group of elements can print independently of others.

**Features:** [Type wheel (types on the rim)](../features/elem-wheel-rim.md), [Typewriter with adding machine](../features/use-calculating.md)
