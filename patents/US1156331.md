## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Mechanisms for setting or restoring tabulation stops

**In the patent’s own words:** The invention relates particularly to mechanism adapted for tabulator work with e ther type set alone or for shifting the carr age from its position into cooperative relation to one type set to a predetermined position in rela tion to another type set.

**How it works (reading):** Swinging tabulator racks with adjustable stops on each frame, actuated by keys, plus a shift key that moves the carriage from one type zone and column to the other.

## Reading (short summary from the opening, OCR fair)

**Problem:** A carriage that shifts between two type-bar systems cannot easily tabulate within one system or move to a set column position in the other.

**Solution:** Swinging tabulator racks with adjustable stops on each frame, actuated by keys, plus a shift key that moves the carriage from one type zone and column to the other.
