## Reading (full text, OCR good)

**Problem:** Writing an amount (yen and sen) several times on one paper, or singly, is slow and error-prone by hand.

**Solution:** Digit-keys stop spring-pulled rack plates that turn per-place type wheels, with a common control bar that releases the racks and returns them all.

**How it works:** Number wheels (0-9) on a shaft each mesh through a pinion with a rack plate pulled by a spring; three sets of wheels share each rack so the amount is set three times. Ten push-button keys per place, spaced one wheel pitch apart, drop a stem into the path of a lug on the rack and so stop it at the chosen digit. Pressing a key also moves a link whose pawl releases the rack. A control bar with handle, unlocked by a button, is slid so the racks run to their stops, turning the wheels to show the amount; ink is applied and a striking lever raises the paper table to print all three places. Pulling the bar back returns racks, re-latches them and lifts the keys.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention relates to a printing machine having: rack plates, each meshing with many type wheels set loosely in a row on one shaft so that each turns on its own, and each always pulled in one direction; push-button keys as many as the type faces of all the wheels, whose action limits the pulling stroke of the rack plates; and a control bar common to all the rack plates, which when moved one way marshals and draws them all back against that pull, and when moved the other way lets them advance in the direction of pull while restraining their free pull. Its object is that pressing the keys ensures the wanted characters are set out in the printing position, and that the action of the control bar makes the showing of those characters, and the return of all the parts to their original state, smooth and automatic.
