**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tables or desks for office equipment, e.g. typewriters, keyboards

**In Google’s translation of the patent’s own words:** The invention relates to a typewriter table that comes from the protective case the typewriter itself can be produced.

**How it works (reading):** The normal protective case serves as the base and the typewriter base plate as the table top, joined by telescoping lockable tubes so the height can be adjusted.

## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriter tables built from special protective cases are bulky and unsuitable for shipping.

**Solution:** The normal protective case serves as the base and the typewriter base plate as the table top, joined by telescoping lockable tubes so the height can be adjusted.
