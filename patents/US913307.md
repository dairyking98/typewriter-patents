## Reading (opening only, OCR fair)

**Problem:** Letters need differing space allowances, but one key must select among several key-levers.

**Solution:** Shiftable keys operate one of several key-levers, which set the proportional space for their typebars, and the spacing mechanism feeds the carriage accordingly.

**How it works:** A keyboard with shiftable keys works a set of key-levers, each linked to a typebar. Each key can operate any of several levers, and each lever with its connections determines the space allotted for its character. The spacing mechanism gives each impression device the proportional carriage movement.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [ELEM:typebar](../features/elem-typebar.md)

**Parts:** key; key lever; typebar; carriage; platen; spacing mechanism
