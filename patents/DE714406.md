## Summary

**Kind:** typebar machine · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**In Google’s translation of the patent’s own words:** The invention relates to the method for producing types for Typewriters, calculators or the like with a recessed area for aligning the types on the type carrier serving reference mark, in which the reference mark simultaneously with the Type character is embossed by means of eifies stamp.

**How it works (reading):** Pre-emboss the reference mark on the profile bar before cutting the blank, to the height of the letter plus the finished mark, so the final stamp only corrects it.

## Reading (short summary from the opening, OCR fair)

**Problem:** Embossing the final alignment mark on a type blank wore out the embossing stamp because the blank material flowed against the mark.

**Solution:** Pre-emboss the reference mark on the profile bar before cutting the blank, to the height of the letter plus the finished mark, so the final stamp only corrects it.
