## Reading (short summary from the opening, OCR fair)

**Problem:** Column carriage setting needed a scale; earlier column adjusters used one stop per character.

**Solution:** A rail carrying the stop plates is fixed to the machine frame parallel to the paper guide, and a lever on the carriage selects the stop, so the carriage is set by pressing.
