## Summary

**Category:** related office machine, not a typewriter (cash register print device with receipt sensing)

**In Google’s translation of the patent’s own words:** The invention relates to a printing device for cash registers in which the print hammer can only come into operation when the receipt to be printed has been properly placed in the machine beforehand.

**How it works (reading):** One sensor is placed on each side of the print point, coupled so that both move together; whichever touches the receipt releases the hammer, so the receipt can be printed at the head or the foot.

## Reading (short summary from the opening, OCR fair)

**Problem:** A single sensor for the inserted receipt forces the receipt into one exact position, so the print hammer blocks if the receipt is shifted out of range.

**Solution:** One sensor is placed on each side of the print point, coupled so that both move together; whichever touches the receipt releases the hammer, so the receipt can be printed at the head or the foot.
