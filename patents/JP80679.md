## Reading (full text, OCR good)

**Problem:** In existing Japanese typewriters a picker merely hooks the side of the type, pulls it up and strikes it against the cylinder, so the type can jump or work loose and print inaccurately.

**Solution:** The picked-up type is thrown into a box on a swinging printing arm, where a spring-returned sliding frame is pushed by the picker's own tip into the type's side groove and the arm's slot, clasping the type rigidly during the blow.

**How it works:** Pressing the print lever swings a starting lever whose end strikes the tail of the one type picker (one per magazine row) that has been brought to the print point; the picker's tip, engaged in a cross groove in the type's side, lifts the type into a box at the tip of a printing arm. The picker tip reaches a long cross slot in the arm, lifts the arm and, because the arm and picker pivot at different centres, slides along the slot. In doing so it pushes a box-shaped holding frame against a spiral spring so that its square hook passes through the type's groove and into the arm slot, locking the type to the arm. The arm's momentum carries the type face to the paper on the cylinder. A detent lever locks the magazine during printing, an ink-roller arm lifted by the arm lets the type brush an ink roller, and springs return everything.

## Description (English translation of the Japanese text, opening)

> Specification. Printing device for a Japanese-script typewriter. Nature and object of the invention. This invention relates to the printing device of a Japanese typewriter constructed as follows. A type-holding box, into and out of which the one type to be printed can pass, is formed at the tip of a swinging printing arm placed at the printing point. In one side wall of this box an up-and-down opening is made, so that the type-engaging tip projection of a type picker (one picker is provided for each row of the type magazine) can pass freely into and out of the box of the printing arm while still engaged with the type. Further, a long cross slot is cut in the swinging arm so as to cross the side opening of the box, and in it a box-shaped type-holding frame, partly cut away, is fitted so as to slide freely. When, in printing, the tip projection of the picker, still engaged in the cross groove on the side of the type, enters the box of the printing arm together with the type as the picker swings, the projection pushes the holding frame.
