## Reading (opening only, OCR fair)

**Problem:** On Remington-type machines the extra carriage movement for a capital was always the same one tooth, so letters could not be spaced to their true width.

**Solution:** Movable fingers and cross-bars under the key levers, shifted by the upper-case key, let each key give any chosen carriage step in upper and lower case, with part of the move on release and an extra-space key.

**How it works:** Cross-bars under the key levers are linked to a rod that slides when the upper-case key is depressed, so protuberances on each key lever act on different bars in the two cases. The bars set movable fingers that modify the play of the pivoted escapement dog and so the number of rack teeth passed (for example 1 tooth for l and 3 for L). Long movements are split, part on depression and part on release, and an additional catch-held key adds extra space between every two letters.

**Features:** [ESC:variable-spacing](../features/esc-variable-spacing.md), [ESC:pawl-rack](../features/esc-pawl-rack.md), [SHIFT:platen](../features/shift-platen.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md)

**Parts:** cross-bar; slide rod; elbow lever; key lever; protuberance; finger; pivoted dog; rack; upper-case key; space bar; spring

**Improves on:**

- Howard 1884 application Serial 144,979: extra upper-case movement can now be any number of teeth, not always one
- Remington No. 2: works with the existing keyboard unchanged
