> Description Translated from German Type body for typewriters The invention relates to a type body for typewriters o. the like. With the same for aligning it when it is applied raised set-up marks on the type levers. When placing the type body on the type lever, it is necessary to that the same at a constant distance from the type lever bearing axis. To make this possible, every type body used to be in placed a negative of a mounting disk and then placed on the one placed in its slot Type lever soldered on. This device was, besides that, for every script a special washer was required, even more disadvantageous as that Negative first had to be aligned in the position of use. It was therefore already suggested straightening projections in the middle of the type body between the two Arrange types. It was found, however, that these projections when striking the Types that were printed and, as a result, for the delivery of a flawless one Font were unusable.
