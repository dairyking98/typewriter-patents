## Summary

**Kind:** typebar machine · **Subject (patent classes):** Construction of type-levers

**In Google’s translation of the patent’s own words:** The invention relates to an adjustable bearing for type levers, in particular for Typewriters that have an adjustable pivot pin for the type lever and a spherical or conical support body engaging in its axis of rotation bore having.

**How it works (reading):** A ball set in a fork bearing or type lever circle segment, positioned by a screw with a fine thread; the screw presses the ball so the type lever is pushed against the fork wall.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type levers are hard to set in their bearings and cannot be changed quickly.

**Solution:** A ball set in a fork bearing or type lever circle segment, positioned by a screw with a fine thread; the screw presses the ball so the type lever is pushed against the fork wall.
