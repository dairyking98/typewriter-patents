## Summary

**Kind:** a part or mechanism (any kind of machine)

**How it works (reading):** Support the push frame on adjustable conical pivot pins, one eccentric and lockable, so its working edge can be set parallel without bending.

## Reading (opening only, OCR good)

**Problem:** On Underwood typebar machines the light escapement push frame must have its working edge parallel to the type lever pivots for precise ribbon lift; this was done by bending the weak frame, which is slow, skilled and breakage-prone.

**Solution:** Support the push frame on adjustable conical pivot pins, one eccentric and lockable, so its working edge can be set parallel without bending.

**How it works:** Each depressed type lever moves a universal rail backwards, which carries a frame whose rear bar rocks the escapement anchor (fixed and stepped pawl) so the escape wheel and rack advance the carriage. The same frame lifts the ribbon via a lever. The frame's guide arms sit on a swingable shaft mounted between two conical-tipped adjustable pins that engage conical recesses at the shaft ends. Adjusting one pin, with an eccentric tip locked by a pin in slots, moves one side of the frame forward or back so the rail edge lies parallel to the type-pivot arc. The separate tips and conical seats give slight resilience.

**Features:** [Escape-wheel escapement](../features/esc-escape-wheel.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md), [Ribbon lift](../features/ink-ribbon-lift.md), [Adjustment and wear take-up](../features/frm-adjustment-wear.md), [Typebars](../features/elem-typebar.md)

**Parts:** universal rail; push frame; escapement anchor; fixed pawl; stepped pawl; escape wheel; rack; guide arm; swing shaft; conical pivot pin; eccentric tip; ribbon lifter; return spring

**Improves on:**

- bending the push frame to align it: adjustable conical bearings instead
