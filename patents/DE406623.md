## Summary

**Kind:** typebar machine · **Subject (patent classes):** Character-by-character adjustment

**How it works (reading):** A central spring acts against all type lever movement, and each lever has a stationary individual adjustment so strike force is uniform.

## Reading (short summary from the opening, OCR fair)

**Problem:** Power-drive typewriters had uneven strike force across the line, mainly in outer levers.

**Solution:** A central spring acts against all type lever movement, and each lever has a stationary individual adjustment so strike force is uniform.

**Features:** [Impression adjustment](../features/imp-impression-adjust.md), [Typebars](../features/elem-typebar.md)
