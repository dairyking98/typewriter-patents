> Description Translated from German Movably arranged counter for typewriters The invention relates to a movably arranged counter for typewriters, calculating machines and the like with a special device serving to bring in an additional value, by one arranged on the counter itself, preferably at the same time by another Process when calculating serving member is controllable. The calculation of certain values caused difficulties with the known machines of this type and easily led to errors because the result set displayed too little i. This is e.g. B. the case when from the numbers of z. B. issued tickets the number of tickets sold should be determined. If the card sold last has the number 700 and the card issued first has the number 350, the counter will display the number 35o when these values are calculated. However, not 350, but 35 i cards have been issued, so that if the attention is not paid enough, the number of cards can easily be booked incorrectly. To avoid this disadvantage, adding machines: already suggested that by pressing a key an additional i in the fixed To bring in counter.
