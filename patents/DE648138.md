## Summary

**Category:** related office machine, not a typewriter (movable counter for typewriters and calculators)

**In Google’s translation of the patent’s own words:** The invention relates to a movably arranged counter for typewriters, calculating machines and the like with a special device serving to bring in an additional value, by one arranged on the counter itself, preferably at the same time by another Process when calculating serving member is controllable.

**How it works (reading):** A special device adds one to the movable counter only when it moves in one direction, so the extra count is applied exactly once.

## Reading (short summary from the opening, OCR fair)

**Problem:** Adding a one to a movable counter for ticket counts can be done wrongly, because the existing devices act in both directions and a number of tickets is then off by one.

**Solution:** A special device adds one to the movable counter only when it moves in one direction, so the extra count is applied exactly once.
