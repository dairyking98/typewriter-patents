## Summary

**Category:** related office machine, not a typewriter (time-stamp type wheels by rotary embossing) · **Subject (patent classes):** Typewriters or selective printing mechanisms characterised by the mounting, arrangement or disposition of the types or dies with types or dies carried upon levers or radial arms, e.g. manually operated

**How it works (reading):** Type wheels are produced by rotary embossing from an original roller, which is engraved with the type shape on a base of the curvature the wheel must have (flat for stamps, concave for typewriter wheels), so the type surface is correct for a single impression.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type wheels for time stamps and typewriters are costly to engrave one by one.

**Solution:** Type wheels are produced by rotary embossing from an original roller, which is engraved with the type shape on a base of the curvature the wheel must have (flat for stamps, concave for typewriter wheels), so the type surface is correct for a single impression.
