## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**How it works (reading):** The articulation point of the holding rod can be moved by hand to one of four positions, so the type stops just short of the platen, making the machine quiet; in the other positions it strikes normally.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type levers strike the platen with noise, which is unwanted when a single copy is written.

**Solution:** The articulation point of the holding rod can be moved by hand to one of four positions, so the type stops just short of the platen, making the machine quiet; in the other positions it strikes normally.
