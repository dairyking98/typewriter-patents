## Reading (short summary from the opening, OCR fair)

**Problem:** On statistical machines with a hundred or more type carriers, setting each hammer's control takes too long and causes errors.

**Solution:** A locking slide for each print hammer lets operators preset groups of hammers in advance, so fewer manual setting controls are needed.
