## Reading (opening only, OCR fair)

**Problem:** A ribbon at rest should sit as near the printing point as possible without hiding the writing so the vibrator adds little to key resistance.

**Solution:** An adjustable ribbon vibrator mechanism keeps the ribbon close to the print line, with a quiescent position for stencil work.

**How it works:** Segmental typebars strike the platen front, each key sub-lever linked to a bar. The vibrator actuating mechanism improves on A. T. Brown's earlier application, with several adjustments giving different rest and lift positions so little lift is needed per stroke. Only the opening is available.

**Features:** [INK:ribbon](../features/ink-ribbon.md), [INK:ribbon-lift](../features/ink-ribbon-lift.md), [FRM:writing-visible](../features/frm-writing-visible.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** ribbon vibrator; typebar; sub-lever; restoring spring; platen

**Improves on:**

- A. T. Brown application Serial No. 305,561: ribbon rest nearer the print line with adjustment
