## Reading (opening only, OCR fair)

**Problem:** Elastic type bands bent strongly by the print hammer take permanent deformation, so line straightness is lost.

**Solution:** Most of the type band's travel to the platen is done by swinging its holder, so the hammer only has to flex the band slightly at the print point.

**How it works:** A lever plate with characters arranged obliquely in rows is pressed down; a pointer-like lever transmits this to a pivoted print hammer. The hammer's elastic driver (light spring) first swings the metal type-band holder close to the impression plane until a stop halts it. Further hammer motion bends the rubber type band slightly so the selected type presses the paper against the abutment surface. A rack on the carriage base provides spacing and a platen roller with line-space pawl handles lines.

**Improves on:**
