## Summary

**Kind:** typebar machine · **Subject (patent classes):** Construction of type-levers

**In the patent’s own words:** This invention relates to a type bar slotted se ment in which the type bars are pivoted.

**How it works (reading):** An integral type bar segment with a radial web and slotted rim, plus a segmental seat and an open slot that lets a single pivot rod lock all the type bars.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type bars pivoted in a segment must be held reliably, and the pivot seat needs to be assembled and kept in place.

**Solution:** An integral type bar segment with a radial web and slotted rim, plus a segmental seat and an open slot that lets a single pivot rod lock all the type bars.
