## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Paper-carriage guides or races

**In the patent’s own words:** My invention relates to typewriting, machines and more particularly to anti-friction roller separators which in the present instance are used for the antifriction rollers which support the carriage.

**How it works (reading):** Twisted sheet-metal separator plates hold anti-friction rollers at right angles so one set takes thrust in one direction and the other set in the other.

## Reading (short summary from the opening, OCR fair)

**Problem:** Carriage rollers need to be held apart in crossed V-groove bearings.

**Solution:** Twisted sheet-metal separator plates hold anti-friction rollers at right angles so one set takes thrust in one direction and the other set in the other.
