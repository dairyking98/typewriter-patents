## Summary

**Category:** related office machine, not a typewriter (check writer attachment) · **Subject (patent classes):** Cheque stamping machines

**In the patent’s own words:** This invention relates to new and useful improvements in attachments for check writers and the object in view is to render more eiiicient apparatus of this nature, mak- 1 ing the check writer absolutely accurate in its printing.

**How it works (reading):** A key and pointer throw actuate a stop lug, and a yoke carrying a pawl is moved beyond the stop and then released so a spring returns the pawl solidly against it, ensuring the character prints accurately.

## Reading (short summary from the opening, OCR fair)

**Problem:** Check writers need the operator to move the pointer exactly onto the scale line for each character, and any deviation makes the print wrong.

**Solution:** A key and pointer throw actuate a stop lug, and a yoke carrying a pawl is moved beyond the stop and then released so a spring returns the pawl solidly against it, ensuring the character prints accurately.
