## Summary

**Category:** related office machine, not a typewriter (cash register printing unit)

**How it works (reading):** Locking pins disengage the drive so that each section is printed once in the required number of sections.

## Reading (short summary from the opening, OCR fair)

**Problem:** A cash register cannot print several separate documents in one checkout without manual restarts.

**Solution:** Locking pins disengage the drive so that each section is printed once in the required number of sections.
