## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Typewriters or selective printing or marking mechanisms characterised by the purpose for which they are constructed for printing musical scores

**How it works (reading):** All note characters sit as type levers on one circular type basket, and a single keyboard of as many keys as pitch heights moves a vertically displaceable type-lever carrier slide so the attachment point of the type lever shifts to the required pitch; a scale-rail adjuster sets the basket position.

## Reading (short summary from the opening, OCR fair)

**Problem:** Note typewriters either need two-dimensional paper movement, which is cumbersome, or several keyboards for different pitches, which enlarges the mechanism and hinders clear writing.

**Solution:** All note characters sit as type levers on one circular type basket, and a single keyboard of as many keys as pitch heights moves a vertically displaceable type-lever carrier slide so the attachment point of the type lever shifts to the required pitch; a scale-rail adjuster sets the basket position.
