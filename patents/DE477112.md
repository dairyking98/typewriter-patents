## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Character- or line-spacing mechanisms with means for effecting line or character spacing in either direction

**In Google’s translation of the patent’s own words:** The invention relates to typewriters of the type in which the type carrier has several character rows for different fonts wear whose character strings are opposite to each other, as z.

**How it works (reading):** A reversing roller is fixed to the paper carriage for one font and to the machine frame for the other, so the mainspring pull on the carriage reverses automatically when the font is switched.

## Reading (short summary from the opening, OCR fair)

**Problem:** Type carriers with opposite-reading character rows made the carriage move the wrong way when a font was switched, and the change had to be made by hand.

**Solution:** A reversing roller is fixed to the paper carriage for one font and to the machine frame for the other, so the mainspring pull on the carriage reverses automatically when the font is switched.
