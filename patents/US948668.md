## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Keyboards with one set of keys for each denomination; Casings convertible reductible in size, e.g. for transportation

**In the patent’s own words:** This invention relates to the keys of typewriting and other instruments, and particularly to the denomination keys of tabulating mechanisms.

**How it works (reading):** Two nested helical character disks are slit radially so the key cap rotates the movable helix to uncover a second character set under the fixed one.

## Reading (short summary from the opening, OCR fair)

**Problem:** A single denomination key cannot readily serve different denominations because the character on the key cap is fixed.

**Solution:** Two nested helical character disks are slit radially so the key cap rotates the movable helix to uncover a second character set under the fixed one.
