## Reading (opening only, OCR fair)

**Problem:** A single paper carriage can write only the characters of one type set.

**Solution:** Join two front-strike machines on multiple-length rails so one carriage moves between two type sets, each with its own keys, ribbon and escapement.

**How it works:** Two Underwood front-strike machines sit side by side with long front and rear carriage rails, and the carriage moves from one machine to the other. Each section has its own keyboard, ribbon vibrator, escapement dogs acting on the carriage rack, shift key and backspacer. The platen frame roll sits just above the shift rail so the carriage can pass when both rails are at the same level. Uses include Greek, italic, or special characters.

**Features:** [Special scripts and characters](../features/use-special-script.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md), [Typebars](../features/elem-typebar.md), [Shift by moving the platen](../features/shift-platen.md), [Interchangeable element](../features/elem-interchangeable.md), [Ink ribbon](../features/ink-ribbon.md)

**Parts:** carriage; long rail; type set; keyboard; ribbon vibrator; escapement; shift rail; backspacer
