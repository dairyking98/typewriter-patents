## Summary

**Category:** related office machine, not a typewriter (printing unit for adding machines) · **Subject (patent classes):** Output mechanisms with printing mechanisms, e.g. for character-at-a-time or line-at-a-time printing

**In Google’s translation of the patent’s own words:** The invention relates to a printing unit for adding machines, calculating machines and the like which a printing element is provided for each computing point, which both serve to print items and totals.

**How it works (reading):** Setting the operation or counter selects a number-type form for each printing element, so the type of calculation shows without extra columns.

## Reading (short summary from the opening, OCR fair)

**Problem:** Printing operation type on adding machines needed special characters, which took a column place on the form.

**Solution:** Setting the operation or counter selects a number-type form for each printing element, so the type of calculation shows without extra columns.
