## Reading (short summary from the opening, OCR fair)

**Problem:** Repeat-entry of a fixed value on a counter needs separate preset elements that must be set by hand.

**Solution:** The ordinary arithmetic keys preset the counter, and decoupled setting members move to the keyed value during the summation scan.

> Description Translated from German Typewriter, calculating machine or the like with automatic summation and / or Printing device The invention relates to a typewriter, calculating machine o. The like. With automatic sum pulling device, in which for the repeatable Playback of one and the same value, e.g. B. to print data, the machine next to one or more other counters serving the computing process with a counter is provided in which presettable setting members are provided for the counting members are that the counting elements after their zero setting by the summation device Automatically bring it back into the preset position, according to patent 7 1i 464. The device described in the patent mentioned had the disadvantage that a value to be repeatedly entered into the counter by means of special presetting elements had to be set. According to the invention, this disadvantage is now eliminated by that the usual arithmetic keys serve as presetting members and optionally from the arithmetic drive Decoupling adjustment members are provided, which by the scanning movement of the Summation device adjustable to the value preset by the arithmetic keys are.
