## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Tables or desks for office equipment, e.g. typewriters, keyboards with vertical adjustable parts

**How it works (reading):** One flap tabletop is linked by a pull element to a folding side wall, and a tilting form box on the base is pushed open by the raised tabletop so all parts set together.

## Reading (short summary from the opening, OCR fair)

**Problem:** Typewriter and household tables need a fold-out table extension, side wall and box that are set up separately, each by hand.

**Solution:** One flap tabletop is linked by a pull element to a folding side wall, and a tilting form box on the base is pushed open by the raised tabletop so all parts set together.
