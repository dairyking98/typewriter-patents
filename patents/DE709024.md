## Reading (short summary from the opening, OCR good)

**Problem:** Riveted type levers cannot be removed singly; the whole segment must be taken off.

**Solution:** Each type lever hooks onto a bearing pin of the neighbouring connecting plate and can be detached and moved around the segment pin; the plate carries a tooth sector.

## Description (Google Patents OCR, opening)

> Description Translated from German Typewriter Type Levers The invention relates to typewriter type levers of the kind that are pivotably arranged with the help of a pivot on the type lever segment pin Connecting plate are attached and driven. They are types of Typewriter type levers known in which the connector with the type lever is rigidly connected by rivets. The purpose of the invention is to create an arrangement such that an improvement by simply detaching and attaching each individual type lever or simplification is achieved precisely in those type lever systems that these Not yet showing relief. According to the invention this improvement is achieved in that the Type lever with its foot end except on the segment pin on a bearing pin of the next to the type lever in a correspondingly expanded section of the segment arranged connecting plate is easily detachably hooked and from the connecting plate is moved around the segment pin. In pursuance of the inventive idea, when used in typewriters with toothed drive for the type lever the execution done in such a way that the connecting plate is provided with a tooth sector.
