## Summary

**Kind:** a part or mechanism (any kind of machine) · **Subject (patent classes):** Fount-change arrangements

**In the patent’s own words:** My invention relates to typewriting machines and more especially to the type bar action of such machines.

**How it works (reading):** Each type bar carries two types and is pivoted about either of two pivots, with two keys connected to each bar, so either character can be made to print by swinging the bar about the matching pivot; the bars are held in radial slots of a fixed segment.

## Reading (short summary from the opening, OCR fair)

**Problem:** A front-strike machine needs one type bar per character, so the basket of type bars must be large; the inventor wants each bar to carry two types.

**Solution:** Each type bar carries two types and is pivoted about either of two pivots, with two keys connected to each bar, so either character can be made to print by swinging the bar about the matching pivot; the bars are held in radial slots of a fixed segment.
