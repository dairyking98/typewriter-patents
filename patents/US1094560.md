## Reading (opening only, OCR fair)

**Problem:** A front-strike carriage must move lengthwise with little friction while the platen is shifted vertically for multi-character type heads.

**Solution:** A carriage with a main frame and a supplementary frame holding the platen, so the two travel together while the platen can shift vertically on its own, supported on independent ball bearings.

**How it works:** The platen shaft passes through a slot in the main carriage frame, letting the platen and its supplementary frame move vertically for case shift independently of the main frame. Independent ball bearings carry the carriage along its support. Key levers are T-shaped single pieces pivoted in staggered brackets and pinned into slots in the type bars, so a type bar starts slowly and speeds up as the pin nears the pivot. Each type head carries up to three characters.

**Features:** [SHIFT:platen](../features/shift-platen.md), [SHIFT:triple](../features/shift-triple.md), [ELEM:typebar](../features/elem-typebar.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [PAP:platen-roller](../features/pap-platen-roller.md), [FRM:writing-visible](../features/frm-writing-visible.md), [FRM:frame-construction](../features/frm-frame-construction.md)

**Parts:** main frame; supplementary frame; platen; platen shaft; slot; ball bearing; key lever; type bar; bracket; carriage support

**Numbers:** four rows of key levers; three characters per type head; key levers grouped in fours
