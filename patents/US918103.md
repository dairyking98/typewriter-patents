## Reading (opening only, OCR poor)

**Problem:** Typewriter keys serve only one function each, and the margin stops and tabulator stops are clumsy in detail.

**Solution:** Make ordinary character keys double-function so a different movement also works the tabulator or backs the carriage, and improve the margin and tabulating stops.

**How it works:** Type levers are linked by two-part elastic links to elbow levers that are driven by key levers carrying spring and adjustable-screw returns. Keys can be built as double-function keys, with a different movement operating the tabulating mechanism, and one key also moves the carriage backward. A key can be converted to an ordinary single-function key. Redesigned margin stops and carriage-mounted tabulating stops are provided, with a brake operated by its own mechanism.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [ESC:tabulator](../features/esc-tabulator.md), [ESC:margin-stop](../features/esc-margin-stop.md), [ESC:backspace](../features/esc-backspace.md), [SEL:keyboard-full](../features/sel-keyboard-full.md), [FRM:adjustment-wear](../features/frm-adjustment-wear.md)

**Parts:** key lever; type lever; elastic link; elbow lever; segment; margin stop; tabulating stop; brake; return spring; adjusting screw
