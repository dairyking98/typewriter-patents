**In Google’s translation of the patent’s own words:** The invention relates to subtle typewriters with the type wheels turned into the writing position when the keys are pressed down and at the same time paper pressed against the type wheels, with which with the keys connected control elements at the same time as stop parts for correct setting the type wheels are used.

**How it works (reading):** Let each type wheel turn either way, with two keys per control member and tongues arranged so that frequent types lie at the shortest angular paths.

## Reading (opening only, OCR fair)

**Problem:** In syllable typewriters whose type wheels turn only one way, the rotation to a stop can reach half a wheel circumference or more, which limits speed.

**Solution:** Let each type wheel turn either way, with two keys per control member and tongues arranged so that frequent types lie at the shortest angular paths.

**How it works:** The keys turn type wheels into position when pressed and at the same time press paper against the wheels. Stop tongues on each wheel shaft act on control members lying in two planes diametrically opposite across the shaft. Each control member has two keys and two opposed stops, so one key drives forward rotation and the other reverse, each tongue meeting its nearest stop. The most frequent types get the shortest angular paths. Wheels W1 to W4 carry digits, consonants, vowels with fixed syllables, and vowel combinations, with a space lock key.
