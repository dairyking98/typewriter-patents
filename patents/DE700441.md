## Summary

**Category:** related office machine, not a typewriter (teleprinter with character storage) · **Subject (patent classes):** Contact operating means; Apparatus or circuits at the transmitting end with keyboard co-operating with code-bars combined with perforating apparatus

**In Google’s translation of the patent’s own words:** This purpose is the main patent a switch bar is provided that controls the cam-controlled ratchet switchgear in such a way that that the type group change character is automatically given in the memory device will.

**How it works (reading):** A switch rail in the memory transmitter keys the type-group change character into the perforated tape by a second stamp or stamps of the existing set, so an ordinary typewriter keyboard can be used.

## Reading (short summary from the opening, OCR fair)

**Problem:** Teleprinter keying needs a special key for the type-group change character, which operators find unfamiliar.

**Solution:** A switch rail in the memory transmitter keys the type-group change character into the perforated tape by a second stamp or stamps of the existing set, so an ordinary typewriter keyboard can be used.

**Features:** [Printing telegraph](../features/use-telegraph-printer.md), [Full keyboard, a key per character](../features/sel-keyboard-full.md)
