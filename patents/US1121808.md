## Reading (opening only, OCR good)

**Problem:** On a combined typewriter and adding machine the operator needs to set numbers into the computing mechanism without printing them.

**Solution:** A key lifts the type guide so its fingers block the wide typebar shanks short of the platen, while the key action still runs.

**How it works:** A non-print key is depressed and latched, rocking a shaft whose finger lifts the vertically sliding type guide on the segment. The guide opening is now in the path of the typebar shanks, which are wider than the slot, so the types are stopped before the platen. The typebars still strike the universal bar (letter feed) and the bell cranks (computing keys) before being stopped. Releasing the key lets a spring restore the guide.

**Features:** [Typebars](../features/elem-typebar.md), [Pawl-and-rack escapement](../features/esc-pawl-rack.md), [Typewriter with adding machine](../features/use-calculating.md), [Space key or bar](../features/esc-space-key.md)

**Parts:** type guide; guide finger; typebar; segment; non-print key; rock shaft; universal bar; spring

**Improves on:**

- Underwood-Hanson adding typewriter: adds a non-print key by shifting the type guide into a stop position
