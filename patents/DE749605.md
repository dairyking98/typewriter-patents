## Summary

**Category:** related office machine, not a typewriter (printing unit, cash registers) · **Subject (patent classes):** Means to give uniformity of impression

**In Google’s translation of the patent’s own words:** The invention relates to a printing unit for cash registers or accounting machines' with a number corresponding to the number of columns of the document to be printed of type carrier sets and a corresponding number of positively driven Pressure organs, one or more of which can be made effective in each case.

**How it works (reading):** Pressure members are driven rotationally and sensors on the document set each member against the type carrier, so only the selected member presses, scaled to the inserted thickness.

## Reading (short summary from the opening, OCR fair)

**Problem:** On column-printing cash registers with positively driven pressure members, print clarity varies with document thickness.

**Solution:** Pressure members are driven rotationally and sensors on the document set each member against the type carrier, so only the selected member presses, scaled to the inserted thickness.
