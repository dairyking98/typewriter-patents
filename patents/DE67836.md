## Reading (opening only, OCR fair)

**Problem:** A set of improvements on a Remington-type machine whose typebars each carry two types (upper and lower case), with two print positions chosen by moving the carriage.

**Solution:** A reworked carriage slide and frame with shift (print-position) switching, row displacement, line spacing, paper holding, quick-return lifting, tabulating, ribbon width movement and ribbon reel arrangements.

**How it works:** Typebars arranged in a circle each carry two types and are pulled by key levers via straps. A common cross bar under the key levers moves an oscillator when any key is pressed. The oscillator carries a pawl that engages a ratchet wheel, which drives a rack on the carriage slide to space it. The carriage slide rides on rollers on a rod and can be tipped back to view the writing. Only the first part of a long description is available; the remaining devices are named in the introduction but not described here.
