## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms; Air blast devices acting on stacking devices; Apparatus for vibrating or knocking the pile during piling

**In Google’s translation of the patent’s own words:** The invention relates to a device for driving the type lever of typewriters, in which intermediate levers are used to drive the type lever, namely refers the invention relates to drives of the type in which one arm of the intermediate lever with the type lever and the other arm through a pivot rod with the button lever is connected, the type lever in the rest position almost a right angle forms with the key lever.

**How it works (reading):** Key levers and type levers nearly in line, with an intermediate lever on a toggle rod, giving an accelerated elastic strike in a compact depth; type levers in a 45-degree semicircular frame.

## Reading (short summary from the opening, OCR good)

**Problem:** Type lever drives gave either a heavy stop or made the machine too deep front to back.

**Solution:** Key levers and type levers nearly in line, with an intermediate lever on a toggle rod, giving an accelerated elastic strike in a compact depth; type levers in a 45-degree semicircular frame.
