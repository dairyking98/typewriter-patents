## Reading (opening only, OCR fair)

**Problem:** Ordinary typewriters need hand force or ink ribbon handling; the inventor wants types inked on a pad and impressed with electric force.

**Solution:** Typebars rest on an inked surface, a key lifts the type into position, then closes a circuit so an electromagnet drives the type onto the paper.

**How it works:** Each writing key is linked to a sliding typebar guided in a circular frame. Pressing the key moves the type off the inked surface to the print position and then closes a circuit; a magnet armature arm pushes the type lever so the type strikes the paper directly. Releasing the key opens the circuit and returns the type to the ink pad. Upper and lower case via key position, with an automatic paper roll rotation, spacing and line-space mechanisms, and the machine can also make matrices.
