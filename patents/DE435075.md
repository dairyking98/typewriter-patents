## Reading (short summary from the opening, OCR fair)

**Problem:** Cash register drive is locked until a slip or punch card is inserted, so machine operations cannot run when no slip is present.

**Solution:** An adjusting device lets the operator switch off the sensor-controlled lock on the release button, so the register can run without a slip; the lock is a push rod and angle levers driven by a feeler plunger.

## Description (Google Patents OCR, opening)

> Description Translated from German Locking device for the drive of machines with pressure or guide mechanisms, z. B. Cash registers. The invention relates to the drive mechanism of such Machines which are equipped with printing units for printing slips of paper or with Feeling mechanisms are equipped for scanning punch cards and by pressing them down a release button or by moving a lever. So that a machine run cannot take place before a print slip or a punch card has been inserted, such machines are equipped with a locking device for the release button, the work of which is controlled by a sensor who executes a tactile movement against the print slip or the punch card and the locking device of the release button can be effective, if no print slip is inserted. The aim of the invention is to design machines of the type in question so that that, if necessary, machine operations can also be carried out if none Note or no punch card is inserted. To this end, according to the invention a special adjusting device is provided through which the temperature controlled by the sensor Locking of the release button can be switched off as desired.
