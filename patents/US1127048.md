## Reading (opening only, OCR fair)

**Problem:** A noiseless typewriter needs a silent type action with easy key dip, no rebound, and simple construction.

**Solution:** A toggle-actuated type carrier moves in a guided bed with arresting means that stop rebounding.

**How it works:** A reciprocating type carrier with normal, upper and lower case types is moved by a toggle from the key lever. Protecting lugs prevent neighbouring radial carriers colliding. A comb on the bed plate stops sideways tilt. Arresting means in several forms stop the parts at the end of stroke. A light platen carriage is also shown.

**Features:** [ELEM:typebar](../features/elem-typebar.md), [IMP:element-to-platen](../features/imp-element-to-platen.md), [SHIFT:platen](../features/shift-platen.md), [ELEM:alignment-lock](../features/elem-alignment-lock.md)

**Parts:** type carrier; type member; toggle; key lever; comb; bed plate; arresting means; platen carriage

**Improves on:**

- [US879107](../patents/US879107.md): improved noiseless type action
