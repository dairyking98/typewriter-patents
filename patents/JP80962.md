## Reading (full text, OCR good)

**Problem:** Ordinary typewriters cannot produce justified, letterpress-like lines; the line cannot be checked or corrected before printing and the types are narrow.

**Solution:** A keyboard machine that assembles a whole line from full-width sliding type bars drawn out of type cases, justifies it with spaces, and prints the whole line at once with a paper cylinder.

**How it works:** Each key stroke sets a spring lever on one of many lengthwise-moving support bars, then a setting bar advances one tooth to the next support bar. When the line is set, cross bars sweep the set levers into a row, which first raises the right type case to a set height and then pulls the chosen type bar out of the case toward the printing position. Type bars are grouped by width in cases and slide between spring guides; a locking bar joins them into a line. A line-length device sets the line width and wedge-shaped spaces are pushed between words to justify. A mirror lets the operator check the line, then the inked line is printed under a paper cylinder. All motions are driven from a crank wheel with partial gears and racks. A shift moves the type bar relative to its carrier to double the number of types.

## Description (English translation of the Japanese text, opening)

> Specification. Printing machine. Nature and object of the invention. This invention relates to a printing machine with many type bars, each carrying one row of types and moving lengthwise. Pressing a key sets a movable lever fitted to a lengthwise-moving support bar, which prepares a type bar to be carried to the printing position. Then the support bars are slid by the action of a cross bar, which works the movable levers pivoted to them and carries the type bars to the printing position, forming a line. The object is a machine that draws the type bars out of the type case towards the printing position, makes up a line of fixed length there, and returns the type bars to their places by the opposite motion; that lets the assembled line be corrected before printing; that carries full-width types on full-width type bars; and that, by inserting spaces between the words at the printing position, prints very simply a text like printed (letterpress) type.
