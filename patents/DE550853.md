## Reading (full text, OCR good)

**Problem:** Typewriters that stamp a repeated group of characters such as a date need the stamp inked by a separate inking unit or pressed against a deflected ribbon outside the ribbon spool, which is awkward and makes the typist spread the ribbon wide.

**Solution:** A lever carrying a small set of settable type wheels is pivoted on an axis beside the print point so it swings in and strikes the ordinary ribbon next to the normal print position.

**How it works:** Four small type wheels sit on a lever pivoted on bolts in the frame, to the side of the normal print point. Each wheel is set by hand to a character and held by a locking lever engaging grooves, backed by springs. Pressing a button works levers and a pull rod that swing the lever from rest to the print position, pressing the wheels against the ribbon and platen beside the usual typing. The lever sits in a hub piece with a thickened end held by a screw, so it can be removed to reset the wheels or exchanged for a longer or shorter one. Several such levers can be fitted.
