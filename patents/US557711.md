## Summary

**Kind:** typebar machine · **Subject (patent classes):** Type-lever actuating mechanisms

**In the patent’s own words:** My invention consists in certain combinations of devices and features of construction and arrangement, all as will be hereinafter more fully described, and particularly pointed out in the appended claims.

**How it works (reading):** A tripping device between key and type releases both type and feed mechanisms, so they return independently of the key.

## Reading (short summary from the opening, OCR fair)

**Problem:** The type and feed mechanisms return only after the finger key is released, slowing the operator.

**Solution:** A tripping device between key and type releases both type and feed mechanisms, so they return independently of the key.

**Features:**

- **Type element:** [Typebars](../features/elem-typebar.md)
- **Spacing and escapement:** [Prints and spaces in one stroke](../features/esc-print-and-space.md)
