# Countries

The library is organised so that every country gets the same treatment: its patents (when the library holds that patent office) and the typewriters made there, analysed the same way, so countries compare directly. The timelines and the mechanism pages put them all together.

## More countries

The library is built to take more patent offices. Each one comes in the same way: the list of its typewriter patents, their text (OCR, or a translation for other languages), a reading of every patent, and then its own page here, a row in the [timeline browser](../explore/timeline.md), and its place in the decade counts and mechanism pages. The countries with the most machines but no patents here yet are [England](england.md), [France](france.md), [Italy](italy.md), [Switzerland](switzerland.md), [Sweden](sweden.md).
